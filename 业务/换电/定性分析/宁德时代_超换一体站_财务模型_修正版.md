### 二、推导逻辑链（总纲）

本部分所有假设均遵循"自底向上"（Bottom-Up）的推导逻辑，从物理事实出发，通过数学推导得出运营参数，再叠加商业假设计算财务结果。

```
物理事实
  ├─ 电池容量：56度（宁德时代25#巧克力换电块，官方标称）
  ├─ 车辆能耗：15度/100km（A级纯电轿车行业均值，NEDC工况）
  ├─ 营运车月行驶：8000km（网约车行业均值，滴滴/曹操出行财报）
  ├─ 私家车月行驶：2000km（城市通勤均值，国家统计局交通调查）
  ├─ 单站换电能力：125次/天（16小时双班倒，基于物理极限+排队论计算，见第三节）
  └─ 用户换电习惯：剩余10%电量时换电（行业惯例，避免抛锚）
       ↓
数学推导
  ├─ 营运车日耗电 = 8000÷30×0.15 = 40度
  ├─ 营运车日均换电 = 40÷56 = 0.71次（重庆3天2次，20250715，参考https://www.douyin.com/user/self?from_tab_name=main&modal_id=7527261316734520603&showTab=record）
  ├─ 私家车日耗电 = 2000÷30×0.15 = 10度
  ├─ 私家车日均换电 = 10÷50 = 0.20次（每次换入50度=56×90%）
  ├─ 单站125次中：营运100次（80%）、私家25次（20%）
  ├─ 单站营运用户数 = 100÷0.71 = 141人
  ├─ 单站私家用户数 = 25÷0.20 = 125人
  └─ 单站总用户数 = 266人
       ↓
商业假设
  ├─ 换电服务费：0.40元/度（vs 蔚来0.5-0.6元，宁德时代低价策略）
  ├─ 超充服务费：0.30元/度（行业均值）
  ├─ 电池租赁费：369-599元/月（宁德时代官方定价，20#/25#）
  └─ 系统电损率：9%（见第二部分推导）
       ↓
财务结果
  ├─ 年收入：272.88万（电池租赁159.4万 + 换电服务费91.3万 + 其他22.2万）
  ├─ 年OPEX：49.3万（电损+人工+租金+维保）
  └─ 年EBITDA：223.6万
```

### 三、单站换电能力物理极限

**物理参数（来源：超换一体_重构版.md）：**
- 单次换电操作时间：99秒（1.65分钟）
- 20%→80%充电时间：224秒（3分44秒）
- 单块电池完整周转周期：353秒（≈5.9分钟）

#### 理论极限计算
```
理论极限 = 3600秒 ÷ 353秒 × 16小时 = 10.2次/小时 × 16h = 163次/天
```
> **运营时长说明**：采用 16 小时双班倒（如 6:00-22:00），覆盖早高峰至夜高峰全时段。当前换电站需人工巡检，双班倒为现实可行方案。若未来实现全自动无人值守，可扩展至 24 小时运营（见下文远期场景）。

#### 扣除因素（按影响程度排序）

理论极限 163次/天 假设车辆每 353 秒恰好到达一辆（利用率 ρ=100%），这在现实中不可能实现。
核心损耗来源于**客户到达的随机性**（排队论），辅以少量运营损耗。

##### 1. 到达随机性空闲（排队论 M/D/1 模型）——扣除约 33 次

客户到达服从泊松分布，换电服务时间固定（353秒），构成 M/D/1 排队系统。
为保证可接受的用户体验（平均等待时间 ≤12分钟），系统利用率 ρ 不应超过 80%。

推导过程：
```
M/D/1 模型平均等待时间公式：
  Wq = ρ / (2μ × (1-ρ))
  其中：ρ = 利用率，μ = 服务率 = 1/Ts，Ts = 服务时间 353秒

代入 Ts = 353秒：
  当 ρ = 0.80：Wq = 0.80 / (2 × (1/353) × 0.20) = 706秒 ≈ 12分钟  ✓ 可接受
  当 ρ = 0.85：Wq = 0.85 / (2 × (1/353) × 0.15) = 1000秒 ≈ 17分钟  ✗ 偏长
  当 ρ = 0.90：Wq = 0.90 / (2 × (1/353) × 0.10) = 1589秒 ≈ 26分钟  ✗ 不可接受

取 ρ = 0.80（服务行业公认的合理利用率上限）：
  有效服务次数 = 163 × 0.80 ≈ 130次/天
  空闲损耗 = 163 - 130 = 33次

  空闲时间构成（M/D/1 模型分解）：
  ┌─────────────────────────────────────────────┐
  │ 服务器空闲概率 P0 = 1 - ρ = 20%              │
  │ 即：16小时运营中有 3.2小时处于"等客"状态      │
  │ 3.2h × 3600 ÷ 353 ≈ 33次 的换电机会因无客流失 │
  │                                               │
  │ 其中：非高峰到达间隔空闲    ≈ 24次 (72%)      │
  │       高峰时段排队溢出损失   ≈  9次 (28%)      │
  └─────────────────────────────────────────────┘

  保守取整：扣除 33 次
```

##### 2. 设备维护——扣除 2-3 次

每日例行检查约 30 分钟（行业惯例），此部分停机时间与排队论空闲时间存在部分重叠（可安排在闲时进行），净影响约 2-3 次。

##### 3. 电池均衡——扣除 1-2 次

SOC 不一致时 BMS 触发均衡，延长个别电池的可用周转时间，影响约 1-2 次。

##### 4. 异常处理——扣除可忽略（<0.1次）

宁德时代官方标称换电成功率 **99.99%**（来源：[catl.com](https://www.catl.com/brand/servicebrand/)），运营实测一次换电成功率 **99.96%**（来源：汽车显微镜 2026.03 报道），故障率仅 0.01%-0.04%。按 163 次/天计算，异常影响不足 0.1 次，可忽略不计。

##### 5. 热管理降速——不再单独扣除

宁德时代巧克力换电站官方标称支持 **-30℃ 极寒正常换电**，电池块内置加热膜热管理。极端高温场景（持续 40℃+）可通过空调散热系统应对，不构成独立的效率损耗项。

##### 合计扣除：33 + 2~3 + 1~2 ≈ 36~38次

#### 实际有效值：125次/天

排队论推导有效值：163 - 36~38 = 125~127次**

**最终取值的调整考量：**
- 纯 M/D/1 模型（ρ=0.80）推导值：**130次/天**
- 扣除维护与均衡重叠影响后：**125~127次/天**
- 实际运营中可通过 APP 预约、动态调度优化到达分布，利用率可略高于理论值
- 宁德时代重庆实测盈亏平衡点约 **100次/天**（5500度÷56度），125次处于健康盈利区间
- 财务模型宜保持适度保守

**综合取值：125次/天**（对应利用率约 80.4%，与排队论推导的 130 次扣除运营损耗后一致）

#### 远期场景：24小时全自动无人值守

> **前提条件**：换电站实现全自动无人值守运营，无需人工巡检。当前宁德时代三代站已具备自动换电能力，人工主要承担安全巡检和异常处理。随着技术成熟（机器视觉+远程监控+AI故障诊断），全自动无人值守是确定性演进方向。

**核心认知：夜间需求远低于白天，不能简单套用统一利用率。**

换电需求高度集中在白天（6:00-22:00），夜间（22:00-6:00）仅少量营运车有需求，私家车几乎为零。因此采用**分时段利用率模型**：

```
┌──────────────────────────────────────────────────────────────┐
│                      分时段利用率模型                          │
│                                                              │
│  白天 16h（6:00-22:00）         夜间 8h（22:00-6:00）         │
│  ┌─────────────────────┐       ┌─────────────────┐          │
│  │ 理论容量：163次      │       │ 理论容量：82次   │          │
│  │ 利用率 ρ≈0.80       │       │ 利用率 ρ≈0.20   │          │
│  │ 有效：~130次         │       │ 有效：~16次      │          │
│  │                     │       │                 │          │
│  │ 需求旺盛             │       │ 仅少量营运车     │          │
│  │ 营运+私家双高峰      │       │ 私家车几乎为零   │          │
│  └─────────────────────┘       └─────────────────┘          │
│                                                              │
│  夜间额外收益：维护窗口解放                                   │
│  ┌─────────────────────────────────────────────────┐        │
│  │ 16h场景：维护挤占白天 2-3次换电机会               │        │
│  │ 24h场景：维护移至夜间闲时 → 白天释放 +2~3次       │        │
│  └─────────────────────────────────────────────────┘        │
│                                                              │
│  合计有效：130 + 16 - 5(均衡等) ≈ 140次/天                   │
└──────────────────────────────────────────────────────────────┘
```

**分时段推导：**

**白天 16h（与双班倒场景一致）：**
```
理论容量 = 3600 ÷ 353 × 16 = 163次
M/D/1 ρ=0.80 → 有效 130次
夜间维护后，白天不再扣除维护时间 → 实际可达 ~130次
```

**夜间 8h（低需求时段）：**
```
理论容量 = 3600 ÷ 353 × 8 = 82次
夜间需求估算：
  - 营运车夜间（22:00-6:00）仍有少量运营（夜班网约车、代驾等）
  - 夜间营运车活跃度约为白天的 20-25%
  - 私家车夜间换电需求接近零
  - 综合利用率 ρ ≈ 0.20
有效 = 82 × 0.20 ≈ 16次
```

**维护窗口解放：**
```
16h场景：每日维护 30min 挤占白天 ~2-3次
24h场景：维护移至夜间闲时（凌晨 2:00-4:00），白天零维护损耗
→ 白天净释放 +2~3次（已体现在白天 130次中）
```

**合计：白天 130次 + 夜间 16次 - 均衡损耗 5次 ≈ 140次/天**

**综合取值：140次/天**（保守取整）

> **核心结论**：
> 1. 24小时全自动无人值守的**核心价值是人工成本归零**（贡献 35% 的 EBITDA 增量），而非换电次数的大幅增长
> 2. 夜间 8 小时仅贡献约 15 次/天的增量——这是用户行为决定的，不是设备瓶颈
> 3. IRR 从 19.7% 提升至 ~22%，增幅温和但确定性强
> 4. **真正的"杀手场景"不是 24h 运营本身，而是全自动无人值守带来的人工成本节省**——这适用于任何运营时长

### 四、收费标准

#### 服务费

1.  **电费 (Electricity Cost)**：实时穿透。车主App直接连接电网实时结算价。
2.  **换电服务费 (Swapping Service Fee)**：2026年标准调优为 **0.40 - 0.50 元/度**（注：相比2025年的0.2元有所提升，因为换电被定义为"极速补能服务"，其溢价高于普通充电），以下计算用 0.4元/度。
3.  **超充服务费 (Super-charging Service Fee)**：维持在 **0.25 - 0.35 元/度**，以下计算用 0.3元/度。

#### 电池租赁套餐包（BaaS 定价体系）

宁德时代"巧克力换电块"采用 BaaS（Battery as a Service）模式，用户按月租赁电池，无需一次性购买电池资产。官方定价体系如下（来源：[易车 2025.11.18 报道](https://news.yiche.com/hao/wenzhang/105245316/)）：

| 套餐名称 | 20# 电池（42度） | 25# 电池（56度） | 包含权益 |
|:---|:---|:---|:---|
| **家庭包** | **369元/月** | **499元/月** | 月行驶≤3,000km，超里程0.2元/km，含基础保险 |
| **畅行包** | **469元/月** | **599元/月** | 不限里程换电，含基础保险+道路救援 |

> **限时优惠**：25# 家庭包首发大定用户享终身优惠价 **399元/月**。模型中假设 30% 的 25# 家庭包用户享受此优惠（早期尝鲜用户占比有限，大规模推广后以标准价为主）。

> **关键规则**：
> - 家庭包月行驶≤3,000km，超出按 **0.2元/公里** 收取超里程费（单月未使用里程可次月结转）
> - 整车购买入网需缴 **699元/年** 电池管理费 + **299元/次** 电池检测费 + **499元/年** 电池保障权益费（首发大定用户终身赠送）
> - 电池租用方案：3年内买断电池，已付租金 **100%全额抵扣** 电池款
> - 营运车（月行驶8,000km）远超家庭包3,000km限制，必须选择畅行包。官方尚未发布营运专属套餐，当前模型以 25# 畅行包(599元)作为营运车保守定价

> **关于电池管理费/检测费/保障权益费的归属分析**（审慎结论）：
> 
> | 费用项目 | 金额 | 归属方 | 理由 | 是否计入模型 |
> |:---|:---|:---|:---|:---|
> | **电池管理费**（年费） | 699元/车/年 | **电池银行** | 为电池资产提供管理服务（监控、调度、维护），电池银行作为资产持有方收取 | 暂不纳入（首发大定用户终身赠送，实际收取比例低） |
> | **电池检测费**（次费） | 299元/次 | **换电站** | 检测在换电站现场进行，属于换电站的运营服务 | 暂不纳入（检测频次低，且已含在换电服务费中） |
> | **电池保障权益费**（年费） | 499元/车/年 | **电池银行** | 为电池资产提供保障/保险，电池银行作为资产持有方需要为电池投保 | 暂不纳入（首发大定用户终身赠送，实际收取比例低） |

> **蔚能实际情况参考**：蔚来BaaS模式下，用户月租费（75度980元/月，100度1488元/月）**已打包包含**电池使用权、维护、保险等所有费用，未单独列示管理费/检测费/保障费。蔚来代电池资产公司负责日常运营、维护及保险理赔。宁德时代将费用拆分出来，可能是为了更透明的定价策略，但增加了用户认知负担。（[汽车之家](https://www.autohome.com.cn/ask/22612080.html)）

#### 1. 电能损耗（系统级电损）

电量损耗推导逻辑：宁德时代官方称超换一体"综合电损率较配储充电站降低超过13个百分点"。配储方案含"电网→储能柜→车"两次转换，电损约20-22%；超换一体仅"电网→换电电池→车"一次转换，电损 = 22% - 13% = **9%**。该数值与NREL系统级效率数据（损耗8-15%）一致。参考：[NREL Battery Energy Storage System Round-Trip Efficiency](https://www.nrel.gov/pv/battery-systems.html)、[Sunlit Energy - AC vs DC Round Trip Efficiency](https://sunlithenergy.com/ac-vs-dc-round-trip-efficiency-in-battery-energy-storage-systems/)

  *   计算公式：车主充入电量为"净得"，电网输出总电量 = 净得 ÷ (1 - 电损率)。损耗电费 = 净得 ÷ (1 - 9%) × 9% × 电价。
  *   换电损耗：100次/天 × 50度 ÷ 91% × 9% × 0.61元 × 365 = **110,096 元/年**
  *   超充损耗：40次/天 × 25度 ÷ 91% × 9% × 0.61元 × 365 = **22,019 元/年**

  *   **损耗电费合计 = 132,115 元/年**

#### 6. 仓储物流

> **问题提出**：电池是否需要在每个区域建集中的仓储中心，并在不同站点间调度以补充换电站的缺货？是否还有新的仓储、物流成本？

**1. 区域仓储中心网络（外包运营）**：
- **网络规模**：10万站遍布全国，按每省约3,000站计算，需**约30个区域仓储中心**（每省1个，部分大省2个）
  - **规模合理性评估**：每省3,000站/30仓=100站/仓服务半径。参考京东物流亚洲一号仓覆盖半径约150km、服务1,000+站点，电池仓储中心服务密度更低（100站/仓），原因是：①电池属于危险品（UN38.3），仓储标准高于普通商品；②换电站分布在城市核心区，区域仓需设在郊区（土地成本+安全距离），服务半径受限；③梯次回收电池需暂存、检测、分选，占用仓容周期更长。
  - **结论**：30个区域仓对于10万站网络是**必要且合理**的配置，并非过度建设。
- **单仓功能**：电池集中存储（安全库存）、跨站调拨、梯次回收电池暂存、检测分选
- **单仓面积**：2,000-3,000㎡，按物流园标准建设
  - **面积合理性**：单仓存储约5,000-8,000块电池（含安全库存+周转库存），按电池包装体积0.5㎡/块+通道/消防空间，需2,500㎡左右。与普洛斯物流园标准仓（3,000-5,000㎡）对齐。
- **运营模式**：**外包给第三方物流**（顺丰/京东物流/宁德时代自有物流"时代物流"），不自建物流团队
- **单仓年外包费用**：100万（含租金+人工+能耗+维护+管理）
  - **费用拆解**：租金30万（2,500㎡×10元/㎡/月×12月）+人工20万（5人×4万/年）+能耗10万+维护15万+管理25万=100万/年
- **总网络年外包费用**：30仓 × 100万 = **3,000万/年**

**2. 电池跨站调拨运输成本（外包运输）**：
- **调拨场景**：换电站电池缺货（利用率波动）、新站开业配货、旧电池回收、梯次利用转移
- **调拨频率**：每站每月约1-2次，每次调拨5-10块电池（平均7.5块）
- **运输方式**：短途（<200km）用厢式货车，长途用专业电池运输车
- **单块电池单次运输成本**：按快递/零担物流标准，150km约**15-25元/块**（含包装、保险、装卸）
- **年调拨总量**：10万站 × 12月 × 1.5次 × 7.5块 = **1,350万块次/年**
- **年运输总成本**：1,350万 × 20元 = **2.7亿/年**

**3. 单站分摊仓储物流成本**：
- 年仓运营分摊：3,000万 ÷ 10万站 = **3,000元/站/年**
- 年运输成本分摊：2.7亿 ÷ 10万站 = **2,700元/站/年**
- **合计：5,700元/站/年**，占单站电池资产（831万）的**0.069%**
- **模型取值**：保守按 **0.05%** 计提，即 831万 × 0.05% = **4,155元/站/年**

> **0.05%比例取数理由**：
> 1. **实际测算值**：年仓运营3,000万+年运输2.7亿=3.0亿/年，÷10万站=3.0万元/站/年，÷831万资产=**0.036%**
> 2. **保守上浮**：考虑到①危险品运输溢价（电池属第9类危险品，运输成本比普通货物高30-50%）；②区域仓数量可能从30个增至40-50个（覆盖密度提升）；③梯次回收电池仓储周期延长（从7天增至30天），模型按**0.05%**计提，较实际测算上浮39%。
> 3. **行业对标**：普洛斯物流园资产管理费约0.03-0.05%/年（纯收租模式，无调拨运输），本模型0.05%已包含运输成本，处于合理区间。
> 4. **敏感性**：若运输成本上升至3.5亿/年（调拨频率从1.5次/月增至2次/月），比例升至0.06%；若仓数量增至50个，比例升至0.07%。0.05%是中性偏保守的假设。

> **关键说明**：
> - 区域仓储中心是电池银行运营的**必要基础设施**，但**运营和运输全部外包**，不自建物流团队。
> - 数字化中心开发运筹调度系统（路径优化、库存预测、运输排班），实现智能调度，不额外增加人力。
> - 物流调度中心0人（见团队结构），物流成本按实际发生额计入"区域仓储物流成本"，不再单独计算人工。
> - 0.05%的计提比例较保守，实际运营中可能上升至0.08-0.10%。

### 九、网络规模（建多少站与"台阶效应"）

> **核心认知**：这不是"单站"的生意，是"网络"的生意。用户数增加后，单站容量饱和，必须建新站。存在"台阶效应"。

#### 1. 单站容量极限

单站有效换电能力 125次/天，对应 266个用户（141营运+125私家）。

> **重要澄清："163"是次/天，不是人/天。** 理论极限 163次/天 是换电操作次数上限，不是用户数上限。266 个用户每天仅换 125 次电（人均 0.47 次），125 ≤ 163，一站完全够用。不存在"266人必须建2站"的硬约束。

**真正的建站触发条件不是用户数，而是地理覆盖半径：**

```
单站覆盖模型：
  合理覆盖半径 R ≈ 3-5km（用户不愿跑更远）
  覆盖面积 A = π × R² ≈ 28-79 km² ≈ 50 km²（4km）
  
  设区域用户密度为 D（人/km²），则：
    单站覆盖用户数 = D × A
    单站换电需求 = D × A × 0.47次/人/天
  
  当 D × A × 0.47 > 125 时 → 单站容量不足 → 需加密站点
  当 D × A × 0.47 ≤ 125 但用户分布在 >R 范围 → 地理覆盖不足 → 需新建站点
```

> **两种建站触发条件**：
> 1. **容量触发**：覆盖区内用户密度过高，单站 125 次/天不够用 → 同区域加密
> 2. **地理触发**：用户分布在 5km 以外，不愿跑远 → 新区域建站（更常见）
>
> 当前模型假设 266 个用户恰好分布在一站覆盖半径内（D ≈ 266÷50 ≈ 5.3 人/km²，对应中等密度城区），属于"一站满负荷"的理想状态。实际部署中，地理触发往往先于容量触发。

每次新建一个站，站设备投入（215万）和周转电池（41.6万）一次性跳增，但新站的利用率从零开始爬坡。IRR 先跌后涨。

## 第二部分：一体化全自持模型（Total Business Model）

> **核心逻辑**：先算总账。宁德时代全部自持——既建站，又买电池，直接面向用户运营。总账 IRR 必须过 7.5%，否则生意不成立。
>
> **关键认知**：这不是"单站"的生意，是"网络"的生意。每个用户需要一块车载电池，每座站需要周转电池和站设备。网络级模型必须核算**全部资产**：所有站的设备 + 所有周转电池 + 所有用户车载电池。

## 第三部分：分拆逻辑与内部结算机制

> **核心原则**：总账 IRR 15.8%（单站全资产）必须等于各子业务 IRR 的加权平均。分拆不是简单切割，而是通过**内部结算价**调节利润分配，使两块业务都能独立融资、独立找合作伙伴。
>
> **关键认知**：结算机制的设计必须回答三个问题——①钱从哪来（收入归属）；②钱花在哪（成本承担）；③中间怎么分（结算项目）。

### 一、对错误认知的批判与修正

错误认知："换电站是落地服务供应商、应该拿电池银行给的分佣返点"。

| 错误认知 | 问题分析 | 修正方向 |
|:---|:---|:---|
| 换电站拿电池银行的"分佣返点" | **颠倒了价值链**。换电站是面向用户提供换电服务的主体，服务费是换电站的核心收入。电池银行依赖换电站网络触达用户，而非相反。 | 换电站直接收取服务费，不向电池银行要"返点" |
| 换电服务费在换电站和电池银行间分成 | **混淆了收入属性**。服务费（0.4元/度）是用户为"换电操作服务"支付的对价，对应换电站的设备、人工、场地、电损。电池银行未参与换电服务过程。 | **服务费全归换电站**，电池银行通过"周转电池租金"获得电池资产收益 |
| 周转电池租金要"比买断自持划算" | **方向正确，但定价需合理**。周转电池租金应覆盖电池银行的资金成本+合理利差，但不能过高导致换电站无法盈利。 | 周转电池租金按电池银行资金成本+合理利差定价，**240元/月/块**（双方平衡点） |

**核心结论**：
- 换电站是**运营主体**，收入=服务费+超充费，成本=站设备+人工+场地+电损+周转电池租金+技术服务费
- 电池银行是**资产主体**，收入=用户电池租赁费+周转电池租金+面向换电站的技术服务费，成本=电池折旧+资金成本+运维
- **服务费不应分成**，电池银行的收益应来自电池资产的租赁利差+技术服务溢价

### 三、结算项目设计原则

#### 原则1：收入按"服务提供者"归属

| 收入项目 | 收费方 | 归属方 | 理由 |
|:---|:---|:---|:---|
| 用户电池租赁费（369-599元/月） | 电池银行 | **电池银行** | 电池银行持有电池资产，向用户提供"电池使用权" |
| 换电服务费（0.4元/度） | 换电站 | **换电站** | 换电站提供"换电操作服务"，含设备、人工、场地 |
| 超充服务费（0.3元/度） | 换电站 | **换电站** | 超充是换电站的附加服务，利用共享变压器 |
| CCER/VPP收益 | 电池银行 | **电池银行** | 碳交易和辅助服务收益来自电池资产，非换电服务 |
| 换电站APP平台服务费 | 电池银行 | **电池银行** | 电池银行提供换电站APP、用户找站、预约、结算等平台服务 |
| 电池监控与调度系统费 | 电池银行 | **电池银行** | 电池银行提供实时监控、智能调度、状态预警等系统服务 |
| 运营技术支持费 | 电池银行 | **电池银行** | 电池银行提供软件升级、故障诊断、远程支持等技术服务 |
| 数据服务费 | 电池银行 | **电池银行** | 电池银行提供用户行为分析、运营数据分析、选址优化等数据服务 |

#### 原则2：成本按"资产使用者"承担

| 成本项目 | 承担方 | 结算方式 |
|:---|:---|:---|
| 用户车载电池折旧+资金成本 | 电池银行 | 内含于电池银行成本端 |
| 周转电池折旧+资金成本 | 电池银行 | 通过"周转电池租金"回收 |
| 站设备折旧+维保 | 换电站 | 内含于换电站成本端 |
| 人工+场地+电损 | 换电站 | 内含于换电站成本端 |

#### 原则3：周转电池归属——租赁优于买断，但需警惕资产隔离风险

**一、为什么换电站不能买断周转电池？**

1. **跨站流通导致沉没成本**：周转电池装车后随车主流转至其他站点，买断即"为他人做嫁衣"。
2. **技术迭代贬值风险**：电池成本8年降55%（0.53→0.238元/Wh），买断方承担全部贬值。
3. **运维专业化分工**：电池检测/调度/回收应由电池银行统一负责，换电站专注选址获客。

**二、蔚能模式的启示：资产隔离是更优解**

蔚来体系采用"双实体分拆"架构，已被资本市场验证：

| 实体 | 资产 | 业务 | 融资能力 |
|:---|:---|:---|:---|
| **蔚能**（独立公司，蔚来持股19.4%） | 车主电池（BaaS租赁资产） | 电池租赁、全生命周期管理 | ✅ 8轮融资超20亿，2026年发REITs |
| **蔚来能源**（蔚来全资子公司） | 换电站、周转电池、充电桩 | 充换电网络建设运营 | ✅ 宁德时代注资25亿共建 |

**关键洞察**：蔚能2025年净利4.7亿，累计利润超10亿（[极片Lab](https://caifuhao.eastmoney.com/news/20260507164213102340970)）。其成功核心在于**电池资产与运营资产的彻底隔离**——电池银行轻资产运营（不持站），换电站重资产运营（不持用户电池），各自独立融资、独立估值。

**本模型的风险**：将周转电池与用户电池统一归入"电池银行"，换电站向电池银行租赁周转电池。这导致换电站对电池银行存在**关键依赖**（断供即停摆），且电池银行同时持有两类电池，资产边界模糊，不利于未来独立证券化。

**修正建议**：当网络规模达1万站时，应将电池银行拆分为"用户电池资产公司"（发REITs）和"周转电池运营公司"（服务换电站），复制蔚能模式。

### 五、盈亏平衡测算

> **核心问题**：轻资产换电站在何种利用率下能实现盈亏平衡（净利润=0）？不计利息及资本结构影响。

#### 5.1 关键假设与用户结构动态

**基础参数**：

| 参数 | 数值 | 说明 |
|:---|:---|:---|
| 换电服务费 | 0.4 元/度 | 基准定价 |
| 单次换电电量 | 50 度/次 | 标称容量 |
| 满负荷日均换电次数 | 125 次/天 | 物理极限：3.5分钟/次 × 16h × 85%利用率 ÷ 60 |
| 年运营天数 | 365 天 | — |
| 超充日均服务量 | 1,000 度/天 | 与换电流量正比 |

**用户结构随流量动态变化**：

纯站虽不分摊电池租赁收入，但用户结构影响X→U映射，进而影响盈亏平衡点的经济学解读（需要多少用户支撑）。这是从一体化模型平移过来的核心假设：

```
营运车辆是刚需用户（日均换电0.71次不变），私家车主是边际用户（日均0.20次不变）。
当总次数X下降时，边际用户率先退出，营运占比上升，综合人均频率随之上升。

营运换电次数占比 p(X) = 0.80 + 0.20×(1 − X/125)
  - X=125时 p=0.80（满负荷基准）
  - X=0时   p=1.00（仅剩营运车辆）

综合人均换电频率 f(X) = 1 / [p/0.71 + (1−p)/0.20] （次/人/天）
  解释：p比例的用户日均0.71次，1−p比例的用户日均0.20次，
        总体人均频率 = 总次数/总人数 = 1 / 调和加权平均的倒数

单站所需服务用户数 U(X) = X / f(X)

代入验算（基准125次/天）：
  p(125) = 0.80
  f(125) = 1/[0.80/0.71 + 0.20/0.20] = 1/[1.127+1.0] = 1/2.127 = 0.470
  U(125) = 125/0.470 ≈ 266 人
```

#### 5.4 盈亏平衡求解

```

           = 0.9073X − (0.1923X + 40.33)
           = 0.7150X − 40.33

盈亏平衡条件（净利润 = 0，不计利息/所得税）：
  EBITDA = 折旧
  0.7150X − 40.33 = 21.5
  → X = (21.5 + 40.33) / 0.7150
  → X ≈ 86.5 次/天

→ 纯站盈亏平衡点 ≈ **87 次/天**（上取整，86次/天时 EBITDA仅21.16万＜折旧21.5万，必亏损）
```

### 五、盈亏平衡测算

> **核心问题**：电池银行能否独立实现盈亏平衡？需要多少次换电、多少用户？不计利息及资本结构影响。

#### 5.1 关键前提——站端付费不是"免费的"

电池银行的收入结构中，周转电池租金（0.0168R 万）和技术服务费（3.5万）来自换电站的付费。但这笔钱不是凭空产生的——它来自站端从用户收取的换电服务费。

**站端支付能力约束**：

```
站端EBITDA（付银行前） = Rev_station − OPEX_station（不含银行付费）
                       = 0.9073X − (0.1277X + 36.30)
                       = 0.7796X − 36.30                    万元

站端应付银行           = 周转电池租金 + 技术服务费
                       = 0.0168R + 3.5                      万元

站端能全额支付银行的条件：0.7796X − 36.30 ≥ 0.0168R + 3.5
→ 0.7796X ≥ 39.80 + 0.0168R

当 R = 240 元/月：0.7796X ≥ 43.83 → X ≥ 56.2 次/天
```

| 站端状态 | X范围 | 站端可付银行金额 | 说明 |
|:---|:---|:---|:---|
| 站端亏损 | < 46 次/天 | 0（站自身都在亏损） | 站端EBITDA<0 |
| 站端勉强存活 | 46–56 次/天 | 部分（0.7796X−36.30） | 覆盖自身成本后有少量盈余 |
| **站端全额支付** | **≥ 56 次/天** | **全额（0.0168R+3.5）** | 站端有足够盈余支付银行 |

> **核心洞察**：站端付费不是电池银行的"外部收入"，而是站端流量→站端盈利→站端付费的传递链条。**X < 46 时，站端自身亏损，银行收不到一分钱站端付费**。

#### 5.2 电池银行外部收入盈亏平衡（BaaS only，不含站端付费）

先看最悲观情景——站端无法付费时，银行仅依赖外部收入：

```
银行外部收入 = 用户BaaS租赁 + CCER + VPP
             = 0.5992U + 0.08968X                        万元

银行OPEX     = 0.0653U + 1.6141                          万元  （含人工0.0010×280=0.028万）
银行折旧     = 0.17808U + 2.4931                         万元
银行CAPEX    = 2.968U + 41.55                            万元

净利润 = 0.35582U + 0.08968X − 4.1072
```

**BaaS-only 盈亏平衡求解**：

```
设 净利润 = 0：
  0.35582U + 0.08968X = 4.1072

利用用户结构 U(X) = X / f(X)：
  - 当 X=2：p≈0.997, f≈0.709, U≈2.8 → 净利润 ≈ 1.00+0.18−4.11 = −2.93万
  - 当 X=7：p≈0.989, f≈0.693, U≈10.1 → 净利润 ≈ 3.59+0.63−4.11 = +0.11万

  → BaaS-only 盈亏平衡 ≈ 7次/天，≈10 人
```

| X（次/天） | U（人） | 年净利润（万） | CAPEX（万） | 15年IRR |
|:---|:---:|:---:|:---:|:---:|
| **7** | ≈10 | **≈0** | ≈71 | ≈4% |
| 20 | ≈30 | ≈10 | ≈131 | ≈9% |

> BaaS-only 银行在~7次/天即技术上盈亏平衡，但IRR极低（~4%）。要达7.5%门槛需约20次/天——而此时站端（需55次/天才能全额支付）仍在亏损。

#### 5.3 综合盈亏平衡——银行+站端必须共同存活

电池银行的现实盈亏平衡不能孤立分析，必须考虑站端存活：

```
银行综合盈利路径：
  X < 46次/天  → 站端亏损，银行收不到站端付费 → 银行仅靠BaaS（IRR < 9%）
  X 46~55次/天 → 站端微利，银行收到部分站端付费 → 银行IRR逐步改善
  X ≥ 55次/天  → 站端全额支付银行 → 银行IRR跃升至≈17%+
```

| X（次/天） | U（人） | 站端状态 | 银行收到站端付费 | 银行年净利润（万） | 银行15年IRR |
|:---|:---:|:---|:---|:---:|:---:|
| 7 | ≈10 | 亏损 | 0 | ≈0 | ≈4% |
| 20 | ≈30 | 亏损 | 0 | ≈10 | ≈9% |
| 46 | ≈74 | 刚存活 | 少量 | ≈44 | ≈15% |
| **55** | **≈85** | **全额支付** | **全额** | **≈55** | **≈16%** |
| 80 | ≈149 | 微利 | 全额 | ≈64 | ≈17% |
| 100 | ≈198 | 健康 | 全额 | ≈83 | ≈18% |
| 125 | ≈266 | 满负荷 | 全额 | ≈109 | ≈18% |

> **结论**：电池银行的**可持续盈亏平衡点 ≈ 55 次/天、≈85 人**。低于此线，站端无力支付银行，银行只能靠BaaS勉强存活；达到此线，站端→银行付费链闭合，银行IRR跃升至≈16%+。
>
> **与一体化模型对照**：一体化盈亏平衡≈43次/天，范围包括了电池银行亏损阶段的流量。银行付费链闭合点（55次/天）高于一体化盈亏平衡点（43次/天），说明在43-55次区间，站端自身已有盈利但仍无力全额支付银行——这正是CATL内部结算价格（240元/月租金+3.5万技术服务费）的调节空间所在。

#### 5.4 边际用户单位经济

> 虽然银行整体盈亏平衡需要站端存活，但每新增一个用户的增量经济贡献是独立的：

### 七、与蔚能REITs收益率差异分析

**蔚能REITs（2026年发行）的关键特征**：

| 维度 | 蔚能REITs | 当前模型 | 差异原因 |
|:---|:---|:---|:---|
| **电池来源** | 多品牌外采（含溢价） | 宁德时代自产（成本价） | 蔚能采购成本更高，但**租金定价也更高** |
| **BaaS租金水平** | **约728元/月**（蔚来标准） | 499元/月 | 蔚来品牌溢价+服务包捆绑 |
| **电池折旧年限** | **15年**（REITs匹配） | 10年 | 更长的折旧期降低年折旧额 |
| **实际杠杆** | **有**（REITs本质是杠杆） | 无杠杆 | REITs通过份额化实现资金杠杆 |
| **IRR口径** | **分派率**（可分配现金流/REITs估值） | 项目IRR（NPV=0） | 口径不同，分派率≤项目IRR |

**核心发现**：

1. **租金定价差异是主因**：蔚能728元/月 vs 模型499元/月，**租金高出46%**
   - 若模型租金提升至728元/月，年收入 = 266 × 728 × 12 + 4.03万 = **236.5万**
   - 对应IRR = **12.8%**，显著高于7.5%

2. **折旧年限差异是次因**：蔚能15年折旧 vs 模型10年折旧
   - 若模型改为15年折旧（残值10%），年折旧 = 831万 × 6% = 49.9万
   - 对应IRR = **8.2%**，接近7.5%门槛

3. **杠杆效应是表因**：REITs分派率≠项目IRR
   - 蔚能REITs分派率7.5%+，但底层项目IRR可能仅5-6%
   - 分派率 = 现金流 / REITs份额估值，估值有溢价（PBV>1）

**电池银行IRR（含技术服务费，对标蔚能模式）**：

| 情景 | 租金水平 | 技术服务费 | 折旧年限 | 杠杆 | 测算IRR | 说明 |
|:---|:---|:---|:---|:---|:---|:---|
| 当前模型 | 499元/月 | 3.5万/站/年 | 10年 | 无 | **≈16.5%** | 基准情景，已高于门槛 |
| 对标蔚能租金 | 728元/月 | 3.5万/站/年 | 10年 | 无 | **≈26%** | 蔚来品牌溢价+技术服务 |
| 对标蔚能折旧 | 499元/月 | 3.5万/站/年 | 15年 | 无 | **≈17.5%** | 匹配REITs久期，折旧税盾略减 |
| **综合对标** | **728元/月** | **3.5万/站/年** | **15年** | **无** | **≈27%** | **远超蔚能水平** |

> **关键洞察**：电池银行即使按CATL当前499元/月定价，IRR已达16.3%，远超蔚能REITs分派率（~7.5%）。若采用蔚来728元/月定价，IRR可达26%+。CATL的竞争优势来自：①自产电芯成本低20%；②10-15年电池真实寿命远超行业假设。

### 二、敏感性分析

**关键变量对一体化 IRR 的影响：**

| 变量 | 基准值 | -20% | -10% | +10% | +20% | IRR敏感度 |
|:---|:---|:---|:---|:---|:---|:---|
| 换电服务费 | 0.4元/度 | 11.0% | 14.8% | 22.0% | 25.5% | **高** |

| 电池租赁费 | 499元/月 | 16.0% | 17.3% | 19.8% | 21.0% | 中 |
| 系统电损率 | 9% | 19.0% | 18.8% | 18.2% | 17.9% | 低 |
| 加权电价 | 0.61元 | 19.9% | 19.8% | 19.6% | 19.5% | 低 |

**结论**：
1. **换电服务费**是最敏感变量：从0.32元到0.48元，IRR波动15.2个百分点
2. **电池采购成本**次之：宁德时代自产电芯的成本优势是核心竞争力
3. **日均换电次数**：以基准情景125次/天为锚点，±20%波动使IRR在~15%–~21%间摆动。盈亏平衡仅需~43次/天，安全边际充足（2.9倍）。利用率是决定项目成败的核心变量

### 三、关键假设压力测试（基于日均换电次数）

> **基准说明**：125次/天是物理推导的极限值（基于换电时间3.5分钟/次 × 16小时运营 × 85%设备利用率）。实际运营中，受用户分布、时段波动、设备故障等影响，很难长期维持极限值。以下测试不同日均换电次数下的一体化全自持模型表现。

**假设条件**：
- 换电服务费：0.4元/度（基准不变）
- 电池租赁费：加权499元/月（基准不变）
- **用户结构随次数动态变化**：营运车辆是刚需用户（日均0.71次不变），私家车主是边际用户（日均0.20次不变）。当总次数下降时，边际用户率先退出，营运占比上升，综合人均换电频率随之上升——**0.47次/人/天仅在125次极限情景下成立**

**核心函数**：
- （1）用户结构：
  - 日均换电次数 X
  - 营运换电次数占比 p(X) = 0.80 + 0.20×(1 - X/125)：线性插值：X=0时p=1.0全营运，X=125时p=0.80
  - 综合人均换电频率 f(X) = 1 / [p/0.71 + (1-p)/0.20] （次/人/天）：调和加权，营运0.71次/天、私家0.20次/天
  - 单站所需服务用户数 U(X) = X / f(X)

- （2）收入：Rev(X, U) = 0.908X + 0.5992U
  - 电池租金：0.5992U 万元 = U人 × 加权499元/月 × 12月 ÷ 1万
  - 换电服务费：0.73X 万元 = X次/天 × 0.4元/度 × 50度/次 × 365天 ÷ 1万
  - 超充+CCER+VPP：0.1776X 万元 = 22.16万 × (X/125)，三项均与站流量/能源吞吐量成正比

- （3）CAPEX(X, U) = 256.6 + 2.968U
  - 换电站投资：256.6 = 站设备215 + 周转电池41.6(14块×2.968万)
  - 用户电池：2.968U = 用户电池U(X)块 × 2.968万/块

- （4）OPEX(X, U) = 0.1352X + 34.4453 + 0.06530×(14+U)
  - 固定费用 32.7225：
    - 人工14.4(16h双班×2人) + 租金12.0 + 维保6.0 + 换电站设备保费0.3225）
  - 电池可变费用：0.06530×(14+U)
    - 电池运维管理：0.05936×(14+U) ，每块 = 2.968万/块 × 维护费率 2%
    - 电池资产保费：0.00594×(14+U) ，每块 = 2.968万/块 × 保费费率 0.20%
  - 电损：0.1352X = 16.9×(X/125)，正比于用电量
  - ⚠ 技术服务费3.5万/站/年属内部结算——换电站付给电池银行，合并时抵消，不出现

- （5）EBITDA = Rev(X, U) - OPEX(X, U) = 0.7728X + 0.53390U - 34.4453

#### 预期回报推导：15年期IRR = WACC = 7.5%，55 次/天，单站用户 ≈ 95 人

- 平衡条件：EBITDA=CRF×CAPEX 等效 CAPEX=EBITDA×PVIFA
- 资本回收系数 CRF(7.5%,15) = 0.075/(1−1.075⁻¹⁵) ≈ 0.11326
- 年金现值系数 PVIFA(7.5%,15) = 1/CRF ≈ 8.8267年

```
代入核心函数：
  CAPEX/EBITDA = 8.8267
  EBITDA = 0.7728X + 0.53984U − 33.23104
  CAPEX  = 256.6 + 2.968U
  U(X)   = X·[1/0.71 × p + 1/0.20 × (1−p)] = X·(1.40845 + 0.0057465X)
  → 0.01033X² + 9.352X − 549.9 = 0

求解：X = 55.4 ，U = 95
```

→ **预期回报需要：单站换电次数 ≈ 55 次/天，单站用户 ≈ 95 人**

#### 盈亏平衡点推导（净利润=0）：43 次/天，单站用户 ≈ 71 人

**折旧计算**：

| 资产 | 原值 | 年限 | 年折旧 | 说明 |
|:---|---:|---:|:---|:---|

**盈亏平衡方程（税前利润 = 0，不计资本结构）**：

```
EBITDA = 折旧
0.7728X + 0.53390U − 34.4453 = 21.5 + (U+14)×0.17808
                                = 21.5 + 0.17808U + 2.4931
                                = 23.993 + 0.17808U
→ 0.7728X + 0.35582U = 58.438
U(X) = X·[1/0.71 × p + 1/0.20 × (1−p)] = X·(1.40845 + 0.0057465X)
→ 0.002045X² + 1.27395X − 58.438 = 0

求解：X ≈ 42.9 ，U ≈ 71
```

→ **盈亏平衡点 ≈ 43 次/天，单站用户 ≈ 71 人**

> **注**：本模型为无杠杆分析，不计利息及融资结构。盈亏平衡条件简化为 EBITDA = 折旧，即 EBITDA 仅需覆盖折旧即可实现税前盈亏平衡。

## 第八部分：REITs发行收益率测算（3年培育期 + 12年REITs存续期）

| **原始权益人保留** | 30% | 30% | 10%股权（宁德时代） |

**核心结论**：

1. **换电站可以独立发行REITs**：原始权益人IRR 28.4%，投资者分派率7.1%，双赢结构
2. **电池银行独立发行REITs**：电池银行为独立业务主体，单独发行REITs；基准情景分派率4.4%低于7.5%门槛，需通过以下路径改善后发行：
   - **延长折旧至15年**：降低年折旧额，提升可分配现金流
   - **提升租金**：直接增厚现金流
   - **扩大资产规模**：每形成50亿资产包即可发行一批，规模效应降低单位发行成本
3. **合作站也可打包发行REITs**：合作站同样具备稳定现金流特征，可由合作方主导发行REITs，宁德时代作为10%股东享有分红；合作站REITs发行后可加速合作方资金回笼，推动网络扩张
4. **REITs发行节奏**：每形成50亿资产包即可发行一批，滚动发行、持续扩募（详见第八部分之六）
5. **电池银行的改善路径**：
   - **提升租金**
   - **延长折旧至15年**，降低年折旧额，提升现金流
   - **扩大资产规模**，降低单位发行成本，提升分派率

> - 2022年是极端低点（17.2%），主要由原材料价格暴涨导致，即使龙头企业也无法完全对冲原材料波动

> - 未来15年的压力因素：电池价格持续下降（BNEF预测年均降3-6%）、原材料价格波动（碳酸锂周期性波动）、行业竞争加剧（产能过剩900GWh in 2025）、出口退税率取消（2027年全面取消）、技术迭代风险（钠电池2027年可能低于磷酸铁锂）、海内外市场分化（国内价格战 vs 海外高毛利）

#### **电池成本下降公式**

$$Cost_t = Cost_{2026} \times (1 - r)^{t}$$

其中：
- $Cost_t$ = 第t年的56kWh电池采购成本（元）
- $Cost_{2026}$ = 21,280元（基准年成本）
- $r$ = 年复合降幅 = 5.8%（BNEF中性预测）
- $t$ = 距2026年的年数
