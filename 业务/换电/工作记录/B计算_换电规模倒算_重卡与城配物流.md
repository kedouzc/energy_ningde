## ① 重卡 HDT（核心分母，已对齐 Excel）

**逻辑**：以终为始，从「2030 重卡保有量目标」倒推 5 年新能源重卡累计销量，再乘换电渗透率与 CATL 份额。

```
2030重卡保有量 900万
   └─ ÷ 更新周期 9年 = 年均销量 100万
        └─ × 5年 = 重卡总销量 500万（2026-2030）
             └─ × NEV平均渗透率 0.444 = 新能源重卡总销量 222万  ← 模型 HV_FLEET_SIZE
                  └─ × 增量换电渗透率 0.448 = 99.5万
                       └─ × 增量CATL份额 0.348 = 增量换电车辆 34.6万
        （存量另算：2025 NEV 23万 × 0.30 × 0.10 = 0.7万）
   ─────────────────────────────────────────────────
   重卡换电车辆合计 ≈ 35.3万（增量34.6 + 存量0.7；Excel整数 35+0.7）

单车带电量：171 kWh/块（时代标准，不可调）× 2.92块 ≈ 500 kWh
   → 重卡装车电池（增量）= 34.6万 × 500 kWh ≈ 17.3 GWh
```

**参数表（自变量）**

| 参数 | 值 | 口径/来源 |
|---|---|---|
| 2030保有量 | 900万 | 政策目标 |
| 更新周期 | 9年 | 历史8-10年中值 |
| 预测年数 | 5 | 2026-2030 |
| NEV平均渗透率 | 0.444 | S型曲线 0.28→0.5 均值 |
| 增量换电渗透率 | 0.448 | a/b/c 场景加权 |
| 增量CATL份额 | 0.348 | a/b/c 场景加权 |
| 单块电量 | 171 kWh | 时代 75# 标准（不可调） |
| 单车块数 | 2.92 | 500÷171，凑 500kWh |

**结果**：重卡终局换电车辆 **34.6 万**（增量）+ 0.7 万（存量）；装车电池约 **17.3 GWh**。

## ② 城配物流 LCV（毛估估，站点共用 LV）

**假设**：城配物流换电站点 **与出租车/网约车等乘用车营运车（LV）共用** → 不新增站数与站内周转电池，仅新增「在车装车电池」桶。

```
城配物流车保有量 1200万  【经验假设】
   └─ × 2030 NEV渗透率 0.30  【经验假设】
        └─ × 换电占比 0.225  （论文20-25%中值）
             └─ × CATL份额 0.60  【经验假设】
                  = 城配物流换电车辆 48.6万
   单车带电量 81 kWh（江淮换电版）
   → 城配装车电池 = 48.6万 × 81 kWh ≈ 39.4 GWh
```

**参数表（自变量）**

| 参数 | 值 | 口径/来源 |
|---|---|---|
| 城配物流车保有量 | 1200万 | 【经验假设·毛估估】非外部信源 |
| 2030 NEV渗透率 | 0.30 | 【经验假设】低于乘用车 |
| 换电占比 | 0.225 | 论文区间中值 |
| CATL份额 | 0.60 | 【经验假设】巧克力垄断但竞品存在 |
| 单车带电量 | 81 kWh | 江淮换电版（论文） |
| 换电频次 | 1.5 次/天 | 【经验假设】高频子场景 |
| 电池租金 | 867 元/月 | 【经验假设】81度车按56度599元等比 |

**结果**：城配物流终局换电车辆 **48.6 万**；装车电池 **39.4 GWh**（并入营运车电池桶，站点零新增）。
