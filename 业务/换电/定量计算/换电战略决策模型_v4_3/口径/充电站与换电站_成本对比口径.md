# 口径 · 超充站与换电站的成本对比：每一步都能用计算器复核

> **这份文件是给不看代码的人写的。**`src/charging.py` 里的每一个数，在这里都有一行算式。
> 拿计算器按一遍，对不上就是程序错了。
>
> 对应程序：`src/charging.py`；参数：`configs/base.toml` 的 `[charging_station]` 段。
> 建立于 2026-09-19，同日修订（撤回一处过度解读，见第五节）。

## 〇、先说这份对比回答什么、不回答什么

**回答**：两座站交付同样多的电，各自的**度电固定成本**是多少、各自要占**多大的电网接口**。

**不回答**：谁的车队总成本更低。那是第 3 章的 TCO 账，口径不同，别混用。

**一条贯穿全文的口径**：本文所有"利用率"都是**能量利用率**，定义是

> 能量利用率 ＝ 一年实际充出去的电量 ÷（装机功率 × 8760 小时）

行业里还流行另外两个"利用率"——**时间利用率**（枪被占用的小时数占比）和**功率利用率**
（实际输出功率占额定功率的比例）。三者的关系大致是 `能量 ≈ 时间 × 功率`。
**市面上大部分测算之所以互相打架，就是因为混用了这三个口径。**本文只用能量口径。

## 一、第一笔账：超充站的度电固定成本

### 1.1 用到哪些成本项（全部列出，没有别的）

| 成本项 | 取值 | 出处 |
|---|---|---|
| 单位装机造价（全站，含电力增容与土建，**不含地价**） | 600 元/kW | 行业调研 150–300 万元/站，与黄骅港站 500 万元 ÷ 8,320kW ＝ 601 元/kW 互证 |
| 设备折旧年限 | 8 年 | 券商模型与重卡站模型两源一致 |
| 残值率 | 5% | 同上 |
| 运营方资金成本 | 6% | 同上（50% 负债、6% 利率口径） |
| 年运维费 | 造价的 3.5% | 同上 |
| **容量电费** | **默认不算**，见第二节 | — |
| 电损率 | 5% | 重卡站实测 4%–6% |

**没有计入的项，这里必须承认**：场地租金（重卡站的租金数据只有一个县域单点，不足以入模）、
人工（部分站无人值守）、平台分成。所以**这条成本线是偏低的估计——它对超充有利**。

### 1.2 算式，一步一步

**第一步：把一次性投资摊成每年多少钱。**

用的是"资本回收系数"——一次性花 1 元，要在 8 年里每年收回多少才够本（含 6% 的资金成本）：

```
资本回收系数 = 6% ÷ [1 − 1.06^(−8)]
             = 0.06 ÷ (1 − 0.62741)
             = 0.06 ÷ 0.37259
             = 0.16104
```

残值要先折现扣掉（8 年后还能卖 5%，那部分不用摊）：

```
残值的现值 = 600 × 5% ÷ 1.06^8 = 30 ÷ 1.59385 = 18.82 元/kW
净投入     = 600 − 18.82 = 581.18 元/kW
年化投资   = 581.18 × 0.16104 = 93.59 元/kW·年
```

**第二步：加上每年的固定运维。**

```
年运维 = 600 × 3.5% = 21.00 元/kW·年
每年固定成本合计 = 93.59 + 21.00 = 114.59 元/kW·年
```

**第三步：除以这一年能卖出多少度电。**

一台 1 kW 的设备，一年最多发 8,760 度；利用率 22% 就是实际发 1,927.2 度：

```
8,760 × 22% = 1,927.2 度
度电固定成本 = 114.59 ÷ 1,927.2 = 0.0595 元/kWh
```

**换成乘用车公共桩的利用率 6.7%，同一条算式：**

```
8,760 × 6.7% = 586.9 度
度电固定成本 = 114.59 ÷ 586.9 = 0.1952 元/kWh
```

> **注意这里没有"地板"这回事。**分母是"卖了多少度电"，利用率越低这个数越大，没有下限。
> 报告此前引用的"超充度电成本地板 0.34 元"既查不到出处，概念本身也不成立——**已弃用**。

### 1.3 那它赚不赚钱

```
服务费收入          0.23 元/kWh   （重卡实测主流 0.21–0.25 的中值）
减：度电固定成本   −0.0595
减：电损成本       −0.015        （5% 电损 × 谷电价 0.30 元）
─────────────────────────────
度电毛差            0.1554 元/kWh
```

**结论：重卡充电站现在是赚钱的。** 打平只需要

```
打平利用率 = 114.59 ÷ [8,760 × (0.23 − 0.015)] = 114.59 ÷ 1,883 = 6.1%
```

而重卡站实测是 18%–40%。**对照乘用车公共桩：0.23 − 0.1952 − 0.015 ＝ 0.020 元/kWh，
几乎不赚——"充电一度电只赚两分钱"说的是这一档。**

**这就是本轮最要紧的一条纠错**：报告此前把乘用车的亏损叙事搬到了重卡侧，方向正好反了。

## 二、容量电费：算了没有？

**默认没算进去，这是一个有意的保守选择。**

容量电费是两部制电价里按**变压器容量**收的那笔钱，跟你发多少电无关。
企业高管的具名口径是：一座 2,500kVA 的重卡站按 30 元/kVA·月算，**一年约 90 万元**。

**如果照收，账会变成这样：**

```
配容比 1.05 kVA/kW × 30 元/kVA·月 × 12 个月 = 378 元/kW·年
@22% 利用率：378 ÷ 1,927.2 = 0.1961 元/kWh
度电固定成本 = 0.0595 + 0.1961 = 0.2556 元/kWh
```

**0.2556 已经高于服务费 0.23——上一节"充电站赚钱"的结论当场翻过来。**

**为什么默认不算：**集中式充换电设施免收基本电费的政策是否仍然有效、何时到期，
翻遍国家发改委与省级文件都没取到正文条款。**在查实之前，把有利条件给对手**——
即假定对手不用交这笔钱。真要交，对手比现在难过得多。

> **这是整个对比里最大的未解变量，而且它比利用率更能决定成败。**
> 在 15% 利用率下，交与不交，度电固定成本差 4 倍以上。**建议做一手求证。**

## 三、第二笔账：电网容量——换电真正的优势在这里

### 3.1 一句话的道理

两座站交付同样多的电，电网接口谁大谁小，**只取决于这份电摊在多少小时里**：

> 需要的电网容量 ≈ 一天的用电量 ÷（24 小时 × 负荷率）

- **超充站**只有车插着枪的时候才用电，所以它的负荷率**就等于它的能量利用率**。
- **换电站**的电池什么时候充都行，可以摊到全天，所以负荷率高得多。

**两者之比，就是负荷率之比。没有别的机关。**

### 3.2 换电站这一侧，一步一步

```
每站每天交付给车的电        78,791 度   （模型成熟期假设）
÷ 充放综合效率 0.92         85,642
× (1 + 站用电率 0.02)       87,355 度   ← 站里一天真正要从电网买的电
÷ 24 小时                    3,640 kW   ← 摊平之后的平均功率
```

站上的箱变是 **4,500 kW**（取自孝感项目立项公示）。所以

```
负荷率 = 3,640 ÷ 4,500 = 80.9%
电网容量强度 = 4,500 kW ÷ 78.791 MWh = 57.1 kW/(MWh·天)
```

### 3.3 超充站这一侧

```
1 kW 装机，利用率 22%，一天出 24 × 22% = 5.28 度
要一天出 1,000 度（1 MWh），需要 1,000 ÷ 5.28 = 189.4 kW
```

### 3.4 结果，以及它有多不稳

```
倍数 = 189.4 ÷ 57.1 = 3.3 倍
```

**但这个倍数对"超充站有多忙"极其敏感，所以必须报区间：**

| 超充站利用率 | 电网容量强度 | 对换电的倍数 |
|---|---|---|
| 18%（实测最闲） | 231.5 | **4.1 倍** |
| 22%（中位） | 189.4 | **3.3 倍** |
| 40%（实测最忙） | 104.2 | **1.8 倍** |

> **正确的读法：这项优势在两倍到四倍之间，而且超充站越忙、它越小。**
> 它不是一条恒定的护城河，是一个**随对手利用率衰减**的优势。
> **推论：超充站的利用率本身就该进一级跟踪。**

### 3.5 这项优势值多少钱

两条传导路径，都不经过服务费：

1. **建站时**：电力增容与接入占重卡充电站总投资的 **35%–50%**，是第一大项（不是充电设备）。
2. **运营时**：容量电费按配电容量收——第二节那笔钱，换电站按同样的倍数少交。

**而且它不随价格战变化。**服务费可以一夜之间砍半，电网容量不会。

## 四、一处模型自身的不一致，必须挂出来

换电站一天要从电网买 87,355 度，而配置里写的充电窗口是 **16 小时**：

```
16 小时内要充进 87,355 度，需要功率 = 87,355 ÷ 16 = 5,460 kW
而箱变只有 4,500 kW  →  占用率 121%，物理上不成立
```

**两种可能，都要查：**

- **充电窗口不该是 16 小时。**电池夜里也能充，16 小时更像"对外服务时间"而不是"充电时间"。
  若按 24 小时算，需要 3,640 kW，箱变够用。
- **或者站数偏少**，每站被摊了过多的车。

**这一条直接关系到"单站日均服务车次"这个假设的可信度**，也就是第 3 章那个
"两条成本线在多少车次相交"的读数的前提。**在查实之前，那个读数要带着这个保留去读。**

## 五、已撤回的一条说法（2026-09-19 修订）

此前这里写过：本模型算出的电网容量倍数"与公司'单个车位服务能力是配储充电站 3 倍'
的口径独立吻合，两条互不相干的算法收敛到同一个数"。

**这是过度解读，已撤回。**

公司那句话讲的是**车位被占用的时长**：换电一次 5 分钟、兆瓦超充一次约 18 分钟，
18 ÷ 5 ＝ 3.6——**同样的时间里，一个车位能服务几辆车**。那是**吞吐**，不是电网容量。
实际上，如果一个车位服务的车更多，它交付的电更多，**需要的平均功率反而更高**，
方向和电网容量的论证正好相反。

**两个数都落在 3 附近纯属巧合，机理完全不同。**
本节的倍数**没有任何外部印证，只有本模型自己的算式**——就是第三节那三步。

> **教训**：两个数字接近不等于互相印证。**印证的前提是两条算法算的是同一件事**，
> 而这里一个算时长、一个算功率。

## 六、哪几个数最不牢靠（按重要性排）

| 排序 | 参数 | 为什么不牢靠 | 影响 |
|---|---|---|---|
| 1 | **容量电费是否征收** | 政策正文查不到 | 直接翻转"充电站赚不赚钱" |

| 3 | 超充站的实测利用率 | 四个样本，且装机功率是我按"320kW/桩"推的 | 电网容量倍数在 1.8–4.1 倍之间摆动 |
| 4 | 兆瓦超充站单位造价 1,650 元/kW | **单样本**（北川示范站），含地、光伏、储能，带示范溢价 | 只影响兆瓦级那一档 |
| 5 | 液冷设备 8 年寿命 | 液冷 2023 年才商用，**不存在 8 年的实证** | 年化投资偏乐观或偏保守，方向未知 |
