## 使用指南

### 日常流程（用户视角）

```
1. 放入新资料 → 触发 Ingest
   ↓
2. 提问查询 → 触发 Query
   ↓
3. 定期检查 → 触发 Lint（产出内联标注 + overview汇总）
   ↓
4. 发现关联 → 触发 Synthesize
```

### LLM工作流（LLM视角）

```
Ingest：读Raw → 写source摘要 → 更新entity/concept页 → 追加log
Query：读index → 定位候选 → 读页面 → 综合回答（带引用）
Lint：6项扫描 → 双轨标注（内联+overview）→ 呈现张力不修复
Synthesize：全库扫描 → 发现跨页关联 → 创建synthesis页
```

> **设计原则**：
> - 地图≠建筑：Wiki是脚手架，用户思考是建筑本身
> - 只标记不修复：Lint保留认知摩擦，交给用户判断

> - DNA双螺旋：框架探索 ↔ 问题涌现，相互促进
