# 附录　复盘：认知是怎么一步步改过来的

> 不回答三问，记录研究自己走过的弯路。每个转折写四样：当时怎么想、发生了什么、为什么改、学到什么。最后一栏是方法上的教训，沉淀进计算书工作法和共振框架两张方法卡片。
> 来源：模型根目录 `DECISIONS.md`（2026-09-02 起逐日记录）、`_archive/冲刺_2026-10-03/`、`主线2_大账版/03_决策日志.md`。

**一句话**：这一个多月，研究的结论从"换电能让宁德翻倍"到"换电亏钱、宁德净损失几百亿"再到"换电 2030 年加两成、几倍在 2035 年"，三次大翻转都不是因为数据变了，而是因为**问题的组织方式**变了——先是从"精算"退到"毛估"，再是从"一本账"拆成"出钱人、管理人、制造三本账"。这本身就像一次相变：微观的参数没怎么动，宏观的结论整体换了一种结构。

## 转折一（2026-09-02）：从精算退到毛估

| | |
|---|---|
| 当时怎么想 | 旧模型（v4.3）用等效年金、分年份装机、逐年折旧，想把换电的现金流精确算到每一年 |
| 发生了什么 | 一天之内查出三处结构性错：成熟期折旧把全周期的钱压进一代电池寿命摊完；年金的资本底座混了不同年份的钱；"三情景"里只有私家车渗透率在动，名不副实 |
| 为什么改 | 方法越精细，错得越隐蔽；而这些错对"几年几倍"的影响远大于精度带来的好处 |
| 学到什么 | **宁要粗略的正确，不要精确的错误**。先用毛估把方向定下来，再在会翻结论的地方算细（"算细读粗"） |

## 转折二（2026-09-05）：目标市场定错了

| | |
|---|---|
| 当时怎么想 | 按私家车市场、用"10 万座站"的规模建模，换电是个全民生意 |
| 发生了什么 | 私家车一年只开一两万公里，电池是"放老的"不是"用坏的"，延寿兑现不了；换电的真需求在跑得狠的营运车 |
| 为什么改 | 换电的价值来自受控充电延寿，只有高频车才吃得到 |
| 学到什么 | **先问谁是真需求**：高频、大金额、价格敏感的用户。私家车降为期权（见正文第 2 章） |

## 转折三（2026-09-24／25）：理论在前，跟踪在后；不回测

| | |
|---|---|
| 当时怎么想 | 想用 2024–2026 年换电占比、单站利用率回测模型 |
| 发生了什么 | 网络型生意在站密度过门槛之前，低采用率是"站少 → 没人买换电车 → 车企不出车型"的鸡生蛋，不能拿来判断终局 |
| 为什么改 | 门槛前的数据只反映供给不足，用它回测会把"还没开始"读成"不行" |
| 学到什么 | **网络型生意不能用门槛前的历史回测**。像渗流：网没连通之前，任何局部读数都偏低。先从本质推出先验，再用跟踪清单验证（正文第 3、5 章） |

## 转折四（2026-09-28／30）：推倒重来，单一数字之家

| | |
|---|---|
| 当时怎么想 | 在旧的十几份"口径"文档上一份份修 |
| 发生了什么 | 文档互相引用、没有编号的口径在不同文件里漂移，同一个数各处不一样，越修越乱 |
| 为什么改 | 研究者判断不如从车队的全生命周期账重建，把所有数写进一份自成一体的计算书 |
| 学到什么 | **一个数只有一个家；已定口径编号，推翻要写理由；一个对话只做一件事；不做只换字的修改**（计算书工作法的核心规矩） |

## 转折五（2026-10-02）：放弃排队公式；对手按"零回报"限价

| | |
|---|---|
| 当时怎么想 | 用排队论求换电站的最优忙度和报价；对手按含 7.5% 回报的完全成本定价 |
| 发生了什么 | 排队公式带出一串没有信源的参数，还藏了一个循环（站开多忙取决于来的是哪群车）；研究者改为三条路线共用"每千瓦设备每天卖 7.3 度"一把尺子。同时把对手限价改成"全投资收益率为 0"——自由进入会把回报打光 |
| 为什么改 | 前者对：方法要简单、能手算、有信源。后者在当时也说得通 |
| 学到什么 | **方法的复杂度要配得上数据**。但"对手零回报"这一条后来成了结论的卡点（转折六） |

## 转折六（2026-10-03 → 10-04）：冲刺结论作废

| | |
|---|---|
| 当时怎么想 | 冲刺一晚把计算书第 4–8 章写完：2030 年换电约 2,053 亿度、近两万座站、投入约 4,631 亿元，税前回报 1%–2%，给宁德净增约 −1,648／−558／＋738 亿元——换电是个"守护城河、自己亏钱"的生意 |
| 发生了什么 | 第二天复盘，结论错在三处，都是组织方式的错：① **把价格战当稳态**——对手零回报是压力档，不是对手长期愿意接受的价；② **把出钱人和管理人混成一个**——按宁德全额出资、要 7.5% 算，便宜的钱持有资产、宁德收管理费的分工根本没进账；③ **倍数贴错了层**——把 18 倍贴在扣了电池更新的整盘重资产生意上，而管理人、锁住的制造、资产层本该各用各的尺子 |
| 为什么改 | 研究者重新定：对手按正常回报定价（零回报只作压力档）；出钱人按 3% 无风险回报；分部估值 |
| 学到什么 | **先分清"谁出钱、谁管、谁造"，再给倍数**。同一盘生意，拆成三本账和揉成一本账，结论可以差一个符号 |

## 转折七（2026-10-04）：主线 2，从能源本质到几年几倍

| | |
|---|---|
| 当时怎么想 | 研究要回答的只有三问（会不会相变、谁有能力做没做、几年几倍），对应方法论四层；论证压成七环，每环说理 ＋ 一行算法 ＋ 大数 |
| 发生了什么 | 引入基本盘／利润源（跑得狠的车背站，其他车蹭站）、3% 的出钱人回报、两跳规模、分部估值；结论变成"2030 年换电加约两到四成、2035 年再造半个宁德" |
| 为什么改 | 让每一步都回到本质（能源的物理、谁掌握成本两端）和单位经济（每度多少钱、每度投多少） |
| 学到什么 | **四层方法可以迁移**：先判相变，再找有能力的人，再看他做没做，最后才算几年几倍 |

## 转折八（2026-10-04／05，本轮）：自己立的检验，要真去跑

| | |
|---|---|
| 当时怎么想 | 七环原稿给自己立了一条检验：体系留的钱应相当于管着的资产收约 1% 的费，和黑石一类一致 |
| 发生了什么 | 按研究者已定的参数对齐以后（超充站的回报按它自己的投资算、配的储能也要回报、蹭站时对手照样付整座站），体系一年约 165 亿，对约 4,000 亿资产是 4%——检验不过。拆开看，换电真比对手省的每度只有约 4 分，其余是"用 3% 的钱打对手 7.5% 的价"的资金价差。查实时还发现，电动重卡充电服务费 2026 年 9 月已压到 1 毛、局部 8 分——价格战今天就在打 |
| 为什么改 | 按"口径冲突取保守值"，主口径只把相当于管理费的部分给 25 倍，资金价差按宁德现在的 15 倍；结论落在 18%–29%（上沿 26%–44%） |
| 学到什么 | **检验要写成算式并真去算；差价要拆成"真成本优势"和"资金回报"两块**——前者是护城河，后者谁有便宜的钱谁就拿得到。结论的卡点因此从"电池延寿多少"移到了"谁的钱更便宜、对手要多少回报" |

## 三条贯穿的教训

1. **组织方式比参数重要**。八次转折里，只有转折二是"事实认错了"，其余都是"账的结构搭错了"。复杂系统里，结构决定行为；研究也是。
2. **每个结论都要能被一把尺子反过来量**。反算尺（要几倍需要多少度）、合理性检验（管理费率）、常识核对（市场为什么不这么做）——每一把都在某次转折里拦住过错误。
3. **最危险的假设，是看起来最无害的那条"口径"**。"对手零回报""全额出资""一个倍数"，当时都只是一行口径，后来都翻了结论。已定口径要编号、要写理由，正是为了让它们在被推翻时看得见。
