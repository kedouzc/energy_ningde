## 如何创建新的演化记录

### 1. 创建阶段目录
```bash
cd "d:\AI\证券投资\wiki\01_演化过程"
mkdir "阶段5_验证_2026-04-XX"
cd "阶段5_验证_2026-04-XX"
```

### 2. 复制模板
```bash
copy "..\_模板_演化记录.md" "_阶段概述.md"
```

### 3. 填写内容
按照模板填写四个部分：
- 01_框架_[框架名].md
- 02_问题_[问题描述].md
- 03_AI回答_[主题].md
- 04_交叉_[洞察].md

### 4. 更新索引
- 更新本文件的"演化阶段列表"
- 更新 [[../00_当前状态/最近演化]]
- 更新 [[../00_当前状态/当前框架]]（如果框架有更新）
- 更新 [[../00_当前状态/当前问题]]（如果问题有更新）

## 演化模式

### DNA双螺旋结构

```
        框架探索（左链）              问题涌现（右链）
              │                            │
              │                            │
    ┌─────────┴─────────┐      ┌───────────┴───────────┐
    │                   │      │                       │
    │ 用框架分析案例    │◄────►│ 发现新问题            │
    │ 深挖框架本质      │      │ 追问问题根源          │
    │ 更新框架定义      │      │ 形成新问题体系        │
    │                   │      │                       │
    └─────────┬─────────┘      └───────────┬───────────┘
              │                            │
              └────────────┬───────────────┘
                           │
                    ┌──────┴──────┐
                    │  交叉演化    │
                    │  （留痕）    │
                    └──────┬──────┘
                           │
              ┌────────────┼────────────┐
              ▼            ▼            ▼
        概念沉淀      案例积累      洞察生成
        (02_概念层)   (03_案例层)   (04_洞察层)
```

### 关键原则

1. **过程优先**：记录"如何思考"比"思考结果"更重要
2. **双螺旋留痕**：每个交叉点都要记录
3. **AI回答记录**：AI的启示是交联点，必须记录
4. **反哺完善**：每个答案反哺框架，每个新问题驱动深挖
