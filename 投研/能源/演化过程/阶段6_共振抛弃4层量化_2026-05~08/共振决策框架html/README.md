# 共振决策框架

知行合一的操作化表达 · 多层嵌套结构可视化

## 这是什么？

这是一个**网站项目**，用来展示"共振决策分析框架"—— 一种帮助你分析公司战略和投资价值的思维工具。

你可以把它理解为一个"可交互的PPT"，但比PPT更灵活，可以：
- 点击查看不同公司/业务的具体分析
- 在手机和电脑上都能正常显示
- 未来可以扩展到更多公司

## 如何查看最终网页？

### 方法1：本地预览（推荐）

1. 打开终端，进入项目目录：
   ```bash
   cd d:\AI\证券投资\投研\共振决策框架
   ```

2. 安装依赖（只需执行一次）：
   ```bash
   npm install
   ```

3. 启动预览：
   ```bash
   npm run dev
   ```

4. 浏览器会自动打开，通常是 `http://localhost:5173`

### 方法2：生成静态文件（用于上传到Netlify等平台）

```bash
npm run build
```

这会在 `dist` 文件夹生成网页文件，可以直接上传到Netlify、Vercel等平台。

## 核心概念

### 框架的三层嵌套

```
┌─────────────────────────────────────────┐
│  客观大场（最外层）                      │
│  ┌───────────────────────────────────┐  │
│  │  主观小场（中间层）                  │  │
│  │  ┌─────────┬─────────┬─────────┐  │  │
│  │  │   知   │   行   │   合   │  │  │
│  │  └─────────┴─────────┴─────────┘  │  │
│  └───────────────────────────────────┘  │
│  ┌───────────────────────────────────┐  │
│  │  双视角（与主观小场并列）            │  │
│  └───────────────────────────────────┘  │
└─────────────────────────────────────────┘
```

### 箭头含义

| 箭头 | 颜色 | 含义 |
|------|------|------|
| 触发/注入/反馈 | 青色 | 内环信息流（知→行→合→知） |
| 提取/选择/改变 | 橙色 | 外环能量流（客观大场↔知行合） |

## 常见问题

### Q: 为何有node_modules文件夹？
A: 这是npm安装的依赖，不需要手动管理，`.gitignore`会忽略它。

### Q: 为何有dist文件夹？
A: 这是`npm run build`生成的静态文件，用于部署到Netlify等平台。

### Q: 如何添加新公司？
A: 在`src/data/`创建新的数据文件（如`byd-battery.js`），然后在`src/pages/CompanyPage.jsx`中添加路由和公司数据映射。

## 如何部署到Netlify？

1. 在GitHub创建仓库，上传代码
2. 登录 [Netlify](https://www.netlify.com)
3. 点击 "Add new site" → "Import an existing project"
4. 连接你的GitHub仓库
5. 构建命令：`npm run build`
6. 发布目录：`dist`
7. 点击 Deploy！

部署后会获得一个永久链接，如 `xxx.netlify.app`
