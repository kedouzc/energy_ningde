# 口径 · 三种补能站：投资与站层一年的账（解释 `src/charging.py`）

> **回答什么**：同样一笔钱投下去建一座站，超充站和换电站**站这一层**各自一年能挣回多少。只算站层；电池的钱归电池银行（车队总账），不在这里。
> **不回答**：谁的车队总成本更低（车队总账）；充电服务费终局停在哪（车队总账第 3.1 节）。
> **对应程序**：`src/charging.py`；参数 `[charging_station]`、`[swap_business]` 站点项。本文的数由 `src/inject.py` 注入（现算表来自 `src/caliber_docs.py`）。
> **来历**：见 `DECISIONS.md` 2026-09-19、2026-09-20；本文只写现行口径。

## 〇、口径

- **三种站**：常规重卡充电站（观测样本）、兆瓦超充站、换电站。**补能站的投资与站层成本只写在本文**；定价（服务费停在哪、三条路线怎么博弈）住 `车队总账_换电对充电.md` 第 3.1 节，那里只引用本文的数。
- **投资一律同一个定义**：站体＋电力接入（箱变、增容）＋土建，**不含电池、不含地价**。换电站的站内周转电池是电池银行的资产（`运营收入与成本_口径.md` 第 4 节），本文只作备注列出。
- **用"全投资现金回报率"，不含资金成本**：先看这门生意本身能挣多少，再拿它跟别的机会比。折现率只用在需要折现的地方（均衡服务费、车队持有期账）。
- **利用率一律是能量利用率** ＝ 一年实际充出的电量 ÷（装机功率 × 8,760 小时）≈ 时间利用率 × 功率利用率。市面测算互相打架，多半是混用了这几个口径。

## 一、常规重卡充电站：观测样本一年的账

**样本站**：黄骅港站，26 桩 × 320 kW ＝ 8,320kW（常规直流快充，不是兆瓦超充），总投资 500 万元，月充 112.7 万度、月服务费收入 23.5 万元（src.chargeonline_2026）——少数"投资额、电量、收入"三样都公开、能反查的样本。模型按 600元/kW × 装机 ＝ 499 万元，与披露吻合。

| 成本项 | 取值 | 说明 |
|---|---|---|
| 单位造价 | 600 元/kW | 黄骅港 500 万 ÷ 8,320 kW ＝ 601；充换电研究院问卷单站 150–300 万元、单车位 10–16 万元（src.hdt_charging_report_2026） |
| 设备折旧 | 直线法，(投资 − 残值 5%) ÷ 8年 | 券商模型与重卡站模型两源一致（src.donghai_charging_2024）；液冷 2023 年才规模商用，8 年是外推 |
| 运维 | 投资 × 3.5%／年 | 含设备维保（src.donghai_charging_2024） |
| 场地 | 15万元/年 | 与换电站同口径 |
| 人工 | 26.88万元/年 | 与换电重卡站同口径（双班两人）；部分充电站无人值守，对充电偏保守 |
| 电损 | 电量 × 5% × 谷电价 | 重卡站实测 4%–6% |
| 平台分成 | 基准 0%，压力档 6% | 见下 |
| 容量电费 | 不计 | 政策事实：2030 年前免收（第二节） |

**一年的账**（利用率 22%，服务费按实测中值 0.23元/kWh）：

| 项 | 读数 |
|---|---|
| 年服务费收入 | 369万元/年 |
| 年现金成本 | 83万元/年 |
| 年现金流 | 285万元/年 |
| 全投资现金回报率 | 57% |
| 静态回收期 | 1.7年 |
| 会计口径度电成本（含直线折旧） | 0.089元/kWh |
| 回报率：最闲一档／最忙一档 | 45%／114% |
| 回报率：计平台分成压力档 | 53% |
| 现金打平利用率 | 3.8% |

**平台分成为什么基准取零**：乘用车公共站按服务费给聚合平台抽 10%–20%（src.charge_platform_36kr）；重卡是可识别、可签约的车队，有运营商明说避开线上平台 6% 抽佣、改线下会员卡直收，多个场站自有及合作车队贡献五到六成电量（src.hdt_charging_report_2026）。基准取零＝把有利条件给对手；压力档取重卡场景唯一一条实际报价 6%。华为超充联盟是设备供应商形态，成本已在设备单价里，不叠加。

**一处调和不了的矛盾**：行业口径说重卡充电站盈亏平衡利用率约 15%，本算法的现金打平只要 3.8%。可能原因：投资是否含电力增容（增容占总投资 35%–50%）、样本偏明星站、行业用了时间利用率。两个数都摆着；无论按哪个，实测利用率下都高于打平线——"对手在亏本卖、撑不住"两个口径都不支持。

## 二、兆瓦超充站：贵在哪

**每千瓦造价只放大设备，电力接入不放大**：

```
兆瓦超充每千瓦造价 ＝ 常规站 600 ×（1 ＋ 设备占比 0.40 ×（设备单价倍数 3.0 − 1））＝ 1,080 元/kW
同装机（8,320 kW）的兆瓦超充站投资 ＝ 899万元
```

| 参数 | 取值 | 为什么 | 信源 |
|---|---|---|---|
| 设备单价倍数 | 3.0 | 同一篇报道里的一对数：华为 600 kW 全液冷超充整套约 60 万元（约 1 元/W，对外售价约 0.8 元/W）；同文 120 kW 风冷快充 3–5 万元（0.25–0.42 元/W）→ 2.4–4 倍取中。比例可搬，水平锚在常规站 | src.huawei_lc_price_2023 |
| 设备占比 | 0.40 | 常规重卡站投资里电力部分占 55–65%，其余为设备与土建 | src.zhongmeng_station_cost_2025 |
| 电力接入 | 不放大 | 箱变按每 kVA 计价（2000 kVA 约 50 万元，约 250 元/kVA），功率相同量级相同；兆瓦站要更高配容比、专线，没找到定量来源 | 同上 |

**交叉校验**（不同源，不定档）：本仓库 `业务/换电/定性分析/补能竞争_宁德vs华为.md`——纯超充站（4 × 480 kW 液冷、不含储能）约 260–300 万元 ≈ 1,350–1,560 元/kW，普通快充站（10 × 120 kW）80–100 万元 ≈ 670–830 元/kW，整站约 1.9 倍；本文约 1.8 倍。北川百兆瓦站：18 个 1.44 MW 桩＋108 个 600 kW 桩（约 90.7 MW），投资 1.5 亿元 ≈ 1,650 元/kW，含地、光伏、储能（src.huawei_beichuan_2025）。本文取值在偏低一侧，对换电偏保守。

**站规模怎么定**：兆瓦超充站按与样本站同装机（8,320 kW）算——均衡价按每千瓦造价与利用率算，站多大只影响场地、人工这类固定成本的摊薄；真正决定每度电成本的是利用率（`车队总账_换电对充电.md` 第 3.1 节）。

## 三、容量电费：2030 年前不用交

> **2030 年前对实行两部制电价的集中式充（换）电设施用电免收需量（容量）电费。**——交规划发〔2025〕42 号第（二十一）条（src.mot_energy_2025）

- 这是事实，不是保守假设；同时适用于充电与换电，不构成路线差异。
- 所以电网容量的差异在兑现年之前只通过**建站投资**传导（电力增容占充电站总投资 35%–50%），不通过运营成本。
- 兑现年之后若恢复征收（30元/kVA·月），电网容量差异会重新变成运营成本差异——要跟踪的政策变量。

## 四、换电站：同一套定义一年的账

同一套定义：收入只算服务费（电池租金归电池银行）；投资只含站体（含 4,500 kW 箱变与土建），不含电池；成本逐项与充电站对应。

| 项 | 读数 |
|---|---|
| 单站投资（站体，不含电池） | 500万元 |
| 备注：电池银行放在站里的周转电池 | 242万元（不计入站层投资，也不向站收租） |
| 年服务费收入 | 318万元/年 |
| 年现金流 | 208万元/年 |
| 全投资现金回报率 | 42% |
| 静态回收期 | 2.4年 |
| 单站吞吐相对常规样本站 | 29% |

这里的回报还没扣给电池银行的技术服务费；扣完的站层回报见 `运营收入与成本_口径.md` 第 4 节。

## 五、同价同吞吐：换电站对兆瓦超充站

两边都按超充均衡服务费收、都交出样本站在中性利用率下的年电量，只剩两种站的资产结构在比：

| | 兆瓦超充站（同装机） | 换电站（站层） |
|---|---|---|
| 单站投资 | 899万元 | 500万元 |
| 全投资现金回报率 | 17% | 30% |
| 静态回收期 | 6.0年 | 3.3年 |

- **同价同量，换电站的站层更好**：交出同样多的电，兆瓦超充站要按车来那一刻的功率配满设备与电网；换电站有电池缓冲，箱变一天平稳地充，站体投资更小（电网容量见第六节）。周转电池的钱由电池银行出、靠用户租金回收，不压在站上。
- **所以跟平服务费时，换电站层有富余**：这份富余就是换电在补能这一层的成本优势，通过技术服务费在站与电池银行之间分（`运营收入与成本_口径.md` 第 4 节）。
- **证据等级不同**：常规样本站是公开运营数据；兆瓦超充站是按造价推的；换电站是模型的成熟期假设。

## 六、单站吞吐与站端充电能力

换电站一天交出去的电，要在充电窗口里从电网充回来。按 16 小时充电窗口、站端箱变 4,500 kW 算，**吞吐假设是站端充电能力的 0.91倍**。单站设计能力按"建设成本＋用户等待"最优定为 144 次/日（`车辆与站数_推算方法.md` 2.2 节），吞吐不超过站端充电能力，但贴近上限——再提高单站车次，就要延长充电窗口（夜里也充）或加大箱变。按不超上限的吞吐算：回报率 42%、回收期 2.4年。

**电网容量**：超充对换电的电网容量倍数 2.5倍（超充最忙 1.4倍、最闲 3.0倍）；换电站电网负荷率 61%。

## 七、哪几个数最不牢靠（按重要性排）

| 排序 | 参数 | 为什么不牢靠 | 影响 |
|---|---|---|---|
| 1 | 换电站的单站吞吐假设 | 贴近站端充电能力上限（第五节） | 动摇换电侧单站口径与估值锚 |
| 2 | 行业"15% 盈亏平衡利用率"与本模型的差 | 调和不了（第一节） | 影响"对手多赚"的幅度，不影响方向 |
| 3 | 超充站的实测利用率 | 四个样本，装机按每桩 320 kW 推 | 回报率在最闲与最忙两档之间摆动 |

**没有计入、而会让换电更贵的项**：站内电池的衰减与更换——本节只算一年现金流，没有算第二块电池的钱。这是本对比最大的一处偏向换电的遗漏。
