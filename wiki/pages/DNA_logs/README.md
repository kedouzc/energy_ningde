## 📁 文件说明

### 命名规范
- 文件名格式：`演化纪要_YYYY-MM.md`
- 按月归档，每月一个文件
- 内容按时间倒序排列（最新的在最前面）

### 记录格式

每条思维演化记录包含：
```markdown
### [YYYY-MM-DD HH:MM] [触发问题]

**旧框架瓶颈**：
- 描述旧框架在解决该问题时的不足

**交叉比对得到的洞察**：
- 从哪些资料/概念中获得了启发
- 关键的思维跳跃点

**新框架诞生**：
- 新框架的核心变化
- 与旧框架的差异对比

**思维链**：
[触发问题] -> [旧框架瓶颈] -> [交叉比对] -> [新框架]
```

### 触发条件
当且仅当满足以下条件时才记录：
1. ✅ 用户对某一案例提出了新问题
2. ✅ 该问题导致用户**主动更新**了分析框架
3. ✅ 用户明确确认了框架变更

⚠️ **禁止记录**：
- LLM建议但用户未采纳的框架
- 纯粹的信息补充（非框架级变更）
- 寒暄和无意义的数据堆砌
