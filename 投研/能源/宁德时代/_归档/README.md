## 处理原则

1. **不动** —— 当前所有文件保留原位
2. **不删** —— 旧版本和草稿都保留
3. **不批量重命名** —— 文件名是用户的工作记忆，强制改名会破坏心流

## 何时归档？

只在以下情况才考虑移动文件到 _归档：
- 三个月内未被任何报告引用
- 内容已被新版本完全取代
- 用户明确要求"清理"

**当前 V1.0 报告刚发布，所有旧文件都还有审计价值，暂不归档移动。**
