# 补能路线 · 均衡定价：终局时谁赢哪类车、换电能收多少

> **回答什么**：兑现年（2030 年）终局稳态里，每一类车选哪条补能路线；换电赢下的车，整包价（服务费 ＋ 电池租金）最高能收多少、比自己的成本多出多少（利润厚度）。这是框架第三节第 ③ ④ 步（`补能路线比较_总框架.md`）。
> **服务哪些读数**：换电在可及范围内赢的比例、换电每度电的利润厚度 → 下一步拆成服务费与租金、EBITDA。
> **现状**：程序现算（`src/equilibrium.py`），构建时注入；三档随情景轴走；**不进主链读数**（A5 第二步接入）。
> **来历**：`DECISIONS.md` 2026-09-28m 至 2026-09-28p。

## 一、终局是什么

终局是兑现年大家都建得差不多之后的稳态，同时满足三条：

1. **车队不再换路线**：每辆车用的都是它全年资源账最低的补能方式。
2. **运营商不再进出**：价格刚好覆盖含资本回报的成本；多出来的站在终局前被淘汰或并购。
3. **站数与需求匹配**：每条路线都跑在自己的最优利用率（`补能三路线_供给成本.md` 第六节"最优利用率怎么算"）。

今天充电站只有两成上下的实测利用率，是过渡期的状态，只作敏感性（对换电有利的一侧）。

**车分两类**（研究者 2026-09-28 确认）：
- **封闭短途多班倒**（港口、钢厂、矿山）：车连续运转，没有强制休息；对手有常规快充、兆瓦超充、车队自备轮换。
- **干线**：中途与长途跑的是同一批路、同一批站，只是每天跑的里程不同，合并成一类，按日里程分布逐车比较。干线充电站里各种功率的桩混装，每辆车选对自己最省的桩；常规快充在物理上主要在两头（物流园、场站，夜里慢充）和干线站里的低功率桩。

## 二、算式

```
每一类车按日里程抽样：
  封闭短途：代表里程 260 公里的 60%／80%／100%／120%／140%，五点等权
  干线：400 公里与 650 公里两个代表点各取上面五点，按原场景权重（0.50 与 0.12）合并
每辆车四（三）条路线的全年资源账：车队总账第〇之二节的算法（各路线都按自己的最优利用率）
这辆车选资源账最低的路线
若换电最低：
    整包价上限 ＝ 第二名的全年资源账（第二名在终局只能按成本收）
    利润厚度 ＝ 上限 − 换电自己的资源账（万元/车·年）；每度电 ＝ 利润厚度 ÷ 年用电
换电赢的比例 ＝ 换电最低的那些车的权重之和（这是可及范围内的比例，再乘可及比例才是份额）
```

## 六、价格由谁定、份额多少：交给财务的数

> **状态：待改为分项定价**。本节现为"整包价"算法，与已定判断第 2、3、7 条（服务费跟平、租金取租赁商保本价、分项跟平防套利）不一致，研究者确认后改写（DECISIONS 2026-09-29c）。在此之前本节读数不作结论。

**这一节是均衡层的出口**：财务测算（EBITDA、站数、估值）只从这里取数。

**逻辑**（研究者 2026-09-29）：终局时充电体系内部（常规快充与兆瓦超充）自由竞争，服务费停在它们各自的成本线上；车队在两者之间按全年总账（服务费 ＋ 时间 ＋ 电池）选。换电不自己定价，**跟随充电体系定下的价**：车队付给换电的整包（服务费 ＋ 电池租金）不能高于它走充电的总账。换电的成本比这个价低，差额就是利润；成本高于这个价的车（日里程低、电池摊不薄），换电不服务——这是成本决定的，改定价方式改不了。

**算式**

```
每辆车：车队最省的充电替代 ＝ 常规快充与兆瓦超充里全年资源账低的那条（封闭短途还比车队自备轮换）
       车队愿付给换电的整包价（元/度，不含电费）＝（充电替代的全年资源账 − 换电车自己承担的时间与车端溢价）÷ 年用电
这一类车的价 ＝ 上式按电量加权平均（充电体系在这一类车上的价格水平）
换电服务哪些车 ＝ 自己每度电成本（补能设施 ＋ 电池）低于这个价的车
利润厚度 ＝ 价 − 服务到的车的平均成本
份额（占该类电动重卡）＝ 可及比例 × 可及范围内换电服务到的比例
    可及比例：封闭短途 30%、干线 80%；三档随 [drivers.swap_share_ceiling]
重卡合计份额 ＝ 两类按车类权重（封闭短途 0.38、干线 0.62）加权
```

**怎么用**：
- **进 EBITDA 的是"价 × 换电电量"与"换电成本"**：价里服务费多少、租金多少，不影响系统 EBITDA，只影响换电站与电池银行怎么分钱——住 `运营收入与成本_口径.md` 第 4 节（全景计划 B1）。
- **份额进站数与电量**：份额 × 电动重卡保有 × 每车年用电 → 换电电量 → 站数（`车辆与站数_推算方法.md`）。
- **与现行主链的差别**：现行主链中性份额约六成，整包价按"服务费跟平超充 0.154 元 ＋ 电池租金取对手保本价"，干线折每度电约 0.34 元（含站体与电池的全部回收）；本层中性干线约 0.24 元/度。接入主链时逐项对照（A5 第二步）。
- **待补**：站址来车密度（下一轮）会改变各路线的站规格与最优利用率，进而改变这里的价与份额。

## 七、读法

1. **中性终局**：封闭短途换电全赢，每度电利润厚度 0.049 元；干线换电赢 68% 的车（日里程高的那部分），每度电 0.027 元。价格由谁定、份额多少见第六节。
2. **利润厚度很薄**：每度电几分钱，远低于现行主链按"服务费跟平超充 ＋ 租金取对手保本价"推出的整包利润；接入主链会明显压低 EBITDA——这是下一步要逐项对照的。
3. **悲观终局换电一辆车也赢不了**：电池寿命差小、兆瓦大站、换电站 4 人且设备 300 万、换电底盘贵 3 万同时成立时，资源账上换电处处更贵。
4. **今天的低利用率是换电的上行空间**：若终局前充电站没有出清、利用率停在两成，换电每度电利润厚度升到 0.10 元以上、干线全赢。
