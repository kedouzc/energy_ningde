# 共振决策分析框架 V8.1

> **核心命题**：不论企业家还是投资人，做的所有决定本质上都是投资——决策要怎么投自己的精力、能调动的资源。只有两个视角产生共振，资源才能发挥最大作用，决策才能产生更大能量。
>
> **哲学根基**：知行合一——王阳明"知是行的主意，行是知的功夫；知是行之始，行是知之成"
>
> **操作化表达**：**知行合一 = 主观小场在客观大场中持续运转**——信息流让循环更聪明，能量流让循环改变世界，"一"是循环持续运转的状态
>
> **方法论定位**：以东方哲学为体，西方工具为用

## 二、各层精确定义

### 【基底】客观大场
- **定义**：独立于主观意识存在的底层运行规律，但**呈钟摆式周期运动**，不存在永恒不变的"正确频率"
- **特征**：不可控但可感知；是所有主观行为的约束条件；**周期极端位置比趋势方向更重要**
- **关键认知**：不是"找到共振频率"，而是"识别钟摆位置"
- *（注：霍华德·马克斯《周期》——钟摆永远在极端之间摆动）*
- **可被改变**：客观大场不以人的意志为转移，但可以被行+合的能量输出**局部改变**——改变场的不是信息，而是能量

### 【知】信息×意识耦合
- **定义**：主观感知客观的界面，整个系统的**带宽基础设施 + 偏差校准机制 + 反馈接收端**
- **结构**：信息(客观) × 意识(主观) 的共振
- **带宽三维度**：广度（信息源多样性）、深度（第一性原理拆解）、速度（信息处理与更新速度）
- **偏差校准机制**：事前验尸 / 红队机制 / 外部视角
- *（注：卡尼曼——认知偏差是系统性的，需要制度对抗而非信息堆砌）*
- **特殊角色**：决定系统能否及时感知客观场变化；包含"第二层思维"；包含"战略失谐"判断；**接收合的反馈(ΔE, dE/dt)作为下一轮输入**
- **知-Q：认知相干度**——信息与意识是否同频？认知有没有偏差？

### 【行】物质×力耦合
- **定义**：组织执行的效率界面，**被知触发**后独立运行
- **结构**：物质(Matter, mc²) × 力(Force, pc)
- **双重模式**：运营共振模式（高效对齐、低内耗）/ 战略失谐模式（故意偏离共识、探索边缘）
- *（注：贝佐斯"Day 1"——保持不适应是创新的前提）*
- **行-Q：执行相干度**——物质与力是否匹配？组织有没有内耗？
- **改变客观场的行动端**：行的执行不只是内部效率问题，更是改变客观大场的杠杆点

### 【合】跨界耦合涌现 E²
- **定义**：知和行**共同注入**后跨界耦合的本体——物质和力的耦合产出
- **度量锚定**：E² = (mc²)² + (pc)² —— **思考锚定，不是计算公式**
- **产出**：**ΔE（能量变化量）** 和 **dE/dt（变化速度）**——IRR变化、市场份额变化、估值变化及其速度
- **测量仪表**：观测时空（IRR/市值/份额）← **E的读数，非E本身**
- **交叉验证**：每个决策经过至少三个不同学科视角的交叉验证
- *（注：芒格——多元思维模型；达利欧——概率加权决策）*
- **合-Q：跨界相干度**——战略与执行是否对齐？1+1是否>2？
- **反馈角色**：合的产出有两条出路——①ΔE, dE/dt通过信息反馈回知（信息流）②能量输出到客观大场（能量流），改变客观大场

### 【一】循环持续运转的状态（V8.1核心修正）

- **定义**：**一不是任何一条线，而是整个知→行→合→知循环持续运转的状态。** 循环在转，一就在；循环停了，一就灭。
- **三层含义**：

| 视角 | "一"是什么 | 图上怎么体现 |
|:---|:---|:---|
| 静态看 | 知→行→合→知循环的结构 | 圆环包裹知/行/合 |
| 动态看 | 循环持续运转的状态——回路在转就是一在，回路停就是一灭 | 圆环上的虚线（持续运转的节律） |
| 本体看 | 让知/行/合成为"一件事"的统一性——没有这个统一性，知行合就是三个孤立的动作 | 圆环本身——不是内部任何元素，而是它们之所以能成为整体的那个"一" |

- **两种流**（不是"一"的功能，而是"一"运转时产生的两种流）：

| 流的类型 | 路径 | 内容 | 改变什么 |
|:---|:---|:---|:---|
| **信息流** | 知→行 | 决策指令 | 触发行动 |
| **信息流** | 合→知 | ΔE, dE/dt | 更新认知 |
| **能量流** | 行→合 | 物质×力注入 | 产生涌现 |
| **能量流** | 合→客观大场 | 能量输出 | 改变客观大场 |

- **关键区分**：改变客观大场的是**能量流**（行+合的能量输出），不是信息流（合→知的反馈）。信息流让循环更聪明，能量流让循环改变世界。
- **为什么没有"感知线"**：知感知客观大场的方式，就是通过合→知的信息反馈。ΔE和dE/dt本身就是客观大场变化的度量。客观大场不说话，它只通过你行动后的结果来"回答"你。（马克思：人不行动就认识不了世界 · 毛泽东：你要知道梨子的滋味，就要亲口吃一吃）
- **核心特征**：不要求时时共振，要求失谐后能快速回归；从失谐中获益；反馈速度 > 反馈精度
- *（注：博伊德OODA——比对手更快完成观察-调整-决策-行动；塔勒布——反脆弱）*
- **度量**：循环运转速度 / 信息反馈质量 / 能量输出强度 / 失谐学习收益
- **一-Q：循环运转品质**——循环在不在？信息流通畅吗？能量流够强吗？失谐后能获益吗？

> **核心逻辑（V8.1）**：信息流——知→行（决策指令）+ 合→知（ΔE, dE/dt信息反馈）。能量流——行→合（物质×力注入）+ 合→客观大场（能量输出，改变客观大场）。**一** = 整个循环持续运转的状态——不是任何一条线，而是所有线一起转起来。**人的意识的伟大之处**：主观小场在客观大场中持续运转，通过信息流让循环更聪明，通过能量流改变客观大场。

### 七位思想者的批判与优化

| 思想者 | 支持 | 批判/补充 | 对框架的优化 |
|:---|:---|:---|:---|
| **马克思** | "问题在于改变世界"——支持"改变客观大场" | 改变世界的不是认识（信息反馈），而是实践（行+合的能量输出） | 能量输出线（合→客观大场）与信息反馈线（合→知）分开画 |
| **王阳明** | "知行合一本是一件事"——一不是某条线，而是统一性 | 把知/行/合分成三个再用"一"连起来，已经是"析心与理为二" | "一"用圆环体现，不是任何一条线；框架的分解是工具，不是本体 |
| **毛泽东** | "实践—认识—再实践"——对应循环 | 物质变精神（信息反馈）+ 精神变物质（知→行→合的能量输出）——两条线不同 | 信息流和能量流用不同颜色和线型区分 |
| **普利高津** | 远离平衡态才能创造新秩序 | 创造新秩序的是能量流，不是信息流——信息流是导航，能量流是引擎 | 能量流用粗实线，信息流用细虚线 |
| **维纳** | 反馈回路是控制论的核心机制 | 信息线和能量线是两条不同的线，不能混为一谈 | 严格区分两种流，不把"一"等同于任何一条 |
| **哈耶克** | —— | 客观大场（市场）是自发秩序，无法被设计 | 能量输出只是局部扰动，不是控制；一的最高形态是在自发秩序中找杠杆点 |
| **塔勒布** | —— | "改变客观大场"还是工程师思维——真正的伟大是从无序中获益 | 反脆弱来自行+合的能量暴露，不是来自信息反馈 |

## 三、七步分析流程

> **核心原则**：七个步骤是分析的内容维度——问什么问题。每步顺序推进，每步建在上一步之上。每一步都必须通过知-Q/行-Q/合-Q的诊断，同时从决策者和投资人两个视角展开。一-Q衡量循环持续运转的品质。
>
> **三维结构**：
> - **X轴：分析步骤**——问什么问题（1→7顺序推进）
> - **Y轴：共振诊断**——怎么问（知-Q/行-Q/合-Q，每步都要检验；一-Q衡量循环运转品质）
> - **Z轴：双视角**——谁在问（决策者/投资人，交叉验证，识别烟雾弹）

### 为什么不能把步骤"分配"给某一层？

旧做法（V4及之前）把7个步骤硬塞进知/行/合三层：
- 知层 → 展开1-3（问题界定+需求验证+产业结构）
- 行层 → 展开4-6（战略必要性+能力圈+合作方）
- 合层 → 展开7（概率判断）

这种映射**强行对应、丢失维度**——每个步骤都被阉割了它本应具备的知/行/合/一完整诊断。

以"战略必要性"为例：
- 知-Q：我获取了什么威胁信息？对威胁的认知有没有偏差？
- 行-Q：我采取了什么行动去验证威胁？验证方式有效吗？
- 合-Q：我的"必要性判断"可靠吗？有没有交叉验证？
- 一-Q：合的产出(威胁验证结果)通过信息反馈多快回到知？能量输出能否改变行业格局？循环持续运转的品质如何？

如果硬把"战略必要性"归为"行层"，就丢失了它的知/合维度，也忽略了反馈闭环回路的价值。

## 四、七步展开详细规范

### 展开1：问题界定

**核心问题**：我要判断什么？边界在哪？

**为什么必须存在**：没有边界的分析会无限扩大。分析范围越大，深度越浅，结论越模糊。

**必须回答的四个问题**：

| 问题 | 为什么必须回答 | 不回答的后果 |
|:---|:---|:---|
| **决策类型**：做不做/怎么做/何时做？ | 不同决策类型需要不同深度 | 分析方向跑偏 |
| **时间范围**：1年/3年/10年？ | 判断的时间有效期不同 | 用短期数据做长期判断 |
| **资源约束**：可投入的资金和管理带宽？ | 决定分析的颗粒度 | 算出了需要500亿但只能调动100亿 |
| **不可逆程度**：退出代价多大？ | 决定容错空间 | 把可逆决策当不可逆做，过度谨慎 |

**关卡：战略转折点检测**

在问题界定时，必须检测是否存在战略转折点：
- 行业是否正在发生10倍速变化？（竞争格局/技术/用户行为/供应链/政策）
- 如果是，问题界定本身可能需要重新设定——不是"要不要做"，而是"不做是否还能生存"

*（注：格鲁夫——只有偏执狂才能生存；战略转折点不是你听到炮声的地方，而是你感觉地面在移动的地方）*

**输出格式**：

```
## 展开1：问题界定
### 决策边界声明书
- 决策类型：[做不做/怎么做/何时做]
- 时间范围：___
- 资源约束：___
- 不可逆程度：[高/中/低]，依据：___

### 战略转折点检测
| 维度 | 是否正在发生10倍速变化 | 依据 |
|:---|:---|:---|
| 竞争格局 | _ | _ |
| 技术 | _ | _ |
| 用户行为 | _ | _ |
| 供应链 | _ | _ |
| 政策 | _ | _

### 时间有效期：___
### 确定性等级：[高/中/低]
```

### 展开2：需求验证

**核心问题**：用户真正在买什么？

**为什么是"待办任务"而非"用户需不需要"**：
- 问"用户需不需要换电" → 陷入技术路线之争
- 问"用户的待办任务是什么" → 发现用户真正在买的是"确定性"和"风险转移"

**分析步骤**：

**第一步：待办任务分析**

对每一类用户，回答三个问题：
1. 用户雇佣这个产品，要完成的任务是什么？
2. 现有方案在完成这个任务时的不足是什么？
3. 新方案在完成这个任务上的优势是什么？

**第二步：需求结构分析**

区分不同用户群体的需求差异：按用户类型拆分，每类用户的核心诉求、敏感度排序、市场规模占比。

**第三步：颠覆式创新检验**

- 有没有被过度服务的用户群体？
- 新方案是否可能从这些被过度服务的用户开始，向上生长？
- 需求是否可能被技术变革彻底改变？

**关卡：待办任务 + 颠覆检验**

这两个检验必须通过，否则需求验证不成立：
- 待办任务检验：用户真正在买的，是不是你以为他们在买的？
- 颠覆检验：这个需求会不会被更低端的方案从底部颠覆？

*（注：德鲁克——企业的唯一目的是创造客户；克里斯坦森——颠覆从低端开始）*

**子模块：需求不变性锚点**

区分三类需求属性：
- **基本不变**：如营运车的时间成本永远敏感
- **可能变但方向确定**：如补能速度会提升但不会超过物理极限
- **高度不确定**：如政策变化、用户习惯迁移方向

用不变的锚来验证需求的持久性。

**输出格式**：

```

### 待办任务分析
| 用户类型 | 待办任务 | 现有方案不足 | 新方案优势 |
|:---|:---|:---|:---|
| ... | ... | ... | ... |

### 需求结构
| 用户类型 | 核心诉求 | 敏感度排序 | 市场规模占比 |
|:---|:---|:---|:---|
| ... | ... | ... | ... |

### 颠覆式创新检验
- [ ] 被过度服务的用户群体：___
- [ ] 底部颠覆路径：___

### 需求不变性锚点
| 需求属性 | 类型 | 锚点依据 |
|:---|:---|:---|
| ... | 基本不变/可能变/不确定 | ... |

### 关卡结论
- [ ] 通过待办任务检验
- [ ] 通过颠覆检验
```

### 展开3：产业结构分析

**核心问题**：这个行业允不允许赚钱？护城河深不深？

**为什么必须在需求验证之后**：
- 先确认"有人要买"，再看"能不能赚到钱"
- 否则可能在没人要的市场里算出漂亮的财务模型

**五力分析（波特）**：

| 力量 | 分析要点 | 宁德时代案例 |
|:---|:---|:---|
| **供应商议价能力** | 供应商集中度 / 切换成本 / 向前一体化威胁 | 上游锂矿资源集中，宁德时代有锁价长协 |
| **购买者议价能力** | 客户集中度 / 价格敏感度 / 向后一体化威胁 | 下游车企集中度高，但宁德时代技术壁垒高 |
| **替代品威胁** | 替代方案的性价比 / 切换成本 | 充电 vs 换电 vs 固态电池 |
| **新进入者威胁** | 资本壁垒 / 技术壁垒 / 规模效应 | 高资本投入 + 技术积累 + 规模效应形成壁垒 |
| **现有竞争强度** | 行业增长率 / 退出壁垒 / 产品差异化 | 行业高速增长但竞争激烈 |

**护城河分析（巴菲特/莫宁斯塔）**：

| 护城河类型 | 定义 | 如何识别 | 是否存在 |
|:---|:---|:---|:---|
| **无形资产** | 品牌/专利/牌照 | 能否提价而不流失客户？ | 技术+品牌双护城河 |
| **转换成本** | 切换到竞品的代价 | 客户流失率低？ | B端高转换成本 |
| **网络效应** | 用户越多价值越大 | 是否有梅特卡夫定律效应？ | 换电站网络效应 |
| **成本优势** | 规模/工艺/资源垄断 | 成本曲线低于同行？ | 规模+工艺领先 |

**关卡：五力综合评估 + 护城河深度**

- 五力综合评分：[1-5分]（5=非常有利）
- 护城河深度：[宽/窄/无]
- 如果五力评分<3 且 护城河窄/无 → 进入展开4之前先重新审视需求假设

*（注：波特——产业结构决定盈利上限；巴菲特——护城河决定可持续性）*

```

## 五、双视角共振诊断

### 核心原则

> **一个真实的战略，必然同时满足：决策者在积极推进 + 投资人在真金白银投入。**
>
> **一个虚假的战略（烟雾弹）：要么决策者口头重视但实际没动，要么投资人被忽悠了。**

### 双视角仪表盘

#### 决策者视角仪表盘（Inside-Out）

| 指标类别 | 先行指标 | 含义 | 数据来源 |
|:---|:---|:---|:---|
| **战略推进** | 项目立项数/团队扩张速度/预算执行率 | 内部资源倾斜程度 | 内部管理数据 |
| **技术进展** | 专利申请数/研发投入占比/技术里程碑 | 技术壁垒构建进度 | 研发部门/专利数据库 |
| **市场动作** | 合作签约数/渠道铺设速度/营销活动频次 | 市场拓展力度 | 商务/市场部门 |
| **管理层信号** | 公开讲话频率/战略文件发布/组织架构调整 | 战略优先级信号 | 公开信息/内部消息 |

#### 投资人视角仪表盘（Outside-In）

| 指标类别 | 验证指标 | 含义 | 数据来源 |
|:---|:---|:---|:---|
| **资本行为** | 融资轮次/金额/估值变化/投资方背景 | 资本市场的真实投票 | 融资公告/工商变更 |
| **产业动作** | 产能建设进度/设备采购订单/土地储备 | 重资产投入的真实性 | 产业链调研/公开招标 |
| **合作方态度** | 核心合作伙伴的签约/续约/退出 | 产业链盟友的真实态度 | 合作协议/行业情报 |
| **政策信号** | 补贴政策落地/标准制定参与度/监管态度 | 政策环境的实际友好度 | 政府文件/行业标准 |

### 共振判断矩阵

当决策者视角和投资人视角出现分歧时：

| 决策者视角 | 投资人视角 | 共振判断 | 行动建议 |
|:---|:---|:---|:---|
| 积极推进 | 真金白银投入 | ✅ 真战略，共振 | 跟随，加大配置 |
| 积极推进 | 口头重视但无投入 | ⚠️ 烟雾弹/试探 | 观察，等验证信号 |
| 推进遇阻 | 持续投入 | ⚠️ 战略定力/盲目坚持 | 分析是"定力"还是"沉没成本" |
| 推进遇阻 | 削减投入 | ❌ 战略收缩/放弃 | 重新评估可行性 |

### 信息源规范

**原则：没有不可查证的信息，就没有可信的分析。**

#### 两类合法信息源

| 信息源类型 | 定义 | 引用格式 | 可信度等级 |
|:---|:---|:---|:---|
| **本地知识库** | 项目目录中已人工筛选的可靠信息 | `[判断内容] → 来源：[相对路径]` | **高** |
| **网络搜索** | 通过WebSearch实时搜索的公开信息 | `[判断内容] → 来源：[URL]（[网站名]，[日期]）` | **中** |

**禁止使用的"信息源"**：❌ "行业常识" ❌ "众所周知" ❌ "一般认为" ❌ "据估计" ❌ AI自身训练数据中的模糊记忆

#### 引用标注规则

**规则1**：每个关键判断必须标注来源

**规则2**：推论链中的每一步都必须有锚点——纯逻辑推论不需要数据来源，但推论的起点必须有来源

**规则3**：信息源优先级——本地知识库 > 网络搜索（需≥2个独立来源确认）

**规则4**：每步展开小结必须包含信息源汇总

#### 信息源检索方法

**本地知识库检索**：
1. 使用SearchCodebase工具搜索项目目录
2. **公司级全量RAG**：对分析对象公司所在目录进行全量检索
3. **行业级补充RAG**：对分析对象公司所处的行业目录进行共性内容检索

**网络搜索检索**：
1. 优先搜索：公司官网、监管机构公告、行业协会数据、权威媒体报道
2. 搜索结果需标注URL和访问日期

## 六、动态调谐机制（一的操作化）

> 一 = 循环持续运转的状态。操作化就是：让信息流和能量流持续运转，不断感知、不断改变、不断从失谐中获益。

### 6.1 调谐循环

```
观察(信息流：感知ΔE, dE/dt) → 调整认知 → 再决策(信息流：知→行) → 行动(能量流：行→合) → 能量输出(能量流：合→客观大场) → 反馈(信息流：合→知)
  ↑                                                                                                                              │
  └──────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────┘
```

| 阶段 | 操作 | 流的类型 | 频率 |
|:---|:---|:---|:---|
| **观察** | 监控双视角仪表盘，感知ΔE和dE/dt | 信息流：合→知 | 实时/日/周 |
| **调整认知** | 对比预设假设vs实际，识别认知偏见 | 信息流：知内部更新 | 周/月 |
| **再决策** | 基于新信息调整战略，更新概率加权 | 信息流：知→行 | 月/季 |
| **行动** | 执行调整，物质×力注入 | 能量流：行→合 | 即时 |
| **能量输出** | 行+合的能量涌现改变客观大场 | 能量流：合→客观大场 | 持续 |
| **反馈** | 新的ΔE, dE/dt反馈回知，新一轮观察 | 信息流：合→知 | 持续 |

### 6.2 Day 1触发器

什么情况下必须立即重启整个分析：

| 触发器 | 含义 | 行动 |
|:---|:---|:---|
| 替代方案联盟成员数超临界 | 替代方案可能成行业标准 | 立即召开战略紧急会议 |
| 核心用户选择率<40% | 商业模式不被接受 | 暂停扩张，重新评估价值主张 |
| 核心合作方退出联盟 | 网络效应开始瓦解 | 启动危机公关+替代合作方谈判 |
| 关键成本<临界点 | 竞争优势被抵消 | 加速差异化 |
| 政策强制统一非己方标准 | 标准定义权丧失 | 评估是否加入新标准 |
| 核心指标连续3个月触发警报 | 商业模式不成立 | 暂停新建，优化存量 |

### 6.3 反脆弱设计

| 情景 | 脆弱设计 | 反脆弱设计 | 回路功能 |
|:---|:---|:---|:---|
| 竞争对手成为标准 | 全部押注单一方案 | 兼容设计，可灵活切换 | 从失谐中学习 |
| 颠覆性技术提前量产 | 速度优势消失 | 技术路线储备，模块化接口 | 从失谐中获益 |
| 政策强制非己方标准 | 坚持自有标准被孤立 | 积极参与标准制定 | 在矛盾中推进 |
| 合作方大规模退出 | 网络扩张停滞 | 自建标杆+轻资产加盟双轨并行 | 撬动集体力量 |
| 利用率长期低迷 | 持续亏损拖垮现金流 | 资产证券化出表，隔离风险 | 接受不确定性 |
| **失谐成为常态** | 追求快速回归共振 | **从每次失谐中学习并升级系统** | **反脆弱：越乱越强** |

### 6.4 相干度诊断体系

**相干度** = 各层主客体耦合的共振质量度量。

| 层 | 相干度名称 | 诊断问题 | 高相干度信号 | 低相干度/失谐信号 |
|:---|:---|:---|:---|:---|
| **知-Q** | 认知相干度 | 信息与意识是否同频？ | 认知清晰、决策果断、偏差校准有效 | 认知混乱、反复摇摆、确认偏误严重 |
| **行-Q** | 执行相干度 | 物质与力是否匹配？ | 组织高效、执行力强、内耗低 | 内耗严重、推不动、部门墙高 |
| **合-Q** | 跨界相干度 | 战略与执行是否对齐？ | 结果超预期、正向惊喜 | 结果与预期脱节、1+1<2 |
| **一-Q** | 循环运转品质 | 循环在不在？信息流通畅吗？能量流够强吗？ | 循环持续运转、信息流畅通、能量输出强劲 | 循环断裂、信息阻塞、能量输出微弱 |

**诊断操作**：

```
步骤1：逐层打分（1-10分）
  知-Q = ?  行-Q = ?  合-Q = ?  一-Q = ?

步骤2：识别瓶颈层
  最低相干度层 = 当前最大瓶颈 → 优先投入资源改进

步骤3：检查循环运转（一-Q专项）
  循环是否通畅？→ 信息流速度？→ 能量流强度？→ 失谐后能否恢复运转？

步骤4：交叉验证
  用至少2个独立信息源验证相干度判断

步骤5：制定调谐计划
  针对瓶颈层设计具体改进行动，设定可验证的改进指标

步骤6：循环迭代
  定期（月度/季度）重新诊断，跟踪相干度变化趋势
```

展开1 问题界定 → 决策边界 → 决定哪些指标"在范围内"
展开2 需求验证 → 待办任务 → 决定"需求层"先行指标（使用频次/增长率/NPS）
展开3 产业结构 → 五力+护城河 → 决定"竞争层"先行指标（替代方案联盟/覆盖率）
展开4 战略必要性 → 不可逆点 → 决定"紧迫度"触发器
展开5 能力圈检验 → 财务模型 → 决定"财务层"先行指标（EBITDA/CAC/证券化进度）
展开6 合作方博弈 → 议价能力 → 决定"合作层"先行指标（签约数/适配产品数）
展开7 概率判断 → 绑定指标 → 决定情景概率调整的触发条件
```

每个展开步骤产出的指标，自动成为决策者仪表盘和投资人仪表盘的输入。**不重复、不遗漏**。

## 八、写作规范

1. **开篇前置核心结论**：在文章开头用一段话给出最终判断
2. **每步展开独立成章**：每步独立成章，但要在步骤之间写明逻辑衔接
3. **数据必须标注来源**：所有关键数据必须标注出处，无来源的数据不得写入正文——宁可留空标注"待验证"
4. **判断必须标注确定性和时间有效期**：每个关键判断都要标注确定性等级和时间有效期
5. **回溯必须显式标注**：当某一步的分析导致回溯修正上层假设时，必须显式标注"⚠️ 回溯修正展开X的假设：___"
6. **表格优先**：对比分析尽量用表格，减少大段文字
7. **避免伪精确**：不要给出虚假的精确数字，用区间和量级代替
8. **概率必须绑定指标**：情景概率不能凭空给出，必须绑定可验证的外部指标

## 九、Skill执行规范

### 必须强制执行的内容

- **信息源标注**：每个关键判断和数据必须标注来源
- **展开1问题界定**：不能跳过边界设定直接进入分析
- **展开2待办任务**：不能用"需求验证"替代"待办任务分析"
- **展开3五力+护城河**：不能跳过产业结构直接谈战略必要性
- **展开5粗算→能力圈→精算迭代**：不能跳过能力圈检验直接建精算模型
- **展开7双轨制**：不能只用概率或只用底线
- **双视角共振**：必须同时建立决策者仪表盘和投资人仪表盘
- **动态调谐**：必须嵌入调谐循环和Day 1触发器
- **共振诊断**：每个步骤都必须经过知-Q/行-Q/合-Q的诊断和一-Q的循环运转品质评估，不能只做单维度分析

### 允许灵活调整的内容

- 每步展开的详细程度（取决于决策的不可逆程度）
- 合作方分析的范围（如果业务不需要合作方，展开6可以简化）
- 挑战分析的深度（取决于展开5暴露的能力缺口大小）

### 核心原则

> **"不是给答案，而是确保你问了所有该问的问题。"**
>
> 每一步展开不是一个"结论生成器"，而是一个"问题清单"。框架的价值不在于替你思考，而在于确保你没有遗漏任何一个该思考的维度。

## 十、常见错误与纠正

| 常见错误 | 错误表现 | 纠正方式 |
|:---|:---|:---|
| **把"一"当第四层** | 知/行/合/一并列 | 一是循环持续运转的状态，不是与知/行/合同级的层 |
| **把"一"等同于某条线** | 一 = 反馈回路 / 一 = 能量输出 | 一不是任何一条线，而是所有线一起转起来的状态 |
| **混淆信息流和能量流** | 以为反馈回路能改变客观大场 | 信息流（感知）≠ 能量流（改变），改变场的是行+合的能量输出 |
| **画多余的感知线** | 客观大场→知的单独感知线 | 感知靠行动后的信息反馈，不需要单独的感知线 |
| **步骤归层化** | 把步骤硬塞进知/行/合 | 每步都经历知→行→合的完整循环 |
| **需求静态化** | "用户现在需要，所以未来也需要" | 加入替代方案进化分析 |
| **竞争后置** | 先算账，再看竞争 | 产业结构在展开3就评估 |
| **战略一次性** | "战略必要性确认了，推进" | 建立双视角仪表盘，持续监控 |
| **财务真空化** | 算的是没有竞争的模型 | 加入竞争压缩系数 |
| **合作方被动化** | "谁适合我，就选谁" | "我能给什么不可替代的价值" |
| **概率拍脑袋** | "我觉得有50%概率" | 绑定可验证指标，动态调整 |
| **框架公式化** | 把E²=(mc²)²+(pc)²当计算公式 | 当作思考锚定，管理是实践不是物理 |
| **共振绝对化** | "必须时时与场共振" | 允许战略失谐，保持不适应 |
| **调谐完美化** | "精度比速度重要" | 动态调谐循环速度决定生死 |
| **失谐恐惧化** | "失谐是失败，要快速回归" | 设计从失谐中获益的机制 |
| **单视角陷阱** | 只从决策者或投资人一个视角看 | 双视角共振，识别烟雾弹 |

- **SVG图一重构**：从红紫两条线变为信息流（靛蓝细虚线）+ 能量流（橙色粗实线），"一"用圆环包裹知/行/合体现
- **嵌套结构**：客观大场（最外层）→ 一/圆环（主观小场持续运转）→ 知/行/合（循环内容）
- **一-Q重命名**：从"反馈闭环品质"变为"循环运转品质"
- **七位思想者批判更新**：重点从"一的双重功能"转向"信息流vs能量流的区分"
