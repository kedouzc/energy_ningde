### 宁德时代"超换一体站"单站财务精算报告
**评估基准**：15年运营期，7.5%折现率，不含税（EBITDA及现金流口径）

> **核心方法论**：本报告采用"自底向上"（Bottom-Up）的推导逻辑。所有假设均从物理事实（车辆能耗、电池容量、设备能力）出发，通过数学推导得出运营参数，再叠加商业假设（服务费、租赁费）计算财务结果。**杜绝拍脑袋假设**。

### 第四部分：宁德时代需投入的资金

#### 1. 对标蔚来（NIO Power + 蔚能BaaS）数据交叉验证
*   **蔚来的重资产困境**：合并测算蔚来电站运营与蔚能电池资产，蔚来四代站单站建安造价约150万元，内含23块高成本电池包。由于其长期主要服务于自有品牌中高端私家车，除江浙沪等高密度包邮区核心站点能实现日均50单以上的单站盈利外，全国整体网络日均单量常年徘徊在30~40单区间，承受着巨大的固定资产与电池折旧财务包袱。
*   **宁德时代的财务抗压对比**：
    *   **压力端**：宁德时代的"超换一体站"额外叠加了大功率液冷超充模块，单站综合初始固投略高于纯换电站；且面向大众市场设定的C端价格包（如25#不限里程599元/月）盈利率低于蔚来。
    *   **绝对底气所在**：蔚能需向原厂全资采购电池承担高BOM成本；而宁德时代拥有全球无可匹敌的电芯制造成本控制力，实质上是用**绝对底部的制造成本**对抗第三方的**重资产采购折旧**。

#### 2. 宁德时代资金链极限穿透测试
*   **10万座基建的宏观资金盘口**：
    *   若终局10万座全部由宁德时代独资自建标准"超换一体站"（单站建安含超充桩约180万+标配电池包总资产约80万，合计单站造价约260万），总资金需求将达到 **2600亿元人民币**。
*   **企业现金流承载力**：
    *   **静态底盘**：宁德时代目前存量现金储备高达约 **4000亿元**，且依托全球近40%的动力电池市占率，每年可产生 **超700亿元** 的新增自由现金流（FCF）。从纯数学角度，即使分5年全额自资推进全网建设，每年的资本开支也完全在其自由现金流的安全垫之内。
    *   **商业执行层面的杠杆转移**：如前述战略规划，宁德时代自始至终采用的是**"自持打样+合伙人共建"**架构。时代电服仅需在初期投入数百亿资金完成上万座样板核心站点的自持布局；随后的十万级网络扩展，实质上是打包"技术标准、神行桩设备与巧克力电池池"，吸引地方政府专债、两桶油及社会资本共投共建。
*   **最终结论**：面对这项具有极高战略防御和网络外部性的百年大计，宁德时代无论是自身的静态资金池厚度，还是动态的造血能力与模式杠杆，都完全足以支撑起这套万亿级补能基础生态在初期长达数年的铺设投入与战略性亏损穿透期。

### 第十部分：城市级换电网络模型——从城市到网络

> 之前算的是"单站/多站"的微观模型，现在切换到城市级宏观视角：不是从用户数倒推站数，而是从城市车辆保有量×渗透率推导网络规模。这也符合宁德时代"先铺站再吸引用户"的实际策略。

#### 一、推导逻辑

```
城市汽车保有量
  → × 电动车渗透率 = 电动车保有量
    → × 换电渗透率 = 换电用户总数
      → ÷ 单站服务用户数 = 需要的站数
        → 站设备投入 = 站数 × 205万
        → 周转电池 = 站数 × 20块 × 2.97万
        → 用户电池 = 用户数 × 1块 × 2.97万
        → 总投入 = 站设备 + 用户电池 + 周转电池

用户数（自变量，由市场拓展决定）
  │
  ├─→ 日均换电次数 = 营运用户×0.71 + 私家用户×0.2
  │        │
  │        └─→ 站数 = ⌈换电次数 ÷ 单站容量上限(150次/天)⌉
  │              │
  │              ├─→ 站设备投入 = 站数 × 205万
  │              └─→ 周转电池投入 = 站数 × 20块 × 2.97万
  │
  ├─→ 用户电池投入 = 用户数 × 2.97万
  │
  └─→ 收入 = 租赁费 + 服务费 + 超充 + CCER + VPP

单站服务用户数推导（单工位站，115次/天实际有效值）：
  营运占80% = 92次 → 92÷0.71 = 130个营运用户
  私家占20% = 23次 → 23÷0.20 = 115个私家用户
  单站服务用户数 = 130+115 = 245人
```

#### 九、最终结论

1. **城市级模型的逻辑**：不是"先有用户再建站"，而是"先铺站再吸引用户"（宁德时代策略）。站数由城市车辆保有量×渗透率决定。

2. **重庆现状**：62站，5500用户，利用率47%，IRR -2.3%（无补贴）/ 2.9%（有补贴）。**当前仍在战略性亏损期**，需要1万+用户才能盈亏平衡。邓旭说"换电不是线性生意，密度不够时大家都不敢用，一旦密度跨过阈值，规模效应会突然爆发"。重庆5500辆超出预期，但62站利用率仍只有47%。**密度是前提，但密度本身不等于盈利——还需要足够多的用户把利用率拉上去。**

3. **一线城市5%渗透率**：7.5万用户，308站，总投入30.4亿，IRR 9.5%，**已具备商业可行性**。

4. **IRR与规模无关**：渗透率只影响绝对规模，IRR由单站经济模型决定。县城3站和一线城市300站的IRR相同（约9.5%），但绝对收益天差地别。

5. **宁德的最大优势是电池成本**：0.40元/Wh vs 0.53元/Wh，IRR从9.5%提升到15.7%。这是竞争对手无法复制的护城河。


> **重要修正**：此前城市级模型（analysis_city.py）存在三个错误，已在此版本修正：
> 1. OPEX多算了保险费（0.5%×CAPEX）和营销费（5万/站/年）→ 修正版OPEX仅含4项：电损+人工+租金+维保
> 2. 扣了25%企业所得税 → 修正版用EBITDA口径不扣税
> 3. 电池8年一次性替换 → 修正版按10年折旧
>
> 修正后，重庆62站5500用户+0.2元/度补贴：IRR从2.9%升至12.1%，**确认盈利**，与实际运营情况一致。

#### 十、双版本模型：A版（蔚能模式）vs B版（8年置换）

#### 十一、最终结论

1. **模型修正后重庆确认盈利**：此前OPEX多算保险+营销+所得税，导致IRR被严重压低。修正后重庆62站5500用户+补贴，A版IRR 10.5%，B版IRR 12.4%。

2. **B版IRR始终高于A版约2.3-2.4个百分点**：核心原因是电池降价红利——第8年新电池价格降至0.238元/Wh（vs 初始0.53），净置换支出仅80.9万，远低于初始电池投入691.5万。

3. **A版适合REITs发行**：现金流平稳，无中途大额资本支出，资本市场易理解（仿蔚能模式）。

4. **B版适合自营持有**：捕获电池降价红利，IRR更高，但第8年需要一次性净支出80.9万/站。

5. **宁德的最大优势仍是电池成本**：0.53元/Wh是时代电服独立核算的公允结算价，竞争对手外购价格更高，IRR天然比宁德低。

6. **重庆的启示**：邓旭说"换电不是线性生意，密度不够时大家都不敢用，一旦密度跨过阈值，规模效应会突然爆发"。重庆5500辆超出预期，62站利用率47%仍有盈利空间，**密度阈值已过，用户增长将带来利润非线性放大**。
