# 口径/ —— 每份文档服务哪几个收口读数

> **准入判据**（`交接.md` §5.5，本目录的存废就看这一条）：
>
> **每一份口径文档必须能指名道姓说出「我服务的是报告里的哪几个数」。**
> 说不出来的，它就是按**来源**组织的、不是按**用途**组织的——降级为素材，等章来点名。
>
> 2026-09-11 补齐本表：五份文档一对一挂到 `configs/report_map.toml` 的收口读数上。
> **改口径文档前先查这里**：它服务的读数变了，就是口径变了，要同步改索引表。

## 二、计算层与判断层的分界（2026-09-11 定）

v3.2 §211–816 那条完整链路（车辆数五层漏斗 → 单站能力 → 站数 → CAPEX → 门槛 EBITDA →
可交付 EBITDA → SOTP → 增量价值）在报告里**不是一个整体**，要拆成两层归位：

| 层 | 内容 | 归哪 | 为什么 |
|---|---|---|---|
| **计算层** | 谁由谁算出来、公式与中间量 | **⑥ 决策树下钻**（`tree.py`，166 节点） | 树装得了计算，且能自动派生、不会与代码脱钩 |
| **判断层** | 为什么这么定口径、为什么取这个值不取那个 | **八章正文 + 本目录的文档** | 树装不了判断。例如"站数取反推值而非规划值""辅助服务三项不能相加" |

**这条分界的直接用途**：一页纸只放终端读数，不补完整计算链路（补了就失去"能对账"的
价值）；想看链路的人点下钻，想看"凭什么这么算"的人读正文与口径文档。

## 三、写新口径文档前先答三句

1. 我服务的是**哪几个收口读数**（写 key，不写中文名）？
2. 我论证的是**计算**（怎么算）还是**判断**（为什么这么定）？判断类必须能说出一个
   可观察的推翻条件。
3. 我的数字是**外部信源**（带可点击链接与抓取日期）还是**经验假设**（须显式标注）？

三句答不出来 → 先别建这份文档，它是素材不是口径。

## 四、月度跟踪的数据源口径（2026-09-16 定）

五层漏斗月度数据**不服务报告的收口读数**，服务的是 `configs/base.toml` 里 12 张 `[[watch]]`
中检卡——它们是模型假设的外部验证面（总量/城配/电池份额/重卡单月六张为本轮新增，
决策见 [DECISIONS.md 2026-09-16b](../DECISIONS.md)）。逐月数值的机读口径以
`audit/tracking_hdt.json` 的 `layers[*].caliber` 为准，跨层规则只在这里声明一次：

| 层 | 底稿表（外部 xlsx） | 发布方与统计口径 | 禁用／注意 |
|---|---|---|---|
| **总量** | `Part1_中汽协总量` | 中汽协月度产销，**国内口径，不含出口**（出口在底稿单列） | 含出口数不可填国内销量/渗透率 |
| **乘用车** | `Part2_乘联会乘用车` | 乘联会**零售**；BEV＝零售纯电 | 批发纯电不可用（批发≠终端）；初步统计版不录，只录终稿 |
| **重卡** | `Part3_商用车细分` | 第一商用车网月度，**交强险/上险口径**，含燃气/柴油/新能源/换电/充电拆分 | 不用北斗营运证口径；换电/充电拆分月报惯例 20–26 日发布，未出**留空不猜** |
| **城配物流车** | Part3 同簿（电车资源块） | 电车资源月度，七类物流车型**上险** | 不用厂家批发/销量口径 |
| **电池份额** | `Part4_动力电池` | 动力电池产业创新联盟月度**装车量**＋ CATL 乘用/商用份额 | 装车量≠产量≠装机规划 |

**跨层规则**

1. **双口径并行**：单月值进逐月 series（看边际、服务调仓）；累计与年化
   （＝当年累计 ÷ 已过月数 × 12，抹平季节性）比模型年度假设（看重标）。watch 卡两种 period 都有。
2. **缺月不回填、不插值**：发布方未出即留空，JSON 该点为 null，仪表盘自动断线；
   四个历史手工缺口（2024-10／2024-11／2025-05／2025-10）保持留空。
3. **信源同行**：每行带发布方原文链接（Part3 按 nev/gas/swap/charge 数据块各给；
   Part1/2/4 挂年月格）＋信源台账 id；新数据源先登 [`../audit/信源审计台账.md`](../audit/信源审计台账.md) 再填数。
4. **单位判定按键名**：比率只认键名白名单（`pen`/`share`/`bev_in_nev`/`catl_passenger`/`catl_commercial`），
   其余按万辆/GWh——禁止按数值大小猜单位。
5. **比对两侧都住在卡里**：模型侧＝点路径或 `calc:` 复合值
   （重卡换电加权渗透、城配年化 EV、四池流量总量、全国装车当年值、商用 CATL 份额五个）；
   实测侧＝hdt JSON 的 `layers.<层>.<键>`；阈值/方向（model_high/model_low/either）/周期写卡上，程序只遍历。
