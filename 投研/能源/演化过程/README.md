### 2. 复制模板

- 03_AI回答_[主题].md

- 更新 [[../00_当前状态/当前问题]]（如果问题有更新）

## ⚠️ 重要：不同阶段的模板差异

### 为什么阶段5没有沿用阶段0的模板？

阶段0采用**四档位线性结构**（01框架/02问题/03AI回答/04交叉），适用于：
- ✅ 单次短对话（1-2小时）
- ✅ 框架探索、问题涌现、AI回答可以清晰分离的场景
- ✅ 以"完成一个PBL循环"为目标

阶段5采用**时间线+嵌套结构**（00源头/01v2/02七轮辩论/03总结/04裁决），适用于：
- ✅ 多轮密集辩论（7轮，跨越4天）
- ✅ 每一轮都是完整的"问-答-修正"循环，无法拆分
- ✅ 以"形成可执行SOP"为目标，需要保留完整思维链

### 选择建议（供未来参考）

| 场景 | 推荐模板 | 理由 |
|------|---------|------|
| 单次案例研究（1-2天） | 阶段0模板 | 框架/问题/AI回答可清晰分离 |
| 多轮框架迭代（3天以上） | 阶段5模板 | 时间线能保留思维链连贯性 |
| 有明确裁决决策时 | +04_裁决记录子目录 | 决策资产需要独立索引 |
| 纯理论探讨（无SOP输出） | 阶段5去掉03总结 | 不需要"终点"文档 |

## 演化模式（通用原则）

### DNA双螺旋结构

```
        框架探索（左链）              问题涌现（右链）
              │                            │
              │                            │
    ┌─────────┴─────────┐      ┌───────────┴───────────┐
    │                   │      │                       │
    │ 用框架分析案例    │◄────►│ 发现新问题            │
    │ 深挖框架本质      │      │ 追问问题根源          │
    │ 更新框架定义      │      │ 形成新问题体系        │
    │                   │      │                       │
    └─────────┬─────────┘      └───────────┬───────────┘
              │                            │
              └────────────┬───────────────┘
                           │
                    ┌──────┴──────┐
                    │  交叉演化    │
                    │  （留痕）    │
                    └──────┬──────┘
                           │
              ┌────────────┼────────────┐
              ▼            ▼            ▼
        概念沉淀      案例积累      洞察生成
```

### 关键原则

1. **过程优先**：记录"如何思考"比"思考结果"更重要
2. **双螺旋留痕**：每个交叉点都要记录
3. **即时归档**：讨论中产生的洞察必须在当次会话中记录（不推给"下次再整理"）
4. **Action-Bias**：永远给出"立即可用"版本，而非"待设计"框架
