# 顶部结论

重构动力电池业务基础：摆脱制造业务内卷、切换到更为稳健且高壁垒可持续的资产运营业务，投入有限、财务回报丰厚、风险可控，将带动公司价值重估。

建立动力电池用能标准：推动“电动车用能=CATL换电=便宜+好用”的用户心智达成，固态电池等技术迭代、使用场景拓展（如电动船舶、工业机器人等）会进一步强化 CATL 在动力电池领域的寡头地位，帮助 CATL 建立电池从研发、制造、动力电池使用、退役为储能电池、回收的全生命周期开发利用闭环，形成数据驱动的增长飞轮，进一步打开估值空间。

# 结论卡片

## 必要性

过去是每次招投标竞价卖电池、追求销售利润率，价格战一来净利率就被压。换电之后是**一次绑定、持续收取服务费**——它换掉的不是销量，是**定价方式本身**。

由此得到两个结果：后续更换与增购被锁定（**锁量**），不再逐次竞价（**护价**）。落到钱上：制造线净利率守得住而不用在价格战里下滑，这一条就值{{制造侧增量价值}}。

要分清的是：这一条只解释「为什么必须做」。至于「为什么值得投这么大」（成为能源运营商），那是**上限**问题，不是必要性——见「冲击与重估」一章。

# 口径与信源

以上每个数的口径与出处（改文案时可一并核对，避免"数还在、口径已经换了"）：

- **营运车总规模{{营运车总市场}}**：重卡 + 城配 + 出租 + 网约 + Robotaxi 全口径保有量，取自 `configs/base.toml` 的运营事实字段（`vehicles.*.stock_wan`、`operating_demand.*`），**非模型推导**，故与分子（模型推算的 CATL 换电车辆）相互独立，不构成循环论证。
- **每年{{稳态年更新装机（车端+站内）}}更新订单**：建设期结束后只剩**更新需求**，按更新理论分池计算（Σ 池机队 GWh ÷ 池寿命），**含车端 + 站内**。必须分池是因为倒短池寿命 8.37 年、干线池仅 2.94 年，用单一寿命会抹平干线池的更换频率。分母 644GWh 为 2026E 动力电池出货（`finance` 段）。
- **持股{{建站持股比例}}、估值倍数{{拍定EV/EBITDA倍数:n}}倍**：均为**可调参数**，拖动"CATL持股比例""换电运营 EV/EBITDA 倍数"滑块时本段数字会同步变化。
- **换电站内装机规模{{换电装机保有量站内}}**：占国内储能装机{{站内装机GWh / 最新储能装机}}的**分子只算站内周转电池**（常驻在站、可参与电网调度），**不是**全部在网电池——装在车上跑的那部分不参与电网调节，算进分子会得出大于百分之百的荒谬结果。
- **用户实付用能单价{{重卡用户能源单价}}**：＝ 电费 + 服务费 + 电池租金摊薄；与上面 TCO 里的{{重卡TCO·换电度电(N1)}}同源，是同一口径的两种呈现。
- **重卡用户全成本 TCO**：口径是 **JPM Table 3 的持有期总成本**（购车 − 补贴 + 年运营 × N），不是只算能源；含购车、购置税、补贴、维保、载重损失。公式已用原表反算验证（电动 595,000 + 276,250×8 = 2,805,000，与 Table 3 八年行完全一致）。
  - 换电侧只替换**能源单价**一项：JPM 电动列用 0.85 元/kWh 的工商业充电价 → 换电能源单价 = **谷电采购价 + 峰谷套利价差** = {{用户侧度电用能成本}}（谷电 0.30 + 峰谷价差 0.40，base.toml:815；换电站有峰谷套利收入，该价差必须计入能源真实成本，不能只取谷电价）。再加上服务费与电池租金，用户实付全口径 = {{重卡TCO·换电度电(N1)}}（见上方结论区）。其余（购车/税/补贴/维保/载重损失）照搬 JPM 电动列，保证三者在同一套自洽参数下对照。
  - BaaS 免去的电池购置按**单车带电量 × 模型电池价**计算（当前约 29.5 万元，占 JPM 整车价 70 万的 42%，落在 JPM §8.3"电池占整车 40–50%"区间内），不用 JPM 的 40–50% 估计——因为电池价在模型里是价格曲线参数，要随调参一起变。
  - 单车年增收 4 万元（换电 vs 充电的时间价值，JPM §8.3）已计入。
  - 元/kWh 为**折算值**：三种动力年里程同为 15 万 km，分母同为等效能耗，故可直接并排比较。
