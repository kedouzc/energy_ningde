# _sources/ 存取规则

> **原则**：轻量级存储，AI蒸馏优先

---

## 存什么？

只存"里程碑式"资料：

| 类型 | 示例 | 存储位置 |
|------|------|---------|
| **首次覆盖研报** | 宁德时代首次深度覆盖 | `重量级研报/` |
| **重大事件分析** | 技术突破、政策变化 | `重量级研报/` |
| **行业格局报告** | 年度行业展望 | `重量级研报/` |
| **财报原文** | 年报、季报PDF | `原始数据/` |
| **核心数据** | 产能、装机量数据 | `原始数据/` |

## 不存什么？

常规研报通过AI蒸馏直接融入wiki：

| 类型 | 处理方式 |
|------|---------|
| **定期跟踪报告** | AI阅读 → 提取关键变化 → 更新案例层 |
| **事件点评** | AI阅读 → 提取影响 → 更新洞察层 |
| **市场快评** | AI阅读 → 快速消化 → 不存档 |

---

## AI蒸馏流程

```
新研报
   ↓
AI阅读（Claude/Gemini）
   ↓
提取：
  - 核心观点（3-5条）
  - 关键数据（支撑观点）
  - 与现有认知的差异
  - 思维链（如何得出这些结论）
   ↓
融入wiki对应页面
   ↓
记录思维链到 01_演化过程/
```

### 蒸馏Prompt模板

```markdown
【研报蒸馏】

请阅读附件研报，提取以下信息：

1. **核心观点**（3-5条）
   - 最重要的投资结论
   - 每个观点的支撑逻辑

2. **关键数据**
   - 支撑核心观点的数据
   - 与之前数据的对比

3. **与现有认知的差异**
   - 哪些观点与现有框架一致
   - 哪些观点挑战现有框架
   - 是否需要更新框架

4. **思维链**
   - 作者如何得出这些结论
   - 推理过程是否合理

输出格式：
- 用Markdown格式
- 引用原文关键段落
- 标注数据来源
```

## 命名规范

### 研报
```
[公司]_[日期]_[事件/里程碑].pdf

示例：
- 宁德时代_2026-03-19_首次深度覆盖.pdf
- 储能行业_2026-04-01_年度展望.pdf
```

### 数据
```
[公司]_[年份]_[类型].[格式]

示例：
- 宁德时代_2025_年报.pdf
- 动力电池装机量_2020-2025.csv
```

---

## 存储空间管理

**总容量控制**：< 1GB
**清理周期**：每季度

**清理标准**：
- 已完全消化并融入wiki的研报
- 过时的定期报告
- 重复的数据文件

---

## 与wiki的关联
