# 共振决策分析框架 V5.0

> **核心命题**：不论企业家还是投资人，做的所有决定本质上都是投资——决策要怎么投自己的精力、能调动的资源。只有两个视角产生共振，资源才能发挥最大作用，决策才能产生更大能量。
>
> **哲学根基**：知行合一——王阳明"知是行的主意，行是知的功夫；知是行之始，行是知之成"
>
> **操作化表达**：共振——多层共振界面 + 动态调谐能力
>
> **方法论定位**：以东方哲学为体，西方工具为用

## 二、各层精确定义

### 【基底】客观大场
- **定义**：独立于主观意识存在的底层运行规律，但**呈钟摆式周期运动**，不存在永恒不变的"正确频率"
- **特征**：不可控但可感知；是所有主观行为的约束条件；**周期极端位置比趋势方向更重要**
- **关键认知**：不是"找到共振频率"，而是"识别钟摆位置"
- *（注：霍华德·马克斯《周期》——钟摆永远在极端之间摆动）*

### 【知】信息×意识耦合层 —— 上层基建
- **定义**：主观感知客观的界面，整个调谐系统的**带宽基础设施 + 偏差校准机制**
- **结构**：信息(客观) × 意识(主观) 的共振
- **带宽三维度**：广度（信息源多样性）、深度（第一性原理拆解）、速度（信息处理与更新速度）
- **偏差校准机制**：事前验尸 / 红队机制 / 外部视角
- *（注：卡尼曼——认知偏差是系统性的，需要制度对抗而非信息堆砌）*
- **特殊角色**：决定系统能否及时感知客观场变化；包含"第二层思维"；包含"战略失谐"判断

### 【行】物质×力耦合层 —— 中层执行
- **定义**：组织执行的效率界面，被知触发后独立运行
- **结构**：物质(Matter, mc²) × 力(Force, pc)
- **双重模式**：运营共振模式（高效对齐、低内耗）/ 战略失谐模式（故意偏离共识、探索边缘）
- *（注：贝佐斯"Day 1"——保持不适应是创新的前提）*

### 【合】跨界耦合涌现层 —— 下层耦合
- **定义**：知和行**共同注入**后跨界耦合的本体
- **度量锚定**：E² = (mc²)² + (pc)² —— **思考锚定，不是计算公式**
- **测量仪表**：观测时空（IRR/市值/份额）← **E的读数，非E本身**
- **交叉验证**：每个决策经过至少三个不同学科视角的交叉验证
- *（注：芒格——多元思维模型；达利欧——概率加权决策）*

### 【一】动态调谐能力 —— 跨层调谐（非第四个并列层）
- **定义**：主观小场（知行合）与客观大场（道/趋势/周期）之间的**持续对齐过程**
- **核心特征**：不要求时时共振，要求失谐后能快速回归；从失谐中获益；调谐速度 > 调谐精度
- *（注：博伊德OODA——比对手更快完成观察-调整-决策-行动；塔勒布——反脆弱）*
- **度量**：失谐识别速度 / 回归调整速度 / 失谐学习收益

## 四、七步展开详细规范

### 展开1：问题界定（知层入口）

**核心问题**：我要判断什么？边界在哪？

**为什么必须存在**：没有边界的分析会无限扩大。分析范围越大，深度越浅，结论越模糊。

**必须回答的四个问题**：

| 问题 | 为什么必须回答 | 不回答的后果 |
|:---|:---|:---|
| **决策类型**：做不做/怎么做/何时做？ | 不同决策类型需要不同深度 | 分析方向跑偏 |
| **时间范围**：1年/3年/10年？ | 判断的时间有效期不同 | 用短期数据做长期判断 |
| **资源约束**：可投入的资金和管理带宽？ | 决定分析的颗粒度 | 算出了需要500亿但只能调动100亿 |
| **不可逆程度**：退出代价多大？ | 决定容错空间 | 把可逆决策当不可逆做，过度谨慎 |

*（注：格鲁夫——只有偏执狂才能生存；战略转折点不是你听到炮声的地方，而是你感觉地面在移动的地方）*

### 展开2：需求验证（知层核心）

**核心问题**：用户真正在买什么？

**为什么是"待办任务"而非"用户需不需要"**：
- 问"用户需不需要换电" → 陷入技术路线之争
- 问"用户的待办任务是什么" → 发现用户真正在买的是"确定性"和"风险转移"

**分析步骤**：

**第一步：待办任务分析**

对每一类用户，回答三个问题：
1. 用户雇佣这个产品，要完成的任务是什么？
2. 现有方案在完成这个任务时的不足是什么？
3. 新方案在完成这个任务上的优势是什么？

**第二步：需求结构分析**

区分不同用户群体的需求差异：按用户类型拆分，每类用户的核心诉求、敏感度排序、市场规模占比。

**第三步：颠覆式创新检验**

- 有没有被过度服务的用户群体？
- 新方案是否可能从这些被过度服务的用户开始，向上生长？
- 需求是否可能被技术变革彻底改变？

**关卡：待办任务 + 颠覆检验**

这两个检验必须通过，否则需求验证不成立：
- 待办任务检验：用户真正在买的，是不是你以为他们在买的？
- 颠覆检验：这个需求会不会被更低端的方案从底部颠覆？

*（注：德鲁克——企业的唯一目的是创造客户；克里斯坦森——颠覆从低端开始）*

**子模块：需求不变性锚点**

区分三类需求属性：

- **高度不确定**：如政策变化、用户习惯迁移方向

用不变的锚来验证需求的持久性。

### 展开4：战略必要性（行层入口）

**核心问题**：不做会怎样？拖一年又会怎样？

**防守逻辑（不做会怎样）**：
- 现有核心业务是否受到威胁？

**进攻逻辑（做了能获得什么）**：

### 展开5：能力圈检验（行层核心）

**核心问题**：有没有资格做？能力撑不撑得住？账算不算得过？

**关卡：8维度 + 粗算→精算迭代**

**能力圈8维度**：

| 能力维度 | 对算账的影响 | 算账对该维度的影响 |
|:---|:---|:---|
| **资金能力** | 决定投入规模上限、融资成本 | 算出需要多少钱，才能判断资金缺口 |
| **技术能力** | 决定产品能不能做出来、技术路线成本 | 算出技术投入规模，才能判断技术是否可及 |
| **运营能力** | 决定利用率、服务品质、客户留存 | 算出运营指标要求，才能判断运营缺口 |
| **组织能力** | 决定执行速度、人才密度 | 算出组织规模需求，才能判断人才缺口 |
| **品牌/渠道能力** | 决定获客成本、客户信任度 | 算出获客规模，才能判断渠道是否够用 |
| **生态/关系能力** | 决定合作方撬动难度、资源整合速度 | 算出生态建设投入，才能判断关系缺口 |
| **政策/合规能力** | 决定准入门槛、合规成本 | 算出合规投入，才能判断政策风险 |
| **供应链能力** | 决定成本结构、交付速度 | 算出供应链规模，才能判断供应缺口 |

| 能力维度 | 现有水平 | 所需水平 | 缺口大小 | 补齐方式 | 补齐难度 | 圈内/圈边/圈外 |
|:---|:---|:---|:---|:---|:---|:---|
| ... | ... | ... | ... | ... | ... | ... |

**关键判断**：如果多个核心维度都在"圈外"，这不是"能力缺口"问题，而是"基因错配"问题——基因错配意味着能力圈无法通过投入补齐，只能通过根本性的组织变革解决。

**第三步：精算（详细财务模型）**

在能力圈约束下建立详细财务模型——每个能力维度的约束都映射到模型假设。

**精算内部必须包含**：

**子步骤A：不变性审查**
- 锚点变量（10年不变的东西）→ 模型基础假设

- 情景变量（高度不确定）→ 情景分析

- 间接价值（阻止竞争对手、保护估值逻辑、获取标准定义权）

**估值-资源反馈环**：

```
业务进展好 → 估值上升 → 融资能力增强 → 资金能力扩大

```

### 展开7：挑战路径与概率判断（合层）

**核心问题**：底线在哪？期望多大？

**关卡：底线条件 + 概率绑定指标 + 战略期权**

**为什么必须双轨制**：
- 只用底线思维：知道什么一定不成，但不知道最可能成多大 → 无法决定投入多少
- 只用期望值思维：知道期望回报，但不知道尾部风险 → 可能在最坏情况下翻车
- 两者结合：**底线保生存，期望定节奏**

**第一轨：底线思维**

列出"一定不成的条件"清单——每个条件标注当前逼近度、逼近速度、不可逆临界点。

**一票否决权**：如果任何底线条件逼近度达到"高"，无论期望值多高，都必须降档或暂停。但可通过"战略期权价值"对冲。

**第二轨：期望值思维**

做概率加权情景分析：每个情景的概率必须绑定可验证指标，指标变化时概率自动调整。

**两轨的结合逻辑**：

```
底线条件全部"低"逼近度 → 正常推进，按期望值分配资源
底线条件有"中"逼近度 → 提高警惕，增加监控频率，准备应急预案
底线条件有"高"逼近度 → 一票否决或降档，无论期望值多高
底线条件逼近度从"中"升到"高" → 自动触发概率分布调整（悲观情景概率上调）
```

**子模块：战略期权价值**

即使直接经济回报不确定，还需评估间接价值：阻止竞争对手垄断、保护既有业务估值逻辑、获取标准定义权、建立生态锁定效应。

**挑战-可突破性矩阵**：

| | 可突破（有明确路径） | 难突破（路径不清晰） |
|:---|:---|:---|
| **影响大** | 优先投入资源突破 | 需要创新性解决方案 |
| **影响小** | 正常推进 | 监控即可 |

*（注：塔勒布——底线思维保生存；达利欧——概率判断需绑定可验证指标；芒格——反过来想，总是反过来想）*

**输出格式**：

```
## 展开7：挑战路径与概率判断
### 第一轨：底线思维
| 底线条件 | 当前逼近度 | 逼近速度 | 不可逆临界点 |
```

## 五、双视角共振决策框架

战略决策不是单点分析，而是**内部执行与外部验证的持续共振**。只有两个视角产生共振，资源才能发挥最大作用，决策才能产生更大能量。

### 5.1 双视角仪表盘

**核心逻辑**：每一步展开同时从决策者和投资人两个视角展开，跟踪指标从框架中自然推导。

#### 决策者仪表盘（先行指标）

**目标**：在财务结果显现之前，判断战略推进是否有效。

| 展开步骤 | 对应指标 | 频率 | 警报触发 | 利好触发 |
|:---|:---|:---|:---|:---|
| **展开2 需求验证** | 核心用户使用频次 | 周 | <设计产能的55% | >设计产能的120% |
| | 订阅/会员净增长率 | 月 | 环比<0% | 环比>20% |
| | 用户NPS评分 | 季 | <30分 | >50分 |
| **展开3 产业结构** | 替代方案联盟成员数 | 月 | >临界数量 | 停滞或下降 |
| | 替代方案覆盖率 | 月 | >30% | <15% |
| **展开5 能力圈** | 单点EBITDA利润率 | 季 | <15% | >25% |
| | 资产证券化发行进度 | 即时 | 审批受阻 | 成功发行 |
| | 单位获客成本(CAC) | 月 | 上升>30% | 下降>20% |
| **展开6 合作方** | 合作方适配产品上市数 | 季 | 季度新增<2款 | 季度新增>5款 |
| | 合作方签约数 | 季 | 季度新增<1家 | 季度新增>3家 |
| | 合作方参与意愿指数 | 季 | 下降>20% | 上升>20% |

#### 投资人仪表盘（验证指标）

**目标**：判断"公司说的是不是真的"，识别烟雾弹 vs 真战略。

| 维度 | 指标 | 验证逻辑 | 烟雾弹信号 | 真战略信号 |
|:---|:---|:---|:---|:---|
| **资本配置** | 战略CAPEX占经营性现金流比例 | 真战略会真金白银投入 | 口头重视但CAPEX<5% | CAPEX>15%且持续 |
| | 高管薪酬与战略KPI绑定度 | 真战略会激励相容 | 无绑定或绑定无关指标 | 核心高管奖金与战略指标挂钩 |
| | 融资用途披露 | 看钱到底花在哪 | "补充流动资金" | 明确用于战略网络 |
| **组织信号** | 业务单元独立融资进度 | 真战略会让业务独立造血 | 无独立融资计划 | 引入战投/独立IPO计划 |
| | 核心技术人员流向 | 真战略会吸引人才 | 战略团队核心人员离职 | 竞争对手人才加入 |
| **市场验证** | 战略相关专利申报数 | 真战略会持续投入研发 | 专利数停滞或下降 | 专利数季度增长>10% |
| | 与核心合作方协议的约束性 | 真战略会锁定核心伙伴 | 合作协议无实质约束 | 3年以上排他/优先协议 |
| **外部交叉验证** | 券商研报对战略业务的估值 | 市场是否买账 | 所有研报忽略该业务 | 有研报单独给该业务估值 |
| | 产业链上下游访谈 | 合作方怎么说 | "没听说"或"不看好" | "很重视"且已签约 |
| | 竞争对手对该战略的反应 | 对手最怕什么 | "不评论" | 针对性推出竞品 |

### 5.2 共振判断矩阵

当两个视角的指标出现分歧时，需要深入分析：

| 决策者视角 | 投资人视角 | 共振判断 | 行动建议 |
|:---|:---|:---|:---|
| **积极推进** | **真金白银投入** | ✅ **真战略，共振** | 跟随，加大配置 |
| **积极推进** | **口头重视但无投入** | ⚠️ **烟雾弹/试探** | 观察，等验证信号 |
| **推进遇阻** | **持续投入** | ⚠️ **战略定力/盲目坚持** | 分析是"定力"还是"沉没成本谬误" |
| **推进遇阻** | **削减投入** | ❌ **战略收缩/放弃** | 重新评估战略可行性 |

### 5.3 跟踪指标的推导逻辑

**关键原则**：跟踪指标不是事后附加的，而是从知行合各展开中自然推导出来的。

推导路径：

```
展开1 问题界定 → 决策边界 → 决定哪些指标"在范围内"
展开2 需求验证 → 待办任务 → 决定"需求层"先行指标（使用频次/增长率/NPS）
展开3 产业结构 → 五力+护城河 → 决定"竞争层"先行指标（替代方案联盟/覆盖率）
展开4 战略必要性 → 不可逆点 → 决定"紧迫度"触发器
展开5 能力圈检验 → 财务模型 → 决定"财务层"先行指标（EBITDA/CAC/证券化进度）
展开6 合作方博弈 → 议价能力 → 决定"合作层"先行指标（签约数/适配产品数）
展开7 概率判断 → 绑定指标 → 决定情景概率调整的触发条件
```

每个展开步骤产出的指标，自动成为决策者仪表盘和投资人仪表盘的输入。**不重复、不遗漏**。

## 六、动态调谐机制（一层的操作化）

### 6.1 调谐循环

```
观察 → 调整认知 → 再决策 → 行动 → 反馈
  ↑                                      │
  └──────────────────────────────────────┘
```

| 阶段 | 对应四层 | 操作 | 频率 |
|:---|:---|:---|:---|
| **观察** | 知层带宽检验 | 监控双视角仪表盘，收集一线情报 | 实时/日/周 |
| **调整认知** | 知层偏差校准 + 一层失谐识别 | 对比预设假设vs实际，识别认知偏见 | 周/月 |
| **再决策** | 合层交叉验证 | 基于新信息调整战略，更新概率加权 | 月/季 |
| **行动** | 行层执行 + 一层调谐 | 执行调整，沟通内外部 | 即时 |
| **反馈** | 一层→知层闭环 | 共振结果 → 知的带宽解析 → 下一轮 | 持续 |

### 6.2 Day 1触发器

什么情况下必须立即重启整个分析：

| 触发器 | 含义 | 行动 |
|:---|:---|:---|
| 替代方案联盟成员数超临界 | 替代方案可能成行业标准 | 立即召开战略紧急会议 |
| 核心用户选择率<40% | 商业模式不被接受 | 暂停扩张，重新评估价值主张 |
| 核心合作方退出联盟 | 网络效应开始瓦解 | 启动危机公关+替代合作方谈判 |
| 关键成本<临界点 | 竞争优势被抵消 | 加速差异化 |
| 政策强制统一非己方标准 | 标准定义权丧失 | 评估是否加入新标准 |
| 核心指标连续3个月触发警报 | 商业模式不成立 | 暂停新建，优化存量 |

### 6.3 反脆弱设计

| 情景 | 脆弱设计 | 反脆弱设计 |
|:---|:---|:---|
| 竞争对手成为标准 | 全部押注单一方案 | 兼容设计，可灵活切换 |
| 颠覆性技术提前量产 | 速度优势消失 | 技术路线储备，模块化接口 |
| 政策强制非己方标准 | 坚持自有标准被孤立 | 积极参与标准制定 |
| 合作方大规模退出 | 网络扩张停滞 | 自建标杆+轻资产加盟双轨并行 |
| 利用率长期低迷 | 持续亏损拖垮现金流 | 资产证券化出表，隔离风险 |
| **失谐成为常态** | 追求快速回归共振 | **从每次失谐中学习并升级系统** |

### 6.4 相干度诊断体系

**相干度** = 各层主客体耦合的共振质量度量。

| 层 | 相干度名称 | 诊断问题 | 高相干度信号 | 低相干度/失谐信号 |
|:---|:---|:---|:---|:---|
| **知-Q** | 认知相干度 | 信息与意识是否同频？ | 认知清晰、决策果断、偏差校准有效 | 认知混乱、反复摇摆、确认偏误严重 |
| **行-Q** | 执行相干度 | 物质与力是否匹配？ | 组织高效、执行力强、内耗低 | 内耗严重、推不动、部门墙高 |
| **合-Q** | 跨界相干度 | 战略与执行是否对齐？ | 结果超预期、正向惊喜 | 结果与预期脱节、1+1<2 |
| **一-Q** | 全系统相干度 | 系统与场是否合拍？ | 趋势朋友、乘风而起 | 逆势而行、越努力越亏 |

**诊断操作**：

```
步骤1：逐层打分（1-10分）
  知-Q = ?  行-Q = ?  合-Q = ?  一-Q = ?

步骤2：识别瓶颈层
  最低相干度层 = 当前最大瓶颈 → 优先投入资源改进

步骤3：交叉验证
  用至少2个独立信息源验证相干度判断

步骤4：制定调谐计划
  针对瓶颈层设计具体改进行动，设定可验证的改进指标

步骤5：循环迭代
  定期（月度/季度）重新诊断，跟踪相干度变化趋势
```

## 七、信息源规范

**原则：没有不可查证的信息，就没有可信的分析。**

### 两类合法信息源

| 信息源类型 | 定义 | 引用格式 | 可信度等级 |
|:---|:---|:---|:---|
| **本地知识库** | 项目目录中已人工筛选的可靠信息 | `[判断内容] → 来源：[相对路径]` | **高** |
| **网络搜索** | 通过WebSearch实时搜索的公开信息 | `[判断内容] → 来源：[URL]（[网站名]，[日期]）` | **中** |

**禁止使用的"信息源"**：❌ "行业常识" ❌ "众所周知" ❌ "一般认为" ❌ "据估计" ❌ AI自身训练数据中的模糊记忆

### 引用标注规则

**规则1**：每个关键判断必须标注来源

**规则2**：推论链中的每一步都必须有锚点——纯逻辑推论不需要数据来源，但推论的起点必须有来源

**规则3**：信息源优先级——本地知识库 > 网络搜索（需≥2个独立来源确认）

**规则4**：每步展开小结必须包含信息源汇总

### 信息源检索方法

**本地知识库检索**：
1. 使用SearchCodebase工具搜索项目目录
2. **公司级全量RAG**：对分析对象公司所在目录进行全量检索
3. **行业级补充RAG**：对分析对象公司所处的行业目录进行共性内容检索

**网络搜索检索**：
1. 优先搜索：公司官网、监管机构公告、行业协会数据、权威媒体报道
2. 搜索结果需标注URL和访问日期

## 八、写作规范

1. **开篇前置核心结论**：在文章开头用一段话给出最终判断
2. **每步展开独立成章**：每步独立成章，但要在步骤之间写明逻辑衔接
3. **数据必须标注来源**：所有关键数据必须标注出处，无来源的数据不得写入正文——宁可留空标注"待验证"
4. **判断必须标注确定性和时间有效期**：每个关键判断都要标注确定性等级和时间有效期
5. **回溯必须显式标注**：当某一步的分析导致回溯修正上层假设时，必须显式标注"⚠️ 回溯修正展开X的假设：___"
6. **表格优先**：对比分析尽量用表格，减少大段文字
7. **避免伪精确**：不要给出虚假的精确数字，用区间和量级代替
8. **概率必须绑定指标**：情景概率不能凭空给出，必须绑定可验证的外部指标

## 九、Skill执行规范

### 必须强制执行的内容

- **信息源标注**：每个关键判断和数据必须标注来源
- **展开1问题界定**：不能跳过边界设定直接进入分析
- **展开2待办任务**：不能用"需求验证"替代"待办任务分析"
- **展开3五力+护城河**：不能跳过产业结构直接谈战略必要性
- **展开5粗算→能力圈→精算迭代**：不能跳过能力圈检验直接建精算模型
- **展开7双轨制**：不能只用概率或只用底线
- **双视角共振**：必须同时建立决策者仪表盘和投资人仪表盘
- **动态调谐**：必须嵌入调谐循环和Day 1触发器

### 允许灵活调整的内容

- 每步展开的详细程度（取决于决策的不可逆程度）
- 合作方分析的范围（如果业务不需要合作方，展开6可以简化）
- 挑战分析的深度（取决于展开5暴露的能力缺口大小）

### 核心原则

> **"不是给答案，而是确保你问了所有该问的问题。"**
>
> 每一步展开不是一个"结论生成器"，而是一个"问题清单"。框架的价值不在于替你思考，而在于确保你没有遗漏任何一个该思考的维度。

## 十、常见错误与纠正

| 常见错误 | 错误表现 | 纠正方式 |
|:---|:---|:---|
| **需求静态化** | "用户现在需要，所以未来也需要" | 加入替代方案进化分析 |
| **竞争后置** | 先算账，再看竞争 | 产业结构在展开3就评估 |
| **战略一次性** | "战略必要性确认了，推进" | 建立双视角仪表盘，持续监控 |
| **财务真空化** | 算的是没有竞争的模型 | 加入竞争压缩系数 |
| **合作方被动化** | "谁适合我，就选谁" | "我能给什么不可替代的价值" |
| **概率拍脑袋** | "我觉得有50%概率" | 绑定可验证指标，动态调整 |
| **框架公式化** | 把E²=(mc²)²+(pc)²当计算公式 | 当作思考锚定，管理是实践不是物理 |
| **共振绝对化** | "必须时时与场共振" | 允许战略失谐，保持不适应 |
| **调谐完美化** | "精度比速度重要" | 动态调谐循环速度决定生死 |
| **失谐恐惧化** | "失谐是失败，要快速回归" | 设计从失谐中获益的机制 |
| **单视角陷阱** | 只从决策者或投资人一个视角看 | 双视角共振，识别烟雾弹 |
