### 电池容量计算
1. **核心定义区分**
   - **Ah（安时）**：容量单位，代表电芯/电池系统的存电能力，是电芯出厂的核心标定参数；宁德时代587Ah、海辰587Ah均为单颗储能级大电芯的出厂标定容量。
   - **kWh（度电）**：电量单位，计算公式为「电量=标称电压×容量」，是整车电池包、储能系统的核心计价与性能参数。

2. **电芯容量非整数的核心原因**
   电芯容量是**材料体系+电芯尺寸+极片涂布密度+工艺良率+安全降额系数**共同计算得出的客观最优值，强行调整为整数会导致两个问题：一是阉割容量，浪费内部空间与材料，降低能量密度；二是超设计值扩容，牺牲安全冗余、循环寿命与电芯一致性，提升热失控风险。

3. **单电芯容量的决定逻辑**
   通用核心公式：**电芯容量=极片活性物质总面积×材料克容量×工艺良率×安全降额系数**
   - 体积天花板：电芯的物理尺寸决定了内部可用空间上限，尺寸越大、层数越多，容量上限越高
   - 材料密度：正极材料的克容量、极片涂布厚度，决定了单位空间内的活性物质总量，是容量密度的核心决定因素

4. **电池系统的层级关系（从小到大）**
   单电芯 → 电池模组（多颗电芯串并联） → 电池包（多模组集成+BMS/热管理，适配整车） → 储能集装箱/大柜（多电池包集成，适配储能电站）
   
5. **下游需求的逆向拆解逻辑（车企/储能电站→电芯）**
    - 第一步：确定总需求目标
    例：储能电站单柜总电量1MWh、纯电整车电池包总电量70kWh
    - 第二步：确定系统电压平台
    乘用车主流400V/800V高压平台、储能主流1500V直流平台，电压平台决定电芯的串联数量
    - 第三步：选定单电芯规格
    结合成本、性能、供应链，选定单电芯的容量、电压、尺寸，计算需要并联的电芯数量，补足总容量需求
    - 第四步：系统集成落地
    完成电芯串并联组合，配套BMS电池管理系统、液冷热管理、消防、结构件，最终形成可装车/落地的电池系统

### 技术参数 → 财务数据的桥接逻辑

电池制造的核心，是把"材料"变成"电量"，再把"电量"变成"收入"。本节以**对比形式**讲解储能与动力电池的技术逻辑异同。

#### 1. 电压参数对比：为什么储能1500V、电动车800V？

| 对比维度 | 储能系统 | 电动汽车 |
|---------|---------|----------|
| **系统电压** | 1500V DC（直流大型电站母线） | 400V/800V/1000V DC（车载平台） |
| **电压来源** | 来自光伏行业标准（国际低压定义：直流1500V以下） | 车载平台演进：400V→800V→1000V |
| **电芯标称电压** | LFP：3.2V | NCM：3.65V |
| **电芯满充电压** | LFP：3.65V | NCM：4.2V |
| **电芯终止电压** | LFP：2.5V（可放至0%） | NCM：3.0V（建议不放空） |
| **与新能源关系** | 光伏直流直连储能（直流耦合），风电交流需整流（交流耦合） | 车载自成一系：电池直流→电机交流 |
| **不匹配后果** | 能量需额外转换，效率降2-3% | 无此问题 |

**为什么储能主要和光伏匹配，而不是风电？**

| 新能源类型 | 发电形式 | 储能的接入方式 | 对储能的影响 |
|-----------|---------|--------------|-------------|
| **光伏** | 直流（DC） | 可以直流侧直连（直流耦合），效率高 | 直流耦合损耗约1-2% |
| **风电** | 交流（AC）同步发电机 | 必须先整流再接入储能（交流耦合） | 整流损耗约2-3%，成本更高 |

**风电对储能同样重要**：
- 风电发电波动性比光伏更大（风速不稳定）
- 储能可以平抑风电功率波动，提高并网稳定性
- 风电+储能项目越来越多（如内蒙古、新疆的风储一体化项目）

**电压演进逻辑（储能）**：
```
电压↑ → 电流↓ → 线缆更细 ↓ → 损耗↓ → 效率↑ → 成本↓
电压：600V → 1000V → 1500V（当前主流） → 2000V（未来）
效率：~82%    ~85%     90%+                更高
```

**为什么1500V是当前主流？**
- 光伏行业已从1000V转向1500V，储能需与光伏系统匹配
- 1500V储能系统可减少PCS数量、降低线缆成本、提升系统效率
- GGII预测：2025年国内1500V及以上储能系统占比突破60%

**为什么储能要和光伏匹配？**
- 光储一体化是趋势：光伏直流发电→储能直流存储→电网交流输送
- 储能系统和光伏共享PCS（储能变流器），电压必须匹配

#### 2. 锂电池电压参数详解（不同材料对比）

**三种电压的定义**：

| 电压类型 | 定义 | LFP值 | 三元值 |
|---------|------|-------|-------|
| **标称电压** | 正常工作时的参考电压 | 3.2V | 3.65V |
| **满充电压** | 充到100%时的最高电压 | 3.65V | 4.2V |
| **终止电压** | 放完电时的最低电压（不得低于此值） | 2.5V | 3.0V |

**终止电压的意义**：低于终止电压继续放电会损伤电芯，导致容量不可逆衰减。类比手机"低电量自动关机"。

**为什么不同材料的电压参数不同？**

由正极材料的化学特性决定（负极都是石墨）：

| 材料 | 正极材料 | 标称电压 | 满充电压 | 终止电压 | 主要应用 |
|------|---------|---------|---------|---------|---------|
| 磷酸铁锂 | LiFePO₄ | 3.2V | 3.65V | 2.5V | 储能、公交 |
| 三元锂 | NCM/NCA | 3.65V | 4.2V | 3.0V | 乘用车、高端 |
| 锰酸锂 | LMO | 3.7V | 4.2V | 3.0V | 工具、低端 |
| 钴酸锂 | LCO | 3.7V | 4.2V | 3.0V | 手机、笔记本 |

**LFP可以100%充放电，三元建议≤90%**：LFP满充电压3.65V副反应少，三元4.2V副反应剧烈。

**骁遥双核电池**：通过BMS软件标定不同的SOC-电压曲线，硬件同一套可兼容不同材料电芯。

#### 3. 电芯容量确定：储能反推、动力正推

**设计逻辑对比**：

| 设计逻辑 | 储能电池 | 电动汽车电池 |
|---------|---------|------------|
| **设计方法** | **反推法**：45吨限重 → 集装箱尺寸 → 确定单芯容量 | **正推法**：续航目标 → 所需电量 → 电池包设计 |
| **核心约束** | 集装箱尺寸（20尺：6.1m×2.4m×2.9m）+ 海运重量（第9类危险品限重≤45吨） | 整车重量 + 续航里程 + 底盘空间 |
| **容量演进** | 280Ah→314Ah→587Ah（越来越大） | 50Ah→100Ah→200Ah（专为高端定制） |

**储能587Ah反推逻辑**：
```
目标电量：6.25MWh = 6250kWh
约束1：电压 1500V ÷ 3.65V = 411颗/串（固定）
约束2：重量 ≤45吨
约束3：尺寸 ≤20尺集装箱
    ↓
反向推导 → 单芯容量必须约587Ah
```

**电动车电池正推逻辑（麒麟125kWh）**：
```
目标续航：1000km，百公里电耗15kWh
    ↓
所需电量 = 15 × 10 = 150kWh → 取125kWh（留余量）
    ↓
麒麟电池能量密度280Wh/kg
电池包重量 = 125000 ÷ 280 ≈ 446kg ✓
```

**为什么是"有零有整"？**
- 280Ah：280是2的N次方×105，便于串并联计算
- 314Ah：在280基础上优化，提升能量密度
- 587Ah：通过多目标优化算法，考虑五重边界后的最优解

#### 4. 重量与能量密度：储能"够用就好"、动力"追求极致"

**核心公式**：
```
电芯重量 = 电量(Wh) ÷ 能量密度(Wh/kg)
```

**储能与电动汽车对比**：

| 对比维度 | 储能电池 | 电动汽车 |
|---------|----------|----------|
| **能量密度** | ~190 Wh/kg（够用就行，追求低成本） | **280 Wh/kg+**（麒麟三元），减重=高端 |
| **主要材料** | LFP（成本低、安全、寿命长） | 高端用NCM（能量密度高） |
| **循环寿命** | 6000-10000次（年均500-1000次循环） | 1500-3000次（年均约200次） |
| **设计哲学** | LCOE最优：全生命周期成本最低 | 续航+轻量化：用户感知价值最高 |

**587Ah电芯重量计算示例**：
| 参数 | 数值 |
|------|------|
| 电芯容量 | 587Ah |
| 标称电压 | 3.2V |
| 电芯能量 | 587 × 3.2 = **1878Wh** |
| 能量密度 | 约190 Wh/kg（LFP储能电芯） |
| 电芯重量 | 1878 ÷ 190 ≈ **9.9kg** |

**6.25MWh集装箱重量验证**：3288颗×9.9kg + 12.5吨结构件 ≈ **45吨** ✓

**电动车减重100kg只省1.5度电，这笔账划算吗？**

| 视角 | 分析 |
|------|------|
| **用户省电视角** | 100kg减重→省1.5度电/百公里→家充电0.5元/度→年省150元→10年省1500元 |
| **但车价贵2万** | 10年都省不回来！对家用车确实不划算 |
| **车企视角不同** | 续航门槛、补贴政策、竞品压力，品牌溢价 → 减重是产品力的一部分 |

**高端vs经济型电动车的设计取舍**：

| 车型定位 | 电池选择 | 能量密度 | 续航 | 理由 |
|---------|---------|---------|------|------|
| 25万以上高端 | NCM三元 | 280Wh/kg | 1000km+ | 宁德CTO："用LFP就是变相减配" |
| 10-20万经济型 | LFP铁锂 | 180Wh/kg | 400-600km | 成本低、寿命长、安全性好 |
| 换电车型 | 兼容双材料 | 自适应 | 等价替换 | 用户不拥有电池，只关心续航 |

**动力电池技术路线对比**：

| 厂商 | 技术路线 | 能量密度 | 续航能力 | 快充 | 主要客户 |
|------|---------|---------|---------|------|---------|
| 宁德时代 | 麒麟电池（三元） | **280Wh/kg** | 1000km+ | 6分钟充满 | 特斯拉、理想、蔚来 |
| 比亚迪 | 刀片电池（LFP） | 180Wh/kg | 715km | 5分钟充70% | 比亚迪全系 |
| 特斯拉 | 4680大圆柱 | 300Wh/kg | 600km+ | 15分钟充50% | 特斯拉 |
| 蔚来 | 半固态电池 | 360Wh/kg | 930km | - | 蔚来 |

#### 5. 充放电倍率（C-rate）：4C是什么意思？

**C的定义**：充电电流与电池容量的比值
```
C = 充电电流(A) ÷ 容量(Ah)
1C = 1小时充满；4C = 15分钟充满；10C = 6分钟充满
```

| C倍率 | 充满时间（以100kWh电池为例） | 典型应用 |
|------|----------------------------|--------|
| 1C | 60分钟 | 基本要求 |
| 2C | 30分钟 | 普通快充 |
| 4C | 15分钟 | 麒麟电池：10-80%仅需6-8分钟 |
| 10C | 6分钟 | 极致快充（实验室水平） |

**C倍率受什么限制？**电芯发热、锂离子迁移速度、电解液分解、负极嵌入速度。

| 参数 | 数值 | 说明 |

#### 8. 技术参数 → 财务数据的桥接

以上技术参数如何转化为财务数据？核心桥梁是**元/kWh**：

```
电芯售价（元/kWh）
    ↓
电芯成本（元/kWh）= 材料成本 + 制造成本
    ↓
单位毛利润 = 售价 - 成本
    ↓
销量（GWh）× 单位毛利润 = 总毛利润
```

**宁德时代2025年实际数据验证**：

| 业务 | 售价 | 成本 | 毛利率 |
|------|------|------|--------|
| 动力电池 | 0.59元/Wh | 0.44元/Wh | 23.84% |
| 储能电池 | 0.52元/Wh | 0.38元/Wh | 26.71% |

#### 9. 动力 vs 储能：两种不同的技术→财务桥接路径

**动力电池：Wh/kg → 成本摊薄 → 盈利优势**
```
重量能量密度(Wh/kg) ↑ → 同样原料产出更多kWh → 单位成本↓ → 盈利更强
```

宁德时代麒麟电池Wh/kg行业领先 → 同等成本下售价更高 or 同等售价下成本更低 → 毛利率23.84%

**储能电池：循环寿命 → LCOE → 售价溢价**
```
循环寿命 ↑ → 全生命周期充放电量↑ → LCOE↓ → 可卖更高价
```

宁德时代储能循环寿命15000次 → LCOE优势明显 → 售价溢价能力强 → 毛利率26.71% > 动力

**结论**：储能毛利率高于动力，本质是"循环寿命溢价"在储能赛道比"能量密度溢价"在动力赛道更被客户认可。

#### 10. 产能调配决策：元/kWh净利润的运筹优化

当两种电池共用产线时（磷酸铁锂产线可同时生产动力和储能电芯），决策依据是：

```
储能元/kWh净利润 > 动力元/kWh净利润 → 产能紧张时优先接储能订单
```

2025年Q3/Q4宁德时代产能满载 → 主动选择高毛利储能订单 → 储能业务同比增长30%、毛利率26.71%
