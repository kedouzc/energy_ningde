# Step 1：全行业底层需求及约束分析 — 结构化工作流

> **定位**：8步工作流第1步。核心功能 = 解码客观大场，识别行业底层需求 + 硬约束 + 默认模式坍塌推演。
> **分形角色**：【知】解码客观大场——提取行业运行的隐藏秩序。
> **设计原则**：从硬约束而非用户欲望出发，把政策法规、技术物理、社会认知当成生死线而非背景板。
> **人机分工**：分析起点、边界、核心问题链由人工给定（AI不能代劳），AI负责按工作流执行推演。

### 人机交互规则

1. **阶段之间串行**：每阶段完成后，人工必须审核确认，才能进入下一阶段
2. **阶段内部可多轮交互**：一个阶段内部可能需要多轮AI交互（初始输出→人工批判→修正→确认）
3. **关键问题由人工确认**：每阶段的关键问题可以由AI提议，但必须由人工确认或修改
4. **每阶段输出记录**：记录初始输出、人工批判点、修正后输出、最终确认结论

## 二、输入输出契约

### 输入（人工给定，第一步无上游）

| 输入项 | 内容 | 说明 |
|:---|:---|:---|
| 分析对象 | [行业名称，如：动力电池行业（车场景）] | — |
| 分析起点 | [不变的事实+对比参照] | 这个事实不会因技术变化而改变；对比参照帮助锚定差异 |
| 分析边界 | [聚焦什么、不聚焦什么] | 明确"看什么、不看什么" |
| 核心问题链 | [从起点出发的逻辑顺序提问] | 由裁判掌控，AI不自主衍生 |

**输入示例（人工填写）**：

| 输入项 | 示例内容 |
|:---|:---|
| 分析对象 | 动力电池行业（车场景应用） |
| 分析起点 | 电池是可以标准化的储能体，会衰减（非线性，到一定循环后加速）。对比：发动机是机械动力源，与底盘传动深度耦合，不好分拆，各车型间不通用。电池是电气接口，标准化门槛更低，不同车之间可以换。 |
| 分析边界 | 只讨论车用动力电池；聚焦电池作为车的动力源的功能定位；对比电池和发动机在车上的本质差异（不变的）；所有后续维度（政策约束、技术演进、用户需求、社会需求等）都是围绕这个核心功能实现推导出来的。不从企业角度分析。 |
| 核心问题链 | ①电池和发动机作为车的动力源，本质差异是什么（不变的）？→②车和电池正在发生什么变化（变化的，从人的需求/社会需求/政策约束/技术演进/产业链格局等多维度穷举）？→③这些不变和变化催生了哪些需求？→④哪些需求是长坡厚雪的？→⑤行业的硬约束（生死线）是什么？ |

### 核心回答3个问题

1. 电池作为车的动力源，哪些本质是不变的？什么是深层变化的（结构性判断，而非现象穷举）？
2. 不变×变化产生什么张力？这些张力催生了哪些底层需求？哪些是长坡厚雪的？
3. 行业的硬约束（生死线）是什么？当前默认模式在硬约束下会坍塌吗？

### 禁止做的事

- 禁止做企业层面的能力盘点（那是Step 2的职责）；
- 禁止做战略方向判断（那是Step 2的职责）；
- 禁止做具体业务拆解（那是Step 3的职责）；
- 禁止做单业务深度分析（那是Step 4-7的职责）；
- 禁止AI自主设定分析起点和边界（这是人工职责）。

### 输出物

按《8步工作流标准输入输出规范》中Step 1标准输出模板输出。

## 三、各阶段详细定义与Prompt

### 阶段0：本质锚定（前置）

**目标**：基于人工给定的起点和边界，锚定"不变的"本质维度 + 提炼"变化的"深层结构性判断。不做现象穷举。

**人机分工**：
- "不变的"维度：AI从分析起点推导，人工审核
- "变化的"深层判断：**人工主导提出**（这是认知锚点，决定整个Step1的认知天花板，AI不能代劳），AI负责结构化整理+苏格拉底式追问挑战
- 具体变化现象的展开：不在本阶段做，留待阶段1张力解码中按需引入

**Prompt**：
```
【角色】你是行业分析师，服务于投研团队。

【任务】基于人工给定的分析起点和边界，锚定"不变的"本质维度，并整理人工提出的"变化的"深层结构性判断。

【输入】
- 分析对象：[人工填入]
- 分析起点（不变的事实+对比参照）：[人工填入]
- 分析边界：[人工填入]
- 核心问题链：[人工填入]
- 人工给出的"变化的"深层结构性判断：[人工填入——认知锚点，AI不能代劳]

【要求】
1. "不变的"维度（AI推导，人工审核）：
   从分析起点出发，哪些本质属性不会因技术变化而改变？
   参考维度（不限于）：
   - 物理本质（如：电池是储能体，可充放）
   - 衰减规律（如：电池非线性衰减）
   - 标准化潜力（如：电池电气接口可标准化）
   - 物理定律约束（如：能量守恒、热力学第二定律）
   每个维度标注：与核心功能的关系、是否在边界内。

2. "变化的"深层结构性判断（人工主导，AI整理+追问）：
   - 将人工提出的深层判断结构化整理
   - 追问：这些判断的证据支撑是什么？是否遗漏了其他深层判断？
   - 如果判断涉及系统重构，归纳重构的层面
   - 标注认知误区（如：单一主体建构论、技术决定论、终局稳态思维）

3. 不做现象穷举——穷举既不可能到位，反而限制后续深挖。
   具体变化维度的展开，留待阶段1张力解码中按需引入。

【输出格式】
## 阶段0：本质锚定

### 关键问题
什么是不变的？什么是深层变化的？（What）

### A. 不变的维度

|:---|:---|:---|:---|
| [维度] | [内容] | [关系] | ✅/❌ |

### B. 变化的深层结构性判断
[人工提出的深层判断，AI结构化整理]

#### 判断一：[判断名]
[判断内容]

#### 判断二：[判断名]
[判断内容]

#### 系统重构层面（如有）
| 重构层面 | 旧范式 | 新范式 | 核心变化 |
|:---|:---|:---|:---|
| [层面] | [旧] | [新] | [变化] |

#### 认知校验
[需规避的认知误区]
```

### 阶段1：张力解码与隐藏秩序（【知】解码客观大场）

**目标**：分析"不变本质×深层变化判断"之间的交叉张力，从张力中归纳行业运行的隐藏秩序。

**与阶段0的边界**：
- 阶段0回答"什么不变？什么在深层变化？"（What）——本质锚定
- 阶段1回答"不变×变化产生什么张力？隐藏秩序是什么？"（So What）——交叉分析
- 阶段1不重复描述变化本身，而是展开变化与不变本质的交叉张力

**Prompt**：
```
【角色】你是行业分析师，负责解码客观大场的运行规律。

【任务】分析[行业名称]中"不变本质×深层变化判断"的交叉张力，提取隐藏秩序。

【输入】
- 阶段0的本质锚定（"不变的"维度+"变化的"深层判断）
- 分析起点（不变的事实+对比参照）

【要求】
1. 不变本质的张力解码：
   - 对每个"不变的"维度，追问：这个不变的本质，在深层变化判断下产生了什么张力？
   - 特别关注：不变的本质为变化提供了什么可能性？变化又在什么方向上挑战不变的本质？
   - 示例：电池会衰减是不变的，但AI介入研发可能重构电化学理论→衰减规律本身可能被重写→张力

2. 深层判断的具体展开与张力：
   - 围绕阶段0的深层判断，展开具体变化表现（按需引入，不穷举）
   - 追问：这些具体变化与不变本质的交叉点在哪里？产生什么张力？
   - 特别关注：不同变化之间是否存在交叉/耦合/冲突关系？

3. 隐藏秩序识别：
   - 从不变×变化的交叉张力中，归纳出行业运行的底层规律
   - 识别"不变的本质"如何在"变化的环境"中催生新的需求
   - 隐藏秩序是阶段2需求推导的直接输入

【输出格式】
## 阶段1：张力解码与隐藏秩序

### 关键问题
不变本质×深层变化判断之间产生什么张力？从张力中能归纳什么隐藏秩序？

### A. 不变本质的张力解码
#### [维度1]：[不变的内容]
- 具体表现：[描述]
- 对行业的根本影响：[影响]
- 与深层变化判断的张力：[张力描述]

### B. 深层判断的具体展开与张力
#### [判断1]：[判断内容]
- 具体表现：[按需展开，不穷举]
- 与不变本质的交叉张力：[张力描述]
- 与其他判断的关系：[交叉/耦合/冲突]

### C. 隐藏秩序识别
- 秩序1：[从不变×变化的交叉张力中归纳出的底层规律]
- 秩序2：[...]
```

### 阶段2：需求推导（【知】需求发现）

**目标**：从不变本质和变化趋势中，推导行业底层需求。所有需求都应能追溯到核心功能实现的某个方面。

**Prompt**：
```
【角色】你是需求发现专家。

【任务】从阶段1的大场解码（不变本质+变化趋势）中，推导[行业名称]的底层需求。

【输入】
- 阶段1的大场解码结果

【要求】
1. 对每个"不变的"维度，追问：
   - 这个不变的本质，本身就需要什么支撑？（如：电池会衰减→需要衰减管理）
   - 这个不变的本质，在变化的环境下是否产生了新的张力？
     （如：衰减不变+寿命延长→残值实现需求）

2. 对每个"变化的"维度，追问：
   - 这个变化催生了什么新需求？或改变了什么旧需求？
   - 这个需求是否能追溯到核心功能实现的某个方面？

3. 需求表述要具体，不要笼统说"需要更好的X"，要说"需要X来解决Y问题"

4. 对每个需求，标注：
   - 需求来源（哪个不变本质/变化趋势催生的）
   - 驱动力强度（政策强制/技术刚需/用户痛点/社会演进）
   - 确定性（★★★确定/★★☆高/★☆☆有条件）
   - 持续性（长坡厚雪/周期性/短期）

5. 区分"真实需求"和"伪需求"——
   伪需求的特征：①靠技术假设成立 ②靠补贴成立 ③靠特定用户群体成立

6. 不做业务形态判断（那是Step 2-3的职责），只做需求识别。

【输出格式】
## 阶段2：需求推导

### 关键问题
[本阶段要回答什么问题？由AI提议、人工确认]

### 需求推导

### 需求 N-1：[需求表述]
- 来源：[不变本质X / 变化趋势Y]
- 驱动力：[驱动力]
- 确定性：[★★★/★★☆/★☆☆]
- 持续性：[长坡/周期/短期]
- 真实/伪需求判定：[真实/伪需求 + 理由]

### 需求 N-2：...
```

### 阶段3：硬约束提取（【知】约束识别）

**目标**：识别行业的硬约束（生死线），区分生死线、强约束、弱约束。

**Prompt**：
```
【角色】你是行业约束分析专家。

【任务】识别[行业名称]的硬约束，区分生死线、强约束、弱约束。

【输入】
- 阶段1的大场解码结果
- 阶段2的需求清单

【要求】
1. 硬约束来源（穷举）：
   - 政策法规约束：强制性法规、行业准入、合规要求
   - 技术物理约束：物理规律、化学定律、工程极限（注意：这些往往与"不变的本质"直接相关）
   - 社会认知约束：用户认知惯性、社会接受度、文化习惯
   - 资源环境约束：原材料供给、能源供给、环境承载力

2. 对每个约束，判断其约束强度：
   - 生死线：违反则业务无法存在
   - 强约束：违反则业务严重受损但可补救
   - 弱约束：违反则业务受影响但不致命

3. 特别关注：约束之间的叠加效应——多个约束同时作用时，
   可能产生单独看时不明显的"死亡组合"。

4. 标注每个约束的生效时间和演进趋势。

【输出格式】

[本阶段要回答什么问题？由AI提议、人工确认]

- 生效时间：[时间]
- 约束强度：[生死线/强约束/弱约束]
- 演进趋势：[变强/稳定/变弱]
- 与其他约束的叠加效应：[有/无 + 说明]

### 死亡组合识别
| 组合 | 约束1 | 约束2 | 叠加效应 | 单独看是否致命 |

### 阶段5：坍塌检验（【合】偏差检验）

**目标**：基于阶段4的推演结果，检验默认模式是否坍塌，如果坍塌，回溯到"知"寻找新机制。

**Prompt**：
```
【角色】你是偏差检验引擎。

【输入】

【要求】

## 四、与分形矩阵的映射关系

| 工作流阶段 | 分形角色 | 对应内容 |
|:---|:---|:---|
| 阶段0-1 | 【知】解码大场 | 本质锚定（不变维度+深层判断） + 张力解码 + 隐藏秩序识别 |
| 阶段2-3 | 【知】需求与约束 | 需求推导 + 硬约束提取 |

## 五、使用说明

1. **人工先填写输入契约**（分析对象 + 分析起点+对比参照 + 分析边界 + 核心问题链），这是人工职责，AI不能代劳；
2. **按阶段0→7顺序执行**，每阶段AI输出后人工验收，确认后再进入下一阶段；
3. **阶段0做"本质锚定"**：锚定"不变的"本质维度 + 提炼"变化的"深层结构性判断（人工主导）。不做现象穷举；
4. **阶段1做"张力解码"**：分析"不变本质×深层变化判断"的交叉张力，归纳隐藏秩序。不重复描述变化本身；
5. **阶段2的需求推导必须能追溯到核心功能实现的某个方面**，不能脱离核心功能空想需求；
6. **阶段4-5是核心**，如果默认模式不坍塌，需要回溯检查阶段1-3是否遗漏了关键变化或约束；
7. **阶段7输出后**，人工做最终裁定；
8. **Step 1的输出自动作为Step 2的输入**，无需人工重填。
