# 专题 · 用人信号：战略定力与执行跟踪

> **被谁引用**：第 2 章（必要性——为什么必须是 CATL、它有没有决心）、第 6 章（中检点与退出信号）。
> **它为什么是专题**：判据 ①（两章引用）＋ ②（**更新周期与模型完全无关**——人事变动跟重跑模型没有任何关系，
> 但它每发生一次就要更新）。
> **原始记录**：`定性分析/用人信号.md`（**持续更新**，本专题只做读法）。

## 一、为什么人事是一类特殊的证据

**人事是最难伪装的承诺信号。**

| 信号类型 | 伪装成本 |
|---|---|
| 公关口径的规划数 | **极低**——说一句话的事 |
| 签一份合作协议 | 低——**是"推"不是"拉"**（见 `赔率与跟踪_从世界A到世界B`） |
| 资本开支 | 中——但可以缓建、可以计提 |
| **换掉一把手、空降一个更贵的人** | **高**——它同时消耗**组织资本**与**创始人信誉** |

> **判据：一个组织在什么事情上换人、换什么样的人，比它在什么事情上花钱更能说明它把这件事看得多重。**
> 钱可以来自"战略预算"这个筐；**换人必须有人拍板，而且拍板的人要为结果负责。**

## 二、这次换人换了什么：从"内部培养"到"空降运营型"

| | 前任 | 继任 |
|---|---|---|
| **来源** | **内部培养**——从创立早期班底一路做上来，做过电芯开发、公共事务、市场，也做过董事长助理 | **空降**——来自出行平台，做过战略合作与汽车资产管理、车服总经理、定制网约车的首席产品官、充电桩运营板块负责人 |
| **能力画像** | **技术与公司内部**（电芯开发、公共事务） | **运营、产品、资本** |
| **任内标志事件** | 品牌与换电块发布，宣布要在两三年内建成全球最大服务网络 | 生态大会（地方主要领导站台）＋ 品牌更名 ＋ 引入车企、运营商、保险公司等一众合作伙伴；与出行平台正式合资落地 |
| **换人时的处境** | 网络建设与车型适配双双推进不利 | — |

**三条读法：**

**① 换的不是人，是能力模型。**
从**"技术＋公司内部"换成"运营＋产品＋资本"**——
这恰好对应 `业务本质_第一性原理拆解` 里那句判定：
**换电的性质不是技术变革，是模式转变。** 用技术出身的人去做模式转变，能力错配。

> **人事变动是"这门生意是什么性质"这个判断的第三方验证**——
> 公司自己用行动回答了它认为这是什么生意。**而且这个回答比任何 PR 稿都可信。**

**② 换人之后的动作，形态也变了。**
前任任内是**发布与宣告**（品牌、产品、目标）；
继任任内是**结盟与合资**（生态大会、合作伙伴、与出行平台的合资公司落地）。
**从"我要做成"变成"我拉谁一起做"**——这正是 `竞争格局` 第三节说的
**"CATL 面对强议价合作方，必须深度绑定"**在组织行为上的体现。

**③ 但它仍然是"推"不是"拉"。**
**换人、结盟、合资，全部是 CATL 自己发起的动作**——它们证明的是**决心**，不是**标准已立**。
按指标纪律，全部标**推**。
**用它论证"CATL 有决心"是对的；用它论证"标准要立住了"是越界。**

## 三、它进哪一章、怎么用

| 用在哪 | 怎么用 |
|---|---|
| **第 2 章 必要性** | 回答"**为什么必须是 CATL**"的补充证据：不只是承重方结构上只能是它，**它也确实在为此调配最稀缺的资源——人** |
| **第 6 章 中检点** | 作为**战略定力**的跟踪项。**注意它是滞后指标**：换人通常发生在推进不利**之后**，所以它验证的是"公司自己认不认错、纠不纠偏"，不是"业务好不好" |

## 四、后续要跟什么

**这一份必须持续更新**，跟踪清单：

| 跟什么 | 意味着什么 |
|---|---|
| 换电条线负责人再次变动 | **警示**——若在网络铺开前再换一次，说明打法仍未收敛 |
| 合资平台的法定代表人／核心岗位 | 谁在实际操盘、汇报线在哪 |
| 从外部引入的高管来自哪个行业 | **来源行业＝公司认为这门生意像什么**。若开始从基建/资管行业引人，是族定位的软信号 |
| 核心团队的留存 | 结盟型打法最怕人走盘散 |
| 该条线在集团层级的位置 | 独立事业部／子公司／合资平台，层级本身是资源承诺的读数 |

> **判据（可迁移）：跟踪人事时，看三样——换谁、换成什么背景、换人之后动作的形态变没变。**
> **只看"换了人"是新闻，看到"能力模型换了"才是信号。**

## 五、边界

- **人事信号只能证明决心，不能证明结果。** 决心是必要条件，不是充分条件。
- **它是滞后指标**，不要拿它做先行判断。
- **原始记录在 `定性分析/用人信号.md`，本专题只做读法。**
  新的人事变动先记在那里，**读法有变化时才改本文件。**
