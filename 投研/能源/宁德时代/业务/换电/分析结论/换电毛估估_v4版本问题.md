#### 1. scale.py -- 车辆规模与装机底座

**核心函数：`build_scale(config, sourcing)`**

**Step 1.1：网约车车流量推算**

网约车是隐式从总共享出行池减去出租车推算：

```text
robotaxi_km = robotaxi_fleet_wan × robotaxi_daily_km × robotaxi_days / 10000
            = 50.0 × 350 × 330 / 10000
            = 577.5 万辆·公里

human_stock = (pool_2030_yi_km - robotaxi_km) / (human_daily_km × human_days / 10000)
            = (3500.0 - 577.5) / (350 × 330 / 10000)
            = 2517.5 / 11.55
            ≈ 218.0 万辆

ridehail_stock = human_stock - taxi_stock_wan
               = 218.0 - 139.0
               ≈ 79.0 万辆
```

网约车 8 年生命周期：`79.0 / 8 = 9.875` 万辆/年。

**Step 1.2：年 EV 销量推算**

```python
def _annual_ev_wan(vehicle, year_index, stocks):
    pure = vehicle.get("pure_electric_share", 1.0)
    if "annual_sales_wan" in vehicle:
        return vehicle["annual_sales_wan"][year_index] * pure
    stock = stocks[vehicle["stock_source"]]
    return stock / vehicle["replacement_cycle_years"] * vehicle["nev_rates"][year_index] * pure
```

例如重卡 2026 年：

```text
stock = 900 万辆
nev_rate = 0.35
annual_ev = 900 / 9.0 × 0.35 × 1.0 = 35 万辆

重卡场景拆分：
短途：35 × 0.38 = 13.3 万辆
中途：35 × 0.50 = 17.5 万辆
长途：35 × 0.12 = 4.2 万辆
```

**Step 1.3：市占率与 MNA 扰动接入**

```text
heavy_share_uplift = sourcing.heavy_catl_swap_share_uplift
passenger_share_uplift = sourcing.passenger_catl_swap_share_uplift

heavy 场景 CATL 换电市占率：
catl_swap_share = min(1.0, scene["catl_swap_share"] + heavy_share_uplift)

车网场景 CATL 换电市占率：
catl_swap_share = min(1.0, scene["catl_swap_share"] + passenger_share_uplift)
```

中性基线默认方案为“启源入股_不收蔚来”，其中：

```text
heavy_catl_swap_share_uplift = 0.01
passenger_catl_swap_share_uplift = 0.0
```

```text

重卡中途 CATL 换电市占率 = 0.30 + 0.01 = 0.31
重卡长途 CATL 换电市占率 = 0.70 + 0.01 = 0.71
车网场景不加 uplift
```

#### 3. 口径差异与注意点

1. **V4 明确区分寿命与回报周期**  
   `capex.py` 按电池寿命生成更新批次，并在寿命到期时按未来价格计算更新支出。这与仅按建设周期折旧的简化口径不同。

2. **WACC 与 CRF 分离**  
   V4 把 WACC 用于生命周期 CAPEX 折现，把 CRF 用于倒算年资本要求。该设计明确避免把折现率直接当作回报门槛。

3. **价值桥审慎化**  
   旧版可能把所有制造增量都归因给换电；V4 拆出“制造销量/市占率差”和“其余制造收入利润率差”，可归因换电价值只包括换电可服务范围利润率保护 + 直接换电运营。

4. **轻资产估值三块分开**  
   轻资产不是单一估值；其持续动力价值由制造线、保留运营价值、资管平台价值三块构成。资管平台 AUM 是从换电运营价值内部推导，而不是简单等于 EV。

5. **站网与时间分离**  
   V4 的终局站数来自车辆需求反推，建设节奏来自 2026 里程碑和 2028 网络完成约束。2029—2030 仍有车辆电池和更新，但新增站数为 0。

6. **MNA 扰动是独立重算**  
   `build_model()` 对每个 MNA 场景重新调用 `_build_core()`，因此可计算市占率、站网复用、已获资产带来的增量，而不是简单追加价格。

7. **集团资金表保守处理**  
   2026 年资金表先扣除 2026H1 已实现 CFO，再用 2026 分红、回购上限、已识别并购现金和换电资本；未披露时点或不在合并口径的 64 亿元世纪互联交易、300 亿元矿产资源投资上限不机械计入年度现金支出。
