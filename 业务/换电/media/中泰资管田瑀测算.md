投资小瑀宙 | 纯电车的换电站运营划算吗？2022-10-22

# 原文
按照399元/月的电池租赁费用以及1.25元/KWh的换电补能价格，按照26.5KWh的带电量，在补能深度为80%的情况下，每年的能源消耗量为37.14万度，考虑到增值税，其报表确认收入约为346.16万元，
拥有48块电池的换电站，每天换电仅为1次，给电池充电可均以谷时电价完成，成本按0.3元计算；每天完成换电48次，每月完成换电1440次，对应租赁电池客户数量720户，
3名员工、月薪8000元，场地年租金10万，换电站投资260万元、线路投资100万元（对换电站投资金额和线路投资金额的假设，我们采用的是另一家上市公司募集资金时所披露的数据，与某造车新势力的投资数据相比金额更高），均按8年折旧，48块电池投资101.76万元、按照生命周期1500次循环折旧，可得每年换电站的总成本大约在119.7万元，
同时考虑到增值税抵扣、企业所得税、10%的销售管理费用，其税后净利润大约为180万元，可以粗略认为其ROA=180/2038.1=8.89%，若结果可靠，其经济性卓越

# 校验
电站购置电池成本：101.76/48=2.12万/块 ➗ 26.5kwh=0.8元/wh
用户电池投资：720*2.12=1526.4万
电池投资总额：101.76+1526.4=1628.16万
固定资产投资总额：260+100+1628.16=1988.16万
可抵扣进项增值税：1988.16/1.13*13%=228.7264万

用户支付电池租金：399*12*720=344.736万
每年能耗：26.5*80%*48*365=37.1424万度
用户支付换电服务费：1.25*37.1424=46.428万
合计含税收入：344.736+46.428=391.164万
增值税率：13%
不含税收入：391.164/1.13=346.1628万
销项税：391.164-346.1628=46.428万

充电费：0.3*37.1424=11.1424万，其中增值税 11.1424/1.13*13%=1.2819万，不含税 9.8605万
薪资：3*8000*12=28.8万，社保费率 * 0.4=11.52万，合计 40.32万
场地租金：10万
基建折旧：(260+100)/8=45万
❌电池折旧：101.76/1500*365=24.76万：不能单算换电站的周转电池，要合并计算720+48=768块，使用频率48*1/768=0.0625次/天，生命周期1500次循环，1500/(0.0625*365)=65.75年，每年折旧1628.16/65.75=24.76万。但实际上电池不可能用65.75年。
折旧合计：前8年 69.76万，第9年无折旧
成本：119.7024万 -1.2819万 + 11.52万 = 129.9421万
毛利：346.1628 - 119.7024 = 226.4604，+1.2819-11.52=216.2223

销售费用：346.1628*10%=34.61628万
可抵扣年数：228.7264/46.428=5.02年
电费进项税：1.2819万
增值税附加：第6年开始，(46.428-1.2819)*10%=4.5146万

税前利润：前5年，216.2223 - 34.61628 = 181.606，第6-8年 - 4.5146 = 177.0914，第9年开始 +45=222.0914
所得税率：25%
所得税：前5年 45.4015万，第6-8年 44.27285万，第9年开始 55.52285万
净利润：191.8476 - 45.4015万 = 146.4461，第6-8年 177.0914 - 44.27285 = 132.8169，第9年开始 222.0914 - 55.52285 = 166.572
净cf：前5年 146.4461 + 69.76 = 216.2223，第6-8年 132.8169 + 69.76 = 202.5769，第9年开始 166.572
初始投资：1988.16万 + 40.32万 + 10万 + 34.61628万 = 2073.09628万
