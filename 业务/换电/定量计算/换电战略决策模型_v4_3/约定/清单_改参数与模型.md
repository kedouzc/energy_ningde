# 清单 · 改参数与模型（改 `configs/base.toml` 或 `src/` 之前）

> 属于 `研究项目约定.md` M 组与 D 组。

- [ ] **定义对齐了吗**（C2）：这个量的定义和算式，研究者认可吗？
- [ ] **先读已有推导**（M12）：参数注释里的推导链、台账里的批次审计行；改值要说明比原推导好在哪。
- [ ] **信源**（D1、D2）：一手或可追溯；新信源先登记台账；没有信源标"声明值"，取整档，不装精确。
- [ ] **成对同源、基数对齐**（M4、M5）：成对的数同一出处；比例写清占哪年哪个价、哪个口径。
- [ ] **终局价的输入取终局那年的值**（M2）。
- [ ] **结构检查**（M3）：新加的占比或过滤器，在基准处是不是恒为 1 或 0？是就等于没有。
- [ ] **写清为什么是这个数、换成别的会怎样**（D8）：写进参数注释和对应口径文档。
- [ ] **影响测一遍**（C3、C5）：对份额和宁德归属现金流折现各变多少；≤ 5% 自己定，> 5% 提给研究者。
- [ ] **多主体的账逐池配平**（D7）：站 ＋ 电池银行 ＝ 系统；内部结算不进系统合计。
- [ ] **三档**（M6）：新参数给悲观／中性／乐观；中性不高于同口径实测。
- [ ] **跑之前写 expect**（D9）。
