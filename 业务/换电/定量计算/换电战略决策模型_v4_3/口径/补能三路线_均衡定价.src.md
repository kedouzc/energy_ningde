# 补能路线 · 均衡定价：终局时谁赢哪类车、换电能收多少

> **回答什么**：兑现年（2030 年）终局稳态里，每一类车选哪条补能路线；换电的服务费、电池租金各自最高能收多少（各自的上限），比自己的成本多出多少（利润），份额多少。这是框架第三节第 ③ ④ 步（`补能路线比较_总框架.md`）。
> **服务哪些读数**：换电份额、每度电利润（服务费一项 ＋ 租金一项）→ 换电站与电池银行两本账、EBITDA、站数。
> **现状**：程序现算（`src/equilibrium.py`），构建时注入；三档随情景轴走；**不进主链读数**（接入主链是下一步）。
> **来历**：`DECISIONS.md` 2026-09-28m 至 2026-09-28p（资源账）；2026-09-29c 至 2026-09-29e（分项定价）。

## 一、终局是什么

终局是兑现年大家都建得差不多之后的稳态，同时满足三条：

1. **车队不再换路线**：每辆车用的都是它全年资源账最低的补能方式。
2. **运营商不再进出**：价格刚好覆盖含资本回报的成本；多出来的站在终局前被淘汰或并购。
3. **站数与需求匹配**：每条路线都跑在自己的最优利用率（`补能三路线_供给成本.md` 第六节"最优利用率怎么算"）。

今天充电站只有两成上下的实测利用率，是过渡期的状态，只作敏感性（对换电有利的一侧）。

**车分两类**（研究者 2026-09-28 确认）：
- **封闭短途多班倒**（港口、钢厂、矿山）：车连续运转，没有强制休息；对手有常规快充、兆瓦超充、车队自备轮换。
- **干线**：中途与长途跑的是同一批路、同一批站，只是每天跑的里程不同，合并成一类，按日里程分布逐车比较。干线充电站里各种功率的桩混装，每辆车选对自己最省的桩；常规快充在物理上主要在两头（物流园、场站，夜里慢充）和干线站里的低功率桩。

## 二、算式

```
每一类车按日里程抽样：
  封闭短途：代表里程 260 公里的 60%／80%／100%／120%／140%，五点等权
  干线：400 公里与 650 公里两个代表点各取上面五点，按原场景权重（0.50 与 0.12）合并
每辆车四（三）条路线的全年资源账：车队总账第〇之二节的算法（各路线都按自己的最优利用率）
这辆车选资源账最低的路线
若换电最低：
    整包价上限 ＝ 第二名的全年资源账（第二名在终局只能按成本收）
    利润厚度 ＝ 上限 − 换电自己的资源账（万元/车·年）；每度电 ＝ 利润厚度 ÷ 年用电
换电赢的比例 ＝ 换电最低的那些车的权重之和（这是可及范围内的比例，再乘可及比例才是份额）
```

## 六、分项定价：服务费、租金各自跟谁，换电留下多少（交给财务的数）

> **状态**：分项口径已定（总框架第八节第 1、2、3、7 条；DECISIONS 2026-09-29c 至 DECISIONS 2026-09-29f）。服务费上限含车队走充电多花的时间成本，与车队总账用同一笔时间账。

**这一节是均衡层的出口**：财务测算（EBITDA、站数、估值）只从这里取数。第四、五节的资源账只回答"谁的成本低"；价格与份额以本节为准。

**逻辑**：车队能拆开买——服务费定高了，换电车可以去充电站充；租金定高了，车队干脆改买充电车，电池自己买或向租赁商租。所以换电不能打包定价，每一项单独跟它的上限：服务费跟"去充电站充"对车队的完全成本，即充电服务费加上多停的时间（车队总账里的补运力成本）；租金跟那辆充电车的电池持有成本。对手是兆瓦超充时，多停的时间几乎都被强制休息吸收，时间差约为零，服务费就是跟平；对手是常规快充时，时间差很大，换电能多收的就是这一截。每一项的上限都是终局的完全成本（自由进入下对手只能收成本价），不是今天的促销价。换电成本低于上限的部分是利润；两项利润加起来为负的车，换电不服务。

**算式**

```
每辆车（日里程分布逐点，同第二节）：
  车队最省的充电替代 ＝ 常规快充与兆瓦超充里"服务费 ＋ 电池持有 ＋ 时间成本"全年合计低的那条

  服务费一项（元/度）
    上限     ＝ 这条替代的每度电站成本（途中那部分按它自己的站，夜里那部分按常规慢充；各站按最优利用率）
               ＋ 时间差 ＝（充电替代每年多停的时间成本 − 换电每年多停的时间成本 − 换电底盘溢价）÷ 年用电，小于零取零
               时间成本 ＝ 多停的小时 × 补运力成本（车队总账第〇、〇之二节）
    换电成本 ＝ 换电站每度电成本（含站内周转电池与排队区，供给成本文档第六节）

  租金一项（元/年，再除以年用电）
    持有成本 ＝ 电池度数 × 电池价 ×（1 ＋ 购置税）×（年金系数 − 旧电池卖价比例 × 卖出年电价比 × 偿债基金系数）
               ＋ 电池度数 × 每年保险维护
    上限     ＝ min（租赁商保本，低息车队自买）；租赁商不在场时 ＝ 低息车队自买
               租赁商：资金 {{分项_租赁商资金}}，旧电池按电池银行的折扣链，保险维护按电池池口径
               车队自买：资金按低息群 {{分项_低息}}，旧电池与保险维护按车队自己的口径
               电池价：常规快充车用普通包，兆瓦车用普通包加高倍率溢价；购置税 {{分项_购置税}}
    换电成本 ＝ 电池银行持有车上那块换电专用包：同一公式，资金按 WACC {{分项_银行资金}}，不交购置税
    寿命     ＝ 各自工况下的循环寿命（兆瓦车按途中快充的电量占比加权），重卡日历上限 12 年

  换电每度电利润 ＝（服务费上限 − 换电站成本）＋（租金上限 − 电池银行成本）
  换电服务这辆车 ＝ 利润 > 0
  车队选换电     ＝ 换电车自己承担的停车时间 ＋ 换电底盘溢价 不高于充电替代（两项都收到上限时车队两边付的一样，按选换电计）
  份额           ＝ 可及比例 × 可及范围内选换电的车的比例
```

## 七、读法

1. **租赁商退不退场，对换电几乎没有影响**：低里程的车，租金上限本来就由低息车队自买定；高里程的车由租赁商定，但它比低息车队自买只便宜一点（算例里两种来源都出现）。"超充 ＋ 租赁"是否扩张，只是跟踪指标。
2. **干线换电的利润主要在服务费一项，来自时间**：对手是常规快充的车（日里程中等），换电省下的停车时间折成服务费；对手是兆瓦超充的车（日里程高），时间差小，利润来自电池（购置税、池里慢充延寿）。
3. **干线的租金一项多半是亏的**：常规快充车的电池本来就慢充、寿命不比换电短（都顶到 12 年日历上限），换电专用包更贵、电池银行的资金成本高于低息车队。这是换电成本结构的实情，不是定价问题。
4. **时间差算不算进服务费，决定份额**：对照行里不计时间差，中性重卡份额只剩一成多，而且三档不单调（乐观档快充伤电池重，兆瓦被挤出，替代变成常规快充，换电的优势全在时间上）。计入后三档单调。
5. **日里程最低的干线车换电算不过**：夜里补满、途中不用停，时间差为零，电池又摊不薄。
6. **悲观档换电出局**（总框架第〇节的终局丙）：资源账上换电处处更贵，任何定价方式都救不了。
