# V2G反向售电机制

#### 一、V2G是什么？（来自宁德时代2026.04.21科技日官方发布）

**官方定义**（[快科技](https://news.mydrivers.com/1/1117/1117419.htm)、[新京报](http://m.toutiao.com/group/7631368126500471348/)、[CarNewsChina](https://www.carnewschina.com/2026/04/21/catls-battery-swap-stations-to-feature-shenxing-supercharging-with-6-minute-full-charge-capability/)）：

从2026年下半年起，巧克力换电用户可在**电价峰值时段**，将**满电电池包反向售电给换电站**，**换电站按电价差价向车主支付费用**，一天收益可达几十元，基本覆盖电池租赁费用。

宁德时代原话：**"以前充电换电是付钱，现在可以从换电站赚钱。"**

**V2G的完整机制**

V2G不是简单的"用户把电卖给换电站"，而是一个**三方受益的电力搬运闭环**：

```
【谷时】用户在家用家用慢充桩，以谷电价（~0.3元/度）充满电池
    │
    ▼
【峰时】用户开车到换电站，将满电电池换给换电站
    │
    ├─► 换电站按峰谷差价向车主支付费用（30-50元/次，含补贴）
    │
    ▼
【换电站获得满电电池后】
    ├─► 优先满足自身峰时换电对满电电池的需求（降低充电功率压力）
    ├─► 如有富余，作为虚拟电厂聚合商参与电网调频调峰（AGC调频+备用市场）
    └─► 削减大工业两部制电价的需量电费（降低变压器报装容量）
    │
    ▼
【电网】省去铺零售网回收电力的投资，获得毫秒级调频资源
```

**V2G不是什么（消除常见误解）**

| ❌ 误解 | ✅ 正确理解 |
|:---|:---|
| 换电站低价收、高价卖，赚差价 | **差价全额让利给用户**，否则价格战会把用户抢完 |
| 换电站是"电力中介/二道贩子" | 换电站的对手盘**不是车主**，而是**电网和自身负债表** |
| V2G主要靠电费套利赚钱 | 电费只是过手，真正赚钱的是**辅助服务费+降本+碳资产** |
| 用户只是"卖电" | 用户是在差价激励下**自愿充当"电力搬运工"**——把分散的谷电"搬运"到换电站集中供给峰时需求 |

#### 三、换电站的收益

##### 1. 电网辅助服务费（AGC调频 + 备用市场）（🔥 核心大头！）

**原理**：换电站作为聚合商（虚拟电厂），拥有大量毫秒级响应的电池资产。

| 服务类型 | 说明 | 收费方式 | 收益水平 |
|:---|:---|:---|:---|
| **AGC调频** | 电网频率波动时，站内电池极小幅度的充放电响应 | 容量补偿 + 里程补偿 | 单价极高（毫秒级响应稀缺） |
| **备用市场** | 将车主送来的满电电池上报为系统"旋转备用容量" | "待命站岗费" | 稳定现金流 |

**实证数据**：

| 来源 | 数据 | 说明 |
|:---|:---|:---|
| **深圳虚拟电厂实测** | **1-3元/度** | 迎峰度夏期间调用资源 |
| **蔚来沈斐公开披露** | **远超常规电费差价** | 参与调峰调频（含毫秒级频率响应） |
| **蔚来已参与站点** | **上千座**（长三角+安徽） | 2024-2025年常态化运行 |

##### 2. 削减大工业两部制电价的需量电费（💰 隐性降本·极其丰厚）

两部制电价：换电站用电 = 电度电费(按量) + 基本电费(按变压器容量)

四代站/超充站变压器容量：1000-2000kVA，每月固定缴纳上万元容量费，尖峰时段多车同时充电 → 变压器超载 → 扩容需几十万至上百万。

V2G模式下，高峰时用户送来满电电池 → DC-to-DC直充 → 亏电电池，可降低报装容量，年节省十万级以上（扩容费 + 基本容量电费）

#### 3. 碳资产（CCER）二次变现（🌱 未来增量）

用户从谷电搬运绿电 → 集中到换电站并网 → 认证为CCER减排量

当前国内碳价：50-100元/吨（波动中），未来潜力（4000座站规模）年吞吐电量百亿度级别，CCER变现千万级/亿级纯利润，是无成本纯利润

#### 四、三方受益闭环与战略价值

> **商业阳谋：用极低的获客成本，买断最优质的分布式储能资产**

V2G的本质不是一个"卖电"生意，而是一个**三方受益的电力搬运闭环**——车主、换电站、电网各方都受益，缺一不可：

| 受益方 | 获得什么 | 为什么愿意参与 |
|:---|:---|:---|
| **车主** | 峰谷差价+地方补贴，日收益30-50元，月收益600-1000元，可覆盖599元月租 | 差价激励下自愿充当"电力搬运工"——在家谷电慢充（几乎无成本），峰时开车到站换电赚差价。换电从"消费"变成"理财" |
| **换电站** | ① 极低成本储能（车主自掏腰包买车+免费搬运）② 辅助服务费（AGC调频+备用市场，单价远超电费差价）③ 需量电费降本（年省十万级）④ CCER碳资产变现 | 满电电池首先满足自身峰时换电需求，降低充电功率压力；富余部分参与电网调频调峰获取高单价收益 |
| **电网** | ① 省去铺零售网回收电力的巨额投资 ② 获得毫秒级调频资源（换电站作为聚合商）③ 削峰填谷缓解电网负荷 ④ 避免超充负荷集中过载 | 车主在差价激励下自愿把分散谷电"搬运"到换电站集中供给峰时需求，电网无需自建储能和输配电网 |

**对换电站的战略价值**：

| 战略价值 | 说明 |
|:---|:---|
| **① 极度廉价的储能** | 传统储能柜1元/Wh且有折旧；现在**车主自掏腰包买储能柜（车），还免费当搬运工** |
| **② 生态护城河** | 一旦V2G跑通，**换电从"消费"变成"理财"**——每月租电池500元，反向送电赚800元，实现免费用车甚至倒赚钱 |
| **③ 抵御超充竞争** | 超充站永远无法提供这种商业闭环——超充只是"消费"，V2G让换电变成"投资" |
| **④ 电网协同节点** | 换电站从"充电服务站"升级为"电网聚合节点"——既是充电基础设施，又是分布式储能节点，双重收入 |
