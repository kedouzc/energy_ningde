## 使用指南

### 日常研究流程

1. **在 `当前思考.md` 中记录**
   - 今天探索了什么框架
   - 涌现了什么问题
   - AI给了什么回答
   - 产生了什么洞察

2. **定期整理到 `演化过程/`**
   - 当某个阶段的研究成熟后
   - 使用 `模板_演化记录.md` 创建阶段记录
   - 为AI训练积累路径数据

3. **更新 `框架/`**
   - 框架有重大更新时创建新版本
   - 在 `框架演化路线图.md` 中记录演化历程

4. **维护 `问题清单/`**
   - 问题清单迭代时创建新版本
   - 保持最新问题清单的可见性

### 研报处理流程（AI蒸馏）

```
新研报进入
    ↓
AI阅读（Claude/Gemini/多AI交叉）
    ↓
提取核心观点、关键数据、与现有认知的差异
    ↓
如果是重量级研报 → 存入 sources/重量级研报/
    ↓
AI蒸馏结果 → 融入 当前思考.md 或 对应案例文件
    ↓
记录思维链到 演化过程/
```

#### 重量级研报标准
- 里程碑式报告（如宁德时代首次覆盖报告）
- 深度超过50页的行业报告
- 包含独特数据或模型的报告

#### 常规研报处理
- 不存储原文
- 只存AI蒸馏后的核心观点
- 融入现有研究文件

### 多AI交叉验证流程

当遇到重要问题时，使用多AI交叉验证：

1. **创建辩论记录**：在 `多AI辩论/` 目录创建 `YYYY-MM-DD_主题.md`（参考 `_模板_多AI辩论记录.md`）
2. **记录多AI回答**：记录不同AI的回答和你的思考
3. **交叉比对**：提取共识、分歧、待验证点
4. **LLM Ingest**：读取辩论记录，提炼关键洞察
5. **融合产出**：重要洞见 → 更新 `框架/` 或 `当前思考.md`
6. **Wiki更新**：LLM自动更新Wiki/pages/

**📂 目录定位**：
- `多AI辩论/` = 探索过程（多视角碰撞，可能包含错误路径）
- `框架/` = 成熟产出（经过验证的框架版本）

**示例**：
- 辩论记录：[多AI辩论/2026-04-13_v2框架批判_共振取代时空耦合.md](多AI辩论/2026-04-13_v2框架批判_共振取代时空耦合.md)
- 融合产出：[框架/2026-04-13_四层与投资原点融合.md](框架/2026-04-13_四层与投资原点融合.md)

## 权威信源

### 一、SNE Research 机构详解
#### 基础信息
- **所属国家**：韩国
- **发展历程**：1999年成立专业研究与咨询公司，2008年正式聚焦二次电池、新能源汽车与可再生能源领域，是全球锂电行业最具公信力的第三方机构之一。

#### 核心独特资源
1.  与全球主流车企、动力电池/储能电池厂商、上游材料企业建立了超过15年的长期合作，深度掌握日韩欧美电池企业的非公开一手运营、产能、出货数据，对海外市场的颗粒度覆盖远超多数机构；
2.  拥有全球统一的「电芯当量」统计标准体系，是行业内最早规范动力电池/储能电池出货量口径的机构，数据可交叉验证性极强。

#### 研究方法特色
- 采用**月度高频跟踪+上下游交叉验证**的研究模式，剔除代工、自用、重复统计等口径干扰，对企业出货量的统计严格以「电芯生产出库、最终交付落地」为锚点，避免口径虚增；
- 数据颗粒度可细化到企业月度分应用场景（动力/储能/消费）出货、分技术路线（三元/磷酸铁锂/其他）产能、分地区市场份额，方法论透明且长期稳定，历史数据可追溯性强。

#### 核心擅长领域
全球动力电池与储能电池的企业竞争格局、分地区/分应用出货量排名、日韩电池产业链深度研究、全球EV电池用量跟踪、电池材料供需与技术路线研判。

#### 行业广泛引用的核心数据
- 全球动力电池月度/年度装机量、出货量企业排名及市占率数据（行业公认的全球格局「金标准」）；
- 全球储能电池全口径电芯出货量排名及市场份额数据（你此前引用的167GWh宁德时代储能出货量即来源于此）；
- 全球电动汽车电池月度装机量、分地区用量数据；
- 日韩头部电池企业（LG新能源、三星SDI、SK On）的产能、出货、技术路线布局深度数据。
