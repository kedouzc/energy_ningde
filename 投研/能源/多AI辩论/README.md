## 目录用途

- 多个AI（Claude/Gemini/GLM等）对同一问题的不同回答
- 交叉比对分析（共识、分歧、待验证点）
- 你的思考和判断
- 辩论后的融合洞察

## 工作流程

```
遇到重要问题
    ↓
1. 创建辩论记录（使用本目录的 _模板_多AI辩论记录.md）
    ↓
2. 向多个AI提问，记录各自回答
    ↓
3. 交叉比对：提取共识、分歧、待验证点
    ↓
4. 你的思考：判断哪个AI更有道理，形成自己的见解
    ↓
5. 融合产出：如果产生重要洞见 → 更新 框架/ 或 当前思考.md
    ↓
6. Wiki更新：LLM自动更新Wiki/pages/（数据源完整后介入整理）
```

## 使用建议

### 什么时候需要多AI辩论？

- ✅ **框架层面的根本性问题**（如v2→v3范式转换）
- ✅ **重大投资决策前的假设验证**
- ✅ **认知瓶颈无法突破时**
- ❌ 不需要每个问题都这么做（成本高）

### 如何提高辩论质量？

1. **问题要具体**：不要问"这个框架好不好"，而要问"把场定义为时空耦合有什么局限性？"
2. **AI要有差异**：选择风格不同的AI（如Gemini偏物理哲学，GLM偏实操落地）
3. **你的角色是裁判**：不是找AI要答案，而是通过AI的碰撞激发自己的思考
4. **记录思维链**：不仅记录结论，更要记录"为什么"

---

> **记住**：多AI辩论的价值不在于找到"正确答案"，而在于**暴露认知盲区**和**拓展思维边界**。
