## 操作类型说明

| 类型代码 | 含义 | 使用场景 |
|---------|------|---------|
| INIT | 初始化 | 首次创建文件/目录 |
| INGEST | 资料摄入 | 从数据源导入论文/研报/思考 |
| UPDATE | 内容更新 | 修改已有页面内容 |
| CREATE | 新建页面 | 创建新的概念/实体/综合页 |
| DELETE | 删除 | 移除过时或错误内容 |
| LINK | 链接维护 | 更新INDEX.md或内部链接 |
| SYNTHESIZE | 综合分析 | Synthesize操作产出 |
| QUERY | 查询归档 | Query后的有价值归档 |
| DNA_EVOLUTION | 思维演化 | 记录框架↔问题双螺旋过程 |
| AI_COLLAB | AI协作 | 多AI辩论等协作记录 |
| CLEANUP | 清理 | 删除重复/过时文件 |
| MAINTAIN | 维护 | 定期巡检、健康检查 |
