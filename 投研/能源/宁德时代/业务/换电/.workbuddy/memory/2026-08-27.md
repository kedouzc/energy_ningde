# 2026-08-27 工作记录

## 换电战略决策模型 v4.1 — 报告定性叙述改造（A→B→C）
- 用户指出 `report.py` 里 `light_conclusion` / `executive_summary` 把"资金表是否触发流动性缺口/是否提前出表"等**判断**写死成散文，而数字表格是数据驱动的 → 数据变化可能出现相反结论。
- 已新开版本（不覆盖老文件）：
  - `定性分析/换电战略决策模型_v4_1/report_v5.py`
  - `定性分析/换电战略决策模型_v4_1/configs/base_v5.toml`（末尾新增 `[llm_narration]` 段）
- 新机制（report_v5.py）：
  - **方案A** `compute_verdicts(config, snapshot)`：从 snapshot + `decision_thresholds` 算出结构化 verdict（funding_gap、ebitda_coverage_pass、value_creation_pass 等）；两处叙述改由 verdicts 分支生成，不再写死。
  - **方案B** `llm_narrate(...)`：当 `llm_narration.enabled=true` 时，把已算好的 verdicts+数字包发给 LLM 写解释段落；任何异常回退到规则文本（报告永不失败）。`render_report` 新增 `use_llm` 参数可临时覆盖。
  - **方案C** `validate_consistency(...)` + `_handle_consistency(...)`：渲染后扫描叙述是否与 verdicts 一致；`strict_consistency=true` 时直接抛错，否则打印到 stderr 兜底。
- 默认 `enabled=false` → 与 v4.1 行为一致（确定性、可复现）。要启用 AI 填充：用 base_v5.toml 并把 `enabled=true`、配置 `api_key_env`/`model`/`base_url`。
