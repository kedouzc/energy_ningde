## 1. 产品概述

### 1.1 产品愿景
用运筹规划建模的方式，做一个证券投资的仓位分配工具，面向不同风格的人，有不同的目标函数、约束条件设置，把学术化的运筹学经济学数学语言，变成大家可以通过游戏模拟的仓位分配小游戏，把晦涩的运筹学翻译成普通人能懂的「投资平行宇宙寻宝游戏」，看到自己的资源在不同配置情况下的结局，能在不同配置的"平行宇宙"间穿梭，当成自己投资的一面镜子，帮助自己制定投资计划。

- 你现在最缺的是什么，多投什么能让你的投资收益最大化

| **【对偶理论=价值平行宇宙】** | 原问题（资源宇宙）：如何分配 5 大资源，让估值错配收益最大化<br>对偶问题（产品宇宙）：市场给标的、流动性、风险的定价，和用户估值的内在定价的差值<br>双空间对称切换，自动发现市场的估值错配 | 把传统的「仓位分配数学题」，变成「基于用户估值的价值发现引擎」，彻底跳出量化工具的同质化竞争 |

### 3.2 核心世界观升级（MILP 与影子价格的调和）

为了容纳 0-1 变量，在运筹学隐喻体系中引入**"量子态"与"经典态"**的设定：

- **量子态选择（MILP 的 0-1 变量）：**
  产品宇宙中的探路者（股票），在被你放入组合前处于"叠加态"。你的**认知带宽**就像"观测仪器"，带宽有限，你只能"坍缩（激活）"有限数量的探路者（变量 $y_i \in \{0,1\}$）。这就是 0-1 整数规划的几何意义：**平行宇宙不是平滑过渡的，而是要跨越特定的"星门"（节点分支）。**

- **经典态滑行（连续变量分配）：**
  一旦探路者被激活进入你的宇宙，资金的分配（权重 $w_i$）就回到了经典力学的滑行阶段，沿着资源边界墙推到极致。

- **高维探测仪（解决 MILP 没有标准影子价格的问题）：**
  数学上，整数规划无法直接求影子价格。但在游戏中，我们设定系统会瞬间开启**"高维探测仪"（即运筹学中的 LP Relaxation 线性松弛法）**：系统会短暂假设"你可以只研究半只股票"，借此去探测那堵挡住你的"墙"背后的价值，从而强行算出那道墙的**"影子价格（突破赏金）"**，告诉你瓶颈在哪。

## 4. 运筹学理论基础

### 4.1 线性规划的几何意义：列空间视角 + 基变换 + 对偶

#### 4.1.1 两个空间：资源宇宙 vs 产品宇宙

- **资源宇宙**
  - 以各类资源为坐标轴，初始坐标系由松弛变量（闲置资源）构成
  - 这个空间只能描述：用了多少资源、剩多少资源，无法直接看出产品总价值

- **产品宇宙（动态、活的平行宇宙）**
  - 以当前选中的产品（基变量）为坐标轴，因为产品之间互相争夺资源，坐标轴一般是斜的
  - 这个空间可以直接描述：生产多少产品、总价值是多少

#### 4.1.2 关键角色

- **宝藏点（RHS 向量）**：你拥有的资源总量，是整个问题要抵达的"资源边界"
- **探路者（产品向量）**：每一种产品，对应一根向量：代表生产 1 单位该产品，要消耗多少各类资源；松弛变量 = 不生产产品，只保留闲置资源的标准向量
- **寻宝路径**：把产品向量按产量缩放、再相加（线性组合），拼出刚好抵达宝藏点的总消耗；路径的每一段，对应一种产品的生产数量
- **赏金（目标函数）**：每种产品有固定收益，我们要让整条路径的总赏金最大

#### 4.1.3 为什么要构建「产品宇宙」？

- 资源宇宙只能看数量，看不见价值
- 产品宇宙用产品当轴，可以直接用 `产量 × 单位价格` 算出总价值，让原本看不见的目标变得可度量、可优化
- 产品宇宙不是一开始就固定，而是随着迭代一步步长成最终形态

#### 4.1.4 求解过程：从资源宇宙走到产品宇宙

1. **起点**：在资源宇宙，以松弛变量为轴，所有资源闲置
2. **换基 = 换坐标系**：每次把一个更赚钱的产品拉进来当新坐标轴，把一个不赚钱的闲置资源扔出去，坐标系一步步从"资源视角"扭成"产品视角"
3. **顶点跳跃 = 撞墙前进**：每一步都沿着约束墙（资源上限）走，把某一种资源用到边界、用到紧约束，直到总价值再也涨不动
4. **消元 = 空间解耦**：把斜着的、互相干扰的产品轴，通过矩阵变换"扶正、解耦"，让每个产品在自己的坐标轴上独立可读
5. **归一 = 重新定度量**：用产品宇宙的价值尺度，重新度量资源，资源在新尺度下的单位长度 = 影子价格 π

#### 4.1.5 影子价格 π 是怎么来的？

- 每一步撞到约束墙 = 某资源被用尽、变稀缺
- 稀缺性 = 多一单位资源能多赚多少钱
- 这个值在坐标变换时自动暴露，就是 π
- 所以：π 不是最后突然算出来的，是迭代中一步步求出来的

#### 4.1.6 行空间 vs 列空间（两种看图方式）

1. **行空间几何（约束视角）**
   - 每一行约束 = 空间里的一堵墙
   - 多堵墙围出一块可行区域，这就是切蛋糕
   - 最优解一定出现在蛋糕的顶点上
   - 目标函数像一个斜面，往上推，直到刚好顶住一个顶点

2. **列空间几何（产品视角）**
   - 每一列 = 一根产品向量（箭）
   - 所有能通过"缩放 + 相加"拼出来的点，就是所有能实现的生产方案
   - 最优路径 = 拼出宝藏点，且总赏金最大

#### 4.1.7 数学家的真正思路（对偶 + 单纯形）

- 世界本身是复杂、斜交的向量系统
- 用矩阵变换，把复杂空间扭成简单、整齐的平行宇宙
- 对偶 = 价值平行宇宙：资源宇宙看消耗，产品宇宙看价值，两者完全对称
- 单纯形法 = 虫洞传送门：从资源宇宙穿到产品宇宙，一次变换，同时拿到两样东西：最优产量、资源影子价格 π

#### 4.1.8 最终一句话总结
资源宇宙管用量，产品宇宙管价值；单纯形是动态换坐标系的虫洞；每一步撞墙，算出一步影子价格；最优时，产量与资源价值同时出现。

## 5. 模型设计

### 5.1 目标函数完整设计

**目标函数核心**：最大化「用户估值体系下的错配赏金」。为保证影子价格的纯洁性，将认知带宽转化为整数规划（MILP）的约束条件，剥离惩罚项，让目标函数纯粹衡量"总赏金"。

#### 5.1.1 目标函数构成项

| 目标函数构成项 | 核心含义 | 对应理论映射 | 模型中的作用 |
| :--- | :--- | :--- | :--- |
| **核心收益项：**<br>Σ(安全边际率ᵢ × 确定性系数ᵢ × 仓位权重 wᵢ) | 持仓标的的总错配收益 | 产品宇宙的「总赏金最大化」，寻宝路径总收益 | 锚定用户自身的估值体系，放大个人投资逻辑 |
| **现金价值项：**<br>现金单位效用 × 现金比例 | 现金总价值（保底无风险收益 + 错配期权价值），和股票平等参与 | 现金作为基变量，对应探路者向量，而非被动约束 | 自动求解最优现金比例，打破"预设必须留多少钱"的定势 |

#### 5.1.2 证券估价与价格挂钩机制

**核心功能**：用户输入明确估价，系统自动计算安全边际和预期收益率。

| 功能模块 | 交互方式 | 计算逻辑 | 显示内容 |
| :--- | :--- | :--- | :--- |
| **估价输入** | 滑块 + 数字输入框 | 用户输入目标估价 P_target | 当前市价 P_current、估价 P_target |
| **安全边际率** | 自动计算 | (P_target - P_current) / P_current × 100% | 安全边际率%、高估/低估标签 |
| **预期收益率** | 实时计算 | 基于估价与市价差值，年化后显示 | 预期年化收益率%、回本周期 |
| **价格提醒** | 可设置触发条件 | 当市价触及估价的 X%时提醒 | "当前价格低于估价 15%，进入击球区" |

**示例交互**：
```
贵州茅台 (600519)
├─ 当前价格：¥1680.00
├─ 我的估价：¥2000.00 [滑块调节：1500 ⟷ 2500]
├─ 安全边际：+19.0% (低估)
└─ 预期年化收益率：23.5% (假设 2 年回归估值)
```

#### 5.1.3 变量定义与逻辑锚定
- 连续变量 $w_i \in [0, 1]$：标的 $i$ 的资金权重（经典态滑行）
- 二元变量 $y_i \in \{0, 1\}$：标的 $i$ 是否被激活（占用认知带宽）（量子态激活）

**逻辑锚定（大 M 法映射）**：
$$w_i \ge \text{Min\_Weight} \times y_i$$
$$w_i \le \text{Max\_Weight} \times y_i$$

**大白话解释**：一旦你消耗精力关注了它（y=1），就至少要买够"建仓底线"，且不能超过"单股上限"；如果不关注（y=0），仓位严格为 0。

#### 5.1.3 目标函数标准化公式（融合混合整数规划 MILP）

```python
import pulp
prob = pulp.LpProblem("Parallel_Universe_Max_Value", pulp.LpMaximize)

# 变量定义：
# w[i]: 连续变量，仓位权重 (经典态滑行)
# y[i]: 0-1 二元变量，是否占用认知带宽激活该股票 (量子态激活)
prob += (
    # 核心收益项
    pulp.lpSum([security_margin[i] * certainty_coeff[i] * w[i] for i in stock_pool])
    # 现金价值项
    + (risk_free_return + mismatch_option_value) * cash_ratio
), "Max_Total_Bounty"
```

### 5.2 约束条件分类

#### 5.2.1 用户可视化自定义项（多邻国式滚动条，零数字输入）

| 约束项名称 | 后端数学逻辑 | 默认值 | 配套多邻国提示语（引导动作） | 对应资源 |
| :--- | :--- | :--- | :--- | :--- |
| **风险容忍度** | Σ(风险占有率ᵢ × wᵢ) ≤ 总风险 | 20% | 「你愿意承担的最大回撤。推高它，探路者就能去更危险但也更肥沃的星系寻宝。」 | 风险预算 |

#### 5.3.3 具体股数建议与可买性校验

**核心功能**：根据用户资金量，计算每只证券的可持有股数，对无法购买的证券给出明确说明。

| 计算项 | 公式 | 示例 | 处理方式 |
| :--- | :--- | :--- | :--- |
| **建议仓位金额** | 总资金 × 优化权重 wᵢ | 100 万 × 15% = 15 万 | 显示为金额和百分比 |
| **可买股数** | floor(建议仓位金额 / 当前股价 / 100) × 100 | 15 万 / 1680 ≈ 89 股 → 取整 100 股 (1 手) | A 股必须为 100 的整数倍 |
| **实际使用资金** | 可买股数 × 当前股价 | 100 股 × ¥1680 = ¥16.8 万 | 可能略高于/低于建议仓位 |
| **零头处理** | 建议仓位 - 实际使用 | 15 万 - 16.8 万 = -1.8 万 | 归入现金储备或调整其他标的 |
| **不足 1 手处理** | 建议仓位 < 当前股价×100 | 建议买 5 万，但茅台 1 手需 16.8 万 | **提供 2 个选项**：剔除 or 增加资金 |

## 7. 自迭代闭环设计（打造越用越爽的飞轮）

### 7.1 个人认知校准飞轮（自我照镜子）

**机制**：记录用户 $T_0$ 的估值参数，比对 $T_1$ 的真实表现。

**输出**：每月推送《平行宇宙探险月报》。"上月你对消费股的判断击败了 80% 的玩家，但【单股最大仓位上限】约束了你的战果！建议下月解锁更高上限。"让用户直观看到自己的成败归因。

### 7.2 第三方估值生态闭环（从单机工具变数据容器）

**机制**：提供开放接口，让大 V、量化平台上传他们的"估值宇宙数据包"供普通用户订阅使用。

**飞轮**：系统统计不同数据包在模型里跑出的胜率，生成"本月最佳星系数据包排行榜"。用量大的工具倒逼数据商主动寻求接入，形成内容生态。

### 7.3 情绪逆向对冲提示（群体智能的高级玩法）

**机制**：当系统察觉全网大量用户同时疯狂拉低某板块的"情绪滚动条"（群体悲观）时，自动提高该板块对应的"错配期权价值"。

**输出**：向高阶用户触发隐藏任务："🌌 探测器发现异常：大众情绪正在恐慌抛售医药股，系统判定错配期权价值极高，是否拨出 5% 的现金前往探底？"

## 9. 术语表

| 术语 | 定义 |
| :--- | :--- |
| 资源宇宙 | 以各类资源为坐标轴的固定坐标系，只能描述资源用量，看不见价值 |
| 产品宇宙 | 以基变量（产品/标的）为坐标轴的动态坐标系，可直接度量价值 |
| 宝藏点 | 用户拥有的资源总量上限，是模型要抵达的资源边界 |
| 探路者 | 每一个投资标的对应的产品向量，负责探索价值 |
| 撞墙 | 模型迭代中触达资源边界的行为，表示某资源被用尽 |
| 影子价格 | 每多一单位稀缺资源能多赚的钱，是撞墙过程中自动计算的价值洞察 |
| 基变换 | 坐标系从资源视角扭转为产品视角的过程 |
| 单纯形法 | 从资源宇宙穿越到产品宇宙的求解算法，同时输出最优解和影子价格 |
| 认知带宽 | 用户能深度跟踪、完成估值的标的数量上限 |
| 0-1 整数规划 | 用于描述"激活/不激活"的二元选择，对应星门激活机制 |
| LP Relaxation | 线性松弛法，用于求解整数规划的影子价格 |
| MILP | 混合整数线性规划，同时包含连续变量和 0-1 二元变量 |
| 大 M 法 | 通过大数 M 绑定连续变量和二元变量的数学技巧 |
| 错配期权价值 | 现金作为探路者，在未来捕捉估值错配机会的期权价值 |
