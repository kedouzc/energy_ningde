# 换电战略决策模型 v4.2.1

本目录是独立于v4.1/v4.2的归因与口径修正版本。v4.1、v4.2目录与报告保持冻结，不参与本版运行；旧版报告只作为方法对照，不作为结果校准锚。自v4.2.1起模板与输出报告均带版本号，修改产生新版本时新建模板文件、冻结旧版。

## 数据流

`configs/base.toml → scale → capex → business → consolidation → capital_cycle/group_constraints → decision → report`

- `base.toml`：只存外生参数、来源和研究情景，不存派生结果。
- `scale.py`：生成唯一的车辆、充换电路线、CATL市占（含充电段份额差实现率）、装机和交易量底座。
- `derived.py`：由价格曲线、寿命、物理参数推导电池价格、EAC/残值、换电频次与单站能力。
- `capex.py`：按批次生成建设期年度CAPEX、更新计划、等效全周期资本底座及CRF资本要求。
- `business.py`：分别计算换电正算、CRF要求回报和制造线回报。
- `consolidation.py`：生成2026E、2030E无换电和2030E重资产换电总账；制造销量/份额差拆分为“换电段+更换循环锁定订单（计入归因）”与“充电段份额净效应（仅敏感性）”。
- `capital_cycle.py`：比较成熟后的权益档、回款、持续价值与未来资本释放（v4.2.1起不再计算资管平台价值）。
- `group_constraints.py`：扣除分红、回购、三项已识别并购（中恒＋世纪互联＋启源）、换电资本后的集团资金上限。
- `model.py`：接入并购扰动、组装统一决策快照，并提供九组单变量敏感性（含充电段份额差、制造净利率差）。
- `decision.py`：各模块子结论与最终判断（v4.2.1起为直陈式结论：支持重注及六段依据）。
- `report.py`：使用无业务结果数字的模板生成MD、JSON和Dashboard参数注册表；当前模板为 `templates/strategic_report_v4_2_1.md.tpl`。
- `make_diff_report.py`：生成v4.1→v4.2红绿对照删改痕迹版（历史工具；v4.2.1起不再生成新对照版，仅供需要时回溯）。

## 运行

在本目录执行 `py -3.11 run.py`（需要Python 3.11+的tomllib）。生成物包括：

- `outputs/decision_snapshot_v4_2.json`
- `outputs/dashboard_parameter_registry_v4_2.json`
- `分析结论/换电毛估估_宁德时代应不应该下重注，以及什么时候能见分晓_v4.2.1.md`

## 测试

执行 `py -3.11 -m pytest tests/ -q`。测试覆盖路线恒等式、站数勾稽、价值桥、权益情景、参数传导、份额差拆分以及旧版结果锚隔离。

## Dashboard接口

Dashboard不应重写任何公式，只读取参数注册表、修改配置副本、重新调用 `build_model()`，再展示新的决策快照。这样MD、静态HTML和未来交互界面共享同一套计算内核。
