# Strategic Decision Framework - 战略决策分析六步法

## 技能描述

本技能用于对企业的重大战略决策进行结构化分析。当用户需要判断"某公司是否应该进入某新业务"、"某战略选择是否合理"、"如何在复杂竞争格局中做取舍"时，应使用本技能。

本方法论融合了彼得·德鲁克、安迪·格鲁夫、杰夫·贝索斯、迈克尔·波特、克莱顿·克里斯坦森、纳西姆·塔勒布、查理·芒格等思想家/企业家的核心洞见，经过批判性重构后形成。

## 核心原则

1. **从"用户真正买什么"出发，而非从"我们要卖什么"出发**（德鲁克）
2. **"不做会怎样"必须与"拖一年不做的代价"在同一层回答**（格鲁夫）
3. **先找"10年不变的东西"，再建财务模型**（贝索斯）
4. **合作方分析必须包含议价能力维度**（波特）
5. **颠覆性创新的早期财务模型几乎一定是错的——加一个"不理性检查点"**（克里斯坦森）
6. **不用中心化概率加权，用"一定不成的条件清单"反向追踪**（塔勒布+芒格）

---

## 六步分析流程

### 第一步：需求原点——用户真正在买什么？

**不要问"用户要不要这个产品"，要问"用户的待办任务（Job to be Done）是什么"。**

分析清单：
- [ ] 目标用户分为几类？每类的核心"待办任务"是什么？（不是"我需要换电"，而是"我需要在不确定的时间确定地走"）
- [ ] 每类用户当前的替代方案是什么？替代方案的痛苦程度如何？
- [ ] 在这项"待办任务"中，什么是10年不变的？（贝索斯测试）
- [ ] 不同用户群体之间的需求是同一质还是分化？如果是分化的，各自的市场空间量级有多大？

**输出**：用户待办任务表 + 场景分化判断 + 不变性锚点清单

---

### 第二步：战略必要性——不做会怎样？拖一年又会怎样？

**不要只列"威胁清单"，要为每项威胁标注时间紧迫度。**

分析清单：
- [ ] 如果完全不做这个业务，3年后公司会面临什么局面？
- [ ] 每项威胁的"逼近速度"如何？是线性逼近还是加速逼近？（格鲁夫拐点测试）
- [ ] 如果今年不做、明年再做，代价增量是多少？
- [ ] 如果这个业务由竞争对手做成，对本业的影响是"市场份额层面的"还是"战略叙事层面的"？两者有何不同？
- [ ] 有没有一个"不可逆点"——过了这个点，再做也来不及了？

**输出**：威胁-紧迫度矩阵 + 不可逆点时间线

---

### 第三步：算账之前先做"不变性审查"，再建财务模型

**贝索斯原则：先把"不变的东西"找出来，再用它们作为财务模型的锚。**

分析清单：
- [ ] **不变性审查**：在这个生意里——哪些基本物理/经济规律10年不变？哪些用户行为10年不变？哪些竞争约束10年不变？
- [ ] **生意本质定义**：这门生意本质上是哪些稀缺资源的套利？套利公式是什么？
- [ ] **收入模型**：收入驱动变量有哪些？每个变量的确定性和波动范围？
- [ ] **成本模型**：成本结构是什么？（必须区分"自己做"和"合作方做"两个视角）
- [ ] **竞争格局映射到财务**：不同竞争情景下，收入驱动变量和成本变量各如何变化？
- [ ] **颠覆性创新检查点**（克里斯坦森）：即使按照当前财务模型，这个业务的IRR不如替代方案——有没有理由仍然要进入？如果竞争对手先进入并跨越临界点，你的既有业务的财务模型会怎样变化？

**输出**：不变性锚点清单 + 套利公式 + 多情景财务模型 + 颠覆性检查点结论

---

### 第四步：合作方拼图——站在合作方的鞋子里算账

**不要只分析"谁该跟谁"，要问"合作方的议价能力有多大"以及"合作方能分走多少"。**

分析清单：
- [ ] **合作方分类**：按照资源禀赋（不是按照行业），将潜在合作方分类。分类维度必须与生意的套利维度一一对应。
- [ ] **合作方视角的经济账**：站在每类合作方的角度，他投这个生意的ROI是多少？他有什么替代选择？
- [ ] **合作方议价能力评估**（波特）：每类合作方——他有多稀缺？他能带给你多少不可替代的资源？他切换到竞争对手的成本有多低？
- [ ] **合作方之间的博弈**：如果A类合作方先入场，B类合作方的行为会如何变化？
- [ ] **合作模式的绑定强度**：利益绑定是"强"还是"弱"？合同条款之外，有什么结构性原因让合作方不会离开？
- [ ] **动态合作演化**：解决问题的速度和决心如何影响合作面？先发优势能否锁定关键合作方？

**输出**：合作方分类表 + 合作方ROI对照表 + 议价能力矩阵 + 绑定强度评估 + 合作演化路径

---

### 第五步：约束与挑战——什么会卡住这个生意？怎么拆？

**五类约束必须全部过一遍，缺一不可。每类约束标注"可突破性"和"时间窗口"。**

分析清单：
- [ ] **需求侧约束**（第一步的延伸）：兼容用户量怎么增长？正反馈的临界条件是什么（单变量还是双变量）？
- [ ] **供给侧约束**（第三步的延伸）：产能、资金、管理带宽，哪个是真正的瓶颈？
- [ ] **硬物理约束**：电网容量、地段、技术物理极限——这些不能靠钱解决。
- [ ] **技术路径约束**：哪些技术变量会改变竞争条件？哪些会直接消灭这个生意？时间窗口？
- [ ] **制度/政策约束**：标准制定权、行业标准（国标）、政策倾向——谁有能力影响这些？

**输出**：五类约束清单 + 每类约束的可突破性评级 + 时间窗口

---

### 第六步：终局判断——不用概率，用"一定不成的条件"

**塔勒布原则：不求精确概率，只求知道什么情况下一定不成。芒格原则：反过来想。**

分析清单：
- [ ] **一定不成的条件清单**：列出所有"如果X发生，这个业务一定不成"的条件。（X的内容从前面五步中提取）
- [ ] **条件逼近度追踪**：每个"一定不成"的条件，当前处于什么状态？是远离还是逼近？
- [ ] **与替代方案的终局比较**：如果你的业务不成，替代方案（竞争对手的方案）会在什么情景下主导市场？那个情景的概率驱动因素是什么？
- [ ] **战略韧性测试**：在最悲观但仍然可能的情景下，公司能承受的损失是多少？有没有"止损点"？
- [ ] **战略期权价值**：即使业务的直接经济回报不确定，它有没有期权价值？（如：阻止竞争对手获得垄断地位、保护既有业务估值逻辑、获取标准定义权）

**输出**：一定不成的条件清单（含逼近度评级） + 替代方案终局情景 + 韧性测试结论 + 期权价值评估

---

## 使用要求

1. **每一步必须写出明确的输出**，不能跳过；每一步的标题按"Q1-Q6"编号
2. **必须引用至少一位思想家/企业家的概念**来支撑每一步的核心判断
3. **财务数据标注来源**，区分"行业公开数据"和"推算数据"
4. **最终结论使用"一定不成的条件清单"而非中心化概率**来表述不确定性
5. **文档体例**：开篇总括 → Q1-Q6递进推演 → 结尾速览。开篇框定六步逻辑全貌，结尾用七维表格收束核心结论

## 适用场景

- 企业是否应进入新业务/新市场
- 复杂竞争格局下的战略取舍
- 重资产基础设施投资的进入判断
- 需要多方合作才能建成的生态型业务
- 面临颠覆性创新威胁时的防守反击评估
