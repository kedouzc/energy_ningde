# 口径 · 超充站与换电站：站层的一年账（解释 `src/charging.py`）

> **回答什么**：同样一笔钱投下去建一座站，超充站和换电站**站这一层**各自一年能挣回多少。只算站层；电池的钱归电池银行（车队总账），不在这里。
> **不回答**：谁的车队总成本更低（车队总账）；充电服务费终局停在哪（车队总账第 3.1 节）。
> **对应程序**：`src/charging.py`；参数 `[charging_station]`、`[swap_business]` 站点项。本文的数由 `src/inject.py` 注入（现算表来自 `src/caliber_docs.py`）。
> **来历**：见 `DECISIONS.md` 2026-09-19、2026-09-20；本文只写现行口径。

## 〇、口径

- **用"全投资现金回报率"，不含资金成本**：先看这门生意本身能挣多少（不加杠杆的现金回报），再拿它跟别的机会比。折现率只用在需要折现的地方（车队持有期账、均衡服务费）。
- **利用率一律是能量利用率** ＝ 一年实际充出的电量 ÷（装机功率 × 8,760 小时）≈ 时间利用率 × 功率利用率。市面测算互相打架，多半是混用了这三个口径。

## 一、超充站：一座参照站一年的账

**参照站**：黄骅港站口径，26 桩 × 320 kW ＝ 8,320kW，总投资 500 万元，月充 112.7 万度、月服务费收入 23.5 万元（src.chargeonline_2026）——少数"投资额、电量、收入"三样都公开、能反查的样本。模型按 600元/kW × 装机 ＝ 499 万元，与披露吻合。

| 成本项 | 取值 | 说明 |
|---|---|---|
| 设备折旧 | 直线法，(投资 − 残值 5%) ÷ 8年 | 不含折现率 |
| 运维 | 投资 × 3.5%／年 | 含设备维保（src.donghai_charging_2024） |
| 场地 | 15万元/年 | 与换电站同口径 |
| 人工 | 26.88万元/年 | 与换电重卡站同口径（双班两人）；部分充电站无人值守，对充电偏保守 |
| 电损 | 电量 × 5% × 谷电价 | 重卡站实测 4%–6% |
| 平台分成 | 基准 0%，压力档 6% | 见下 |
| 容量电费 | 不计 | 政策事实：2030 年前免收（第二节） |

**一年的账**（利用率 22%，服务费按实测中值 0.23元/kWh）：

| 项 | 读数 |
|---|---|
| 年服务费收入 | 369万元/年 |
| 年现金成本 | 83万元/年 |
| 年现金流 | 285万元/年 |
| 全投资现金回报率 | 57% |
| 静态回收期 | 1.7年 |
| 会计口径度电成本（含直线折旧） | 0.089元/kWh |
| 回报率：最闲一档／最忙一档 | 45%／114% |
| 回报率：计平台分成压力档 | 53% |
| 现金打平利用率 | 3.8% |

**平台分成为什么基准取零**：乘用车公共站按服务费给聚合平台抽 10%–20%（src.charge_platform_36kr）；重卡是可识别、可签约的车队，有运营商明说避开线上平台 6% 抽佣、改线下会员卡直收，多个场站自有及合作车队贡献五到六成电量（src.hdt_charging_report_2026）。基准取零＝把有利条件给对手；压力档取重卡场景唯一一条实际报价 6%。华为超充联盟是设备供应商形态，成本已在设备单价里，不叠加。

**一处调和不了的矛盾**：行业口径说重卡充电站盈亏平衡利用率约 15%，本算法的现金打平只要 3.8%。可能原因：投资是否含电力增容（增容占总投资 35%–50%）、样本偏明星站、行业用了时间利用率。两个数都摆着；无论按哪个，实测利用率下都高于打平线——"对手在亏本卖、撑不住"两个口径都不支持。

## 二、容量电费：2030 年前不用交

> **2030 年前对实行两部制电价的集中式充（换）电设施用电免收需量（容量）电费。**——交规划发〔2025〕42 号第（二十一）条（src.mot_energy_2025）

- 这是事实，不是保守假设；同时适用于充电与换电，不构成路线差异。
- 所以电网容量的差异在兑现年之前只通过**建站投资**传导（电力增容占充电站总投资 35%–50%），不通过运营成本。
- 兑现年之后若恢复征收（30元/kVA·月），电网容量差异会重新变成运营成本差异——要跟踪的政策变量。

## 三、换电站：同一套定义一年的账

口径对齐三条：收入只算服务费（电池租金归电池银行）；投资含站内周转电池、不含车端电池；成本逐项与超充站对应。

| 项 | 读数 |
|---|---|
| 单站投资（站体 500 万元 ＋ 站内周转电池） | 742万元（其中周转电池 242万元） |
| 年服务费收入 | 322万元/年 |
| 年现金流 | 211万元/年 |
| 全投资现金回报率 | 28% |
| 静态回收期 | 3.5年 |
| 换电服务费相对超充实测中值 | -33% |
| 单站吞吐相对超充参照站 | 31% |

## 四、结论：同价同吞吐，超充站的站层生意更好

把服务费与单站吞吐拉平到超充参照站的水平：

| | 超充参照站 | 换电站（站层） |
|---|---|---|
| 单站投资 | 499 万元 | 742万元 |
| 同价同吞吐·全投资现金回报率 | 57% | 37% |
| 同价同吞吐·静态回收期 | 1.7年 | 2.7年 |

- **站对站、同价同量，超充赢**：换电站多背了一笔站内周转电池，而这笔钱在站层只能靠同一笔服务费回收。
- **换电站层不是利润中枢**：换电的钱在电池银行的租金（车队总账）。站层只要不亏、能把车吸引进体系就够了——不要把资源投在站层的价格竞争上。
- **证据等级不同**：超充一侧是公开的实际运营数据；换电一侧是模型的成熟期假设。

## 五、单站吞吐与站端充电能力

换电站一天交出去的电，要在充电窗口里从电网充回来。按 16 小时充电窗口、站端箱变 4,500 kW 算，**吞吐假设是站端充电能力的 0.92倍**。单站规划能力按排队利用率 0.8 定为 154 次/日后（`车辆与站数_推算方法.md` 2.2 节），吞吐已不超过站端充电能力，但贴近上限——再提高单站车次，就要延长充电窗口（夜里也充）或加大箱变。按不超上限的吞吐算：回报率 28%、回收期 3.5年。

**电网容量**：超充对换电的电网容量倍数 2.5倍（超充最忙 1.4倍、最闲 3.1倍）；换电站电网负荷率 62%。

## 六、哪几个数最不牢靠（按重要性排）

| 排序 | 参数 | 为什么不牢靠 | 影响 |
|---|---|---|---|
| 1 | 换电站的单站吞吐假设 | 贴近站端充电能力上限（第五节） | 动摇换电侧单站口径与估值锚 |

**没有计入、而会让换电更贵的项**：站内电池的衰减与更换——本节只算一年现金流，没有算第二块电池的钱。这是本对比最大的一处偏向换电的遗漏。
