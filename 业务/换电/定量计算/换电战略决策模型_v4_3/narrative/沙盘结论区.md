# 顶部结论

- 业绩：按目前营运车的电动化趋势，CATL 换电业务可在{target_year}年底前累计装车 {veh_ops} 万辆（占{veh_mkt}万辆营运车总规模的{share}%），锁定之后每年平均{repl_gwh}GWh订单（占2026E出货量的{repl_share_pct}%）
- 估值：为 CATL 每年贡献{dist_cash}亿元可分派现金，按{ebitda}亿EBITDA×{mult}倍，扣除业务整体负债后，CATL在持股{own_pct}%情况下可享有{mktcap}万亿市值
- 卡位：年换电量达{energy}亿度、占全社会用电量的{elec_share}%，换电站内装机规模{batt_station}GWh、占国内储能装机规模的{storage_share}%，{stations}座换电站均位于交通干线，成为最大的分布式储能VPP运营商
- ROI：{target_year}年底前年投入峰值{peak_call}亿元，后续发行REITs可回笼{reit_mult}倍于投资的资金
- 重点：重卡，装车{veh_heavy}万辆（占{heavy_stock_wan}万保有辆的{heavy_pen_pct}%），合计形成{heavy_fleet_gwh}GWh车端装机与{heavy_station_gwh}GWh站内周转装机，锁定之后每年平均{heavy_repl_gwh}GWh订单；用户全成本 TCO 按{heavy_repl_cycle}年持有期为{tco_swap_wan_9}万元（折合{tco_swap_kwh_9}元/kWh），低于 LNG 的{tco_lng_wan_9}万元（{tco_lng_kwh_9}元/kWh）、柴油的{tco_diesel_wan_9}万元（{tco_diesel_kwh_9}元/kWh）；即便本模型按高频使用将电池更换周期压降至{heavy_life_yrs}年，仍有明显优势，为{tco_swap_wan}万元（{tco_swap_kwh}元/kWh）vs LNG {tco_lng_wan}万元（{tco_lng_kwh}）、柴油 {tco_diesel_wan}万元（{tco_diesel_kwh}）
- 结论：
    - 重构动力电池业务基础：摆脱制造业务内卷、切换到更为稳健且高壁垒可持续的资产运营业务，投入有限、财务回报丰厚、风险可控，将带动公司价值重估
    - 建立动力电池用能标准：推动“电动车用能=CATL换电=便宜+好用”的用户心智达成，固态电池等技术迭代、使用场景拓展（如电动船舶、工业机器人等）会进一步强化 CATL 在动力电池领域的寡头地位，帮助 CATL 建立电池从研发、制造、动力电池使用、退役为储能电池、回收的全生命周期开发利用闭环，形成数据驱动的增长飞轮，进一步打开估值空间。

# 口径与信源

以上每个数的口径与出处（改文案时可一并核对，避免"数还在、口径已经换了"）：

- **营运车总规模 {veh_mkt} 万辆**：重卡 + 城配 + 出租 + 网约 + Robotaxi 全口径保有量，取自 `configs/base.toml` 的运营事实字段（`vehicles.*.stock_wan`、`operating_demand.*`），**非模型推导**，故与分子（模型推算的 CATL 换电车辆）相互独立，不构成循环论证。
- **每年平均 {repl_gwh} GWh 订单**：建设期结束后只剩**更新需求**，按更新理论分池计算（Σ 池机队 GWh ÷ 池寿命），**含车端 + 站内**。必须分池是因为倒短池寿命 8.37 年、干线池仅 2.94 年，用单一寿命会抹平干线池的更换频率。分母 644GWh 为 2026E 动力电池出货（`finance` 段）。
- **持股 {own_pct}%、估值倍数 {mult} 倍**：均为**可调参数**，拖动"CATL持股比例""换电运营 EV/EBITDA 倍数"滑块时本段数字会同步变化。
- **重卡用户全成本 TCO**：口径是 **JPM Table 3 的持有期总成本**（购车 − 补贴 + 年运营 × N），不是只算能源；含购车、购置税、补贴、维保、载重损失。公式已用原表反算验证（电动 595,000 + 276,250×8 = 2,805,000，与 Table 3 八年行完全一致）。
  - 换电侧只替换**能源单价**一项：JPM 电动列用 0.85 元/kWh 的工商业充电价 → 换电能源单价 = **谷电采购价 + 峰谷套利价差** = {energy_unit_kwh} 元/kWh（谷电 0.30 + 峰谷价差 0.40，base.toml:815；换电站有峰谷套利收入，该价差必须计入能源真实成本，不能只取谷电价）。再加上服务费与电池租金，用户实付全口径 = {tco_swap_kwh} 元/kWh（见上方结论区）。其余（购车/税/补贴/维保/载重损失）照搬 JPM 电动列，保证三者在同一套自洽参数下对照。
  - BaaS 免去的电池购置按**单车带电量 × 模型电池价**计算（当前约 29.5 万元，占 JPM 整车价 70 万的 42%，落在 JPM §8.3"电池占整车 40–50%"区间内），不用 JPM 的 40–50% 估计——因为电池价在模型里是价格曲线参数，要随调参一起变。
  - 单车年增收 4 万元（换电 vs 充电的时间价值，JPM §8.3）已计入。
  - 元/kWh 为**折算值**：三种动力年里程同为 15 万 km，分母同为等效能耗，故可直接并排比较。
  - 信源：[JPM 重卡电动化 英中对照 · Table 3](../../media/JPM_重卡电动化_英中对照.md)（`Source: J.P. Morgan estimates.`）；算法复刻见 [JPM重卡换电测算.py](../../media/JPM重卡换电测算.py)；口径说明见 [TCO口径_JPM整套引用.md](../口径/TCO口径_JPM整套引用.md)。
