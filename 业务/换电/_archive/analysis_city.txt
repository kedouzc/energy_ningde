一、推导逻辑
──────────────────────────────────────────────────────────────────────

  逻辑链（从城市到网络）：

  城市汽车保有量
    → × 电动车渗透率 = 电动车保有量
      → × 换电渗透率 = 换电用户总数
        → ÷ 单站服务用户数 = 需要的站数
          → 站设备投入 = 站数 × 205万
          → 周转电池 = 站数 × 20块 × 2.97万
          → 用户电池 = 用户数 × 1块 × 2.97万
          → 总投入 = 站设备 + 用户电池 + 周转电池

  单站服务用户数推导（来自temp.md L12-29）：
    单工位站实际日均115次换电
    营运占80% = 92次 → 92÷0.71次/人/天 = 130个营运用户
    私家占20% = 23次 → 23÷0.20次/人/天 = 115个私家用户
    单站服务用户数 = 130+115 = 244人

  每个用户1块电池（装在车上，租赁给用户）
  每站20块周转电池（放在站里供换电周转）

【最终结论】
==========================================================================================

  1. 城市级模型的逻辑：
     不是"先有用户再建站"，而是"先铺站再吸引用户"（宁德时代策略）。
     站数由城市车辆保有量×渗透率决定，不是从单站容量倒推。

  2. 重庆现状（62站）：
     - 62站可服务15128人（满负荷）
     - 5500辆网约车已接入 → 每站日均54次，利用率47%
     - IRR = -2.3%，NPV = -16427万
     - 加0.2元/度补贴后：
     IRR = 2.9%，NPV = -8346万

  3. 一线城市终局（7.5万用户，308站）：
     - 总投入30.4亿（用户电池占73%）
     - 年收入8.8亿，EBITDA7.0亿
     - IRR = 9.5%，NPV = +3.5亿

  4. 关键发现：
     - 用户电池占总投入60-70%，是最大的成本项
     - 电池租赁收入和电池成本基本对冲，利润来自换电服务费
     - 宁德自产电池（0.40元/Wh）vs 外购（0.53元/Wh），IRR差5-6pp
     - 网络密度是前提条件：站不够密→用户不来→利用率低→亏损
     - 宁德"先铺站再吸引用户"策略正确，但前期必然战略性亏损

  5. 商业可行性判断：
     - 0.4元/度 + 0.53元/Wh电池：一线城市5%换电渗透率可达IRR 9.5%
     - 0.4元/度 + 0.40元/Wh电池：同场景IRR可提升至约14%+
     - 重庆当前5500用户+补贴：IRR 2.9%，具备商业可行性
     - 县城/地级市：用户基数太小，单站难以满负荷，IRR偏低
