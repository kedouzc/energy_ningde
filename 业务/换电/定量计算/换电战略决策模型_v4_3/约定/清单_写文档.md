# 清单 · 写文档（写或改章、专题、口径之前）

> 属于 `研究项目约定.md` F7、M1、D5。原"A 类文件交稿清单"的精简版。

## 动笔前
- [ ] 三行（M1）：要判的命题（可判真假）／判它要哪几个数／看到什么会改判。
- [ ] 这段内容的家对吗：算式与口径 → `口径/`；投资论证 → 章或专题；判断的变化 → DECISIONS。
- [ ] 先搜：这件事有没有已经写过的专题、口径或旧稿（M12）。

## 写的时候
- [ ] **结论先行**；每节最后一句回答开头的命题；中间量后面接"所以它怎么影响结论"。
- [ ] **每个数**：说来历（观测／推算／设定）、单位、时间尺度，并说它意味着什么（跟常识参照比）。
- [ ] **模型算的数写占位符**，不手抄（D5）；口径里的输入写键名与取值理由。
- [ ] **一节一个符号方向**；表格前说清正负各代表什么。
- [ ] **只写现在**（F2）：不写"上一版""更正""原先"；来历指向 DECISIONS。
- [ ] **术语**：第一次出现说清楚；不用自造的说法；"覆盖倍数"写明是 EBITDA 对资本回收要求的覆盖。
- [ ] **提出威胁或利好要给量级**；没有数据明说"没找到"，并给临界值。
- [ ] **举例先说代表性**（M7）；**三档并报**（M6）。
- [ ] 详细算式与大表放附录；正文每节最多一张小表。
- [ ] **每张程序现算表配三样**（D13）：算式（大白话）、输入表（键名／取值／信源／为什么）、算例（挑一行按计算器走一遍，中间数由程序注入）。敏感性表要写"每一格是什么、正负各代表什么、怎么读"。

## 交稿前
- [ ] 三句话复述全文；复述不出来就重写。
- [ ] 读者能答出"结论是什么、凭什么、什么会让它错"。
- [ ] build 通过（裸数字、占位符、状态纪律、信源台账四道闸门）。
