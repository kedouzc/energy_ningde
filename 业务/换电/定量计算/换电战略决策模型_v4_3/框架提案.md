## 0. 这份文件的四条写作纪律

前几版反复烂掉，根因只有一个：**它把"目标态"和"当前态"混在了一起。**
每次重跑出新数，就有人把新数 patch 进来；数一变它就过时，于是它变成一面永远擦不干净的
`交接.md` 的镜子——既没有 `交接.md` 新，又没有提案该有的稳定性。

四条纪律，每条都直接对着一类已经发生过的病：

**纪律一 · 只写目标态，不写当前值。**
本文件**不出现任何"今天跑出来的数"**。需要提到某个量时，写它的**中文名 + 程序字段名 +
去哪查**，不写它今天等于多少。

> 判据：**改一个参数重跑，这份文件需不需要改？需要 → 那段写错了地方。**

（这条纪律与叙述层那条"MD 里不许出现字面数字"是同一条纪律的两个应用面。
上一版里 `3,362.9`、`10.6%`、`2.3~2.4 倍`、`105 节点` 全是违反这条纪律的产物——
其中 `3,362.9` 甚至是**已被修掉的旧公式**算出来的，因为它被 patch 进来之后，
后续修 bug 时没人记得回来改它。）

**纪律二 · 可独立阅读。适用于全部五份纲领文件**（README／约定／本文件／交接／DECISIONS），
不只本文件。
出现的每个专有名词，要么在所在文件内定义，要么给出"去哪一节查"的明确指针。
**不允许出现只有作者当时知道的编号或缩写。**

> 这条犯过两次：上一版的 `T5`（本文件）、以及 `交接.md` 里的 `T1`——
> **第二次之所以还会犯，是因为纪律只声明了本文件这一个作用域**。
> 见 `DECISIONS.md`「2026-09-06k」：**一条纪律如果没写清作用域，
> 它的作用域就是"我写它时正在看的那份文件"。**

见文末术语表。

**纪律三 · 每一节必须属于三类之一**：目标产物长什么样 / 怎么造 / 按什么顺序造。
**"某个具体判断的论证"不属于这里**——那属于已定决策（`交接.md` 第三节）或报告正文
（`narrative/*.src.md`）。

> 具体到易混的一处：**写"第 5 章必须回答什么、按什么结构展开"是本文件的事；
> 写"第 5 章的答案是什么"不是。** 上一版的「06 五年期」整节就是越界——
> 终局年为什么选 2030 是一条**已定决策**，本文件只需要在报告骨架里写一行
> "第 0 章必须交代终局年及其理由"，并指向决策出处。

**纪律四 · 每一步都要带验收标准。**
一句能判定"做完没有"的话。没有验收标准的步骤等于没写。

## 1. 目标产物：报告长什么样

不是"模型结果的说明书"，是一份投资人拿去做五年决策的报告。
所以骨架**不按模型的层**（车辆/站点/运营/财务）走，**按决策的问题**走——
每一章都必须由一个**算出来的数**收口，否则那章就是散文。

### 1.2 第 4 章：不做逐年表，也不需要爬坡参数

这条曾长期挂在"最大缺口／方法论待拍板"，**现在彻底关闭**，而且比上一版关得更干净。

`口径/capex_debt_估值公式链.md` §1.1 已经把前提问清楚了：

- **问题 A**（这门生意稳态运营后值多少）→ 站在 2030 锚点资本化，**不需要爬坡曲线**

### 1.3 第 3A 章：谁是真用户——用第一性原理拆解，收口于「痛点强度」

**这一节是本轮新增，也是整份提案里唯一一处「上游」——它决定了模型算哪些细分市场。**
早期在私家车市场用"10 万站"建模，就是跳过了这一步的直接后果
（见 `DECISIONS.md`「2026-09-06c」）。

**七步拆解链**（每一步只问物理/事实，不问商业故事）：

| 步 | 问什么 | 本案例 |
|---|---|---|
| ① | 载体本质是什么（物理层） | 电池 ＝ 储能单元 |
| ② | 核心属性是什么（最终交付什么） | **能量**——不是信息 |
| ③ | 关键指标是什么（用户拿什么衡量） | **便宜、好用** |
| ④ | 谁对这些指标最敏感 | 把能量成本直接算进利润的人 |
| ⑤ | 现有方案哪一项不满足 | 充电：好用不足；购车：便宜不足 |
| ⑥ | 新方案重塑了什么价值、谁的利益被重分配<br>**核心：谁扛最重的那块成本？**（见下） | 电池银行扛下电池 → 利益绑定 → 才有东西让渡给用户 |
| ⑦ | **这个重塑属于哪一类** | **← 估值倍数的分水岭，见 1.5** |

#### 第 ⑥ 步不能停在"重塑了价值"——必须问出承重方

**价值重分配不会自动发生，它需要一个人站出来扛最重的那块成本。**
这一步是整条链的枢纽，也是"标准确立"能不能成立的前提。

```
电池是最贵的那块（400kWh 包占整车成本 30–40 万，约整车 40–50%）
  ↓  必须有人持有它，才能把它从「用户的一次性支出」变成「运营方的持续资产」
谁持有，谁承担成本  →  电池银行（CATL 主导）
  ↓  承担成本的人，才有极大动力把电池寿命拉长
利益绑定：它的利益与「电池便宜好用」这个责任彻底绑在一起
  ↓  寿命拉长 = 单位里程的电池成本下降
才有东西可以让渡给用户  →  便宜的 TCO
  ↓
用户获得「便宜好用」   ← 回到第 ③ 步的关键指标，闭环
```

> **制造模式是一次性买卖**：卖一道收一道钱，用户买走之后什么样，厂商不管。
> **运营模式是按使用付费**：厂商的利益和"把电池做到极致"彻底绑定。
> **只有在利益绝对绑定的情况下，产品才会做到极致，用户才能享受极致产品之上的那份利益。**

**推论（本案例的关键，也是可迁移的判据）：承重方必须同时控制「成本」与「寿命」两端。**

| 谁来持有电池 | 扛成本 | 控寿命 | 结果 |
|---|:---:|:---:|---|
| 第三方运营商 | ✅ | ❌ 不造电池 | 绑定不完整 → 做不到极致 |
| 车企 | — | — | **没动力**（靠卖车赚钱，电池只是成本项） |
| **电池生产者** | ✅ | ✅ | **绑定成立 → 才可能做到极致** |

**这解释了为什么同类玩家做不起来，而且不需要谈"体量不足"——是结构性的，不是规模问题。**

#### 三层递进：从模式转变到不可逾越

| 层 | 说的是什么 |
|---|---|
| **1 · 模式转变** | 一次性买卖 → **按使用付费**。同构于特斯拉不卖车、运营 Robotaxi 卖里程。**几乎所有运营重资产的生意，本质都是一样的** |
| **2 · 规模效应与马太效应** | **正因为是重资产，一旦跑通门槛就特别高**。最后拼的是极致成本效率：规模越大 → 持有方成本越低 → 大用户群反哺运营效率 → 能让渡给用户的利益越大 → 更多用户。**这是一个正反馈环，产业链供方格局的重新分配由此而来** |
| **3 · 竞争壁垒** | 只有当他自己先做到这一点，搅局者才难进——**基建的基础格局已经形成，别人想再投、想超过他都很难** |

**这三层合起来，才是第 ⑦ 步「标准确立」的完整论证**：
第 1 层解释**性质变了**（制造→运营）；第 2 层解释**为什么会赢者通吃**；
第 3 层解释**为什么难被颠覆**。**"载体可换"是结果，这三层是机制。**

---

**收口：痛点强度是可以算的，不是断言。**

```
痛点强度 = TCO 改善幅度 × 该用户对 TCO 的敏感度
```

- **TCO 改善幅度**：换电 vs 充电 vs 燃油，分车型——**可算**
- **TCO 敏感度**：营运车＝**生产资料**（TCO 直接等于利润，敏感度高）；
  私家车＝**消费品**（TCO 只是决策因素之一，敏感度低一个量级）——**可分级**

这样"谁是真用户"就从判断变成读数，符合"每章由一个算出来的数收口"的骨架纪律。

> **一条重要性质：痛点强度不是常数，它随电池价格曲线动。**
> 换电对营运车的痛点强度**随电池降价而增强**——所以窗口不是在关闭，是在打开。
> 这本身就是第 3A 章该写的一条判断。

1. **真正的边际对手是 LNG，不是柴油。** 对柴油 5 年 −25%，对 LNG 只有 −11%，

### 1.4 叙述层的两层结构：章 ＋ 专题

`narrative/` 只有"章"一个粒度是不够的——有些论证被多章引用，有些论证的更新周期
和模型完全无关。但**如果按"逻辑分析都提专题"来切，会切出第二座文件山**。

**判据不是"是不是逻辑分析"，而是"它随什么变、被谁用"。三条，满足任一即提为专题：**

| 判据 | 例子 |
|---|---|
| **① 两章以上引用** | 终局年为什么是 2030 → 第 0 章、第 6 章都要 |
| **② 更新周期与模型无关** | 竞争格局——外部出新东西就得改，跟重跑模型没关系 |
| **③ 它是一条已定决策的完整论证** | 改它等于改结论，需要单独 review |

**都不满足 → 留在章里。默认不拆。**

```
narrative/
  chapters/  0_决策卡.src.md … 7_诚实清单.src.md          ← 固定八份
  topics/    业务本质_第一性原理拆解.md      ← 3A、5 共用（本轮新增，最重要）
             运营期限_换电是哪类资产.md      ← 3A、5 共用（本轮新增）
             终局年_为什么是2030.md          ← 0、6 共用
             必要性_三条路为什么是换电.md    ← 0、2 共用
             目标用户_谁的痛点.md            ← 2、3A 共用
             竞争格局_快充与换电错位.md      ← 2、3B 共用
             非共识_类型判定与证据形态.md    ← 1、5、6 共用（本轮改名，原名「可证伪判据」
                                               只盖住了排除C那一步，盖不住类型判定）
```

章里用 `{{topic: 业务本质_第一性原理拆解}}` 引用，`build.py` 装配时展开。

**两条约束：**

1. **专题也守占位符纪律**——它可以含 `{{val:}}`。它不是"静态散文"，
   它和章是同类文件，只是寻址方式不同。
2. **专题与「已定决策」一一对应**：`交接.md` 第三节是**一行结论 ＋ 索引**，
   `topics/` 是**那一行的完整论证**。这样同一件事不会在两处各写一遍。

### 1.5 第 5 章的写法：先定估值方式 → 影响图 → 基数与倍数 → 赔率

> ⚠️ **写这一章之前，必须先打开 `分析结论/换电毛估估_折扣链与总表_v3.2.md §4.1` 读一遍。**
> **18× 的完整推导在那里**，不在本文件里，也不在任何人的记忆里。
> 这条前置是 `DECISIONS.md`「2026-09-06p」的产物：此前只写了"材料已齐，见 v3.2 §4.1"这个
> **指针**，没写**什么时候必须去走它**，结果反复凭记忆复述、反复复述错。
> **指针不绑触发条件 ＝ 没有指针。**

---

#### 第 0 步 · 定估值方式

**回答"如果市场愿意给它估值，会怎么估"。估值方式的选择本身是一个判断，不是一个惯例。**

| | 制造业口径 | 资产运营口径 |
|---|---|---|
| 业绩基数 | 净利润 | **EBITDA** |
| 估值系数 | PE | **EV/EBITDA** |
| 结构 | 单一 | **SOTP** |

换电 2030 判为资产运营 → 基数 EBITDA、系数 EV/EBITDA；受影响的制造侧仍用制造侧 PE。

> **换基数不是换参数，是换量纲。** 所以「ΔE × Δ倍数」这种二维分解在这里**不成立**——
> 它只在同一框架内部有效。上一版 §1.1 就是这么写的，是把 SOTP 又写回了 PE。

**这一步的产出正好是 1.6 共识锚的镜面**：1.6 观察"市场**现在**用什么方法"，
这一步声明"**该**用什么方法"。**两者之间那道缝，就是非共识本身。**

---

#### 第 1 步 · 影响图

**回答"换电动了估值链上的哪些参数"——是结构，不是量级。**

"谁的影响更大"是这一步的**验收标准**，不是它的输入：程序跑之前不可能知道，
所以它不能是方法步骤的前提。要画的是这四列：

| 要素 | 内容 |
|---|---|
| 换电自身 | 基数是什么、系数是什么、怎么算 |
| 受影响的业务清单 | 制造侧（锁量／护价／充电份额流失）等 |
| 每个业务被动到的是**哪个参数** | 量？价？净利率？久期？WACC？ |
| 每个参数怎么算 | 指向 `ledger` 的具体字段 |

**验收**：跑完回来看量级分配。若 payoff 大部分落在制造侧，则"换电值 18×"就是
**在借别人盘子里的价值抬自己的倍数**——`v3.2 §4.1③` 自己写过"payoff 主要落在
动力电池基本盘，而非换电自身的现金流与估值"。**每块价值用自己盘子的倍数。**

⚠️ **前置阻塞**：`ledger` 里「充电份额流失」与「锁量」是否重复计提，口径未查清
（见 `交接.md` 4.3）。**这一步开写前必须先查掉**，否则第 2 章和第 5 章会同时建在一个存疑的分解上。

---

#### 第 2 步 · 基数与倍数

**基数 ＝ 2030 稳态营运盘**：装机量／换电量／EBITDA／FCFF／CAPEX，
就是反复修订做扎实的那一套（营运车基本盘 ＋ 少量私家车支撑）。
**不用想象中的新场景去垫基数**——想象的部分全部体现在倍数上。

**倍数的锚不是可比公司取平均，是 `v3.2 §4.1` 的三族定位。**
判据是**"谁扛资产、谁赚什么钱、赚的钱最终落在哪盘生意"**，不是资产负债表重不重：

| 族 | 代表与区间 | 换电属不属于 |
|---|---|---|
| **① 资管/科技平台型**（真 GP：出 1–2% 资本，收管理费＋carry） | Blackstone 21.8×（族中位 18×）、Ares 38.8× → **18–22×** | **不是**——CATL 综合自有出资约 16%，是**带电池供应的战略 co-investor ＋ 一点 promote**，与 GP 结构不同构 |
| **② 重资产基建运营型**（LP 式自持、靠分派） | Brookfield 6.7×、公用事业 8–14×、储能平台 10–14× → **6.7–14×** | **也不完全是**——它还握着标准与电池供应两端 |
| **③ 车＋能源网络复合族** | 特斯拉 89.7×（LTM） | **只作叙事参照，不作倍数锚**（`v3.2 §4.1③`3 已定：叙事半径不同） |

（参照：CATL 自身 LTM 13.0×，比亚迪 6.5×。）

> **18× 不是"在中间拍一个中数"，是两条相反方向的边界在同一点相遇：**
>
> - **自下而上**：重资产基建区间上限 14× ＋ 电池供应／标准卡位的战略溢价 → **≈18×**
> - **自上而下**：轻资产资管族 18–22×，但换电不是真 GP，只能取该族**下沿** → **18×**
>
> **两条独立路径收敛到同一个数，比任何单条路径都强。报告必须把这个收敛写出来。**
> 此前只写了自下而上那一条，所以读起来像"14 上面又加了 29%"——
> `DECISIONS.md`「2026-09-06」曾据此判它"垮了"，**那是读浅了**，见「2026-09-06o」。

**期限只有两端，没有中间档：**

| 世界 | 期限形态 | 对应账本 |
|---|---|---|
| 标准没立住 | 15 年设备到寿，生意不好就不再更新 | **有限期账** |
| 标准立住了 | 没有理由结束 | **永续账** |

**两本账就是这个二分。不做 25 年／40 年的中间敏感度**——标准型资产的期限是二元的，
**把二元算成连续 ＝ 把"可能全输"写成"少赚一点"**（同 `交接.md`「窗口成本不量化」那条纪律）。

**18× 是一个「声明」，不是一个测算结果——这完全正当。**
框架里已有这个概念（"情景轴是**声明**不是测量；弹性只用来审计声明"）。
声明的义务不是推导，是**三件事**：

1. **内容**：18× **已经把标准的想象空间装进去了**——不是"基建倍数 ＋ 溢价"之后再叠加别的
2. **位置依据**：上面那个双向收敛
3. **什么会让我改它**（这一条此前完全没有）：

| 方向 | 触发 |
|---|---|
| **往下改** | 2027–28 规模没到档／持续"推多拉少"／第三方按**不同**规格建站 |
| **往上改** | 非 CATL 整车厂按此规格设计／规格进国标／跨品类出现"拉" |
| **不构成改** | **市场仍然不给 SOTP** |

> 最后一行必须明写：**"市场不认"不是证伪，那恰恰是非共识本身。**
> 不写清楚，第 1 章和第 5 章会互相拆台。

**不设独立的「标准价值」科目。**
曾考虑把标准的价值单列成一项挂在公式外面（`V = Σ(基数×系数) + O`）——**撤销**。
商誉是**残差**：可口可乐的品牌值多少，是拿**已实现**的终端溢价倒算出来的。
换电还在铺货，没有已实现的溢价可以倒算，**O 无法计量**；而倍数的功能本来就是装未来。

> **未来放进倍数是对的。错的是放进去而不说清什么会改它**——上面第 3 条正是为此存在。
> （曾写过"任何被塞进系数里而没有自己基数的东西都不可证伪"，**那句太强，已撤销**，
> 见「2026-09-06m」。不装未来的倍数只有清算价值。）

**倍数为什么可以高——性质判定（1.3 第 ⑦ 步）：**

| 类型 | 特征 | 会被什么终结 | 倍数逻辑 |
|---|---|---|---|
| **技术变革** | 用新技术做同一件事 | 下一代技术 | **低**——随时被替代 |
| **场景拓展** | 用同一方案覆盖更多场景 | 场景饱和 | **中**——有天花板 |
| **标准确立** | 让市场接受一套新的**交付方式**，**载体可换、场景可扩** | 只有另一个标准 | **高**——有垄断性 |

**换电的判定**：只做成"一种补能方式" → 场景拓展；
做成"一套**用能**方式 ＋ 用户习惯" → **标准确立**，而标准确立之后载体可换
——固态电池可以换电，工程机械可以换电，工业机器人可以换电。

**但"载体可换"是结果，不是论证。完整论证是 1.3 节第 ⑥ 步那三层：**

| 层 | 回答什么 |
|---|---|
| 1 · 模式转变 | **性质变了**——一次性买卖 → 按使用付费（同构于特斯拉卖里程，见第 3 步的对标表） |
| 2 · 规模与马太 | **为什么会赢者通吃**——重资产 → 门槛高 → 拼极致成本效率 → 规模越大成本越低 → 让渡越多 → 更多用户（正反馈环） |
| 3 · 竞争壁垒 | **为什么难被颠覆**——基建格局已成，后来者想投想超都难 |

**而这三层的枢纽是「承重方」**：必须有人扛下最重的那块成本（电池），
且这个承重方必须**同时控制成本与寿命两端**，利益才能绑定，产品才会做到极致。
**写第 5 章时，这一段是全篇论证密度最高的地方，不能压缩成一句"有网络效应"。**

> **这才是高倍数的真论据，而且它和 DCF 是完全不同的逻辑：
> DCF 给「当前业务配置」的现金流定价；标准的价值在于「承载还没发生的业务」——
> 这是 DCF 结构上装不下的东西，不是 DCF 算错了。**

**前置**：这一步只在资产是**永续经营型**时成立。若是特许经营（有法定到期日），
标准活不过特许期，此论不成立——所以第 ⑦ 步之前必须先有运营期限判定
（专题 `运营期限_换电是哪类资产.md`，方法见 `capex_debt_估值公式链.md` §1.3）。
**它是一道门（是/否），不是一条曲线。**

剩下的差额按四桶归位：

| 桶 | 内容 | 先行指标（2027–28 可观察） |
|---|---|---|
| **①** 预测期外还在长 | **两个来源，不只一个**：<br>(i) **外延**——新品类被验证、渗透率继续爬；<br>(ii) **内涵**——**2030 是车载电池刚装满的那一年，站网利用率还在爬**。终局年的 EBITDA 是稳态**起点**不是峰值，而利用率提升**不需要任何新增 capex**，是纯经营杠杆 | 营运车渗透 S 曲线；单站日均换电次数/利用率趋势 |
| **②** **基准情形外的承载力** | (i) **同一批资产的其他用途**：V2G／储能调度／数据<br>(ii) **同一套标准的其他载体**：固态电池、工程机械、工业机器人——**标准一旦确立，载体可换**<br>**(ii) 是高倍数的核心论据** | 见第 3 步「中检点」表——**每条都标了推/拉，只有"拉"算数** |
| **③** 风险低于 WACC 假设 | 现金流合同化 | 长约占比；REITs/ABS 发行成功 |
| **④** 纯重估押注 | **业务事实全对了，但市场就是不给这个框架** | **没有先行指标——这才是真赌的那部分** |

> **一处已定修正**：此前把"标准/垄断"这类论据笼统丢进桶④，并断言"桶④没有先行指标"。
> **错了**——"标准确立"是一个**业务事实**，它有先行指标，属于桶②(ii)。
> 移过去之后，**最难辩护的那一块变成了有明确观察清单的一块**，
> 而且它 **2027–2028 就能看到，比"市场给不给倍数"早得多**。

桶 ① 的第 (ii) 项与 `公式链` §2.4 是同一件事的两种说法：
**"只算到 2030 满产、不建模 2030 后增长，是保守留白，恰恰是支撑高估值倍数的理由。"**
把它写进桶 ①，这句留白就从"我们没算"变成"我们知道少算了什么、少算了哪个方向"。

#### 第 3 步 · 赔率

**世界 A／世界 B 的边界要写成可观察的，不是抽象的。**
"只做成补能方式／做成一套能量交付标准"这个说法没法观察，换成这个：

| | **补能** ＝ 世界 A | **用能** ＝ 世界 B |
|---|---|---|
| 用户脑子里的问题 | "我去哪儿充/换" | **"我买一台换电的车"** |
| 出现在**哪个决策**里 | 用车时的**服务选择** | **购车时的选型条件** |
| 谁在推 | 运营商找用户 | **用户主动找过来** |

> **从"服务"挪进"购车选型条件"——这一步可以直接问出来。**
> 问一个车队老板买车时在想什么，就知道走到哪一步了。
> 这比"标准是否确立"好用一个量级，也是「痛点强度」在用户认知侧的对应物。

**对标：一个市场已经接受、而且带着狂热信仰的重估先例。**

| | **特斯拉 / Robotaxi** | **换电** |
|---|---|---|
| 原业态 | 卖车（制造） | 卖电池（制造） |
| 新业态 | **卖里程**（出行服务） | **卖用能**（能量服务） |
| 用户侧的变化 | 从"买一台车"到"买出行" | 从"买一台带电池的车"到**"买一台换电的车"** |
| 承重方 | 特斯拉扛车队资产 | **CATL 扛电池资产** |
| 市场给了吗 | **给了，而且给得狂热** | **还没给——当成免费期权** |

> **对标的用途是机制，不是数值。**
> 它把"业态中途切换、倍数体系随之切换"从"我的特殊主张"降格为
> **"市场做过、而且做得很热的一类事"**——举证责任因此从"这种事可能吗"
> 移到"**这一次像不像**"，而后者是能用证据回答的问题。
>
> **数值绝对不能借**：`v3.2 §4.1③`3 已定——特斯拉买的是"电力网络入口＋具身智能"叙事，
> 叙事半径不同，**只作叙事参照，不作倍数锚**。
>
> 一个可能有用的读法：**换电是半程的 Robotaxi**——它只换掉车里最贵的那一块
> （电池占整车 40–50%），没有换掉整车。**这恰好解释了倍数为什么该落在①②两族之间，
> 而不是③族**——对标和三族定位因此是同一件事的两面，不是两套说辞。

**中检点：规模档位第一，其余按推/拉排。**

| 序 | 指标 | 推/拉 |
|---|---|---|
| **1** | **规模档位**：10 万／100 万／1000 万辆——**量级本身传递不同的信息**，它是"有没有实力立标准"的最直接证据 | — |
| 2 | 非 CATL 整车厂按此规格设计车型 | **拉** |
| 3 | 换电块规格进国标／团标 | **拉** |
| 4 | 第三方运营商用同一标准建站 | **拉** |
| 5 | 跨品类应用：CATL 自己签的供能协议（电动船舶、工程机械等） | **推** |
| 6 | 跨品类应用：非 CATL 方主动按此规格设计 | **拉** |

> **每一条先行指标必须标明它是"推"还是"拉"。只有"拉"算数。**
> CATL 签下一个新场景的供能协议 ＝ **推**（卡位；这是**意愿**的证据，不是**标准**的证据）；
> 一个 CATL 没谈过的整车厂或船东**主动按这个规格设计** ＝ **拉**（标准的证据）。
> 原清单里"跨品类应用出现"推拉不分，已拆成第 5、6 两条。

> **规模是不是有效证据，取决于它是被假设出来的，还是被观察到的。**
> **2030 年的 100 万辆，如果是我拍的渗透率算出来的，它不能证明标准会立；
> 2027 年真实跑出来的 10 万辆能。**

**幅度归模型，概率归观察——两者不能互相替代：**

| 问题 | 谁回答 | 为什么不能换人 |
|---|---|---|
| 相变发生了值多少（**幅度**） | **模型** | 这是模型唯一能答的 |
| 相变**会不会**发生（**概率**） | **上表的观察指标** | **模型里已经假设它发生了**——用模型输出证明相变会发生是循环论证 |
| 今天离地板多远 | **共识锚**（换电当前计价为 0） | 定量与定性都答不了，只有市场能答 |

**所以报四行，不报期望值：**

1. **世界 A ＝ 只做成补能方式**（场景拓展，锚 DCF 那一档）＝ **地板**
2. **世界 B ＝ 做成用能标准**（载体可换，18×）＝ **天花板**
3. 从 A 到 B 要看到什么 ＝ 上面的中检点表
4. 今天价格离 A 多远 ＝ **亏损上限**（共识锚已给出：换电计价为 0）

> **不报期望值有两个理由，第二个更硬：**
> ① 分布是双峰的，**在双峰上取平均得到的是任何可能世界都不会出现的数**；
> ② **我们根本没有那个概率**——模型结构上给不出来。
> **而假装有一个概率，是整套方法里最容易骗自己的一步。**

**判据（这一章成立与否的检验）**：
> **论点必须能被市场之外的东西证伪。**
> "市场会给 X 倍"——唯一证伪方式是市场不给，要等 5 年，期间无任何中间信息，
> **那不是非共识，是不可证伪的信仰**。
> "这门生意会跑出 ①②③ 的特征，而具备这些特征的资产历史上都拿到十几倍"——
> 每一条都能在 2027–2028 单独观察。**非共识是"你比市场早看到"，不是"你比市场更相信"。**

### 1.6 第 1 章的写法：先判类型，再找证据

> **为什么这一节排在 1.5 之后，而第 1 章排在第 5 章之前**：它依赖 1.3 第 ⑦ 步的性质判定
> 与 1.5 的双峰赔率。**写的时候第 1 章在前，想的时候它在后。**

#### 1.6.1 定义：断档不是机会，断档接不上的原因才是

**非共识 ＝ 控制参量已经动了、序参量还没动的断档**（两个词的定义见附术语表）。
但**断档本身什么也不说明**——它接不上的原因有三种，**只有前两种是机会，而且是两种不同的机会**：

| | **A · 相变型** | **B · 线性型** | **C · 我看错了** |
|---|---|---|---|
| 断档原因 | **业态变了**，市场还在用旧框架给它定价 | 业态没变，只是横向拓展，市场低估了成功率 | 市场是对的 |
| **老估值方法能否反推** | **不能**——反推等于先承认旧框架 | **能**——同框架不同参数 | — |
| **证据形态** | **形式的**：市场**用什么方法**估值 | **数值的**：成功率 × 增量利润 | — |
| **赔率形态** | **双峰**：地板／天花板，**中间没有平滑地带** | **连续**：按成功率加权，可取期望值 | — |
| 时间形态 | 跳变，可能等很久，期间无价格反馈 | 渐进，随业务逐季兑现 | — |
| **真正的难点** | **判定它到底算不算业态变更** | **判断成功率** | **必须先把这一支排除掉** |

**这张表与 1.3 第 ⑦ 步是同一件事的两个入口**——
技术变革 ＋ 场景拓展 ＝ 线性型；**标准确立 ＝ 相变型**。
一个从"这门生意是什么性质"进，一个从"市场为什么没给它定价"进。
**两边判定必须一致；不一致就说明有一边判错了。这是一条不花钱的交叉校验，写第 1 章时必须做。**

> **可迁移判据（本节的核心，也是 skill 1 的第一节）：**
> **非共识的第一步不是找证据，是判类型。类型判错，后面找的所有证据都是错类型的证据。**
> 相变型去找数值证据 ＝ 用旧框架给新业态定价，自相矛盾；
> 线性型去找形式证据 ＝ 把一次普通的业务拓展说成范式转移。

#### 1.6.2 本案判定：相变型

CATL 现在被按**制造业**估值，用的是 PE。**换电如果切进资产运营业，就不可能继续用 PE**——
市场一旦愿意给换电估值，最终形态一定是 **SOTP**（分部估值）。
**业态变了 → A 型 → 老框架不能用来反推。**

⚠️ **本轮修正**（见 `DECISIONS.md`「2026-09-06l」）：上一版把共识锚写成
"市场当前 PE × EPS 反推它隐含的长期假设"。**那是 B 型的方法，用在了 A 型的案例上**——
它回答的是"如果市场按制造业给换电定价，换电值多少"，而本报告的论点恰恰是
**它不该按制造业定价**。等于先承认对方的框架，再在对方框架里论证对方错了。

#### 1.6.3 共识锚：市场用什么方法，本身就是证据

> **估值方法的选择，是市场认知的可观察显影。**
> 单一 PE ＝ 市场认为这是一家**性质同质的制造业公司**；
> SOTP ＝ 市场认为它里面装着**性质不同的业务**。

三条观察，全部可在公开研报里查证，逐条标来源与日期：

| # | 观察 | 现状 | 说明 |
|---|---|---|---|
| ① | 卖方对 CATL 用不用 SOTP | **否** | 用的是整体 PE |
| ② | 换电有没有在卖方模型里被**单独列示** | **否** | 通常只在定性段落出现 |
| ③ | 有没有机构给过换电**独立估值** | **否** | 一二级市场都没有 |

**三个"否" ＝ 换电没有被给估值，市场把它当免费期权。**

**为什么这比数值反推强**：

| | 可观察 | 可证伪 | 与论点同框架 |
|---|---|---|---|
| PE 反推 | 要猜市场的隐含假设 | 只能等市场 | **否**——必须先接受制造业框架 |
| **形式证据** | **翻研报就能数** | **出现一份 SOTP 就翻** | **是** |

**翻转信号**（同时是第 6 章中检点，按强度排序）：

1. 第一份对 CATL 用 **SOTP** 的卖方研报
2. 换电首次在卖方模型里被**单独列示**
3. **时代电服独立融资或分拆定价 —— 最强。** 一级市场一旦给出独立估值，
   "免费期权"状态直接终结，且它通常**早于二级市场的框架切换**

> **副产品**：免费期权状态本身就是赔率结构的下半截。
> 今天价格里换电 ≈ 0 → 1.5 节双峰赔率第 4 行"今天离地板多远"直接有了答案，不必另算。

#### 1.6.4 排除 C：这一支不写，整章就是信念机器

> **任何"非共识"框架，如果没有"我可能才是错的那个"这一支，它就是一台自我实现的信念机器：**
> 找到断档 → 断言业态变了 → 于是所有反面证据都自动翻译成"市场还没反应过来"。
> **永远不可能被证伪。**

**三问，第 1 章必须逐条作答：**

1. **市场是不是已经知道、只是不在乎？**（量太小／离兑现太远 → 那不是认知差，是**久期差**）
2. **市场是不是知道我不知道的负面信息？**
3. **我的信息／认知优势具体是什么？**

第三问的答案分级——**这条判据决定第 1 章成不成立**：

| 说法 | 强度 | 为什么 |
|---|---|---|
| "我算得更细" | **弱** | 细节不改变框架，市场也能算细 |
| "我有独家信息" | **不能用** | 通常是幻觉；真有则违规 |
| **"我用了一个不同的分析框架，而那个框架不产生这个问题"** | **强** | **且可证伪** |

**本案落在第三行**：优势不是信息（数据全部公开），是**认知**。
把换电判成「标准确立」而不是「场景拓展」，需要走完 1.3 节那条七步链；
而卖方的标准框架是「可比公司 ＋ 盈利预测」——**那个框架结构上不产生这个问题**：
它只会问"换电明年贡献多少利润"，不会问"换电是不是一套标准"。

> **证伪条件**：若出现一份卖方研报做了**同样的性质判定**、仍然给低估值，
> 则"认知优势"不成立，本案退回 C 型。**这一条必须写进报告，不能只写在这里。**

## 2. 流水线：五层 + 两条硬规则

方向已定：**HTML 只做组装、逻辑住在 MD、计算住在程序。**

| 层 | 是谁 | 干什么 | 现状 |
|---|---|---|---|

| **L0 参数** | `configs/base.toml` | 每个参数带信源、理由，以及情景元数据（`role`/`driver`）。**人改的只有这里** | 已有；情景元数据待补 |
| **L1 计算** | `src/*.py` | **唯一引擎**。产出快照与决策树 | 已有 |
| **L2 事实包** | `outputs/facts.json` | 给叙述层用的命名事实字典 | 已有 |
| **L3 叙述** | `narrative/chapters/` ＋ `narrative/topics/` | **两层**（见 1.4）：八章正文 ＋ 可复用专题。只写论证与判断，数字一律占位符 | 待写 |
| **L4 装配** | `report.html` | 替换占位符、渲染 MD、画图、挂沙盘。**薄容器** | 待做 |

**硬规则一 · 叙述层不许出现字面数字**（年份等白名单除外）。
所有数字写成 `{{val.xxx}}`，装配时从事实包注入。
理由：检查从"字符串比对"退化成"文件里还有没有裸数字"，一个正则就能穷尽，**不可能漏**。
副作用更值钱——改一个参数重跑，全文数字自动刷新，不需要 LLM 重写，也不需要人重读。

**硬规则二 · Python 是唯一引擎，JS 只做展示。**
现存三套引擎（`src/*.py`、`报告/换电重估_engine.js`、`model_html/engine/*.js`）算的是重叠的东西，
谁也不知道谁跟谁一致。第 3 节给出交互层怎么在不复制逻辑的前提下做到实时。

**事实包的字段**：`from`（快照取值路径，数字永不手打）／`v`+`unit`+`fmt`／
`watch`（复核阈值）／`gate`（门槛判定条件）／`src`（信源，从 `base.toml` 注释继承）。

**增量重生成**：每段叙述记录它引用了哪些占位符。重跑后——都在 `watch` 阈值内 → 静默更新；
越阈值或某道门通过/不通过翻转 → 该段标"待复核"，只重写这一段。
**这是"全流程自动化"里最难也最值钱的一环。**

**验收**：`python src/build.py` 一条命令走完全链，任何一步失败就停在那里并说清哪一步、为什么。

## 5. 沉淀规格：三个 skill ＋ 一份项目约定

> **这是本项目的第二目的**（第一是把换电报告做到全流程自动化）：
> **每一个案例研究都沉淀为方法论和工具，才能复利迭代生长。**

### 5.1 现在写规格，不写正文——以及为什么

"等跑通了再写"这条决策仍然对：**skill 正文要从跑通的流程里长出来，不能反过来。**
但**规格必须现在写**，否则跑完之后你不知道该收集什么，只能靠回忆，一定漏。

**最重要的不是内容清单，是机制：**

> **不要让沉淀依赖回忆，让它依赖标记。**
> `DECISIONS.md` 每条带一个 `→skill:` 字段，标明它该进哪个 skill 的哪一节。
> 跑通一遍之后写 skill ＝ **把标记过的条目归拢重写**，不是"回忆我学到了什么"。
> **内容清单会变，这个机制不会。**

### 5.2 三个 skill

| skill | 装什么 | 迁移时改什么 | 验收标准 |
|---|---|---|---|
| **1 · 非共识标的诊断**<br>（入口层：值不值得研究、非共识在哪、窗口多大） | **§1 非共识的类型判定（1.6 节，本 skill 的入口，必须排在最前）**：断档不是机会，断档接不上的原因才是 → A 相变型／B 线性型／C 我看错了 → **类型决定证据形态（形式的 vs 数值的）、赔率形态（双峰 vs 连续）、老估值方法能不能反推** → **排除 C 三问 ＋ 认知优势的强弱判据**<br>→ PBL 五问 → 人物校验（家有余粮心理不慌）→ 客观大场定位四步 → 相变六步<br>**→ 业务本质的七步第一性原理拆解链（1.3 节）**——含第 ⑦ 步「技术变革／场景拓展／标准确立」的性质判定，**与 §1 的 A/B 判定互为交叉校验，不一致即有一边判错**<br>→ 真用户与目标市场（痛点强度 ＝ 改善幅度 × 敏感度）<br>**→ §N 相变型的三条判据（1.5 第 3 步）**：① **世界边界要写成可观察的**——把"标准是否确立"翻译成用户在**哪个决策**里想到它（服务选择 vs 购买选型条件）；② **每条先行指标必须标推/拉，只有"拉"算数**（自己签的合作是意愿的证据，不是标准的证据）；③ **对标一个市场已经接受、且带狂热信仰的重估先例**（如特斯拉卖车→卖里程）——**借机制不借数值**，作用是把举证责任从"这种事可能吗"移到"这一次像不像"<br>→ **规模不能直接换倍数**：规模是"有没有实力立标准"的证据，性质才换倍数，中间隔着一步<br>→ **不能用假设了相变的模型去证明相变**：模型答幅度，外部指标答概率；**被假设出来的规模不是证据，被观察到的规模才是**<br>→ 研究纪律：发散管理（留口子、画研究地图、先 close 当下） | **几乎不改**——这一层是 domain-general 的，换成研究一家餐饮连锁也能用。**类型判定尤其不改：它问的是"市场用什么方法给它定价"，任何行业都能问** | 拿储能或 AIDC 试跑，**看它问出来的问题是不是你自己会问的**。<br>**外加一条硬验收：喂给它一个 B 型标的（普通业务拓展），它必须判成 B 并拒绝给双峰赔率**——一个只会判 A 的 skill 是信念机器，不是诊断工具 |
| **2 · 反事实定量建模**<br>（怎么把一个业务算成可证伪的数） | **§0 先定估值方式，再定参数**：业绩基数与估值系数随资产性质换（净利/PE ↔ EBITDA/EV ↔ FFO/cap rate）——**换基数是换量纲，不是换参数**；所以 ΔE × Δ系数 只在同一框架内部成立<br>→ **倍数的锚是"谁扛资产、谁赚什么钱、赚的钱落在哪盘生意"的族定位，不是可比公司取平均**；好的倍数论证是**两条相反方向的边界收敛到同一点**，不是区间中点<br>→ **拆解只有在每个部件都比整体更可观察时才是进步**（否则是把一个难题换成 n 个难题，还多了它们必须自洽的负担）——这是"精度≠假设数量"的镜像<br>→ **二元的东西不许算成连续**：期限、窗口成本这类由"标准立没立住"决定的量只有两端，中间档是精确的错误答案<br>→ 问题 A／问题 B 之分（**先问决策要哪一个**）<br>→ 期限假设与两本账；**运营期限是资产类别判定，是一道门不是一条曲线**<br>→ 分层结构 L(-1)定义域／L1单位／L2代表／L3门槛／L4估值<br>→ 三条方法论纪律（精度≠假设数量、算细读粗、标定一次用很多次）<br>→ 五条估值原则（`公式链` §1.2）<br>→ 情景轴是**声明**不是测量；弹性只用来审计声明<br>→ 恒等式断言纪律（按构造成立；容差只吸收浮点误差）<br>→ 参数与信源绑定；**复合指标引用陷阱**<br>→ 工程骨架（config／engine／snapshot／tree／facts／backscan） | 改"载体本质"与客户拆法；**骨架不改** | 拿另一个重资产业务跑一遍，**在不新拍数的前提下**产出两本账 ＋ 一张门槛表 |
| **3 · 研报装配**<br>（怎么把数变成能做决策的报告） | 八章骨架 ＋ 每章收口要求<br>→ **章／专题两层结构与提升三判据**<br>→ 占位符纪律、事实包结构、待复核机制<br>→ **第 5 章四步法**（定估值方式→影响图→基数与倍数→赔率；倍数锚族定位不锚可比取平均；**声明就写成声明，但必须配"什么会让我改它"**）<br>→ **纲领文件里每一个"材料已齐，见 X"都必须绑一个触发条件**（"写 Y 之前先读 X"）——**指针不绑触发 ＝ 没有指针**<br>→ **第 7A 章从 DECISIONS 生成**<br>→ HTML 薄容器边界 | 几乎不改 | 把 HTML 删掉重写，**报告结论一个字不变** |

### 5.3 第四块：项目约定（不是 skill）

文件治理三分法（状态／过程／产物）、`DECISIONS.md` 的格式与四类标签、
`→skill:` 标记机制、协作协议——**这些是可复用的工作方法，不只 CATL 换电适用**，
但它们**不是 skill**：skill 是"做某类任务时读的检查表"，这些是
**"任何研究项目开工前就该铺好的工作台"**。

> **落地形态：`研究项目约定.md`（已生成，在仓库根目录），新开研究项目时复制过去。**
> 它和三个 skill 的关系是：**skill 决定你怎么想，项目约定决定你想过的东西留不留得住。**
> 没有它，三个 skill 第二次用的时候就会重新长出文件山。

**分不清一条规矩该进哪边时，用这个判据：**

> **AI 不专门读也应该遵守 → 项目约定。只在做某类任务时才需要想起来 → skill。**
>
> - "DECISIONS 只追加" → 每次写文件都该守 → **约定**
> - "给倍数前先判定资产性质" → 只在估值时需要 → **skill**

`研究项目约定.md` 的内容：文件三分法（含目标态/当前态再分）、目录与五份核心文件、
`DECISIONS.md` 的六栏格式与 `→skill:` 机制、协作四步与四条硬约束、
版本与留痕、计算与信源的七条硬规则、开新项目检查表。

## 附 · 术语表

按纪律二，本文件用到的非通用词，全部在此定义。

| 词 | 意思 |
|---|---|
| **状态／过程／产物** | 文件三分法。状态＝现在是什么（可覆盖）；过程＝怎么变成这样（只追加）；产物＝可从状态重新生成（删了不心疼）。判据见 `交接.md` 第七节 |
| **目标态／当前态** | 状态层内部的再分。目标态＝要造成什么样（本文件）；当前态＝现在跑到哪了（`交接.md`）。**目标态文档里不许出现当前值** |
| **两本账** | 估值的两种期限假设：**有限期账**（显式设终点、投入侧按真实更换排期折现、终点配残值）与**永续账**（不设终点、可持续更新支出按更新理论算、不设残值）。两者给出区间的下限与上限。定义见 `公式链` §1.3 |
| **拍定倍数 / 隐含倍数** | 拍定倍数＝相对可比法里人为选定的 EV/EBITDA；隐含倍数＝DCF 算出的企业价值 ÷ EBITDA。两者之差就是需要在第 5 章论证的那段 |
| **押注部分** | 倍数法归属价值 − DCF 归属价值。第 5 章"四桶分解"要拆的就是它 |
| **四桶分解** | 把押注部分拆成①预测期外增长 ②基准外期权 ③风险低于假设 ④纯重估押注。**只有④是赌** |
| **双峰赔率** | 不报期望值，报"世界A地板／世界B天花板／从A到B要看到什么／今天离A多远" |
| **控制参量／序参量** | 相变框架用语。控制参量＝真实投入（资本开支、团队），已经在动；序参量＝市场定价框架（用制造业还是运营业给它定价），还没翻转 |
| **先行指标／验证指标** | 先行指标＝相变发生前就能观察到的经营信号；验证指标＝相变已发生的确认信号。两者收敛度是退出信号 |
| **共识锚** | 第 1 章用来判定"市场现在认为这是什么生意"的**形式证据**：卖方用不用 SOTP／换电有没有被单独列示／有没有机构给过它独立估值。**整篇报告唯一必须从外部取的东西，但取的是方法不是数字。** 曾被写成"PE × EPS 反推隐含假设"，2026-09-06l 纠正——见 1.6 |
| **相变型／线性型非共识** | 断档接不上的两种原因。**相变型**＝业态变了、市场还在用旧框架（老估值方法不能反推，证据是形式的，赔率双峰）；**线性型**＝业态没变、只是横向拓展、市场低估成功率（老框架仍可反推，证据是数值的，赔率连续）。对应 1.3 第 ⑦ 步：标准确立＝相变型，技术变革／场景拓展＝线性型。见 1.6 |
| **形式证据／数值证据** | **形式证据**＝市场**用什么估值方法**本身（可数、可证伪、不需要接受对方框架）；**数值证据**＝在给定框架内反推出的隐含假设。**类型判错就会取错证据形态**，见 1.6 |
| **免费期权** | 一项业务既没有被单独列示、也没有被单独估值，因此当前价格里它计价为零的状态。**它同时是共识锚的结论和双峰赔率"今天离地板多远"的答案** |
| **补能／用能** | 世界 A 与世界 B 的**可观察**边界。补能＝用车时的服务选择（"我去哪儿换"）；**用能＝购车时的选型条件（"我买一台换电的车"）**。判据是它出现在**哪个决策**里，不是它有多普及。见 1.5 第 3 步 |
| **推／拉** | 先行指标的两种成色。**推**＝CATL 自己签下的合作与卡位（意愿的证据）；**拉**＝没谈过的第三方主动按此规格设计（标准的证据）。**只有"拉"算数**，每条指标必须标 |
| **重估先例对标** | 拿一个市场**已经接受、且带狂热信仰**的业态切换案例（特斯拉卖车→卖里程）作参照。**借机制不借数值**；作用是把举证责任从"这种事可能吗"移到"这一次像不像"。见 1.5 第 3 步 |
| **三族定位** | `v3.2 §4.1` 给倍数定锚的方法：按**"谁扛资产、谁赚什么钱、赚的钱落在哪盘生意"**分成资管平台族（18–22×）／重资产基建族（6.7–14×）／车+能源复合族（极高，只作叙事参照），再定位标的落在哪儿。**不是可比公司取平均** |
| **声明（vs 测量）** | 一个被明确承认为"人拍的"的量（情景轴、18× 倍数）。**声明完全正当**，它的义务不是推导，而是写清内容、位置依据、**什么会让我改它**。弹性分析只用来审计声明 |
| **久期差** | 市场其实已经知道，但因为量太小或离兑现太远而不给它定价。**它长得像认知差，实际不是**——认知差会因为新事实而收敛，久期差只会因为时间推进而收敛。排除 C 三问的第一问就是分辨这两者，见 1.6.4 |
| **四道门** | 第 3 章可行性的四项门槛：物理（能不能建）／经济（能不能过线）／资金（钱够不够）／博弈（会不会被快充替代、车企配不配合） |
| **cohort** | 一批同时装机、同寿命、同池的电池。模型按 (池 × 装机年) 展开 |
| **覆盖倍数** | 稳态 EBITDA ÷ 门槛 EBITDA，第 3 章经济门的读数。字段 `swap_business.forward_to_required_ebitda` |
| **驱动因子（driver）** | 情景的定义单位。一个驱动因子扇出到若干同源参数，三档整体切换。**只让同源参数联动**——让全部参数一起变好变坏＝假设完全正相关，区间会宽到没有意义 |
| **爬坡曲线** | 新建站从投产到成熟运营水平所需时间。本项目拍 1–2 年线性，出处见 1.2 |
| **专题（topic）** | `narrative/topics/` 下可被多章引用的论证片段。提升三判据见 1.4。与 `交接.md` 第三节的已定决策一一对应——那里是结论，这里是论证 |
| **定义域 L(-1)** | 算哪些细分市场。在 L0 参数之前，由第 3A 章的痛点强度排序决定，冻结进 `base.toml [vehicles.*]` |
| **痛点强度** | ＝ TCO 改善幅度 × 该用户对 TCO 的敏感度。第 3A 章的收口值；**随电池价格曲线动，不是常数** |
| **第一性原理拆解链** | 1.3 节那七步。第 ⑦ 步（技术变革／场景拓展／标准确立）是估值倍数的分水岭 |
| **技术变革／场景拓展／标准确立** | 价值重塑的三类性质，倍数逻辑完全不同（低／中／高）。**只有"标准确立"这一类 DCF 结构上装不下**——它的价值在于承载还没发生的业务 |
| **运营期限** | 这门生意**能活多久**，由资产性质（特许经营 vs 永续经营）决定。**与终局年是两件事**：终局年是"我什么时候来看"。判断方法见 `公式链` §1.3 |
| **`→skill:` 标记** | `DECISIONS.md` 每条末尾的沉淀标记，标明该条进哪个 skill 的哪一节。**让沉淀依赖标记而不是回忆**，见 5.1 |
| **项目约定** | 文件治理三分法 ＋ DECISIONS 格式 ＋ 协作协议。**是工作台不是 skill**，见 5.3 |
