# 排队系统设计速查手册：M/M/1 与 M/D/1

> TL;DR
> M/M/1 假设服务时间随机波动，M/D/1 假设服务时间固定。同样的到达率和服务率，M/D/1 的平均排队时间是 M/M/1 的一半。原因是随机服务中“正在服务的那辆车平均还剩余完整服务时长”，而固定服务只剩余一半。做容量设计时，先判断你的服务是随机还是固定，再选模型；最后通过“每小时服务成本 + 用户时间成本”这个目标函数定出最优服务时长。

## 1. 核心概念速览

先统一记号。这里“车辆”可以是客户、任务、请求；“服务台”可以是加油枪、收银员、CPU。

| 记号 | 含义 | 常用单位 |
|---|---|---|
| λ | 到达率，每小时平均来几个 | 个/小时 |
| μ | 服务率，服务台每小时平均能完成几个 | 个/小时 |
| s | 平均服务时长，s=1/μ | 小时/个 |
| ρ | 利用率，ρ=λ/μ，服务台忙的时间占比 | 无量纲 |
| L | 平均在场数量（排队+正在服务） | 个 |
| Lq | 平均排队数量（不含正在服务的） | 个 |
| W | 平均总逗留时间（排队+自己服务） | 小时 |
| Wq | 平均纯排队时间 | 小时 |

**Little 定律**（贯穿全文的万能工具）：

```
L = λW
Lq = λWq
```

白话：一段传送带上的存量 = 流入速度 × 在传送带上的时间。  
所以 L 和 λW 是同一个数，Lq 和 λWq 是同一个数。

**稳定条件**：ρ < 1，即 λ < μ。否则队会排到无限长。

## 2. M/M/1：随机服务模型

### 2.1 适用场景

- 服务时间波动大，长短不一；
- 服务过程有记忆缺失（指数分布）；
- 你只有一个服务台。

直觉例子：有人工的收银台、人工加油、客服电话。服务时长随人、随情况变化。

### 2.2 假设

- 到达是泊松过程（随机、无记忆）；
- 服务时间服从指数分布（随机、无记忆）；
- 单服务台，先到先服务。

无记忆意味着：不管一辆车已经服务了多久，它平均还有完整的 s 时间要服务。

### 2.3 推导链路（苏格拉底式）

**Q1：站里有 n 辆车的概率是多少？**

用进出平衡：

从 0→1 的次数 = 到速率 × P0 = λP0  
从 1→0 的次数 = 服务速率 × P1 = μP1

长期相等：

P1 = (λ/μ)P0 = ρP0

同理：

P2 = ρP1 = ρ²P0  
P3 = ρ³P0  
...

所有概率之和为 1：

P0(1 + ρ + ρ² + ...) = 1  
P0 = 1-ρ

所以：

```
P(n辆在场) = (1-ρ)ρⁿ
```

**Q2：平均在场车辆数 L？**

用错位相减法或几何级数：

```
L = ρ/(1-ρ)
```

饮食版本：利用率 0.8 时，L=0.8/0.2=4。

**Q3：平均排队车辆数 Lq？**

平均在场扣除正在被服务的那一辆。正在被服务的概率是 ρ，所以：

```
Lq = L - ρ = ρ²/(1-ρ)
```

**Q4：平均排队时间 Wq？**

Little 定律 Lq=λWq：

```
Wq = Lq/λ = ρ/[μ(1-ρ)] = λ/[μ(μ-λ)]
```

**Q5：平均总逗留时间 W？**

自己的服务时间还要加上：

```
W = Wq + 1/μ = 1/(μ-λ)
```

### 2.4 公式总表

| 指标 | M/M/1 |
|---|---|
| 状态概率 | P(n) = (1-ρ)ρⁿ |
| 平均在场 L | ρ/(1-ρ) |
| 平均排队 Lq | ρ²/(1-ρ) |
| 纯排队 Wq | ρ/[μ(1-ρ)] |
| 总逗留 W | 1/(μ-λ) |

### 2.5 分位数怎么算？

排队超过 k 辆的概率：

```
P(排队>k) = P(在场≥k+2) = ρ^(k+2)
```

解释：排队超过 k，意味着至少 k+1 辆在排队，再加上正在服务的一辆，场里至少 k+2 辆。等比求和把前面的 (1-ρ) 因子约掉了，所以只剩 ρ 的幂。

例：ρ=0.8，要 95% 不溢出，则 ρ^(K+2) ≤ 0.05，解得 K≈12。也就是排队区要按 12 辆车设计。

### 2.6 数值例子

λ=4 辆/小时，μ=5 辆/小时，ρ=0.8。

L=4，Lq=3.2，W=1 小时，Wq=0.8 小时=48 分钟。

## 3. M/D/1：定长服务模型

### 3.1 适用场景

- 服务时间基本固定，波动极小；
- 自动化的、机械化的服务过程；
- 只有一个服务台。

直觉例子：自动洗车机、固定时长的工位、定长数据包处理。

### 3.2 假设

- 到达是泊松过程；
- 服务时间恒定等于 s=1/μ；
- 单服务台。

服务时间没有随机性，所以服务过程是“确定性的”。  
D = Deterministic。

### 3.3 推导链路（苏格拉底式）

**Q1：一辆新车到达时，正在服务的那辆车平均还剩多少时间？**

服务时间固定为 s。  
到达时刻在服务区间 0 到 s 之间均匀分布。  
如果在新服务刚开始时到达，剩 s；如果刚结束，剩 0。  
平均剩余 = s/2。

但服务台不一定忙。忙的概率是 ρ，闲的时候剩余 0。  
所以：

```
平均剩余服务时间 = ρ × s/2
```

**Q2：平均排队时间 Wq 怎么表示？**

新车的等待 = 正在服务的剩余时间 + 前面所有排队车辆各完整服务一次。

```
Wq = ρs/2 + Lq × s
```

再用 Little 定律 Lq=λWq：

```
Wq = ρs/2 + λs Wq
```

注意到 λs=ρ：

```
Wq = ρs/2 + ρWq
Wq(1-ρ) = ρs/2
Wq = ρs/[2(1-ρ)]
```

换成 μ：

```
Wq = ρ/[2μ(1-ρ)]
```

**Q3：其他指标？**

Lq = λWq：

```
Lq = ρ²/[2(1-ρ)]
```

W = Wq + s：

```
W = 1/μ + ρ/[2μ(1-ρ)]
```

L = Lq + ρ：

```
L = ρ + ρ²/[2(1-ρ)]
```

### 3.4 公式总表

| 指标 | M/D/1 |
|---|---|
| 平均在场 L | ρ + ρ²/[2(1-ρ)] |
| 平均排队 Lq | ρ²/[2(1-ρ)] |
| 纯排队 Wq | ρ/[2μ(1-ρ)] |
| 总逗留 W | 1/μ + ρ/[2μ(1-ρ)] |

### 3.5 数值例子

λ=4，μ=5，ρ=0.8。

Lq=1.6，Wq=0.4 小时=24 分钟，W=0.6 小时=36 分钟。

对比 M/M/1 的 48 分钟排队，M/D/1 确实减半。

### 3.6 分位数

M/D/1 没有简单等比形式的分布，分位数通常查表或用数值方法。  
工程上如果要求不高，也可以用 M/M/1 的分位数做保守估计。

## 4. 对比表与选择指南

### 4.1 推导逻辑差异

| 推导步骤 | M/M/1 | M/D/1 | 差异根源 |
|---|---|---|---|
| 系统状态描述 | 只看车辆数就够 | 还必须知道服务已进行多久 | 指数分布无记忆，定长有记忆 |
| 平均剩余服务时间 | ρ×(1/μ) | ρ×(1/(2μ)) | 无记忆→剩余仍是全程；固定→平均只剩一半 |
| Wq 分解 | 剩余+Lq/μ | 剩余+Lq/μ | 两者结构相同，只是代入不同的剩余 |
| 用 Little 定律 | Lq=λWq | Lq=λWq | 完全相同 |

### 4.2 公式对比

| 指标 | M/M/1 | M/D/1 |
|---|---|---|
| L | ρ/(1-ρ) | ρ + ρ²/[2(1-ρ)] |
| Lq | ρ²/(1-ρ) | ρ²/[2(1-ρ)] |
| Wq | ρ/[μ(1-ρ)] | ρ/[2μ(1-ρ)] |
| W | 1/(μ-λ) | 1/μ + ρ/[2μ(1-ρ)] |

观察：Lq 和 Wq，M/D/1 正好是 M/M/1 的一半。L 和 W 不是严格一半，因为“正在服务的那一辆/自己的服务时间”在两种模型下是一样的。

### 4.3 选择指南

| 你的情况 | 用哪个 |
|---|---|
| 服务时间实测方差大，接近平均值 | M/M/1 |
| 服务流程标准化，方差接近 0 | M/D/1 |
| 不知道分布，想保守 | M/M/1 |
| 想知道“如果能稳定服务，能改善多少” | 两者都算，对比差距 |
| 多服务台并行 | 用 M/M/c，不要直接用这两个 |

## 5. 命名规则与模型宇宙

### 5.1 Kendall 记号法

排队系统代号长这样：

```
A / B / m / K
```

- A：到达过程
- B：服务过程
- m：服务台数量
- K：系统容量上限（可省略）

读法：**先到达，后服务，再数量**。顺序不能换。

### 5.2 字母箱

| 字母 | 含义 | 白话 |
|---|---|---|
| M | Markov / Memoryless（指数分布） | 随机、无记忆 |
| D | Deterministic（定长） | 固定、无波动 |
| G | General（一般分布） | 任意分布，通用 |
| E | Erlang（爱尔朗分布） | 几个相同随机阶段的叠加 |

记住：**M 不是 Monte Carlo**。

### 5.3 四个代表模型总表

| 代号 | 含义 | 平均纯排队时间 Wq | 适用场景 |
|---|---|---|---|
| M/M/1 | 随机到达+随机服务+1台 | ρ/[μ(1-ρ)] | 人工收银、加油站、客服 |
| M/D/1 | 随机到达+固定服务+1台 | ρ/[2μ(1-ρ)] | 自动洗车机、定长流水线 |
| M/G/1 | 随机到达+一般服务+1台 | λE[S²]/[2(1-ρ)] | 维修车间、未知分布 |
| M/M/c | 随机到达+随机服务+c台 | Erlang-C 公式 | 银行柜台、呼叫中心 |

### 5.4 为什么 M/M/1 和 M/D/1 都是 M/G/1 的特例？

M/G/1 的排队公式：

```
Wq = λE[S²] / [2(1-ρ)]
```

- 若服务时间服从指数分布，则 E[S²]=2/μ²，代入得 M/M/1 公式；
- 若服务时间固定，则 E[S²]=1/μ²，代入得 M/D/1 公式。

所以两个模型的差异，本质是**服务时间平方均值 E[S²] 的差异**。

### 5.5 决策四象限

```
只有1个服务台？
├─ 服务时间方差大/随机 → M/M/1
├─ 服务时间固定/零方差 → M/D/1
└─ 未知/介于两者之间 → M/G/1
多个服务台并行？
└─ M/M/c
```

## 6. 容量设计与成本优化

### 6.1 目标函数

设计服务能力时，平衡两笔钱：

```
每小时总成本 = 服务成本 + 用户时间成本
C(μ) = c_μ × μ + c_w × L(μ)
```

- c_μ：每提升 1 单位服务率所需的每小时成本（元/（辆/小时））
- c_w：每个用户在场一小时的损失（元/辆·小时）
- L(μ)：模型给出的平均在场车辆数

单位检查：c_μ×μ → 元/小时；c_w×L → 元/小时。两边可加。

### 6.2 M/M/1 时的最优服务率

L = λ/(μ-λ)，所以：

```
C(μ) = c_μ μ + c_w × λ/(μ-λ)
```

求导：

```
C'(μ) = c_μ - c_w λ/(μ-λ)²
```

令导数为 0：

```
μ* = λ + √(c_w λ / c_μ)
```

最优服务时长：

```
s* = 1/μ*
```

### 6.3 M/D/1 时的最优服务率

L = λ/μ + λ²/[2μ(μ-λ)]，所以：

```
C(μ) = c_μ μ + c_w [λ/μ + λ²/(2μ(μ-λ))]
```

求导（过程略，最终）：

```
C'(μ) = c_μ - c_w λ/μ² - c_w λ²(2μ-λ) / [2μ²(μ-λ)²]
```

没有漂亮的根式解，用二分法/牛顿法求零点即可。

### 6.4 数值示例

参数：λ=4 辆/小时，c_μ=40 元/（辆/小时），c_w=80 元/辆·小时。

M/M/1：

```
μ* = 4 + √(80×4/40) = 4 + √8 ≈ 6.83 辆/小时
s* ≈ 8.8 分钟
ρ ≈ 0.59
```

M/D/1（用数值求解）：

```
μ* ≈ 6.12 辆/小时
s* ≈ 9.8 分钟
ρ ≈ 0.65
```

含义：如果服务时间是固定的，你不需要那么快的服务速度，可以省下不少投资。

### 6.5 检查结果

- 验证 ρ<1，否则模型失效；
- 如果 μ* 太接近 λ，系统会非常脆弱，一点波动就排长队；
- 如果 μ* 远大于 λ，说明服务能力过剩，成本还有下降空间。

## 7. 常见陷阱与易错点

| 陷阱 | 错误理解 | 正确理解 |
|---|---|---|
| Little 定律 | W 是排队时间 | W 是总逗留时间（排队+服务） |
| L 与 Lq | 混为一谈 | L 含正在服务的，Lq 不含 |
| 分位数指数 | 以为是 ρ^k | 排队>k 要算在场≥k+2，用 ρ^(k+2) |
| ρ<1 | 只要差不多就行 | 必须严格小于 1，否则模型不适用 |
| 供大于求 | 平均供大于求就不排队 | 由于随机扎堆，仍然会有等待 |
| 无记忆性 | 服务了很久就快结束了 | M/M/1 中剩余期望仍是完整均值 |
| M 的含义 | Monte Carlo | Markov/Memoryless |

## 8. 总结

- M/M/1 是所有排队分析的起点；
- M/D/1 告诉你“稳定服务”价值多大：排队减半；
- 命名规则是 Kendall 记号：到达/服务/台数；
- 成本优化就是在“服务成本”和“等待成本”之间找平衡；
- 所有计算都依赖 ρ<1，这是物理边界。

一句话记住：  
**到达随机造成排队，服务波动加大排队，服务稳定节省排队。**

## 9. 多服务台：M/M/c 与服务水平

### 9.1 什么时候用

一个站有 c 个桩（或工位），车来了排**一条**队，哪个空了去哪个。充电站就是这样。多个台共用一条队，比"每台各排一队"排得短得多——这叫**合并效应**。

### 9.2 公式（Erlang C）

记 a ＝ λ/μ（同时在忙的平均台数），ρ ＝ a/c（每台的利用率），要求 ρ < 1。

```
来了要排队的概率  P_w ＝ [aᶜ/c! × 1/(1−ρ)] ÷ [ Σ_{k=0}^{c−1} aᵏ/k! ＋ aᶜ/c! × 1/(1−ρ) ]
平均排队时间      Wq ＝ P_w ÷ (cμ − λ)
排队超过 t 的概率 P(Wq > t) ＝ P_w × e^{−(cμ−λ)t}
```

c ＝ 1 时退回 M/M/1。

### 9.3 服务时间不是指数分布：M/G/c 的近似

充电时长既不是完全随机，也不是完全固定。常用近似（Allen–Cunneen）：

```
Wq(M/G/c) ≈ Wq(M/M/c) × (1 ＋ C_s²) ÷ 2        C_s ＝ 服务时间的标准差 ÷ 均值
```

C_s ＝ 1 是指数分布（不修正），C_s ＝ 0 是定长（排队减半，与第 4 节一致）。

### 9.4 数值：合并效应有多大

单次服务 20 分钟，按 M/M/c 算平均排队（分钟）：

| 每台利用率 ρ | c ＝ 1 | c ＝ 2 | c ＝ 4 | c ＝ 8 |
|---|---|---|---|---|
| 0.5 | 20.0 | 6.7 | 1.7 | 0.3 |
| 0.7 | 46.7 | 19.2 | 7.1 | 2.3 |
| 0.8 | 80.0 | 35.6 | 14.9 | 5.7 |

读法：同样 70% 的利用率，1 个桩平均要排 47 分钟，8 个桩共用一队只要 2 分钟。所以多桩站可以跑得比单工位满得多，而排队不长。

### 9.5 服务水平：不只看平均

车队在乎的是"大多数时候不耽误"。设计时常用：**九成的车排队不超过 t 分钟**，即 P(Wq > t) ≤ 10%，反解出能跑到的最高利用率。

## 10. 本项目怎么用

### 10.1 两种优化写法是一回事

第 6 节是"需求 λ 给定，挑服务速度 μ"；本项目是"每条工位的速度 μ 给定（换电 5 分钟一次），挑每条工位接多少车（即利用率 ρ），从而定建多少条工位"。目标都是"设施成本 ＋ 用户等待成本"最小。按每次服务的成本写：

```
每次服务的成本 ＝ C ÷ (μρ) ＋ w × Wq(ρ)        C：一条工位每小时的全成本；w：用户每小时的时间价值
M/D/1： ρ* ＝ 1 ÷ (1 ＋ √(w ÷ 2C))
M/M/1： ρ* ＝ 1 ÷ (1 ＋ √(w ÷ C))
```

工位越贵越该用满；时间越值钱越该留空闲。

### 10.2 各路线用哪个模型

| 路线 | 模型 | 设计变量 |
|---|---|---|
| 换电工位 | M/D/1（每条工位一队） | 利用率 → 工位数；另有站内电池块数 |
| 兆瓦超充站、常规快充站 | M/G/c（多桩一队），用 9.3 节修正 | 桩数 c 与每桩利用率 |
| 车队自备轮换 | 不排队（按班次排程） | 备用电池套数 |

用户时间价值 w 在所有路线里取同一个（按场景分档），见 `补能路线比较_总框架.md` 第五节。
