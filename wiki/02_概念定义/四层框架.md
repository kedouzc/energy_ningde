# 四层框架

> **核心概念**：信息 → 量子场 → (物质 ⟷ 力) → 能量

## 定义

四层框架是从物理底层提炼的投资分析结构，连接物理本质与投资价值。

## 四层结构

```
信息层
    │
    ▼
量子场层（客观基底）
    │
    ▼
物质层 ⟷ 力层（相互作用）
    │
    ▼
能量层（总能量与正反馈）
```

## 各层含义

| 层级 | 物理含义 | 投资映射 |
|------|---------|---------|
| 信息层 | 判断对的事 | 反共识识别 |
| 量子场层 | 客观基底 | 物理本质 |
| 物质层 | 选对物质 | 技术路线 |
| 力层 | 建立机制 | 商业模式 |
| 能量层 | 总能量 | 价值创造 |
