## 三、DCF主要输入参数（评估报告摘要披露）

### 3.1 折现率（WACC）组件

| 组件 | 取值 | 来源 |
|---|---|---|
| 无风险利率 Rf | 2.21% | 沪深10年期以上国债到期收益率均值 |
| 市场风险溢价 ERP | 6.12% | 沪深300成份股几何平均收益加权（北京中同华统一测算） |
| β（可比公司剔除资本结构后均值） | 1.1501 | 5家可比：宁德时代、亿纬锂能、国轩高科、许继电气、通合科技 |
| β（重杠杆化） | 1.32 | 目标D/E=16.05%、目标税率21% |
| β（Blume调整后采用值） | 1.21 | βa=0.35+0.65×βh |
| 公司特有风险溢价 Rs | 2% | 业务快速发展期、收入增长快、投资规模大、融资额高 |
| 债务成本 Rd | 3.02% | 启源自身实际利率 |
| 目标资本结构 D/E | 16.05% | 5家可比公司平均 |
| 目标所得税率 | 21% | 多数主体25%，附属高新企业15%，加权 |

评估机构给出的 CAPM 逻辑是：

**Ke = 2.21% + 1.21 × 6.12% + 2.00% = 11.62%**

D/E=16.05%，所以权益权重约86.17%，债务权重约13.83%，由此推算（公告未直接给出最终数值）：

**WACC ≈ 11.62% × 86.17% + 3.02% × (1−21%) × 13.83% ≈ 10.34%。**

### 3.2 预测期与终值

- 有限预测期：2025-12-01至2031-12-31（约6年）；2032年起永续，采用永续增长模型。
- 永续期资本支出按资产类别、更新周期年金化；永续期营运资金增加不再考虑。
- 企业自由现金流 = 净利润＋利息支出×(1-税率)＋折旧摊销−资本支出−营运资金增加。

### 3.3 收入预测结构（按业务分拆）

| 业务 | 预测口径 |
|---|---|
| 电池租赁 | 按不同型号电池分别预测租金；长寿命电池折旧年限10年；单套电池运营费平均0.19万元/年（不含税） |
| 换电站运营 | 分标准站、mini站、充电站三类分别预测；**电费按0.60元/kWh、换电服务费按0.42元/kWh**；负荷率以2025年平均为基础爬升至设计负荷率 |
| 设备销售 | 以2025年实际销售为基（CTB电池、外购直采电池、车辆配套设备），2029年后规模保持稳定 |
| 平台服务费 | 车联网监控调度云、电池银行云、充换电站管理交易云、综合金融服务云；规模小，按固定增长率预测 |

### 3.4 营运资金与其他

- 应收/应付：电池销售回款周期3个月；租赁、换电电费与服务费收入按月度结算。
- 带息负债按账面值确认评估值；非经营性资产负债（含溢余资产）按成本法。
- 2024/2025年为经审核合并财务资料；2026年前4月为挂牌披露口径（未经审核）。

## 五、对本模型的校准意义

1. **换电服务单价**：启源评估采用电费0.60元/kWh＋服务费0.42元/kWh（合计度电收入约1.02元）。本模型v4.1采用度电服务费0.40元＋电池租金120元/kWh年，可与之对照核订单价口径（启源含电费差额部分，本模型按净额法只计损耗电费）。
2. **换电运营估值倍数**：启源DCF隐含约28.9×静态PE、2.18×PB，且为评估机构永续DCF口径。本模型运营线用18×EV/EBITDA，低于该交易隐含口径，处于保守一侧；7.2敏感性区间14—25×可以覆盖。
3. **折现率锚**：启源评估WACC约10.3%（含2%特有风险溢价）。本模型WACC 7.5%取自蔚来ABS，明显低于启源股权评估口径，说明ABS资产端与股权端风险定价的差异，报告2.3节可引用此对照。
4. **并购现金口径**：本模型Part 7.2启源情景的交易现金25.6亿元与本公告一致（25.556597亿元）；宁德时代持股增至30.3159%并成为第一大股东，整合后协同尚未发生，维持"基准不提前确认协同"的处理。
5. **风险提示对照**：评估师明确列示"收入规模增长快、投资规模大、融资额高"为特有风险（+2%溢价），与本报告Part 7.1对服务费/租金、资本调用峰值、CRF覆盖倍数的敏感性关注点一致。

### 现在中国绿色债券一般是什么期限、什么利率？

截至2026年上半年，中国境内绿色债券当年已经发行 **322只、4059.48亿元**。([绿色债券信息平台][6])

期限结构非常明确：**以1–5年为绝对主流，其中3年附近最常见。**

2026年上半年：

| 期限       |     发行规模占比 |
| -------- | ---------: |
| **1–3年** | **54.96%** |
| **3–5年** | **18.56%** |
| 两者合计     | **约73.5%** |

也就是说，“**3年、3+2年、5年**”基本可以看作目前中国绿色信用债最典型的期限结构。([新浪财经][7])

利率水平：

| 发行人/产品         | 2025–2026大致发行水平 |
| -------------- | --------------: |
| 顶级AAA央国企/宁德时代等 | **约1.45%–1.8%** |
| 优质AAA绿色金融债/MTN |  **约1.5%–2.0%** |
| AA+/一般优质企业绿色债  | **约1.8%–2.5%+** |
| ABS优先级         |  **约1.6%–2.5%** |
| 较低等级/次级ABS/民企  |   **3%–5%甚至更高** |

跨整个市场统计，2025年绿色债券平均发行利率约 **2.1%**、中位数约2.0%，样本区间约1.32%–5.5%；但这个平均数受到AAA央国企和金融机构占比很高的影响，**不能直接拿来当普通换电运营商债务成本**。([搜狐][8])

还有一个特别重要的数据：2026年上半年，有可比普通债的绿色债中，约 **68.15%** 的发行成本低于同期限、同评级普通债，但平均只低 **5.35bp**。([新浪财经][7]) 绿色认证带来的独立“greenium”，平均其实只有几个bp。宁德时代能发1.5%，主要因为它是宁德时代，不只是因为债是绿色的。
