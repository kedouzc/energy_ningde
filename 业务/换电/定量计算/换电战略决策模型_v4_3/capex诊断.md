## 原则

这几条是本次讨论反复踩坑后提炼出来的，**处理 capex 相关计算时逐条对照**。

### 原则一 · 追溯本质（以终为始）

**每当要回答一个问题时，先回到"这个问题最终要解决什么背景下的事"，
由事情的本质反推该用什么方法，而不是在既有候选口径里挑一个。**

> 教训：P4（EV 在 2030、债务在 2026）纠结了两轮才解决。
> 根因是一直在"该折到 2026 还是 2030"之间选，
> 而没有先问"我们为什么要估值？→ 估的是 2030 稳态运营的这门生意
> → 那就统一滚到 2030"。**先定场景，方法自然浮现。**

### 原则二 · 口径守恒

同一笔钱在不同问题下有不同答案（见 §7 口径体系）。
**每个答案内部必须口径一致**——只有同口径的量才能相减、才能比较。

### 原则三 · 存量与流量不可跨层混用

| 层级 | 存量（`lifecycle_pv`） | 流量（`EAC`） |
|---|---|---|
| 单站 / 单 cohort | ✅ 有效（锚自身 t₀） | ✅ 有效 |
| 集团 | ❌ **无效**（各批锚不同日期） | ✅ **有效**（同为"每年"的量） |

**集团级存量必须先各自重订基准年、再相加**（§5）。

### 原则四 · 资金运用 ≠ 资金来源

capex 是"钱花到哪去"，debt 是"钱从哪来"。
**capex 的 60% 靠借，是来源标注，不是要扣减的项**（§2.2）。

### 原则五 · 相减的两个量必须在同一时点

`EV − D` 要求两者在同一时点。**跨时点相减是硬错误**（§4.4）。

### 原则六 · 债务不可复利：统一时点时只能移动 EV

| 量 | 性质 | 时点移动方式 |
|---|---|---|
| **EV / 资产价值** | 是"价值"，有时间价值 | ✅ 可折现、可复利（但须**逐笔**） |
| **Debt / 负债余额** | 是"名义契约额"，**无时间价值** | ❌ **不能按折现率复利**；其时点演变由**还款计划**决定 |

> **债务不会以 WACC 的速率增长。**
> 把 2030 年的债务说成"2026 年债务 ×1.075⁴"是错的——
> 2026 到 2030 之间发生了还本、新增借款，那是一个**还款计划**问题，不是复利问题。

⇒ **推论**：统一时点时，**只能移动 EV，不能移动 Debt**。
而最干净的做法是——**让 Debt 在它该在的时点被直接算出来**（§4.2 的 cohort 算法
算出的是 2030 在役批次，**天然就在 2030，根本不需要任何时点转换**）。

### 原则七 · 复合现金流不能用统一因子折算

`valuation_capital_pv`（3,725.0）是 **2026—2045 共 20 年现金流**折到 2026 的加总。
要把它移到 2030：

| 现金流年份 | 折到 2026 | 移到 2030 的因子 |
|---|---|---|
| 2026 年的支出 | 原值 | **×1.075⁴** |
| 2045 年的支出 | ÷1.075¹⁹ | **÷1.075¹⁵** |

⇒ 各笔因子**互不相同**。统一乘 `1.075⁴` 只在"全部现金流都发生在 2026"这一极端情形下成立。

**正确做法：逐笔重算 `Σ_t CF_t / (1+r)^(t − B)`（B = 目标基准年）。**

### 原则八 · 代码未改前，只给公式不给数字

在模型代码实际跑出之前，**不对手工折算的结果下"高估/低估多少"的量化论断**。
文档只负责把**正确公式**写清楚，数值留待代码产出。

> 教训：此前给出"NPV 修正后 88.1／高估约 1,200 亿"——
> 那是基于"统一 ×1.075⁴"这个本身就不成立的简化，**结论不可靠，已撤回**。

## 为什么 capex 必须做成专题

capex 同时决定三件事，任何一件算错，整个模型都建在沙子上：

| | 影响 | 对应问题 |
|---|---|---|
| **(a)** | **投多少、怎么投、什么节奏** | 建设期资金需求、分年出资、峰值出资 |
| **(b)** | **门槛的基本回报水平** | 年度资本要求、覆盖率、EAC |
| **(c)** | **值多少** | 投入现值、EV、NPV、权益价值 |

这三件事要求**不同的口径**，但都来自同一笔钱。
本文目标：**让 (a)(b)(c) 各用各的、互不污染、可互相校验。**

## Q1 · 框架 U 还是 L

- **U 相对更简单**
- **L 的好处**：最后算的是宁德时代自身的权益价值和它要投入的代价，更直接
- **折现率**：7.5% WACC 有外部锚；股权成本无比较值，但可由 2.5% 债务利率和 7.5% 推算
- **两套都能在同一套参数下做出来**

**2套会有差异吗？如果有差异，是什么原因？到底用哪套？**

## Q2 · 框架 U 里要刨掉的那个债务，是什么口径（核心）

```
FCFF 折现 → 企业价值 EV → 刨掉债务 D → 股权总价值 → × 40% 持股 → 宁德时代权益价值
```

**问题：这里要刨掉的 D，是什么口径？**

1. 是像 CRF 方法那样，**全周期投资里的 6 成**？
2. 还是**真实发生的 Capex 所对应的、需要通过债务筹措的那 60%**？

## Q4 · 稳态债务怎么算

按要解决的问题不同，答案不同：

**1. 相对倍数法**：为算 2030 年稳态价值而扣减当下债务。
此时债务应是**按已经更新过的存量债务来算**——出厂那批电池的债已经过去了，
现在是"更换后还在用的这批电池"带来的债务。
**这可以直接用各批次（cohort）数据算出来，技术实现没有难度，参数都有。**

**2. 绝对法（DCF）**：往回走，看的是**今后的债务问题**，跟当下关系不大。

> **判断标准是"要解决什么问题"，不是"误差大不大"。**

**附：时点错配（P4）**——既然定的是 2030 稳态运营、要估值的也是那一年，
**那就没有必要折到 2026，统一滚到 2030 就好**。

## Q5 · `lifecycle_capital_base`（EAC）的存废与层级

一直说它"不伦不类"，各cohort初装capex名义值相加，后续更新又是贴现值，**那怎么能说它在本职算 EAC 里是正确的？它当然不正确。**

**算 EAC 是不是也要区分两级：单站 vs 全集团？**

因为 2026—2028 每年都有新站投产，每一批站形成的时点不同、贡献也不同。
**单站不存在这种混合状态**。
**所以根源在于把单站和集团整体的计算搞混了。**

## Q6 · "值不值"：投多少与值多少必须同口径

"值多少"已考虑了现值，**"投多少"是不是也应该用现值**？

要把 `lifecycle_capital_base` 做一次**归一化统一**——不要有的折现、有的不折现。
都折现后再跟能换回来的价值比较，**这才是可比的**。

> 拿名义、不折现的总投资 5,605 来比较没有实际意义：
> 它只能说明"前后共要花这么多钱"，不能用于"值不值"的价值判断。

## Q7 · capex 口径体系与分池

看下来似乎有：① 名义值（不折现，各年简单加总）② 含现值。
**除了这两个还有别的吗？起码这两个都应该有。**

另外：若要计算各池单独指标体系，**是不是把投入总现值也分池做出来更有备无患？**

## Q8 · 稳态基准年、终局站数与成长性

**基准年选 2030**（重庆案例：巧克力电站 2024 年底铺开、2025 年即转盈，
说明营运车换电是真需求，只要车辆数够爬坡很快）；
2028 年建站满足基本需求，**2030 是所有已建成站体完整的第一个满产运行年度**。

**但**：重卡保有量 900 万、更新周期 9 年，5 年换不完；2031 年之后仍在更新、
渗透率仍在上升。**拿 2030 车队需求当终局反推站数，本身是不是就错了？**

> **进一步**：只拿 2030 年满产状态预估，**既保留了好的经济性，也给未来再增长留足了空间**。
> 这恰恰可以成为支撑高估值倍数的理由——**因为有成长性支撑**。

# 第二部分 · 分析与答复

## §1 · 框架选择：主用 U，用 L 做交叉验证（回答 Q1）

### 1.1 两套框架

| | **框架 U：无杠杆（全投资）** | **框架 L：有杠杆（股权）** |
|---|---|---|
| 现金流 | **FCFF** = 经营流入 − 全部投资流出<br>（**不含任何筹资项**） | **FCFE** = 经营流入 − 权益部分投资<br>− 付息 − 还本 **+ 新借入** |
| 折现率 | **WACC**（含债务成本） | **Ke**（股权成本，Ke > WACC） |
| 折现结果 | **企业价值 EV** | **股权价值 Equity** |
| 债务处理 | 最后 **减一次** 净债务：`Equity = EV − D` | **不再减债务**（已在现金流里） |
| 模型现状 | ✅ **本模型用 U** | ❌ 未使用 |

**U 里为什么不含筹资项？** 因为 **WACC 这把尺子已经把债务成本量进去了**。
FCFF 是"付给所有资本提供者之前"的现金流，折现得到整个资产的价值，
最后把欠债权人的部分减掉即可。

**Ke 推算**（Q1 提到）：由 `WACC = w_d × r_d ×(1−T) + w_e × K_e`

```
K_e = [7.5% − 60% × 2.5% ×(1−25%)] ÷ 40% = [7.5% − 1.125%] ÷ 0.4 = 15.9%
不含税盾：15%
```

### 1.2 两套的算例

装修例子（100 资产，贷 60，5% 利率，2 年摊还，股东 40，息税前现金 62/年，WACC = 7.5%）：

| 年份 | 经营 | 投资 | 筹资：借入 | 筹资：还本 | 筹资：付息 | 净现金流 |
|---|---:|---:|---:|---:|---:|---:|
| t0 | | **−100** | **+60** | | | −40（股东出资 40，合计 0） |
| t1 | +62 | | | −30 | −3 | **+29** |
| t2 | +62 | | | −30 | −1.5 | **+30.5** |

**情形 A · 无税 + 债务摊销（30/年）**

```
Ke = (7.5% − 60%×5%) ÷ 40% = 11.25%
FCFF = 12 + 50 = 62（两年）
U: PV(FCFF)@7.5% = 62/1.075 + 62/1.075² = 111.325  →  Equity = 111.325 − 60 = 51.325
L: FCFE = [29, 30.5] @11.25% = 26.067 + 24.544      →  Equity = 50.612
差额 0.714 → 1.39%
```

**情形 B · 含税盾（T=25%）+ 债务摊销**

```
Ke = (7.5% − 60%×5%×0.75) ÷ 40% = 13.125%
FCFF = 12×0.75 + 50 = 59（两年）
U: PV@7.5% = 59/1.075 + 59/1.075² = 105.939  →  Equity = 105.939 − 60 = 45.939
L: FCFE_1 = 59 − 3×0.75 − 30 = 26.75
   FCFE_2 = 59 − 1.5×0.75 − 30 = 27.875
   PV@13.125% = 23.647 + 21.782                 →  Equity = 45.429
差额 0.510 → 1.11%
```

**情形 C · 含税盾 + 恒定杠杆（债务跟随项目剩余价值调整至 60%）**

```
V_0 = 105.939, V_1 = 59/1.075 = 54.884, V_2 = 0
D_0 = 63.563,  D_1 = 32.930,    D_2 = 0
U: Equity = V_0 − D_0 = 105.939 − 63.563 = 42.376
L: FCFE_1 = 59 − 3.178×0.75 − 30.633 = 25.983
   FCFE_2 = 59 − 1.647×0.75 − 32.930 = 24.835
   PV@13.125% = 22.969 + 19.405                  →  Equity = 42.374
差额 0.002 → 0.00%  ✅ 完全相等
```

**结论:**

| 情形 | 差额 |
|---|---:|
| A 无税 + 摊销 | 1.39% |
| B 含税盾 + 摊销 | **1.11%** ← **没消失** |
| C 含税盾 + **恒定杠杆** | **0.00%** ✅ |

> **税盾是必需的（Ke 公式必须用税后债务成本），但它不是让两者相等的原因。**
> 真正的原因是**杠杆率是否恒定**：
> 单一 WACC 折现隐含"杠杆率不变"；债务一旦摊销，D/V 逐期变化，
> WACC 就不再恒定，U 与 L 必然出现差额。

**对本模型的两点直接推论:**

**推论一（支持既有选择）**：模型按 `debt_ratio` 是**目标资本结构**、
`interest = debt × rate` 是**稳态年利息**（`business.py:367`）来处理，
逻辑上正对应情形 C（恒定杠杆）。
⇒ **"未摊销比例 = 100%"（恒定杠杆）与模型的稳态框架自洽**，应为默认。

**推论二（一个需要留意的不一致）**：

```
模型的 WACC 7.5% 是按 w_d = 60%（成本口径）算出的
但 DCF 折现要求的 w_d 是市场价值口径：D / EV
按新债务口径：D ≈ 1,400–1,580，EV_crf = 4,822.8  →  市场杠杆 ≈ 29%–33%
```

两者不一致。影响范围：**只影响口径 B（`FCFF × 年金因子(WACC,15)`，上界线）**，
主链口径 A 用 CRF 0.15、不用 WACC，不受影响。
列为待议 **T6**，本轮不处理。

### 1.3 为什么主用 U

1. **模型现状即 U**：`forward_fcff = ebitda×(1−tax) + depreciation×tax`
   （`business.py:376`）就是 FCFF；WACC 已是配置参数；DCF 线已在做 `EV − D`。
2. **U 对债务口径争议免疫**：U 里 D 只出现**一次**、是存量、不折现。
   而 L 要把每笔借款、还本、付息排进每年现金流——**在债务口径尚未定案时，
   做 L 会让未决假设渗透进每一年**。
3. **U 与倍数法同源**：倍数法（EV/EBITDA）本身就是无杠杆口径，两条线可直接对照
   （这正是 `dcf_multiple_premium` 要做的事）。
4. **输入参数有外部锚**：WACC 7.5% 有谱系锚（蔚能 REITs 4.68% → 协鑫 8.5–9.1%
   → 启源 10.34%）；Ke 15.9% 是**推导出来的**，无外部比较值。
5. **融资假设尚未定型**：`debt_ratio = 60%` 本身是"经验假设"（`base.toml:47`）。

### 1.4 L 的价值：交叉验证，不是替代

> 若 U 与 L 结果接近 → 说明融资假设不关键，结论稳健；
> 若差异大 → 说明融资结构假设需重新审视。
> **这个差异本身就是信息**，比任何单独结果都值钱。

### 1.5 一个口径细节

模型 DCF 口径 A 是 `EV = FCFF ÷ CRF`，用 **CRF 0.15**（隐含要求回报约 12.4%），
不是 WACC 7.5%。这是 `base.toml:39-43` 的刻意选择——
"WACC 只是必须收回成本的下限，估值要看期望收益率"。
所以口径 A 严格说是"**U 的现金流 + 期望收益率折现**"，
口径 B（`FCFF × 年金因子(WACC,15)`）才是标准 U。
两条并存是有意的（A 与门槛同源、B 给出上界），**不属于错误**。

## §2 · 债务 D 的口径（回答 Q2）

### 2.1 直接回答：是第 2 种

> **D = 真实发生的 Capex 中、通过债务筹措的那 60% 的未偿余额**。
> **不是**"全周期投资（含未来更新）的 6 成"。

U 框架下 D 要减的是"此刻欠债权人多少钱"。
未来的投资尚未发生，**对应的借款在 2030 年的资产负债表上不存在**。

### 2.2 为什么不是"全周期投资的 6 成"：资金运用 ≠ 资金来源

| | 是什么 | 例子 |
|---|---|---|
| **投资（capex）** | **资金的运用**——钱花到哪去了 | 4,297.3 是"总共要投多少钱" |
| **债务（debt）** | **资金的来源**——钱从哪来的 | 其中 60% 靠借、40% 靠股 |

> `lifecycle_capital` 是"要投多少钱"，**它本身不是债务**。
> 它有 60% 靠借，但那是资金来源的标注，**不是要扣减的项**。

### 2.3 未来更新"借新还旧"为什么净额为零

装修例子（100 资产，贷 60，5% 利率，2 年摊还，股东 40）：

| 年份 | 经营 | 投资 | 筹资：借入 | 筹资：还本 | 筹资：付息 | 净现金流 |
|---|---:|---:|---:|---:|---:|---:|
| t0 | | **−100** | **+60** | | | −40（股东出资 40，合计 0） |
| t1 | +62 | | | −30 | −3 | **+29** |
| t2 | +62 | | | −30 | −1.5 | **+30.5** |

**关键点：借到钱是现金流入（+60），不是流出。** 补回 +60 后：

```
借入 +60  与  还本 −60  →  净额 = 0
整个项目真正的融资成本，只有利息 −4.5
```

> **"重复计算"的准确含义**：
> 不能在"已经按全额扣了投资流出"之后，再去扣这笔投资的融资还款——

## §5 · EAC：为什么流量可加、存量不可加（回答 Q5）

### 5.1 钥匙：存量锚在"一个时点"，流量覆盖"一个区间"

| | 锚定方式 | 跨 cohort 可加性 |
|---|---|---|
| **存量** `lifecycle_pv_c` | 锚在**单一时点** t_c | ❌ 不同 t_c 是不同日期的钱，不可加 |
| **流量** `EAC_c` | 覆盖**区间** [t_c, t_c+15]，且**名义等额** | ✅ 同一年内的名义额可加 |

**为什么 EAC 可加？**

`EAC_c = lifecycle_pv_c × CRF`，定义上就是"在 [t_c, t_c+15] **每一年等额支付**的名义金额"。
**第 1 年与第 5 年的名义额相同**——时间价值已在 PV→EAC 的转换中被 CRF 处理掉了。

所以在 2030 年这一年：

- 2026 年装的批次贡献 `EAC_2026`（正在付第 5 年）
- 2030 年装的批次贡献 `EAC_2030`（正在付第 1 年）
- 两者都是 **2030 年这一年的名义现金**，同量纲，可直接相加

> **类比**：三笔贷款分别在 2026 / 2027 / 2028 年借入，都是 15 年等额本息。
> 问 2030 年这一年共还多少？——三笔月供直接相加。
> **不需要再折现，因为它们都是 2030 年的名义现金流。**

⇒ **不是"不同年份的钱相加"，而是"同一年（2030）里多笔钱相加"。**

### 5.2 Σ EAC_c 的准确定性：**2030 年这一年的瞬时值**

**覆盖性验证**：

| | 区间 | 覆盖 2030？ |
|---|---|---|
| 最早 cohort（install_year=2026，含 2025 存量） | [2026, 2041] | ✅ |
| 最晚 cohort（install_year=2030） | [2030, 2045] | ✅ |

⇒ 全部覆盖 2030，`Σ EAC_c = 644.6` 成立。

⚠️ **但它只是 2030 年这一年的值**。到 2042 年，2026 年装的批次已结束，Σ 会变小。
所以它**不是**"任意一年的年度资本要求"，而是"**稳态年（2030）**的年度资本要求"。

⇒ 与 2030 年名义 EBITDA（850.4）同量纲 ⇒ 覆盖率 `850.4 / 644.6 = 1.32` 成立。

### 5.3 用途全清单（不止覆盖率）

```
annual_capital_requirement_yi = lifecycle_capital × CRF = 644.6
```

| 用途 | 位置 | 口径 |
|---|---|---|
| **覆盖率** `forward_to_required_ebitda` | business.py:460-463 | 稳态年 |
| **资本要求 FCFF** `required_fcff_yi` | business.py:501；report.py:1557 | 稳态年 |
| **最低可分派现金** `capreq − interest` | business.py:377 | 稳态年 |
| **回收期** `catl_lifecycle_payback_years` | business.py:517-520 | 稳态年 |
| 分池 `capreq_by_pool` | business.py:332 | 稳态年（分池） |

⇒ **全部是"稳态年"口径，与 644.6 的定性一致，这些用法本身没问题。**
**问题只出在把集团级存量（4,297.3）当总投资额或债务基数。**

> 你猜"主要就是为了算覆盖率"——**部分正确**：覆盖率最显眼，
> 但还有 4 处（含分池版本）同样依赖它。

### 5.4 集团级存量：先重订基准年，再相加

```
lifecycle_capital_pv_B = Σ_c [ lifecycle_pv_c / (1+wacc)^(t_c − B) ]     B = 基准年
```

**关于基准年选哪年——你的质疑成立：若用于估值，基准年应为 2030，不是 2026。**

| 用途 | 基准年 |
|---|---|
| 与现有 `valuation_capital_pv`（现折到 2026）对接互校 | 2026（仅过渡） |
| **用于估值（与 `ev_crf` 相减）** | **2030**（原则一） |

> 更彻底：按 §4.5／§4.6，`valuation_capital` 本身也应**逐笔重算**到 2030
> （**不得**用 ×`1.075⁴`），届时两条路径都应对齐到 2030。

**两条路径互校**（`capex_path_drift`）：

| | 路径 |
|---|---|
| `valuation_capital_pv` | 按**年度现金流**汇总（初装 + 更换，逐年折回基准年） |
| `lifecycle_capital_pv_B` | 按 **cohort** 汇总（各批次 LCC 折回基准年） |

⇒ 两者应当相等，**差异即 `capex_path_drift`，是有价值的诊断指标**。

> **修正此前的错误论证**：曾用"4,297.3 ÷ 1.075² ≈ 3,725.0（差 0.2%）"论证等价——
> **该论证不成立**，"平均装机时点约 2 年"是拍出来的。
> **已作废**；两者是否相等必须由代码按各 cohort 实际装机年逐笔折现验证。

### 5.5 EAC 的存废结论

**保留**，定位与用途收紧：

### 7.3 `valuation_capital_pv` 本身

```python
# capex.py:475-482
valuation_capital_pv = preperiod_station_initial_capex        # ① 2025存量站，按2026价，不折现
```

## §8 · 稳态基准年、终局站数与成长性（回答 Q8）

### 8.1 模型的时间结构（代码事实）

- **建站**：`_station_schedule`（`capex.py:50-65`）返回 `[new_2026, new_2027, new_2028, 0, 0]`
  —— **2029—2030 零新增**
- **站数目标**：`target_station_demand` 由 **2030 车队需求**反推
  （`scale.py`：`站数(池) = ceil(池车日换电次数 ÷ 站日接待能力)`）
- **车辆侧**：换电电量逐年增长（qiji75_short `catl_swap_gwh`：
  4.581 → 5.029 → 5.380 → 5.614 → 5.848，2026→2030 **+27.7%**；
  其中 **2028→2030 仍有 +8.7%**）

```
2026—2028  建站期：产能先行，站等车（利用率爬坡）
2029—2030  填产期：车队长进来，零新增站（电量 +8.7%）
2030       满产年：车队规模刚好长到站网设计能力
```

### 8.2 「满产悖论」消解

**2030 不是"站已满产、新车没人服务"，而是"站的数量本来就按 2030 车队算出来的"。**
重庆案例支撑的正是"爬坡快"。**基准年选 2030，成立。**

### 8.3 「用 2030 反推站数是不是就错了」——**没有错**

你的观察准确：重卡保有量 900 万、更新周期 9 年，5 年换不完；
2031 年之后仍在更新、渗透率仍在上升。**所以 2030 确实不是终局。**

但**这不构成"反推错了"**：

| | 2030 快照 | 长期终局 |
|---|---|---|
| 车队规模 | 2030 年实际换电车队 | 900 万全部换成换电车 |
| 用途 | **估值基准** | **长期空间叙述（市场天花板）** |
| 站数 | 按 2030 需求建 | 按终局需求建 |

**站网本来就是跟随需求滚动建设的**——真实世界里没有谁按 2045 的车队规模一次性建站。

**若改用 900 万终局规模建站**：2030 年大量站闲置 ⇒ 利用率极低 ⇒ 单位经济性崩溃
⇒ **估值反而更低**。所以终局规模**不适合作为 2030 的估值基准**。

### 8.4 「只算到 2030 满产」是**优点**，并支撑高倍数

> **采纳你的论点**。此前我把"2030 后车队冻结"判为"缺失"，**这个判断已翻转**。

```
只拿 2030 年满产状态估值
  ⇒ 既保留了已被验证的经济性（2030 满产、利用率达设计值）
  ⇒ 又完全没有计入 2030 年之后的增长（车队继续增长、渗透率继续上升）
```

**这是保守的、留有上行空间的估值口径。** 而 2030 年之后的增长是**真实存在**的：
重卡 900 万保有量、9 年更新周期 ⇒ 2030 年连一轮都没换完；
2031 年之后仍在更新，渗透率仍在上升；站网可跟随需求滚动扩建（8.3）。

⇒ **这恰恰是支撑高估值倍数的理由：倍数里包含了市场对未来成长的定价。**

**对 T1（18× 是否合理）的意义**：

```
隐含倍数 = ev_crf / ebitda = 4,822.8 / 850.4 = 5.67×
外部给的 18×  ⇒  3.17 倍溢价需要由"成长性"来解释
```

**8.4 节论证的成长性，正是这 3.17 倍溢价的一个候选解释。**
前提是须向读者说明：**18× 里隐含了多少成长预期，以及这个预期是否有依据。**
