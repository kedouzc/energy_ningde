## v4.2.2（2026-08-29）

本版为**电池寿命口径与站数口径的修正版**，模型结构未变，仅改动相关子程序；模型版本号仍为v4.2，报告文件迭代为v4.2.2。

**1. 电池寿命由硬编码改为按使用强度推算（核心变更）**
- 新增 `[battery_life_model]`：`critical_cycles=2000`（LFP SOH≈82–85%的循环临界点）、`calendar_cap_years=10`（日历寿命封顶）。依据：《超换一体.md》§2.1；国标锚点 GB/T 31484-2015、GB/T 46991.1-2025。
- 删除全部7处硬编码 `battery_life_years`（5个车型＋2个站组）。
- 推算式：`life = min(critical_cycles ÷ (f̄ × operating_days), calendar_cap)`，其中 `f̄ = Σ(装机GWh × 频次) / Σ装机GWh`，即**按使用量（装机×频次，与换电度数同逻辑）加权的使用强度**。
- 关键修正：不可对寿命直接按装机加权——寿命是频次的倒数，倒数后加权会因 Jensen 不等式系统性高估。重卡即典型：对寿命加权得3.91年，按使用量加权仅3.13年。
- 站内周转电池寿命按本组CATL换电装机GWh加权的使用强度推算，不再跟随单一车型。

**2. 结论：大车更短、小车更长（v3.2口径与自身参数不自洽）**
- 重卡 5.70 → 3.13 年（分场景2.12/3.45/8.02年）；v3.2的5.7年反推只对应日均1.00次，而模型实算1.83次。
- 巧克力站周转电池 3.80 → 6.54 年（池子混入低频私家车后强度被摊薄）；v3.2的3.8年隐含1.50次，实算0.87次。
- 私家车维持10年（循环可支撑28.4年，由日历寿命封顶）。
- 影响：重卡资本倍数 1.496→2.101，巧克力站 1.831→1.440。

**3. 站数口径改为「冗余优先」**
- 巧克力站规划300次/日、物理上限552次/日，单站冗余252次/日。私家车需求先填该冗余，溢出部分才按规划能力新建站。
- 站数由 8,840 降为 7,877 座（中枢档私家车28.9万次/日远小于冗余总量约198.5万次/日）。
- 修正了v3.2内部矛盾：L471算式把私家车计入站数分母，L481文字却称"不增加站体CAPEX"。

**4. 私家车三情景（需求侧分情景）**
- 新增 `[vehicles.private.scenario_swap_penetration]` 三档：保守/中枢/激进（v3.2 L378-386口径）。
- `build_scale(private_scenario=...)` 支持切换；三档各完整重跑一条链。
- 报告 Part 7 新增 **7.2 私家车渗透率三情景**，与v3.2一致地在**同一报告内并列**呈现（原7.2并购顺延为7.3）。
- 实测：50.9 / 144.4 / 250.6 万辆，与v3.2的 51/145/251 吻合。
- 发现：EBITDA覆盖倍数随渗透率上升而**递减**（1.44→1.40→1.36），私家车是"绝对价值增厚、单位资本效率递减"的业务。

**5. 报告新增章节**
- 2.2.1 电池寿命由使用强度反推：为什么大车更短、小车更长（含寿命对照表与资本倍数）。
- 附录A.2 新旧寿命口径完整重跑对比（`life_mode="legacy_v32"` 对照模式，程序化生成，非手算）。

**6. 程序结构**
- `run.py` 重构为纯组装：只负责载入配置→构建快照→调用 `write_outputs`→打印；所有指标定义、表格与文案移入 `report.py`（`PRIVATE_SCENARIO_METRICS` / `format_private_scenario_console`）。
- `derived.py` 新增 `battery_life_years()` 与 `LEGACY_V32_*` 遗留口径常量（不参与基准）。
- `model.py` 透传 `private_scenario`、`life_mode`（与并购情景 `scenario_name` 正交）。
- `capex.py` / `v32_audit.py` / `report.py` 站内电池寿命改读推算值。

**7. 净影响（中枢档，对照附录A.2）**
- 全周期资本底座 3,894.7 → 4,578.1 亿（+17.5%）；CATL建设期资本调用 430.8 → 463.4 亿（+7.6%）。
- 年折旧 575.1 → 1,032.1 亿（+79.5%）使EBIT由 +223.3 转为 −233.7 亿；但折旧税盾令最低年可分派现金 525.8 → 618.0 亿（+17.5%）。
- 可归因换电增量价值 8,079.0 → 8,214.5 亿（+1.7%）；动力电池业务线价值 16,595.0 → 16,730.4 亿（+0.8%）。结论不变：支持重注。
