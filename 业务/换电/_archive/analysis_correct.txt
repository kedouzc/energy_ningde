【修正因果链的一体化模型】
================================================================================

原文问题：先假设'100次/天'，再倒推需要212个用户 → 因果倒置
正确逻辑：先有用户数，再推导换电次数、收入、电池需求

核心因果链：
  用户数(自变量)
    → 日均换电次数 = 营运用户×0.71 + 私家用户×0.2
    → 收入 = 租赁费 + 服务费 + 超充 + CCER + VPP
    → 电池数 = 用户数 + 站内周转(20块/站)
    → 站数 = ceil(日均换电次数 / 单站容量上限)
    → CAPEX = 站数×单站设备 + 电池数×单块成本

================================================================================
一、原文逻辑拆解：为什么是循环的？
================================================================================

原文说：'日均100次换电 → 需要212个用户'
但212个用户 → 需要212块电池 → CAPEX暴增
而原文CAPEX只算了20块周转电池(59万)，漏了212块用户电池(629万)

这就像说：'我开了个酒店，每天接待100个客人'
  → 需要100个房间(电池)
  → 但投资只算了前台和装修(站设备)，没算盖房间的钱(电池)
  → 然后把房费全算成利润 → IRR当然高

正确的自变量是用户数，不是换电次数。
换电次数是用户数×换电频率的结果，不是前提。

五、单站视角：每站服务多少用户？
────────────────────────────────────────────────────────────

  上面的全景是'整个网络'的视角。但投资决策通常以单站为单位。
  问题是：一个站能覆盖多少用户？

  这取决于服务半径内的用户密度：
  - 核心商圈/交通枢纽：3km半径内可能有200+换电用户 → 单站100+次/天
  - 一般城区：3km半径内可能50-100用户 → 单站30-60次/天
  - 郊区/新城：3km半径内可能<50用户 → 单站<30次/天

  所以'212用户=1站'的假设，只在核心商圈成立。
  一般城区更可能是50-100用户/站。

【最终结论】
================================================================================

  1. 原文的循环问题：
     原文先假设"100次/天"，再倒推需要212个用户。
     但212个用户需要212块电池(629万)，原文CAPEX只算了20块周转电池(59万)。
     这不是"循环计算"，而是"因果倒置+资产遗漏"。

  2. 正确的因果链：
     用户数(自变量) → 换电次数 → 收入
     用户数(自变量) → 电池数 → CAPEX
     用户数越多，收入和CAPEX同步增长，但收入增速 > CAPEX增速（规模效应）

  3. 单站模型核心指标（服务费0.4元/度）：

     212人/站（原文假设，日均100次）:
       CAPEX: 894万, 收入: 250.9万, EBITDA: 192.7万
       IRR: 8.2%, NPV: 34.8万, 回收期: 6.2年

     127人/站（日均60次，更现实的成熟站）:
       CAPEX: 641万, 收入: 155.2万, EBITDA: 104.0万
       IRR: 2.5%, NPV: -173.2万, 回收期: 8.2年

     100人/站（日均44次，一般城区站）:
       CAPEX: 561万, 收入: 125.2万, EBITDA: 76.1万
       IRR: -0.6%, NPV: -237.3万, 回收期: 9.8年

  4. 关键发现：
     - 212人/站是核心商圈的极限场景，一般城区更可能是80-127人/站
     - 用户数和电池数是1:1关系（每个用户1块电池），这是最大的成本项
     - 电池租赁收入和电池成本基本对冲（租赁费≈电池折旧+资金成本）
     - 真正的利润来源是换电服务费，不是电池租赁

  5. 电池租赁的真实经济学：
     每块电池成本: 2.97万
     8年折旧(残值10%): 0.33万/年
     平均租赁收入: 0.63万/年/块
     租赁毛利: 2985元/年/块
     → 电池租赁的利润率很低，本质上是"以租代购"的金融工具

  6. 商业判断：
     - 一体化模型的盈利核心是换电服务费，不是电池租赁
     - 电池租赁只是解决用户"买车不买电池"的金融方案，利润微薄
     - 真正赚钱需要：高流量(127+人/站) + 合理服务费(0.4+元/度)
     - 宁德时代的优势不在租赁，而在：电池成本低 + 换电网络规模效应
