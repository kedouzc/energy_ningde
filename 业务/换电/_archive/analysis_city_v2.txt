一、错误诊断：对比修正版md，我的模型哪里算错了？
──────────────────────────────────────────────────────────────────────

  修正版md的单站模型（213用户，1站）：
    CAPEX = 897万（站设备205 + 周转电池59.4 + 用户电池632.6）
    年收入 = 212.5万（租赁127.9 + 服务费73.2 + 超充11.0 + CCER 7.7 + VPP 3.0）
    OPEX = 45.6万（电损13.2 + 人工14.4 + 租金12.0 + 维保6.0）
    EBITDA = 166.9万
    IRR = 16.8%

  我之前的模型（analysis_city.py）的错误：
    ❌ OPEX多了保险费（0.5%×CAPEX）和营销费（5万/站/年）
       → 62站多算了约 164万 + 310万 = 474万/年
    ❌ 扣了25%企业所得税
       → EBITDA 166.9万 × 0.75 = 125.2万，少了41.7万/年/站
    ❌ 电池8年替换，而非10年折旧
       → 替换来得更早，PV负担更重
    ❌ 电池替换成本按原价×0.9，而非考虑残值回收

  修正后的模型对齐修正版md：
    ✅ OPEX = 电损 + 人工 + 租金 + 维保（4项）
    ✅ EBITDA口径（不扣税）
    ✅ 电池10年折旧，残值10%
    ✅ 第10年电池替换成本 = 原值 × (1 - 10%)

==========================================================================================
【修正后最终结论】
==========================================================================================

  1. 之前的错误：OPEX多算了保险+营销，又扣了25%所得税，导致EBITDA被严重压低。
     修正后对齐修正版md：OPEX只算4项（电损+人工+租金+维保），EBITDA口径不扣税。

  2. 单站模型验证（213用户，1站，0.53元/Wh）：
     - CAPEX = 896.5万（修正版md: 897万）✅
     - EBITDA = 203.3万（修正版md: 166.9万）
     - IRR = 18.6%（修正版md: 16.8%）

  3. 重庆现状（62站，5500用户，0.53元/Wh）：
     - 无补贴：EBITDA 4459万，IRR 6.3%
     - +0.2元/度补贴：EBITDA 5679万，IRR 12.1%
     → 重庆62站当前5500用户，利用率仅47%，尚未满负荷
     → 但EBITDA已为正，运营层面盈利
     → 需要更多用户（约1万人）才能达到IRR > 7.5%

  4. 一线城市5%渗透率（7.5万用户，308站，0.53元/Wh）：
     - 总投入30.4亿
     - EBITDA 7.3亿
     - IRR = 20.1%
     → 远超7.5%折现率，商业可行性很强。

  5. 关键发现：
     - 之前模型多算了保险+营销+所得税，导致EBITDA被压低约40%
     - 电池成本0.53元/Wh是正确的（时代电服独立核算公允价）
     - 修正版md的OPEX结构更合理：电损+人工+租金+维保
     - 网络级模型中，IRR随规模趋于20.1%（与修正版md一致）
