# 补能路线 · 均衡定价：终局时谁赢哪类车、换电能收多少

> **回答什么**：兑现年（2030 年）终局稳态里，每一类车选哪条补能路线；换电赢下的车，整包价（服务费 ＋ 电池租金）最高能收多少、比自己的成本多出多少（利润厚度）。这是框架第三节第 ③ ④ 步（`补能路线比较_总框架.md`）。
> **服务哪些读数**：换电在可及范围内赢的比例、换电每度电的利润厚度 → 下一步拆成服务费与租金、EBITDA。

## 一、终局是什么

终局是兑现年大家都建得差不多之后的稳态，同时满足三条：

1. **车队不再换路线**：每辆车用的都是它全年资源账最低的补能方式。
2. **运营商不再进出**：价格刚好覆盖含资本回报的成本；多出来的站在终局前被淘汰或并购。
3. **站数与需求匹配**：每条路线都跑在自己的最优利用率（`补能三路线_供给成本.md` 第六节"最优利用率怎么算"）。

今天充电站只有两成上下的实测利用率，是过渡期的状态，只作敏感性（对换电有利的一侧）。

**车分两类**（研究者 2026-09-28 确认）：
- **封闭短途多班倒**（港口、钢厂、矿山）：车连续运转，没有强制休息；对手有常规快充、兆瓦超充、车队自备轮换。
- **干线**：中途与长途跑的是同一批路、同一批站，只是每天跑的里程不同，合并成一类，按日里程分布逐车比较。干线充电站里各种功率的桩混装，每辆车选对自己最省的桩；常规快充在物理上主要在两头（物流园、场站，夜里慢充）和干线站里的低功率桩。

## 二、算式

```
每一类车按日里程抽样：
  封闭短途：代表里程 260 公里的 60%／80%／100%／120%／140%，五点等权
  干线：400 公里与 650 公里两个代表点各取上面五点，按原场景权重（0.50 与 0.12）合并
每辆车四（三）条路线的全年资源账：车队总账第〇之二节的算法（各路线都按自己的最优利用率）
这辆车选资源账最低的路线
若换电最低：
    整包价上限 ＝ 第二名的全年资源账（第二名在终局只能按成本收）
    利润厚度 ＝ 上限 − 换电自己的资源账（万元/车·年）；每度电 ＝ 利润厚度 ÷ 年用电
换电赢的比例 ＝ 换电最低的那些车的权重之和（这是可及范围内的比例，再乘可及比例才是份额）
```

## 六、读法

1. **中性终局**：封闭短途换电全赢，每度电利润厚度 0.049 元；干线换电赢 68% 的车（日里程高的那部分），每度电 0.029 元。
2. **利润厚度很薄**：每度电几分钱，远低于现行主链按"服务费跟平超充 ＋ 租金取对手保本价"推出的整包利润；接入主链会明显压低 EBITDA——这是下一步要逐项对照的。
3. **悲观终局换电一辆车也赢不了**：电池寿命差小、兆瓦大站、换电站 4 人且设备 300 万、换电底盘贵 3 万同时成立时，资源账上换电处处更贵。
4. **今天的低利用率是换电的上行空间**：若终局前充电站没有出清、利用率停在两成，换电每度电利润厚度升到 0.10 元以上、干线全赢。
