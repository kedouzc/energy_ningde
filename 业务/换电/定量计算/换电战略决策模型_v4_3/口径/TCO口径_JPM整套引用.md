## 为什么是整套引用

**一套自洽测算里的参数是相互约束的**——高电耗对应高负载、对应低里程。
拆开各取一项拼出来的组合，**可能在物理上根本不存在**。

此前的口径是网搜单点拼的，查出三个问题：

1. **漏了年载重损失**（电池比油箱重，直接吃载货量）——电动重卡最大的隐性成本项
2. **比错了对手**——一直拿换电跟柴油比（好看但没信息量），**真正的边际对手是 LNG**
3. **口径不自洽**——电耗取短途重载、年里程取同场景、油耗取干线实测，三种工况拼出来的
   TCO 不对应任何真实车队

JPM Table 3 是**内部自洽、三种动力齐全、且显式计入载重损失**的完整测算，故整套采用。

## ⚠️ 引用陷阱（这一条是踩出来的）

## 全成本 TCO：换电侧怎么改（2026-09-10 定案）

结论区要回答的是"重卡用户划不划算"，所以口径从**能源成本**升级为 **JPM Table 3 的持有期
总成本**——含购车、购置税、补贴、维保、载重损失，不只是油电差价。

### 公式（已用原表反算验证）

```
年运营成本 = 年能源成本 + 年维保 + 年载重损失
TCO(N)    = 购车总成本 + 年运营成本 × N
```

反算校验（对照 Table 3，**完全一致**）：

| | 年运营成本 | TCO(8) 计算值 | Table 3 |
|---|---:|---:|---:|
| 电动（充电） | 276,250 | 2,805,000 | 2,805,000 ✓ |
| LNG | 365,500 | 3,309,000 | 3,309,000 ✓ |
| 柴油 | 460,806 | 4,016,448 | 4,016,448 ✓ |

> 实现注意：年能源成本必须取 Table 3 的**原列**（191,250 / 325,500 / 430,806），
> 不能用"单公里能源成本 × 年里程"反算——那两列是 JPM 四舍五入后的展示值
> （1.28×150,000 = 192,000 ≠ 191,250），反算会带来约 0.2% 的假精度。

### 换电侧只替换一项：能源单价

换电列不是"再引一套参数"，而是**在 JPM 电动列的同一套参数上只换能源单价**——
这样三者仍在同一套自洽假设下对照：

| 项 | 电动（JPM 原值） | 换电（本模型） |
|---|---|---|
| 购车 | 700,000 | 700,000 − **单车带电量 × 模型电池价** |
| 购置税 / 补贴 | 5% / 140,000 | 同（按 BaaS 后车价计） |
| 能源单价 | 0.85 元/kWh（工商业充电） | **模型实时价**：谷电采购价(0.30) + 峰谷套利价差(0.40, base.toml:815) = 0.70 元/kWh（换电站有峰谷套利收入，该价差必须计入能源真实成本，不能只取谷电价）；再加上 服务费 + 电池租金摊薄，才是用户实付全口径 |
| 维保 / 载重损失 | 15,000 / 70,000 | 同（照搬电动列） |
| 换电专属 | — | 年增收 40,000（JPM §8.3 时间价值）；电池租金已在能源单价里 |

**BaaS 购车降本用模型算，不用 JPM 的 40–50% 估计**（用户 2026-09-10 拍板）：

```
免去的电池购置 = 单车带电量(500 kWh) × battery_price_rmb_kwh(config, reference_year)
              = 500 × 590 = 295,000 元
购车总成本 = (700,000 − 295,000) × 1.05 − 140,000 = 285,250 元
```

用模型算的好处：① 电池价在模型里是**价格曲线参数**，调参时购车降本跟着变；
② 29.5 万占 JPM 整车价 70 万的 **42%**，正好落在 JPM §8.3「电池占整车 40–50%」区间内，
与 JPM 自洽——这反过来验证了用模型算比拍比例更站得住。

### 元/kWh 是折算值，不是电价

`元/kWh = 持有期总成本 ÷ (年里程 15 万 km × 1.5 kWh/km × N)`。
三种动力**年里程相同**，故等效能耗分母相同、可直接并排比。它衡量的是
"全成本摊到每个等效 kWh 上是多少"，**不是**用户看到的电价。

### ⚠ 换电列与 JPM 电动列的三处口径差异（读结论时必须知道）

1. **换电用户不拥有电池**——购车已扣电池购置，电池租金进能源单价；
   JPM 电动列是"买电池 + 充电"。
2. **多算了年增收 4 万**（换电 vs 充电的时间价值，JPM §8.3），这是换电独有项。
3. **未计电池衰减更换**：JPM 电动列 9 年持有期内若电池衰减到 SOH<80% 需自费更换，
   JPM 未计、本模型也未计。补上这一项只会**加大**换电的优势方向，故当前口径偏保守。

### 为什么"远低于 LNG"成立、而且比 JPM 电动的 −11% 更大

9 年持有期：换电 238.5 万 vs LNG 367.4 万（**−35%**）。相对 JPM 电动（−11%）多出的部分，
逐项可拆（每年）：能源 −13.7 万、维保 −1.0 万、载重损失 **+5.5 万**（换电更重，不利）、
年增收 **−4.0 万**；再加购车一次性 −10 万。
也就是说：优势主要来自能源价差 + 换电的时间价值 + BaaS 购车降本，**不是**靠载重损失那一端。
