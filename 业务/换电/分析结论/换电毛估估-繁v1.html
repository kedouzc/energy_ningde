框架概要
Framework Overview

本框架由A从货币史出发构建虚/实二分法，经B多次纠错、C引入系统论语言、A四轮纠正数据与方法论、A终极批判"千亿估值不构成重要性"后淬炼而成。

核心定位：CEO视角的非共识战略期权识别工具。它要求分析者同时具备产业眼光、量化能力和代入最高决策者进行终局推演的视角。框架不预测股价短期波动，核心任务是识别"市场共识"与"产业终局"之间的认知偏差，在估值逻辑可能发生断裂的地方做出前瞻性判断。

五层架构：①产业逻辑层（虚实二分+底层力量）→ ②量化框算层（资本回收系数法+比例放大法）→ ③信息维度层（跨行业交叉验证）→ ④CEO战略资源配置层（多业务线博弈与取舍）→ ⑤断点识别层（估值逻辑相变+跟踪验证）。

核心公式：资本回收系数法
Core Formula
资本回收系数（年金公式倒数）
(A/P, i, n) = i / [1-(1+i)^(-n)]
当 i=7.5%, n=15：(A/P) = 0.075/0.6616 = 0.1134
应用：自有CAPEX 460亿 × 0.1134 ≈ 52亿/年（能量维度稳态EBITDA）

第一章：框架提出与初次碰撞
Framework Proposal
第1轮 A提出初始框架 A：从货币史出发
核心命题
  • 钱是后来发明的信用中介。没有钱的时代只有物物交换，所有东西都是"实"的
  • 有了钱之后，才多了一层"把钱留在金融系统"vs"投到实体生产"的选择
  • 投资品分为虚（钱及金融工具）和实（实体生产的东西），决策逻辑是比较两边的相对回报
  • 目的是"把书读薄"，得到一个随身携带的思维脚手架
B的第一轮回应（错误）
  • B引入四层资产分类、三层驱动结构、自然利率等专业术语
  • A驳回："我要的是简化，人脑喜欢简单的建模才能泛化复用"
第2轮 通胀归属争议 A：坚持简化原则
B的错误
  • B引入通胀作为独立变量，理由是2011年钱收紧了但通胀很高
  • A驳回："通胀本身就是钱出现之后的产物，属于虚侧内部状态描述"
第一章结论
  • 框架收敛为虚/实二分，通胀内化入虚侧
  • 混合品（股票、房产）按驱动逻辑拆分：价值面归实，价格面归虚

第二章：跑历史案例
Historical Case Testing
案例1 2006年资产重估 A分析
虚侧逻辑链
  • 贸易顺差→外汇占款→钱极多→金融体系收钱意愿低（钱便宜）
  • 存钱、买债都不划算 → 虚侧回报差
实侧逻辑链
  • 产能过剩→实体投资回报率有限
  • 但股（IPO审批制，名额少）、房（建设周期长）供给刚性
  • 资金涌向供给刚性资产 → 股房大涨
  • 商品因可进出口、供给弹性大 → 未涨
案例2 2011年刘易斯拐点 A分析
实侧（底层规律）
  • 低端劳动力从过剩变短缺→工资上涨→劳动密集型行业利润受压
虚侧（政策响应）+ 推论
  • 人工涨→食品涨价→通胀上升→央行收紧→钱变贵
  • 结果：虚实双杀 → 结构分化
  • A推论：人工贵→机器替代劳动→技术升级加速→政策引向技术密集型

比例放大法三步法
Scaling Method
第一步 算基础盘（自有CAPEX → 基础估值） B执行
计算过程
  • 基础EBITDA = 460亿 × 0.1134 = 52亿/年（稳态）
  • 按EV/EBITDA 12-18倍：52亿×12~18 = 624亿~936亿
  • 取中值：约800亿基础估值
关键校正
  • ❌ 不独立拆分电池银行利润（460亿已是综合投入）
  • ❌ 不用"每站50万利润"假设（无可靠来源）
  • ✅ 直接用比例放大，决策放大的份额
第二步 算放大倍数（25倍终局） B执行
能量维度放大
  • 基础4000座 → 终局10万座 = 25倍
  • 基础不到100万辆 → 终局1亿辆车 = 25倍
  • 网络密度提升（利用率50→100次）= 额外1.2-1.5倍
信息维度放大
  • 蔚能对标：55万用户→1亿辆车 = 180倍
  • 但宁德作为标准制定者只需切30-50%份额
  • 综合放大效应：180×30%~50% = 54~90倍
第三步 算宁德可切份额 B执行
三种情景

附录一：资本回收系数推导

年金现值公式

已知未来每年等额现金流A，求现值P：

P = A × [1-(1+i)^(-n)] / i

其中 [1-(1+i)^(-n)] / i 称为年金现值系数，记为 (P/A, i, n)。

资本回收公式（年金现值系数的倒数）

已知现值P，求每年应收回的等额现金流A：

A = P × i / [1-(1+i)^(-n)]

其中 i / [1-(1+i)^(-n)] 称为资本回收系数，记为 (A/P, i, n)。

当 i=7.5%, n=15 的计算

(A/P, 7.5%, 15) = 0.075 / [1 - 1.075^(-15)]
= 0.075 / [1 - 0.3384]
= 0.075 / 0.6616 = 0.1134

含义：每投入1元钱，在7.5%的IRR下，15年内每年回收0.1134元，即可在期末刚好收回全部本金和应得回报。

应用：宁德自有CAPEX 460亿 × 0.1134 ≈ 52亿/年（能量维度稳态EBITDA贡献）

比例放大法公式

终局估值 = 基础估值 × 放大倍数 × 综合份额系数

基础估值 = 自有CAPEX × (A/P, IRR, n) × EV/EBITDA倍数

放大倍数 = 终局车辆数 / 基础车辆数（25倍）

综合份额系数 = 自建比例×1.0 + 共建比例×分润比例

信息维度估值公式

信息维度净利润 = 前端租金收入 × 2~3倍（行业共识）× 宁德份额

跨行业验证来源：贝壳（双边佣金2-3%）、查博士（480元/次）、蔚能（55万用户/30亿营收）

信息维度终局估值 = 净利润 × P/E 20-25倍（科技/数据公司溢价）
