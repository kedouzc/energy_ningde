# Step 3：业务初筛分级与反共识标的锁定 — 结构化工作流

> **定位**：8步工作流第3步。核心功能 = 用硬约束做第一轮筛选分级 + 锁定反共识深研标的。
> **方法内核**：AI反共识洞察工作流（AI Insight Workflow），5阶段因果发现引擎。
> **设计原则**：聚焦反共识，共识业务只做锚定式初筛，不深研。

## 二、输入输出契约

### 输入（自动从Step 2导入，无需人工重填）

> Step 2按《Step2_标准输出格式规范》输出后，以下字段自动映射为本步骤输入。
> 若Step 2输出缺少某项，由阶段1（共识测绘）自动补充检索。

| 输入项 | 内容 | 来源（Step 2输出包） |
|:---|:---|:---|
| 战略方向 | 4大全行业战略方向 + 企业适配度判断 | Step 2 第三部分 + 输入包1/3 |
| 企业硬约束 | ①稳主业 ②控现金流 ③保新赛道（含优先级） | Step 2 第一部分 → 输入包2 |
| 行业硬约束 | 政策法规（EPR/电池护照）、技术物理极限、社会认知 | Step 2 第一部分 → 输入包2（不足部分由阶段1补充检索） |
| 能力缺口 | 企业能力缺口清单（供阶段4推演使用） | Step 2 第二部分 → 输入包5 |
| 分析边界 | 时间范围、车型范围、业务范围、地域范围 | Step 2 第四部分 → 输入包4 |

### 核心回答3个问题

1. 每个战略方向可拆解为哪些具体落地业务？分别对应什么价值逻辑？
2. 每项业务是否符合三大硬约束？按"合规性/现金流消耗/战略协同"做初评；
3. 按「共识度+战略权重」可分为哪几个等级？哪些是核心深研标的？哪些是参照锚定？哪些直接排除？

### 禁止做的事

- 禁止做精确的规模测算、财务精算；
- 禁止排出1234的最终优先级；
- 禁止提前讨论单业务的落地细节。

### 输出物

《候选业务初筛分级清单》——见阶段6输出格式。

## 三、各阶段详细定义与Prompt

### 阶段0：业务拆解（前置）

**目标**：将Q2的4大战略方向拆解为可落地的具体业务形态清单。

**Prompt**：
```
【角色】你是战略分析师，服务于投研团队。

【任务】将以下4大行业战略方向，拆解为可落地的具体业务形态。

【输入】
- 4大战略方向：[人工填入Q2输出]
- 分析边界：[人工填入时间/车型/业务范围]

【要求】
1. 每个战略方向至少拆解出2-3个具体业务形态；
2. 每个业务标注：业务名称、所属战略方向、核心价值逻辑（一句话）；
3. 不要做任何评价和排序，只做穷举式拆解；
4. 标注每个业务当前是"已存在"还是"概念/早期"。

【输出格式】
| 序号 | 业务名称 | 所属战略方向 | 核心价值逻辑 | 成熟度 |
|:---|:---|:---|:---|:---|
| B01 | [名称] | [方向] | [一句话] | 已存在/概念/早期 |
```

### 阶段1：共识测绘 (Consensus Mapping)

**目标**：检索并归纳当前行业对上述业务方向的主流共识，建立Baseline。

**Prompt**：
```
【角色】你是投研信息检索与归纳专家。

【任务】检索过去12个月内，关于以下业务领域的行业共识。

【输入】
- 候选业务清单：[阶段0输出]
- 检索范围：全球顶级投行（高盛、大摩等）、核心产业媒体、
  车企/电池企业高管公开声明、券商研报

【要求】
1. 对候选清单中的每个业务方向，检索市场当前的主流判断；
2. 提取3-5条行业公认的主流发展路径或共识性判断；
3. 每条共识标注：信息来源类型、置信度（高/中/低）、共识强度（强/中/弱）；
4. 同时标注：该共识背后隐含的业务假设是什么（为阶段2拆解做准备）。

【输出格式】
## 共识测绘结果（Baseline）

### 共识 A：[共识表述]
- 来源类型：[投行/媒体/高管/研报]
- 置信度：[高/中/低]
- 共识强度：[强/中/弱]
- 隐含假设：[该共识成立的前提假设]

### 共识 B：...

### 共识强度总览
| 业务方向 | 对应共识 | 共识强度 | 市场定价程度 |
|:---|:---|:---|:---|
| [业务] | [共识X] | 强/中/弱 | 已price in/部分定价/未定价 |
```

### 阶段2：本体原子化拆解 (Deconstruction)

**目标**：将阶段1的共识拆解为最底层的业务要素原子，解除要素间的默认绑定。

**Prompt**：
```
【角色】你是商业模式解构专家。

【任务】将以下行业共识中隐含的业务要素，拆解为最底层的原子要素。

【输入】
- 阶段1输出的共识清单

【要求】
1. 将每条共识拆解为其隐含的原子业务要素；
2. 原子维度参考（不限于）：
   - 所有权（资产归谁）
   - 使用权（谁在使用）
   - 物理位置（资产在哪里）
   - 生命周期（资产寿命周期）
   - 资金流（谁付钱、谁收钱）
   - 数据控制权（谁掌握数据）
   - 标准控制权（谁定义标准）
3. 关键：解除原子间的默认绑定关系。
   例如"所有权与使用权绑定"是假设而非事实，需显式标注为可拆分；
4. 标注每个原子的当前绑定状态和理论上可解绑的方向。

【输出格式】
## 原子要素拆解

### 共识A的原子化
| 原子维度 | 当前绑定状态 | 隐含假设 | 可解绑方向 |
|:---|:---|:---|:---|
| 所有权 | 消费者持有电池 | 买断制 | 可转为银行持有/车企持有 |
| 使用权 | 与所有权绑定 | 不可分离 | 可分离（租赁/BaaS） |
| ... | ... | ... | ... |

### 原子要素总池
[车壳], [电池], [消费者资产表], [车企资产表], [电网],
[寿命周期T1], [寿命周期T2], [数据控制权], [标准定义权], ...
```

---

### 阶段3：形态学异常重组 (Morphological Recombination)

**目标**：基于原子要素，通过替换、剥离、逆向等思维工具，生成反共识业务假设。

**Prompt**：
```
【角色】你是反共识商业模式生成器。你的任务是有纪律地"胡思乱想"。

【任务】基于阶段2的原子要素池，生成反共识业务假设。

【输入】
- 阶段1的共识清单（作为"对抗靶标"）
- 阶段2的原子要素池

【要求】
1. 对每条共识，至少生成1-2个与之"完全相反"的业务假设；
2. 使用的思维工具（显式标注用了哪种）：
   - 替换：将某原子替换为对立方（如所有权从消费者→银行）
   - 剥离：将默认绑定的原子强行拆开（如所有权与使用权分离）
   - 逆向：将因果关系反转（如"电池寿命<车寿命"→"电池寿命>车寿命"）
   - 极端化：将某维度推到极致（如"部分回收"→"100%闭环流转"）
3. 每个反共识假设必须标注：对抗的是哪条共识、用了什么思维工具、
   核心变异点是什么；
4. 不做可行性判断（那是阶段4的事），只做可能性生成。

【输出格式】
## 反共识假设清单

### 异常假设 H1
- 对抗共识：[共识A]
- 思维工具：[替换/剥离/逆向/极端化]
- 核心变异：[所有权从消费者→电池银行]
- 假设表述：[一句话]

### 异常假设 H2
...

### 假设-共识对照矩阵
| 异常假设 | 对抗共识 | 思维工具 | 核心变异点 |
|:---|:---|:---|:---|
| H1 | 共识A/B | 替换+剥离 | 所有权分离 |
| H2 | 共识C | 逆向 | 电池寿命>车寿命 |
```

### 阶段4：大场硬约束下的因果交叉验证 (Causal Validation)

> **这是最核心的【合】步骤，决定胡思乱想能否变成伟大洞察。**

**目标**：将共识和反共识假设分别放入硬约束中做因果推演，判断谁会死、谁能活。

**Prompt**：
```
【角色】你是因果推演引擎。你只做一件事：把假设放进硬约束里，
       推演它在极端环境下的生死。

【任务】对共识体系和反共识假设，分别进行硬约束因果验证。

【输入】
- 阶段1的共识清单
- 阶段3的反共识假设清单
- 硬约束清单：
  · 企业硬约束：①稳主业（不能损害核心电池业务）
                ②控现金流（重资产受限）
                ③保新赛道（必须打开新增长空间）
  · 行业硬约束：[人工标注的政策法规/技术物理/社会认知约束]

【要求】
1. 对每个共识和反共识假设，逐一放入每条硬约束中推演；
2. 推演格式：假设 → 约束条件 → 因果链 → 终局（存活/死亡/带伤存活）；
3. 如果"死亡"，必须说清死因（哪条约束、哪个环节导致了系统性崩溃）；
4. 如果"存活"，必须说清它解决了什么共识无法解决的问题；
5. 特别关注：是否存在"共识在极端约束下会死，而反共识能活"的非对称结构——
   这就是反共识超额收益的根源。

【输出格式】
## 因果验证矩阵

### 验证1：共识体系（CTC买断制）vs 硬约束
| 硬约束 | 推演因果链 | 终局 |
|:---|:---|:---|
| EPR法规 | 消费者买断→报废时电池流失→无法追踪→违规 | 🔴 死亡 |
| 稳主业 | ... | 🟢 存活 |
| 控现金流 | ... | 🟢 存活 |
→ 共识体系综合判定：在极端EPR约束下会死

### 验证2：反共识H1（换电+BaaS）vs 硬约束
| 硬约束 | 推演因果链 | 终局 |
|:---|:---|:---|
| EPR法规 | 电池银行持有→全生命周期物理+数据可控→完美合规 | 🟢 存活 |
| 稳主业 | ... | ... |
| 控现金流 | 重资产→需轻资产模式→引外部资金 | 🟡 带伤存活（需模式调整）|
→ 反共识H1综合判定：存活，且解决了共识的EPR绝症

### 非对称结构识别
| 对比维度 | 共识体系 | 反共识H1 |
|:---|:---|:---|
| EPR合规 | 🔴 死亡 | 🟢 存活 |
| 现金流 | 🟢 存活 | 🟡 需调整 |
| → 结论 | 共识在极端约束下崩塌 | 反共识在极端约束下存活且解决绝症 |
```

### 阶段5：洞察涌现与定性 (Insight Emergence)

**目标**：基于因果验证结果，对反共识标的做最终定性。

**Prompt**：
```
【角色】你是投研洞察综合者。

【任务】基于阶段4的因果验证结果，对每个反共识假设做最终定性。

【输入】
- 阶段4的因果验证矩阵

【要求】
1. 对每个存活下来的反共识假设，输出一段洞察定性；
2. 定性必须回答：
   - 这个业务的本质是什么（不是表面功能，而是系统性角色）？
   - 它解决了共识体系无法解决的什么绝症？
   - 它的认知差在哪里（市场怎么想 vs 实际是什么）？
   - 它的战略权重如何（影响基本盘格局 vs 边缘业务）？
3. 对死亡的反共识假设，简要说明死因，归档排除；
4. 不做财务测算，只做定性判断。

【输出格式】
## 反共识洞察定性

### 存活假设：H1（换电+BaaS）

**洞察结论**：
[一段话定性，例如："换电业务并非仅仅是'补能速度的优化'，
而是应对极端EPR合规政策与生命周期错配的系统性最优解。"]

**本质定位**：[资产重构(金融) + 标准统权(话语权)]
**解决的绝症**：[EPR合规 + 上下身寿命错配]
**认知差**：[市场共识：超充+CTC → 实际：换电+电池银行]
**战略权重**：[高/中/低] — [影响基本盘格局/边缘业务]

### 死亡假设：H2
**死因**：[...]
**处置**：归档排除
```

### 阶段6：分级整合（收束）

**目标**：将共识业务和反共识业务整合为统一的分级清单。

**Prompt**：
```
【角色】你是投研初筛整合者。

【任务】将所有候选业务整合为《候选业务初筛分级清单》。

【输入】
- 阶段0的业务清单
- 阶段1的共识测绘结果
- 阶段4的因果验证矩阵
- 阶段5的反共识定性

【要求】
1. 将全部业务分为三个等级：
   - 🔴 核心深研：高认知差 + 高战略权重 + 硬约束验证存活 → 后续全维度深研
   - 🟡 参照锚定：市场共识性强，价值已price in → 仅做参照系，不深研
   - ⚪ 直接排除：硬约束验证死亡 或 战略权重极低 → 排除
2. 每个业务标注：共识度、硬约束校验结果、战略权重、分级理由；
3. 核心深研标的应不超过2个（通常只有1个）；
4. 输出最终结论：哪一个是唯一的反共识深研标的。

【输出格式】
## 候选业务初筛分级清单

| 序号 | 业务名称 | 所属战略方向 | 市场共识度 | 硬约束校验 | 战略权重 | 分级 | 分级理由 |
|:---|:---|:---|:---|:---|:---|:---|:---|
| B01 | 超快充 | 补能方向 | 强共识 | 存活 | 中 | 🟡 参照锚定 | 共识已定价，无超额收益 |
| B02 | CTC底盘一体化 | 集成方向 | 强共识 | 🔴 EPR下死亡 | 高 | ⚪ 直接排除 | 硬约束崩塌 |
| B03 | 换电+BaaS | 补能方向 | 反共识 | 🟢 存活且解绝症 | 高 | 🔴 核心深研 | 唯一高认知差+高权重+存活 |
| ... | ... | ... | ... | ... | ... | ... | ... |

## 最终结论
> [一段话，例如："除换电外，其余业务均为市场共识性标的，价值已基本price in，
> 仅做参照锚定；换电是唯一具备高认知差、高战略权重、影响基本盘格局的
> 反共识标的，为后续唯一核心深研对象。"]

## 动态监测指标（【一】闭环）
| 指标 | 含义 | 触发阈值 | 对应动作 |
|:---|:---|:---|:---|
| 业务共识度指数 | 市场对换电的认知是否在变化 | 共识度快速上升→认知差收窄 | 重新评估超额收益窗口 |
| 资金消耗预估 | 换电业务的现金流压力 | 超过硬约束阈值 | 触发轻资产模式调整 |
```

## 四、与分形矩阵的映射关系

本工作流的每个阶段，对应第3步分形矩阵的【知行合一】：

| 工作流阶段 | 分形角色 | 对应内容 |
|:---|:---|:---|
| 阶段0-1 | 【知】解码大场 | 拆解战略方向 + 测绘行业共识 |
| 阶段2-3 | 【知→行】假设生成 | 原子化拆解 + 异常重组（沙盘假设） |
| 阶段4 | 【行→合】推演验证 | 硬约束因果推演 + 偏差检验（$\Delta E$） |
| 阶段5 | 【合】结果评估 | 洞察涌现，判断反共识是否成立 |
| 阶段6 | 【一】动态闭环 | 分级清单 + 动态监测指标 |
| 任意阶段 | 【破缺回溯】 | 若因果验证发现反共识也死亡 → 回溯阶段3重新生成假设 |

---

## 五、使用说明

1. **从Step 2自动导入输入包**（战略方向 + 硬约束 + 能力缺口 + 分析边界），无需人工重填；
2. **按阶段0→6顺序执行**，每阶段AI输出后人工验收，确认后再进入下一阶段；
3. **阶段4是核心**，如果因果验证发现所有反共识都死了，触发破缺回溯，回到阶段3重新生成假设；
4. **阶段6输出后**，人工做最终裁定，确认分级和锁定标的；
5. **锁定的核心深研标的**进入Step 4及之后的深度分析。
