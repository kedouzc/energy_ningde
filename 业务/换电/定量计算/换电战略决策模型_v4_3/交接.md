## 二、方法论主线（先读这条，它决定其他一切）

**详见 [DECISIONS.md](./DECISIONS.md)「2026-09-02 · 方法论主线」。三条纪律：**

**① 精度不等于假设数量。**
> 毛估估 vs 算细账，区别不在于程序算多少步，而在于**你要拍多少个数**。

电池价格路径由 5 个参数生成 2026–2045 每年的价格——程序算 20 个数，你只拍了 5 个。
**逐年算电池新增假设数 = 0，所以它不是细账。**
判据：**这一步要不要我新拍一个数？要 → 拒绝。不要 → 算，免费的。**

**② 让程序算细，让报告读粗。**
程序逐年逐池逐代地算；报告只读终局年的几个数。中间明细是**可下钻的证据**，不是要读的内容。

**③ 标定一次，用很多次。**
精算一次标定误差，之后放心用粗口径，参数大改才重标。
（本轮实测：把全部批次按一个标准年处理，代价仅 **0.9%**，而服务费的不确定度是 ±33%。）

### 分层结构（定稿）

| 层 | 算什么 | 粒度 | 口径 | 谁读 |
|---|---|---|---|---|
| **L1 单位** | 每个 (站型 × 装机年) 的全周期流，按代展开 | 58 条 cohort | 单位 EAC、单代折旧 | 程序 / 树下钻 |
| **L2 站型** | 4 个站型的代表值（**2026 标准年**） | 4 个 | 覆盖倍数 | **报告读这一层** |
| **L3 集团·门槛** | 加权平均覆盖倍数 | 1 个 | **无量纲比值** | 第 3 章可行性 |
| **L4 集团·估值** | PV@2026 资本 ＋ 终局 EBITDA | 2 个 | 带日期折现 | 第 5 章 |

**门槛检验用无量纲比值（免疫年份问题），估值才做折现。两条线不共用一个数。**
标准年取 **2026**（＝决策时点、＝估值基年，且方向保守），不取 2028——
**当误差小到无关紧要时，选择是口径问题不是数值问题：参照系一致 > 误差最小。**

### 三个资本数，三个用途，永不共用

## 三、已定的决策（不要重开）

| 议题 | 结论 |
|---|---|
| **必要性的论证结构** | **防守反击**，不是竞争威胁。动力电池线市占与净利率都在被挤压，CATL 靠这条线起家不能放弃 → 三条路：固态（技术迭代·开源·作用在**新产品**）、圈矿（**节流**·不带量）、换电（新商业打法·开源·**作用在成熟产品**）→ **开源永远比节流重要** → **换电是唯一既开源又落在存量盘上的**。**不要造"对手做成了"的 C 分支**——换电圈内没有够格对手（启源已被 CATL 控股），快充阵营主攻私家车、与营运车错位竞争。 |
| **2028 的紧迫性** | 站网**必须 2028 建成**，这是由**竞争格局与现状激烈程度**倒逼的硬约束，属于第 2 章必要性的窗口期论证（与"快充会不会挤掉窗口"合并）。 |
| **测算期 / 终局年** | 2026–2030。**2030 的理由 = 2028 硬死线 ＋ 两年爬坡 → 第一次能观察到成熟期读数**；十五五口径（权威预测节点落在 2030/2035）是佐证不是主因。**REITs-ready 是那一年顺带具备的「能力」，是证据不是目的**——发不发是 CATL 的选择，不发不证伪。 |
| **回购对照的位置** | 从必要性**挪到第 3 章资金门**做财务纪律检验。账上近 4,000 亿、回购才 400 亿，是常规市值管理，与换电目的不同。 |
| **估值主口径** | **先定估值方式，再定参数**：换电 2030 判为资产运营 → 基数 EBITDA、系数 EV/EBITDA；受影响的制造侧仍用制造侧 PE；整体是 **SOTP**。**换基数是换量纲不是换参数**，所以「ΔE × Δ倍数」这种二维分解不成立（它只在单一 PE 框架内部有效）。DCF 为主、EV/EBITDA 交叉验证，桥是隐含倍数。**第 5 章按四步写**：定估值方式 → 影响图 → 基数与倍数 → 赔率（四桶分解 ＋ 双峰）。**战略溢价要出倍数、回到制造侧**（锁量／护价用制造侧 PE 计价）。见 `框架提案.md` §1.5 |
| **不设独立的「标准价值」科目** | 曾考虑把标准的价值单列成一项 `O` 挂在估值公式外面——**撤销**。**商誉是残差**：品牌值多少是拿已实现的终端溢价倒算出来的；换电还在铺货，没有已实现溢价可倒算，`O` 无法计量。**倍数的功能本来就是装未来**——未来放进倍数是对的，错的是放进去而不说清什么会改它。见 `DECISIONS.md`「2026-09-06a」 |
| **报告形态** | 一份长报告，章节可折叠、树可下钻。不分册。 |
| **HTML 的边界** | 只做四件事：加载 MD、替换占位符、画图、挂沙盘。**不许出现任何业务数字、公式、口径判断。** 检验：把 HTML 删掉重写，报告结论一个字不变。 |
| **非共识的类型判定** | **断档不是机会，断档接不上的原因才是。** 三种：A **相变型**（业态变了、市场还在用旧框架）／B **线性型**（业态没变、只是横向拓展、市场低估成功率）／C **我看错了**。**类型决定证据形态与赔率形态**：A 型证据是**形式的**（市场用什么估值方法）、赔率**双峰**、**老估值方法不能用来反推**；B 型证据是**数值的**、赔率**连续**、老框架仍可反推。**本案判为 A 型**——换电切进资产运营业就不可能继续用 PE，市场若愿意给它估值最终一定切成 SOTP。**C 必须显式排除**（三问：市场是否已知但不在乎／是否知道我不知道的负面信息／我的优势具体是什么），否则第 1 章是自我实现的信念机器。与第 ⑦ 步性质判定互为交叉校验。见 `框架提案.md` §1.6、`DECISIONS.md`「2026-09-05p」 |
| **共识锚** | **取的是形式证据，不是数值。** 三条观察，由 AI 从公开研报整理、逐条标来源与日期：① 卖方对 CATL 用不用 SOTP ② 换电有没有在卖方模型里被单独列示 ③ 有没有机构给过换电独立估值。**三个"否"＝ 市场没给换电估值，把它当免费期权。** 翻转信号：第一份 SOTP 研报／换电首次被单独列示／**时代电服独立融资或分拆定价（最强，一级市场的独立估值）**。**不做 PE × EPS 反推**——本案是相变型，反推等于先承认旧框架。写法见 `框架提案.md` §1.6.3。 |
| **沉淀形态** | 三个 skill（非共识标的诊断／反事实定量建模／研报装配）＋ 一个「反方审稿」subagent。**不做九个 agent**。等这一遍真跑通了再写。 |
| **文件治理** | 状态／过程／产物三分；版本号只长在发布产物上；留痕用 git 不用复制目录。 |
| **目标市场的定义方式** | **由痛点强度定义，不由保有量定义。** 痛点强度 ＝ TCO 改善幅度 × 该用户对 TCO 的敏感度（营运车是生产资料、敏感度高；私家车是消费品、低一个量级）。**站数一律由需求反推，不采用任何宣发口径的规划数。** 早期"10 万站"就是违反这条的产物，见 `DECISIONS.md`「2026-09-05g」 |
| **运营期限 vs 终局年** | **两件事，必须分开写。** 终局年（2030）＝我什么时候来看，由竞争死线＋爬坡决定；运营期限＝这门生意能活多久，由**资产性质**（特许经营 vs 永续经营）决定。换电查证为**永续经营型**（备案登记非特许经营、用地不构成约束、建在无到期日的加油站场址）。见 `DECISIONS.md`「2026-09-05f」 |
| **必要性论证的枢纽：承重方** | **价值重分配不会自动发生，它需要一个人扛下最重的那块成本。** 电池占整车 40–50%（400kWh 包 30–40 万），电池银行扛下它 → **利益与"电池便宜好用"彻底绑定** → 才有动力把寿命拉长 → 才有东西让渡给用户。**承重方必须同时控制「成本」与「寿命」两端**：第三方运营商扛成本但不造电池（控不住寿命）、车企没动力（靠卖车赚钱）、**只有电池生产者两端都在手里**。这解释了同类玩家为什么做不起来——**是结构性的，不是体量问题**。三层递进：模式转变（一次性买卖→按使用付费）→ 规模与马太（重资产门槛高，规模越大成本越低、让渡越多）→ 竞争壁垒（基建格局已成）。见 `DECISIONS.md`「2026-09-05j」 |

| **倍数论证的材料边界** | **材料已齐，剩下是整理不是研究**：`分析结论/换电毛估估_折扣链与总表_v3.2.md §4.1` ＋ `DECISIONS.md`「2026-09-05e」「09-05f」「09-05j」「09-06c」。<br>⚠️ **触发条件（必须执行，不只是指针）：写第 5 章或「估值_为什么拍这个倍数」专题之前，先打开 `v3.2 §4.1` 读完再动笔。** 不是"引用它"是"读它"——此前只写指针不写触发，导致反复凭记忆复述、反复复述错，见「09-06d」。<br>**禁止引用启源芯动力交易做倍数依据**——CATL 对国资的并购有多种考量，不是市场化定价 |
| **倍数的论证方式** | **不用可比公司取平均，用族定位 ＋ 性质判定。** ①**三族定位**（`v3.2 §4.1`）：判据是"谁扛资产、谁赚什么钱、赚的钱最终落在哪盘生意"，不是资产负债表重不重——资管平台族 18–22×／重资产基建族 6.7–14×／车+能源复合族（特斯拉 89.7×，**只作叙事参照不作倍数锚**）。②**性质判定**（第一性原理第 ⑦ 步）：技术变革／场景拓展／**标准确立**，三者倍数逻辑完全不同。换电做成"用能方式"则**载体可换**，这是高倍数的真论据，**也是 DCF 结构上装不下的东西**。见「2026-09-05e」 |

| **期限只有两端** | 15 年设备到寿不再更新（**有限期账**）／标准立住则没有理由结束（**永续账**）。**两本账就是这个二分，不做 25 年、40 年的中间敏感度。** 标准型资产的期限是二元的，**把二元算成连续 ＝ 把"可能全输"写成"少赚一点"**（同「窗口成本不量化」）。运营期限是**一道门，不是一条曲线** |
| **世界 A／B 的可观察边界：补能 vs 用能** | "标准是否确立"没法观察，换成**它出现在用户的哪个决策里**：**补能**＝用车时的服务选择（"我去哪儿换"）；**用能**＝**购车时的选型条件**（"我买一台换电的车"）。**从服务挪进购车选型条件——这一步可以直接问车队老板问出来。** 见「09-06b」 |
| **对标：已被接受的重估先例** | **特斯拉卖车 → 卖里程（Robotaxi）**：市场已经接受、而且接受得很狂热的一次"业态中途切换、倍数体系随之切换"。换电同构——**卖电池 → 卖用能**，承重方从"用户买断电池"变成"CATL 扛电池资产"。**借机制不借数值**（`v3.2 §4.1③`3 已定：叙事半径不同，不作倍数锚）。作用是把举证责任从"这种事可能吗"移到"**这一次像不像**"。一个读法：**换电是半程的 Robotaxi**——只换掉车里最贵的那一块（电池占整车 40–50%），没换掉整车，这恰好解释倍数为什么落在①②两族之间而不是③族 |
| **先行指标必须标推/拉** | **只有"拉"算数。** **推**＝CATL 自己签下的合作与卡位（如电动船舶供能协议）——那是**意愿**的证据，不是**标准**的证据；**拉**＝没谈过的第三方主动按此规格设计。原清单里"跨品类应用出现"推拉不分，必须拆成两条。**中检点第一条是规模档位**（10 万/100 万/1000 万辆，量级本身传递不同信息），但**被假设出来的规模不算证据，被观察到的才算**——2030 年模型里的 100 万辆不能证明标准会立，2027 年真跑出来的 10 万辆能 |

### git

一个目录只能有一个 `.git`，**不能嵌套**（嵌套时外层把内层整个当未跟踪对象，表现为编辑器一片绿点）。
诊断：`git status --short`（`U`=未跟踪 `M`=改过未提交 `A`=已加待提交，无输出=干净）。
`.gitignore` 至少包含：`__pycache__/`、`*.pyc`、`~$*`、`*.tmp`。

## 八、踩坑清单

### 口径类

- **折旧不是资本要求，资本要求也不是折旧。** 折旧只服务于**税**（决定税盾），
  EAC 只服务于**资本要求**（决定门槛）。共用一个分子必出事，而且
  **折旧虚增 → 利润表被低估（看起来亏钱）＋ 税盾虚增 → 估值被高估，两个方向相反、会互相掩盖。**
- **任何年金化／摊销，先问分子分母是不是同一段时间。**
  `(15年PV倍数) ÷ (单代寿命)` 看上去很自然，但它把 15 年要花的钱压进 3 年摊完。
- **换层级用同一个公式前，先问它的前提在新层级还成不成立。**
  EAC / IRR / 回收期 / 单位经济的前提都是"一笔投入对应一条现金流"，聚合到有建设期的资产组合就破了。
- **门槛类指标尽量做成无量纲比值**——比值天然免疫年份、规模、货币单位的口径问题。
- **取代表值时，参照系一致 > 误差最小**（标准年、基准情景、可比公司口径都适用）。
- **CRF 0.15 不是 WACC 口径。** WACC 7.5% 是成本线下限；CRF 用期望收益率
  （10–15% 中值，隐含约 12.4%），依据 v3.2 §1.2.2。用 WACC 反推的 0.1133 去质疑它是比错了对象。
- **18× 已含战略溢价，不应再叠加。** 但注意 v3.2 §4.1 说"锚 6.7–14× ＋ 温和溢价 → 18×"，
  而 **18 比区间上限 14 高 29%**，根本不在区间内——这是全篇最易被打穿处。
  再投资强度（EAC/EBITDA ≈ 76%）在基建族里属极高，应锚**下沿**。
- **辅助服务三项不能相加。** `ancillary = 容量补偿 + max(需求响应, 调频)`。直接相加会高约 29%。
- **`nev_rates` 是年更新流量口径，不是保有量口径。**
- **`outputs/` 下的 md 是生成物。** 改叙述正文要改 `narrative/*.src.md`。
- **一条"现金流÷折现率"公式里，如果投入侧已经用一份完整的"全部投资现值"去扣减，
  现金流侧就必须是毛值，不能再净一次"可持续资本性支出代理"——两边扣一次是对的，
  两边都扣是重复扣减。** 换一个更"讲究"的折现率不会自动修好这个问题，见
  `口径/capex_debt_估值公式链.md`第1.2节原则三、`DECISIONS.md`「2026-09-05c」。
- **持续更新型资产的"可持续资本性支出"，该用"存量规模÷更新周期"这个更新理论
  第一性原理算，不要挑某一年的实际数、也不要用会计折旧代理**（折旧混了历史买入价，
  且会漏掉资产本身的价格趋势）。见同上第1.2节原则四。

### 方法类

- **断言写成恒等式，不要写成不等式。** `≤` 型只能证伪不能证实。
  更进一步：**好的恒等式应当按构造成立**——把两边写成同一组数的两种排列，
  它就从"一致性检查"退化成"代码正确性检查"，更强、更便宜、更不会漏。
- **容差是用来吸收浮点误差的，不是用来吸收口径错误的。**
  容差 > 1e-6 量级时都要问：这个残差是数值误差，还是我还没查清的错？
  **说得出机制却说不出精确值，就是没查清。**
- **"跑不通"是信息，不是障碍。** 断言要卡在会失败的地方才有价值。
- **不要给一个数编解释。** 看到两个数接近就倒推因果，是最容易混进来的一类错误，因为它读起来最顺。
  **先验算，再解释。**
- **常识反推是有效的审计手段。**「折旧这么高就没人敢买充电重卡了」——比任何代码审查都先命中要害。
  **算出来的数与行业常识冲突时，先信常识。**
- **辨认时间窗要找「谁在逼你」，不是「你何时能兑现」。** 死线由外部竞争给定，兑现只是后果。
- **弹性 ≠ 情景。** 高弹性且高不确定 → 情景轴；高弹性但低不确定 → 去核实它；低弹性 → 不进情景。
  **谁是情景轴是一个「声明」，必须显式写在参数定义里**；`lab.py` 的弹性只用来审计这个声明。
- **散装补丁比没有补丁更危险**——"只给私家车做了三档"看起来像有情景分析，掩盖了"其实没有"。
- **口径分歧优先于数字分歧。** 三份文档数字不一致时，先看拆法是不是同一种。
- **不要为了一份注定被淘汰的产物做基础设施改造。** 先确认目标产物，再动手。
- **审计要分清"抓到了问题"和"对问题的推断"。** 前者是机械事实，后者是判断，不能混。
- **一个借来的假设参数（"N年寿命/周期"），先查它最初的出处回答的是哪个具体问题，
  再决定能不能用在当前这个问题上——两个问题字面像、实质不同是最容易出事的情形。**
  见`口径/capex_debt_估值公式链.md`第1.2节原则五（"15年"这个数最初回答的是"一批不再
  补充的存量电池能撑多久"，被借去回答"持续滚动更新的业务该追踪多久"，是两个
  不同的问题）。
- **两个独立算出的数字接近，不能直接当互相印证，先确认假设是否真的相同**——一个
  永续假设、一个有限期假设，算出接近的数纯属巧合，我自己在09-05c的追查过程里就
  犯过一次这个错误。
- **用户说不清楚具体错在哪、但反复觉得"不对劲"，是需要立刻升级追查力度的强信号，
  不是弱信号**——2.06%这个bug最终被挖出来，起点始终是这类说不出机制的持续怀疑，
  不是自查。见`DECISIONS.md`「2026-09-05c」。
