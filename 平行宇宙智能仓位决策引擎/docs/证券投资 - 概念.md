# 【运筹学理解】
线性规划的几何意义：列空间视角 + 基变换 + 对偶（个人领悟笔记）

一、两个空间：资源宇宙 vs 产品宇宙
- 资源宇宙：以各类资源为坐标轴，初始坐标系由松弛变量（闲置资源）构成。这个空间只能描述：用了多少资源、剩多少资源，无法直接看出产品总价值。
- 产品宇宙（动态、活的平行宇宙）：以当前选中的产品（基变量）为坐标轴，因为产品之间互相争夺资源，坐标轴一般是斜的。这个空间可以直接描述：生产多少产品、总价值是多少。

二、关键角色
- 宝藏点（RHS 向量）：你拥有的资源总量，是整个问题要抵达的“资源边界”。
- 探路者（产品向量）：每一种产品，对应一根向量：代表生产 1 单位该产品，要消耗多少各类资源。松弛变量 = 不生产产品、只保留闲置资源的标准向量。
- 寻宝路径：把产品向量按产量缩放、再相加（线性组合），拼出刚好抵达宝藏点的总消耗。路径的每一段，对应一种产品的生产数量。
- 赏金（目标函数）：每种产品有固定收益，我们要让整条路径的总赏金最大。

三、为什么要构建「产品宇宙」？
- 资源宇宙只能看数量，看不见价值；
- 产品宇宙用产品当轴，可以直接用产量 × 单位价格算出总价值，让原本看不见的目标变得可度量、可优化；
- 产品宇宙不是一开始就固定，而是随着迭代一步步长成最终形态。

四、求解过程：从资源宇宙走到产品宇宙
1. 起点：在资源宇宙，以松弛变量为轴，所有资源闲置。
2. 换基 = 换坐标系：每次把一个更赚钱的产品拉进来当新坐标轴，把一个不赚钱的闲置资源扔出去，坐标系一步步从“资源视角”扭成“产品视角”。
3. 顶点跳跃 = 撞墙前进：每一步都沿着约束墙（资源上限）走，把某一种资源用到边界、用到紧约束，直到总价值再也涨不动。
4. 消元 = 空间解耦：把斜着的、互相干扰的产品轴，通过矩阵变换“扶正、解耦”，让每个产品在自己的坐标轴上独立可读。
5. 归一 = 重新定度量：用产品宇宙的价值尺度，重新度量资源，资源在新尺度下的单位长度 = 影子价格 π。

五、影子价格 π 是怎么来的？
- 每一步撞到约束墙 = 某资源被用尽、变稀缺；
- 稀缺性 = 多一单位资源能多赚多少钱；
- 这个值在坐标变换时自动暴露，就是 π；
- 所以：π 不是最后突然算出来的，是迭代中一步步求出来的。

六、行空间 vs 列空间（两种看图方式）
1. 行空间几何（约束视角）：每一行约束 = 空间里的一堵墙；多堵墙围出一块可行区域，这就是切蛋糕；最优解一定出现在蛋糕的顶点上；目标函数像一个斜面，往上推，直到刚好顶住一个顶点。
2. 列空间几何（产品视角）：每一列 = 一根产品向量（箭）；所有能通过“缩放 + 相加”拼出来的点，就是所有能实现的生产方案；最优路径 = 拼出宝藏点，且总赏金最大。

七、数学家的真正思路（对偶 + 单纯形）
- 世界本身是复杂、斜交的向量系统；用矩阵变换，把复杂空间扭成简单、整齐的平行宇宙；
- 对偶 = 价值平行宇宙：资源宇宙看消耗，产品宇宙看价值，两者完全对称；
- 单纯形法 = 虫洞传送门：从资源宇宙穿到产品宇宙，一次变换，同时拿到两样东西：1. 最优产量 2. 资源影子价格 π

八、最终一句话总结
资源宇宙管用量，产品宇宙管价值；单纯形是动态换坐标系的虫洞；每一步撞墙，算出一步影子价格；最优时，产量与资源价值同时出现。

## 三、核心模型完整设计

### （一）目标函数完整设计（贴合原理论，兼容0-1变量）
目标函数核心：**最大化「用户估值体系下的错配赏金」**。为保证影子价格的纯洁性，将认知带宽转化为整数规划（MILP）的约束条件，剥离惩罚项，让目标函数纯粹衡量“总赏金”。

| 目标函数构成项 | 核心含义 | 对应你的理论映射 | 模型中的作用 |
| :--- | :--- | :--- | :--- |
| **核心收益项：**<br>Σ(安全边际率ᵢ × 确定性系数ᵢ × 仓位权重wᵢ) | 持仓标的的总错配收益。 | 产品宇宙的「总赏金最大化」，寻宝路径总收益。 | 锚定用户自身的估值体系，放大个人投资逻辑。 |
| **现金价值项：**<br>现金单位效用 × 现金比例 | 现金总价值（保底无风险收益+错配期权价值），和股票平等参与。 | 现金作为基变量，对应探路者向量，而非被动约束。 | 自动求解最优现金比例，打破“预设必须留多少钱”的定势。 |

#### 目标函数标准化公式（融合混合整数规划 MILP）
```python
import pulp
prob = pulp.LpProblem("Parallel_Universe_Max_Value", pulp.LpMaximize)

# 变量定义：
# w[i]: 连续变量，仓位权重 (经典态滑行)
# y[i]: 0-1 二元变量，是否占用认知带宽激活该股票 (量子态激活)
prob += (
    # 核心收益项
    pulp.lpSum([security_margin[i] * certainty_coeff[i] * w[i] for i in stock_pool])
    # 现金价值项
    + (risk_free_return + mismatch_option_value) * cash_ratio
), "Max_Total_Bounty"
```

## 五、模型自迭代闭环设计（打造越用越爽的飞轮）

### 1. 个人认知校准飞轮（自我照镜子）
- **机制：** 记录用户 $T_0$ 的估值参数，比对 $T_1$ 的真实表现。
- **输出：** 每月推送《平行宇宙探险月报》。“上月你对消费股的判断击败了80%的玩家，但【单股最大仓位上限】约束了你的战果！建议下月解锁更高上限。” 让用户直观看到自己的成败归因。

### 2. 第三方估值生态闭环（从单机工具变数据容器）
- **机制：** 提供开放接口，让大V、量化平台上传他们的“估值宇宙数据包”供普通用户订阅使用。
- **飞轮：** 系统统计不同数据包在模型里跑出的胜率，生成“本月最佳星系数据包排行榜”。用量大的工具倒逼数据商主动寻求接入，形成内容生态。

### 3. 情绪逆向对冲提示（群体智能的高级玩法）
- **机制：** 当系统察觉全网大量用户同时疯狂拉低某板块的“情绪滚动条”（群体悲观）时，自动提高该板块对应的“错配期权价值”。
- **输出：** 向高阶用户触发隐藏任务：“🌌 探测器发现异常：大众情绪正在恐慌抛售医药股，系统判定错配期权价值极高，是否拨出5%的现金前往探底？”
